\doxysubsection{Detailed Description}
Class implementing a document tree node cursor. Included sub-\/templates are not supported by this type of cursor, i.\+e. the subtree that is managed by an instance of \doxylink{class_d_s_r_included_template_tree_node}{DSRIncluded\+Template\+Tree\+Node} is not iterated.
