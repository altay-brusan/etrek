\doxysubsection{Detailed Description}
This class implements a simple container that stores an input stream, the position of that input stream corresponding to the start of a DICOM element value field contained in the stream and the current "{}owner"{} object. It is used to keep a single file handle open during multiple calls to \doxylink{class_dcm_element_a11c838a282d3b045f4bb3a77f1e595d2}{Dcm\+Element::\+get\+Partial\+Value()}, thus speeding up the reading.
