\doxysubsection{Detailed Description}
an implicit function that implements Perlin noise 

\doxylink{classvtk_perlin_noise}{vtk\+Perlin\+Noise} computes a Perlin noise field as an implicit function. \doxylink{classvtk_perlin_noise}{vtk\+Perlin\+Noise} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. Perlin noise, originally described by Ken Perlin, is a non-\/periodic and continuous noise function useful for modeling real-\/world objects.

\doxylink{requirements_The}{The} amplitude and frequency of the noise pattern are adjustable. This implementation of Perlin noise is derived closely from Greg Ward\textquotesingle{}s version in Graphics Gems II.
