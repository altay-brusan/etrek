\doxysubsection{Detailed Description}
a multi-\/resolution dataset based on \doxylink{classvtk_uniform_grid}{vtk\+Uniform\+Grid} allowing overlaps 

\doxylink{classvtk_overlapping_a_m_r}{vtk\+Overlapping\+AMR} groups \doxylink{classvtk_uniform_grid}{vtk\+Uniform\+Grid} into level of different refinement (AMR stands for Adaptive Mesh Refinement). See Set\+Data\+Set to add a new grid.

\doxylink{requirements_The}{The} grids of a level are expected to have the same spacing and refinement ratio. \doxylink{requirements_The}{The} refinement ratio represent the spacing factor between a level and the previous one. This class does not ensure the link between spacing and refinement ratio:\+ please set them carefully.

Associated to each grid, a \doxylink{classvtk_a_m_r_box}{vtk\+AMRBox} object describes the main information of the grid:\+ origin, extent, spacing. When creating a \doxylink{classvtk_overlapping_a_m_r}{vtk\+Overlapping\+AMR}, you should call Set\+AMRBox for each block of each level.

In a distributed environement, the structure should be shared across all rank:\+ the \doxylink{classvtk_a_m_r_information}{vtk\+AMRInformation} and \doxylink{classvtk_a_m_r_box}{vtk\+AMRBox} should be duplicated as needed.
