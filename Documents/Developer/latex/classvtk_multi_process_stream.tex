\doxysubsection{Detailed Description}
stream used to pass data across processes using \doxylink{classvtk_multi_process_controller}{vtk\+Multi\+Process\+Controller}. 

\doxylink{classvtk_multi_process_stream}{vtk\+Multi\+Process\+Stream} is used to pass data across processes. Using \doxylink{classvtk_multi_process_stream}{vtk\+Multi\+Process\+Stream} it is possible to send data whose length is not known at the receiving end.
