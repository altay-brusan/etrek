Whether to trim whitespace from strings prior to conversion to a numeric. Default is false to preserve backward compatibility.

\doxylink{classvtk_variant}{vtk\+Variant} handles whitespace inconsistently, so trim it before we try to convert it. For example:\+

\doxylink{classvtk_variant}{vtk\+Variant}("{}  2.\+0"{}).To\+Double() == 2.\+0 \texorpdfstring{$<$}{<}-- leading whitespace is not a problem \doxylink{classvtk_variant}{vtk\+Variant}("{}  2.\+0  "{}).To\+Double() == NaN \texorpdfstring{$<$}{<}-- trailing whitespace is a problem \doxylink{classvtk_variant}{vtk\+Variant}("{}  infinity  "{}).To\+Double() == NaN \texorpdfstring{$<$}{<}-- any whitespace is a problem

In these cases, trimming the whitespace gives us the result we expect:\+ 2.\+0 and INF respectively.
