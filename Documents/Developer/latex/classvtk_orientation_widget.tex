\doxysubsection{Detailed Description}
3D Widget for manipulating a \doxylink{classvtk_camera}{vtk\+Camera} 

This 3D widget interacts with a \doxylink{classvtk_orientation_representation}{vtk\+Orientation\+Representation} class (i.\+e., it handles the events that drive its corresponding representation). A nice feature of \doxylink{classvtk_orientation_widget}{vtk\+Orientation\+Widget}, like any 3D widget, will work with the current interactor style. That is, if \doxylink{classvtk_orientation_widget}{vtk\+Orientation\+Widget} does not handle an event, then all other registered observers (including the interactor style) have an opportunity to process the event. Otherwise, the \doxylink{classvtk_orientation_widget}{vtk\+Orientation\+Widget} will terminate the processing of the event that it handles.

To use this widget, you pair it with a \doxylink{classvtk_orientation_representation}{vtk\+Orientation\+Representation} (or a subclass). Various options are available in the representation for controlling how the widget appears, and how the widget functions.

\begin{DoxyParagraph}{Mouse Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
Select and move a torus to update the associated orientation.
Select and move an arrow to update the associated orientation.
\end{DoxyPre}

\end{DoxyParagraph}
