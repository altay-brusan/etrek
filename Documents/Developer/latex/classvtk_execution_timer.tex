\doxysubsection{Detailed Description}
Time filter execution. 

This object monitors a single filter for Start\+Event and End\+Event. Each time it hears Start\+Event it records the time. Each time it hears End\+Event it measures the elapsed time (both CPU and wall-\/clock) since the most recent Start\+Event. Internally we use \doxylink{classvtk_timer_log}{vtk\+Timer\+Log} for measurements.

By default we simply store the elapsed time. You are welcome to subclass and override \doxylink{classvtk_execution_timer_a7687cb99dcd4febe5dd51963cb4dda93}{Timer\+Finished()} to do anything you want.
