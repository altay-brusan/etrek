\doxysubsection{Detailed Description}
Layout graph edges on a globe as arcs. 

\doxylink{classvtk_geo_edge_strategy}{vtk\+Geo\+Edge\+Strategy} produces arcs for each edge in the input graph. This is useful for viewing lines on a sphere (e.\+g. the earth). \doxylink{requirements_The}{The} arcs may "{}jump"{} above the sphere\textquotesingle{}s surface using Explode\+Factor.
