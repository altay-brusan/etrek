\doxysubsection{Detailed Description}
Read an MPAS net\+CDF file. 

This program reads an MPAS net\+CDF data file to allow paraview to display a dual-\/grid sphere or latlon projection. Also allows display of primal-\/grid sphere. \doxylink{requirements_The}{The} variables that have time dim are available to Para\+View.

Assume all variables are of interest if they have dims (Time, n\+Cells\texorpdfstring{$\vert$}{|}n\+Vertices, n\+Vert\+Levels, \+[n\+Tracers]\+). Does not deal with edge data.

When using this reader, it is important that you remember to do the following:\+
\begin{DoxyEnumerate}
\item When changing a selected variable, remember to select it also in the drop down box to "{}color by"{}. It doesn\textquotesingle{}t color by that variable automatically.
\item When selecting multilayer sphere view, make layer thickness around 100,000.
\item When selecting multilayer lat/\+lon view, make layer thickness around 10.
\item Always click the -\/Z orientation after making a switch from lat/\+lon to sphere, from single to multilayer or changing thickness.
\item Be conservative on the number of changes you make before hitting Apply, since there may be bugs in this reader. Just make one change and then hit Apply.
\end{DoxyEnumerate}
