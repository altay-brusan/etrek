Detailed Description

Transparent overlay widget that renders measurement rulers.

This widget is placed on top of a viewport and renders:

  • Ruler lines between start and end points
  • Circular handles at endpoints for dragging
  • Distance labels positioned near the line midpoint

The widget uses a coordinate transform function to convert image coordinates to widget coordinates, allowing rulers to stay aligned with the image during zoom/pan operations.
