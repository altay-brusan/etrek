\item TOPOLOGY\+\_\+\+HADAPT:\+ H-\/\+Adaptivity
\item TOPOLOGY\+\_\+\+GHOST:\+ Ghost nodes/\+edges/\+faces/\+elements created/\+destroyed
\item TOPOLOGY\+\_\+\+GEOMETRY:\+ Model data is modified, overlap removal.
