\doxylink{classvtk_particle_tracer_base}{vtk\+Particle\+Tracer\+Base} is the base class for filters that advect particles in a vector field. Note that the input \doxylink{classvtk_point_data}{vtk\+Point\+Data} structure must be identical on all datasets.
