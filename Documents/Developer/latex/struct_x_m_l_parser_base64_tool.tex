\doxysubsection{Detailed Description}
Helper class to include binary data inside XML strings using "{}\+Base64 encoding"{}. 

\doxylink{requirements_The}{The} "{}\+XMLParser\+Base64\+Tool"{} class allows you to include any binary data (images, sounds,...) into an XML document using "{}\+Base64 encoding"{}. This class is completely separated from the rest of the xml\+Parser library and can be removed without any problem. To include some binary data into an XML file, you must convert the binary data into standard text (using "{}encode"{}). To retrieve the original binary data from the b64-\/encoded text included inside the XML file, use "{}decode"{}. Alternatively, these functions can also be used to "{}encrypt/\+decrypt"{} some critical data contained inside the XML (it\textquotesingle{}s not a strong encryption at all, but sometimes it can be useful).
