\doxysubsection{Detailed Description}
QWidget for displaying a \doxylink{classvtk_render_window}{vtk\+Render\+Window} in a Qt Application. 

\doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} simplifies using a \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} as a widget in Qt application so it can be embedded in a layout rather than being a top-\/level window. \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} has all the limitations posed by Qt with {\ttfamily QWidget::\+create\+Window\+Container} hence developers are advised to refer to Qt docs for more details.

In general \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} may be a better choice, however QVTKOpen\+GLWindow-\/based \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} may be better choice for applications requiring quad-\/buffer stereo.

Due to Qt limitations, \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} does not support being a native widget. But native widget are sometimes mandatory, for example within QScroll\+Area and QMDIArea, so the \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} should be used when in needs of VTK rendering in the context of Qt native widget.

If a \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} is used in a QScroll\+Area or in a QMDIArea, it will force it to be native and this is {\itshape NOT} supported.

Unlike \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget}, \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} does not require that the default surface format for the application be changed. One can simply specify the needed QSurface\+Format for the specific \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} instance by calling {\ttfamily \doxylink{class_q_v_t_k_open_g_l_stereo_widget_acc5f1d592ed2da0fa782db072ddfa525}{QVTKOpen\+GLStereo\+Widget::\+set\+Format}} before the widget is initialized.

Note this returns a QSurface\+Format required to support the Open\+GL rendering capabilities in a \doxylink{classvtk_render_window}{vtk\+Render\+Window}. Set/\+\+Get a custom device pixel ratio to use to map Qt sizes to VTK (or Open\+GL) sizes. Thus, when the QWidget is resized, it called {\ttfamily \doxylink{classvtk_window_ae9fcf005155025536543e87fca1cfd4a}{vtk\+Render\+Window::\+\+Set\+Size}} on the internal \doxylink{classvtk_render_window}{vtk\+Render\+Window} after multiplying the QWidget\textquotesingle{}s size by this scale factor.
