use this macro for creating static \doxylink{class_o_f_condition}{OFCondition} instances. Instead of an \doxylink{class_o_f_condition}{OFCondition} instance which needs a constructor, an instance of \doxylink{struct_o_f_condition_const}{OFCondition\+Const} is created.
