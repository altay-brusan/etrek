\doxysubsection{Detailed Description}
object represents upward pointers from points to list of cells using each point 

\doxylink{classvtk_static_cell_links}{vtk\+Static\+Cell\+Links} is a supplemental object to \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} and \doxylink{classvtk_cell_types}{vtk\+Cell\+Types}, enabling access from points to the cells using the points. \doxylink{classvtk_static_cell_links}{vtk\+Static\+Cell\+Links} is an array of links, each link represents a list of cell ids using a particular point. \doxylink{requirements_The}{The} information provided by this object can be used to determine cell neighbors and construct other local topological information. This class is a faster implementation of \doxylink{classvtk_cell_links}{vtk\+Cell\+Links}. However, it cannot be incrementally constructed; it is meant to be constructed once (statically) and must be rebuilt if the cells change.

\begin{DoxyWarning}{Warning}
This is a drop-\/in replacement for \doxylink{classvtk_cell_links}{vtk\+Cell\+Links} using static link construction. It uses the templated \doxylink{classvtk_static_cell_links_template}{vtk\+Static\+Cell\+Links\+Template} class, instantiating \doxylink{classvtk_static_cell_links_template}{vtk\+Static\+Cell\+Links\+Template} with a vtk\+Id\+Type template parameter. Note that for best performance, the \doxylink{classvtk_static_cell_links_template}{vtk\+Static\+Cell\+Links\+Template} class may be used directly, instantiating it with the appropriate id type. This class is also wrappable and can be used from an interpreted language such as Python.
