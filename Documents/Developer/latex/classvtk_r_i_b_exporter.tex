\doxysubsection{Detailed Description}
export a scene into Render\+Man RIB format. 

\doxylink{classvtk_r_i_b_exporter}{vtk\+RIBExporter} is a concrete subclass of \doxylink{classvtk_exporter}{vtk\+Exporter} that writes a Renderman .RIB files. \doxylink{requirements_The}{The} input specifies a \doxylink{classvtk_render_window}{vtk\+Render\+Window}. All visible actors and lights will be included in the rib file. \doxylink{requirements_The}{The} following file naming conventions apply:\+ rib file -\/ File\+Prefix.\+rib image file created by Render\+Man -\/ File\+Prefix.\+tif texture files -\/ Texture\+Prefix\+\_\+0x\+ADDR\+\_\+\+MTIME.\+tif This object does NOT generate an image file. \doxylink{requirements_The}{The} user must run either Render\+Man or a Render\+Man emulator like Blue Moon Ray Tracer (BMRT). vtk properties are convert to Renderman shaders as follows:\+ Normal property, no texture map -\/ plastic.\+sl Normal property with texture map -\/ txtplastic.\+sl These two shaders must be compiled by the rendering package being used. \doxylink{classvtk_r_i_b_exporter}{vtk\+RIBExporter} also supports custom shaders. \doxylink{requirements_The}{The} shaders are written using the Renderman Shading Language. See "{}\+The Renderman \+Companion"{}, ISBN 0-\/201-\/50868, 1989 for details on writing shaders. \doxylink{classvtk_r_i_b_property}{vtk\+RIBProperty} specifies the declarations and parameter settings for custom shaders.
