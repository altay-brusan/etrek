\doxysubsection{Detailed Description}
This class implements a buffering mechanism that is used when writing large elements that reside in file into an output stream. \doxylink{class_dcm_element_a11c838a282d3b045f4bb3a77f1e595d2}{Dcm\+Element::\+get\+Partial\+Value} is used to fill the buffer maintained by this class, and the buffer content is then copied to the output stream. \doxylink{requirements_The}{The} intermediate buffer is necessary because both \doxylink{class_dcm_element_a11c838a282d3b045f4bb3a77f1e595d2}{Dcm\+Element::\+get\+Partial\+Value} and \doxylink{class_dcm_output_stream_a5b781952ba8d9939cb851cc6159777fa}{Dcm\+Output\+Stream::\+write} expect a buffer to write to and read from, respectively.
