\doxysubsection{Detailed Description}
Reslices a volume along a new set of axes. 

\doxylink{classvtk_image_reslice}{vtk\+Image\+Reslice} is the swiss-\/army-\/knife of image geometry filters:\+ It can permute, rotate, flip, scale, resample, deform, and pad image data in any combination with reasonably high efficiency. Simple operations such as permutation, resampling and padding are done with similar efficiently to the specialized \doxylink{classvtk_image_permute}{vtk\+Image\+Permute}, \doxylink{classvtk_image_resample}{vtk\+Image\+Resample}, and vtk\+Image\+Pad filters. There are a number of tasks that \doxylink{classvtk_image_reslice}{vtk\+Image\+Reslice} is well suited for:\+ 

1) Application of transformations (either linear or nonlinear) to an image. It is sometimes convenient to use \doxylink{classvtk_image_change_information}{vtk\+Image\+Change\+Information} to center the image first, so that scales and rotations occur around the center rather than around the lower-\/left corner of the image. 

2) Resampling of one data set to match the voxel sampling of a second data set via the \doxylink{classvtk_image_reslice_af000f67da5c57736f9e81f2687c89832}{Set\+Information\+Input()} method, e.\+g. for the purpose of comparing two images or combining two images. A transformation, either linear or nonlinear, can be applied at the same time via the Set\+Reslice\+Transform method if the two images are not in the same coordinate space. 

3) Extraction of slices from an image volume. \doxylink{requirements_The}{The} most convenient way to do this is to use \doxylink{classvtk_image_reslice_a683e91a7d2ab49d26c05b2cf51225639}{Set\+Output\+Direction()} to specify the orientation of the output slices. \doxylink{requirements_The}{The} columns of the direction matrix specify the x, y, and z axes for the output volume or slice, and \doxylink{classvtk_image_reslice_a477b6b07bcb4084fd00df7410d992f00}{Set\+Output\+Origin()} can be used to specify the position. You can use these methods together with \doxylink{classvtk_image_reslice_a1f0b56a40d5b335abe8712aa582583ec}{Set\+Reslice\+Transform()} in order to extract slices in a certain orientation while simultaneously applying a transformation to the coordinate system. \begin{DoxyWarning}{Warning}
This filter is very inefficient if the output X dimension is 1. 
\end{DoxyWarning}
