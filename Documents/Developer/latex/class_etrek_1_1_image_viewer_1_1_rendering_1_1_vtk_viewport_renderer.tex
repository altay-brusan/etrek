\doxysubsection{Detailed Description}
Manages VTK rendering pipeline for a single viewport. 

Handles:\+
\begin{DoxyItemize}
\item Image display with window/\+level adjustment
\item DICOM overlay text (4 corners)
\item Zoom and pan operations
\item Crosshair display
\item Measurement annotations 
\end{DoxyItemize}
