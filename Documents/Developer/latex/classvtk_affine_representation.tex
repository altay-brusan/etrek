\doxysubsection{Detailed Description}
abstract class for representing affine transformation widgets 

This class defines an API for affine transformation widget representations. These representations interact with \doxylink{classvtk_affine_widget}{vtk\+Affine\+Widget}. \doxylink{requirements_The}{The} basic functionality of the affine representation is to maintain a transformation matrix.

This class may be subclassed so that alternative representations can be created. \doxylink{requirements_The}{The} class defines an API and a default implementation that the \doxylink{classvtk_affine_widget}{vtk\+Affine\+Widget} interacts with to render itself in the scene.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} separation of the widget event handling and representation enables users and developers to create new appearances for the widget. It also facilitates parallel processing, where the client application handles events, and remote representations of the widget are slaves to the client (and do not handle events).
\end{DoxyWarning}
