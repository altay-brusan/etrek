\doxysubsection{Detailed Description}
implicit sum of other implicit functions 

\doxylink{classvtk_implicit_sum}{vtk\+Implicit\+Sum} produces a linear combination of other implicit functions. \doxylink{requirements_The}{The} contribution of each function is weighted by a scalar coefficient. \doxylink{requirements_The}{The} Normalize\+By\+Weight option normalizes the output so that the scalar weights add up to 1. Note that this function gives accurate sums and gradients only if the input functions are linear.
