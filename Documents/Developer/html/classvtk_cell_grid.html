Detailed Description

Visualization data composed of cells of arbitrary type.

vtkCellGrid inherits vtkDataObject in order to introduce the concept of cells that, instead of relying on spatial points to specify their shape, rely on degrees of freedom (which may or may not be embedded in a world coordinate system).

The degrees of freedom that define cells and the functions using those cells as their domain are provided in data arrays. The arrays are partitioned into groups (vtkDataSetAttributes) by the registered cell types. Each array in a group has the same number of tuples.

See also
vtkDataObject vtkDataSetAttributes

◆ GetCellAttributeRange()

virtual bool vtkCellGrid::GetCellAttributeRange ( vtkCellAttribute * attribute,
int componentIndex,
double range[2],
bool finiteRange = false ) const
virtual

Return information on the range of values taken on by a component of an attribute.

This method also accommodates computing the range of the L₁ or L₂ norm of the entire tuple by passing -1 or -2, respectively, for the componentIndex.

When called with finiteRange equal to false (the default), either component of range may be NaN (not-a-number) or +/-Inf (∞). When finiteRange is true, the returned range values will always be finite.

Note that if this cell-attribute has no values, the range will be marked invalid (i.e., range[1] < range[0]).

Note that attribute must be an attribute owned by this cell-grid.

◆ GetShapeAttribute()

vtkCellAttribute * vtkCellGrid::GetShapeAttribute ( )

Set/get the "shape attribute" (i.e., a vector-valued cell-attribute that maps from reference to world coordinates).

If there is no shape attribute, then a vtkCellGrid cannot be rendered.

A shape attribute must have between 1 and 4 components (inclusive).

If you call SetShapeAttribute with an attribute that does not satisfy this constraint, this method will return false and have no effect. If you wish to "remove" a grid's shape, call SetShapeAttribute(nullptr).
