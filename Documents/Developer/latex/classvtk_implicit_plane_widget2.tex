\doxysubsection{Detailed Description}
3D widget for manipulating an infinite plane 

This 3D widget defines an infinite plane that can be interactively placed in a scene. \doxylink{requirements_The}{The} widget is assumed to consist of four parts:\+ 1) a plane contained in a 2) bounding box, with a 3) plane normal, which is rooted at a 4) point on the plane. (\doxylink{requirements_The}{The} representation paired with this widget determines the actual geometry of the widget.)

To use this widget, you generally pair it with a \doxylink{classvtk_implicit_plane_representation}{vtk\+Implicit\+Plane\+Representation} (or a subclass). Various options are available for controlling how the representation appears, and how the widget functions.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
If the mouse is over the plane normal:
  LeftButtonPressEvent -\/ select normal
  LeftButtonReleaseEvent -\/ release normal
  MouseMoveEvent -\/ orient the normal vector
If the mouse is over the origin point (handle):
  LeftButtonPressEvent -\/ select handle
  LeftButtonReleaseEvent -\/ release handle (if selected)
  MouseMoveEvent -\/ move the origin point (constrained to the plane)
If the mouse is over the plane:
  LeftButtonPressEvent -\/ select plane
  LeftButtonReleaseEvent -\/ release plane (if selected)
  MouseMoveEvent -\/ move the plane
If the mouse is over the outline:
  LeftButtonPressEvent -\/ select outline
  LeftButtonReleaseEvent -\/ release outline (if selected)
  MouseMoveEvent -\/ move the outline
If the keypress characters are used
  'Down/Left' Move plane down
  'Up/Right' Move plane up
In all the cases, independent of what is picked, the widget responds to the
following VTK events:
  MiddleButtonPressEvent -\/ move the plane
  MiddleButtonReleaseEvent -\/ release the plane
  RightButtonPressEvent -\/ scale the widget's representation
  RightButtonReleaseEvent -\/ stop scaling the widget
  MouseMoveEvent -\/ scale (if right button) or move (if middle button) the widget
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::Select -\/-\/ some part of the widget has been selected
  vtkWidgetEvent::EndSelect -\/-\/ the selection process has completed
  vtkWidgetEvent::Move -\/-\/ a request for widget motion has been invoked
  vtkWidgetEvent::Up and vtkWidgetEvent::Down -\/-\/ MovePlaneAction
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
In turn, when these widget events are processed, the \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2} invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (on vtkWidgetEvent::Select)
  vtkCommand::EndInteractionEvent (on vtkWidgetEvent::EndSelect)
  vtkCommand::InteractionEvent (on vtkWidgetEvent::Move)
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
This class, and \doxylink{classvtk_implicit_plane_representation}{vtk\+Implicit\+Plane\+Representation}, are next generation VTK widgets. An earlier version of this functionality was defined in the class \doxylink{classvtk_implicit_plane_widget}{vtk\+Implicit\+Plane\+Widget}.
\end{DoxyParagraph}
