\doxysubsection{Detailed Description}
\doxylink{structvtk_type_list_1_1_type_list}{Type\+List} implementation and utilities. 

\doxylink{classvtk_type_list}{vtk\+Type\+List} provides a way to collect a list of types using C++ templates. In VTK, this is used heavily by the \doxylink{classvtk_array_dispatch}{vtk\+Array\+Dispatch} system to instantiate templated code for specific array implementations. \doxylink{requirements_The}{The} book "{}\+Modern C++ \+Design:\+ Generic Programming and Design Patterns Applied"{} by Andrei Alexandrescu provides additional details and applications for type\+Lists. This implementation is heavily influenced by the example code in the book.

Note that creating a typelist in C++ is simplified greatly by using the vtk\+Type\+List::\+\+Create$<$\+T1, T2, ...$>$ functions.
