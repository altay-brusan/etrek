\doxysubsection{Detailed Description}
generates a 2D reslice cursor polydata 

\doxylink{classvtk_reslice_cursor_poly_data_algorithm}{vtk\+Reslice\+Cursor\+Poly\+Data\+Algorithm} is a class that generates a 2D reslice cursor \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}, suitable for rendering within a \doxylink{classvtk_reslice_cursor_actor}{vtk\+Reslice\+Cursor\+Actor}. \doxylink{requirements_The}{The} class takes as input the reslice plane normal index (an index into the normal plane maintained by the reslice cursor object) and generates the polydata representing the other two reslice axes suitable for rendering on a slice through this plane. \doxylink{requirements_The}{The} cursor consists of two intersection axes lines that meet at the cursor focus. These lines may have a user defined thickness. They need not be orthogonal to each other. \begin{DoxySeeAlso}{See also}
