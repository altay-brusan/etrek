\doxysubsection{Detailed Description}
Asynchronously measures GPU execution time for a single event. 

This class posts events to the Open\+GL server to measure execution times of GPU processes. \doxylink{requirements_The}{The} queries are asynchronous and multiple vtk\+Open\+GLRender\+Timers may overlap /\+ be nested.

This uses GL\+\_\+\+TIMESTAMP rather than GL\+\_\+\+ELAPSED\+\_\+\+TIME, since only one GL\+\_\+\+ELAPSED\+\_\+\+TIME query may be active at a time. Since GL\+\_\+\+TIMESTAMP is not available on Open\+GL ES, timings will not be available on those platforms. Use the static \doxylink{classvtk_open_g_l_render_timer_afb2b5e074f7b5ffb862b74b3d70b2217}{Is\+Supported()} method to determine if the timer is available.

This class can also be used in a reusable manner where the start and stop events stay in flight until they are both completed. Calling Reusable\+Start while they are in flight is ignored. \doxylink{requirements_The}{The} Elapsed time is always the result from the most recently completed flight. Typical usage is

render loop timer-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_open_g_l_render_timer_a32a0853d0ebb51cad69bb31c28e65b1d}{Reusable\+Start()}; /\+/\+ do some rendering timer-\/\texorpdfstring{$>$}{>}Reusable\+Stop(); time = timer-\/\texorpdfstring{$>$}{>}Get\+Reusable\+Elapsed\+Seconds();

the elapsed seconds will return zero until a flight has completed.

\doxylink{requirements_The}{The} idea being that with Open\+GL render commands are asynchronous. You might render multiple times before the first render on the GPU is completed. These reusable methods provide a method for provinding a constant measure of the time required for a command with the efficiency of only having one timing in process/\+flight at a time. Making this a lightweight timer in terms of Open\+GL API calls.
