\doxysubsection{Detailed Description}
a simple event forwarder command 

Use \doxylink{classvtk_event_forwarder_command}{vtk\+Event\+Forwarder\+Command} to forward an event to a new object. This command will intercept the event, and use Invoke\+Event on a \textquotesingle{}target\textquotesingle{} as if that object was the one that invoked the event instead of the object this command was attached to using Add\+Observer.
