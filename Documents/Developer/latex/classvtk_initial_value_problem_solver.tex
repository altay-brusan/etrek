\doxysubsection{Detailed Description}
Integrate a set of ordinary differential equations (initial value problem) in time. 

Given a \doxylink{classvtk_function_set}{vtk\+Function\+Set} which returns d\+F\+\_\+i(x\+\_\+j, t)/\+dt given x\+\_\+j and t, \doxylink{classvtk_initial_value_problem_solver}{vtk\+Initial\+Value\+Problem\+Solver} computes the value of F\+\_\+i at t+deltat.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_initial_value_problem_solver}{vtk\+Initial\+Value\+Problem\+Solver} and it\textquotesingle{}s subclasses are not thread-\/safe. You should create a new integrator for each thread.
\end{DoxyWarning}

Given initial values, xprev , initial time, t and a requested time interval, delT calculate values of x at t+del\+TActual (xnext). For certain concrete sub-\/classes del\+TActual != delT. This occurs when the solver supports adaptive stepsize control. If this is the case, the solver tries to change to stepsize such that the (estimated) error of the integration is less than max\+Error. \doxylink{requirements_The}{The} solver will not set the stepsize smaller than min\+Step or larger than max\+Step. Also note that delT is an in/\+out argument. Adaptive solvers will modify delT to reflect the best (estimated) size for the next integration step. An estimated value for the error is returned (by reference) in error. Note that only some concrete sub-\/classes support this. Otherwise, the error is set to 0.
