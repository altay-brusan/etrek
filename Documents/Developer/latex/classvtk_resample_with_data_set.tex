\doxysubsection{Detailed Description}
sample point and cell data of a dataset on points from another dataset. 

Similar to \doxylink{classvtk_composite_data_probe_filter}{vtk\+Composite\+Data\+Probe\+Filter}, \doxylink{classvtk_resample_with_data_set}{vtk\+Resample\+With\+Data\+Set} takes two inputs -\/ Input and Source, and samples the point and cell values of Source on to the point locations of Input. \doxylink{requirements_The}{The} output has the same structure as Input but its point data have the resampled values from Source. Unlike \doxylink{classvtk_composite_data_probe_filter}{vtk\+Composite\+Data\+Probe\+Filter}, this filter support composite datasets for both Input and Source. \begin{DoxySeeAlso}{See also}
