\doxysubsection{Detailed Description}
Accept or reject \doxylink{class_dcm_item}{Dcm\+Item} objects by comparing a specific attribute to a set of values. \doxylink{class_dcm_attribute_filter}{Dcm\+Attribute\+Filter} objects can be used to compare a specific attribute with one or more values -\/ or to accept any \doxylink{class_dcm_item}{Dcm\+Item} if no attribute is specified. \doxylink{class_dcm_attribute_filter}{Dcm\+Attribute\+Filter} objects can be used like any function taking a \doxylink{class_dcm_item}{Dcm\+Item}\& or a \doxylink{class_dcm_file_format}{Dcm\+File\+Format}\& object as parameter and returning a boolean value.
