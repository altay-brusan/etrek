\doxysubsection{Detailed Description}
class for reading Wind\+Blade data files 

\doxylink{classvtk_wind_blade_reader}{vtk\+Wind\+Blade\+Reader} is a source object that reads Wind\+Blade files which are block binary files with tags before and after each block giving the number of bytes within the block. \doxylink{requirements_The}{The} number of data variables dumped varies. There are 3 output ports with the first being a structured grid with irregular spacing in the Z dimension. \doxylink{requirements_The}{The} second is an unstructured grid only read on process 0 and used to represent the blade. \doxylink{requirements_The}{The} third is also a structured grid with irregular spacing on the Z dimension. Only the first and second output ports have time dependent data.
