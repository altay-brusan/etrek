\doxysubsection{Detailed Description}
a class defining the representation for a \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2} 

This class is a concrete representation for the \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2}. It represents an infinite plane defined by a normal and point in the context of a bounding box. Through interaction with the widget, the plane can be manipulated by adjusting the plane normal or moving the origin point.

To use this representation, you normally define a (plane) origin and (plane) normal. \doxylink{requirements_The}{The} Place\+Widget() method is also used to initially position the representation.

\begin{DoxyWarning}{Warning}
This class, and \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2}, are next generation VTK widgets. An earlier version of this functionality was defined in the class \doxylink{classvtk_implicit_plane_widget}{vtk\+Implicit\+Plane\+Widget}.
\end{DoxyWarning}
