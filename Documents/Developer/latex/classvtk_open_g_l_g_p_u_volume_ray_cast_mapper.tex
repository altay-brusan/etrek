\doxysubsection{Detailed Description}
Open\+GL implementation of volume rendering through ray-\/casting. 

\hypertarget{classvtk_open_g_l_g_p_u_volume_ray_cast_mapper_multi}{}\doxysubsection{\texorpdfstring{Multiple Inputs}{Multiple Inputs}}\label{classvtk_open_g_l_g_p_u_volume_ray_cast_mapper_multi}
When multiple inputs are rendered simultaneously, it is possible to composite overlapping areas correctly. Inputs are connected directly to the mapper and their parameters (transfer functions, transformations, etc.) are specified through standard \doxylink{classvtk_volume}{vtk\+Volume} instances. These \doxylink{classvtk_volume}{vtk\+Volume} instances are to be registered in a special \doxylink{classvtk_prop3_d}{vtk\+Prop3D}, \doxylink{classvtk_multi_volume}{vtk\+Multi\+Volume}.

Structures related to a particular active input are stored in a helper class (\doxylink{classvtk_volume_input_helper}{vtk\+Volume\+Input\+Helper}) and helper structures are kept in a port-\/referenced map (Volume\+Input\+Map). \doxylink{requirements_The}{The} order of the inputs in the map is important as it defines the order in which parameters are bound to uniform variables (transformation matrices, bias, scale and every other required rendering parameter).

A separate code path is used when rendering multiple-\/inputs in order to facilitate the co-\/existance of these two modes (single/\+multiple), due to current feature incompatibilities with multiple inputs (e.\+g. texture-\/streaming, cropping, etc.).

\begin{DoxyNote}{Note}
A limited set of the mapper features are currently supported for multiple inputs:\+
\end{DoxyNote}

\begin{DoxyItemize}
\item Blending
\begin{DoxyItemize}
\item Composite (front-\/to-\/back)
\end{DoxyItemize}
\item Transfer functions (defined separately for per input)
\begin{DoxyItemize}
\item 1D color
\item 1D scalar opacity
\item 1D gradient magnitude opacity
\item 2D scalar-\/gradient magnitude
\end{DoxyItemize}
\item Point and cell data
\begin{DoxyItemize}
\item With the limitation that all of the inputs are assumed to share the same name/\+id.
\end{DoxyItemize}
\item Inputs
\begin{DoxyItemize}
\item 1-\/component inputs with vtk\+Volume\+Property::\+\+Independent\+Components\+On()
\item 4-\/component inputs with vtk\+Volume\+Property::\+\+Independent\+Components\+Off()
\end{DoxyItemize}
\end{DoxyItemize}
