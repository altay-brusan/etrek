\doxysubsection{Detailed Description}
provides an operating system independent abstraction for mutexes (mutual exclusion locks). Mutexes prevent multiple threads from simultaneously executing critical sections of code which access shared data. A successful call for a mutex lock by way of \doxylink{class_o_f_mutex_acd378f61a34167beb8891fdc78f6aaf8}{lock()} will cause another thread that is also trying to lock the same mutex to block until the owner thread unlocks it by way of \doxylink{class_o_f_mutex_a21912fd54ccf9d5ab8778aef64a33512}{unlock()}.
