\doxysubsection{Detailed Description}
implicit function for a sphere 

\doxylink{classvtk_sphere}{vtk\+Sphere} computes the implicit function and/\+or gradient for a sphere. \doxylink{classvtk_sphere}{vtk\+Sphere} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. Additional methods are available for sphere-\/related computations, such as computing bounding spheres for a set of points, or set of spheres.
