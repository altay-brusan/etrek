\doxysubsection{Detailed Description}
abstract Poly\+Data\+Source-\/based 3D widget 

This abstract class serves as parent to 3D widgets that have simple vtk\+Poly\+Data\+Source instances defining their geometry.

In addition to what is offered by the \doxylink{classvtk3_d_widget}{vtk3\+DWidget} parent, this class makes it possible to manipulate the underlying vtk\+Poly\+Data\+Source and to \doxylink{classvtk_poly_data_source_widget_a3c5d3f2e477ba97d4a83293698d22c54}{Place\+Widget()} according to that, instead of having to make use of Set\+Input() or \doxylink{classvtk3_d_widget_a97aaef01f03e49c6807069da0cf189f0}{Set\+Prop3\+D()}.

Implementers of child classes HAVE to implement their Place\+Widget(bounds) to check for the existence of Input and Prop3D FIRST. If these don\textquotesingle{}t exist, place according to the underlying Poly\+Data\+Source. Child classes also have to imprement \doxylink{classvtk_poly_data_source_widget_a23e9bb19f0155a28ed1d21e1a51632ab}{Update\+Placement()}, which updates the widget according to the geometry of the underlying Poly\+Data\+Source.
