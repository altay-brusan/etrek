Detailed Description

Key for vtkObjectBase vector values.

vtkInformationObjectBaseVectorKey is used to represent keys for double vector values in vtkInformation.h. NOTE the interface in this key differs from that in other similar keys because of our internal use of smart pointers.

const char * requiredClass = nullptr )

The name of the static instance and the class in which it is defined(location) should be passed to the constructor. Providing "requiredClass" name one can ensure that only objects of type "requiredClass" are stored in vectors associated with the instance of this key type created. These should be string literals as they are not copied.
