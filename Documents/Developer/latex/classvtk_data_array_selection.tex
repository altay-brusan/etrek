\doxysubsection{Detailed Description}
Store on/\+off settings for data arrays, etc. 

\doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection} is intended to be used by algorithms that want to expose a API that allow the user to enable/\+disable a collection of entities, such as arrays. Readers, for example, can use \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection} to let the user choose which array to read from the file.

Originally intended for selecting data arrays (hence the name), this class can be used for letting users choose other items too, for example, \doxylink{classvtk_i_o_s_s_reader}{vtk\+IOSSReader} uses \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection} to let users choose which blocks to read.

Unlike most other \doxylink{classvtk_object}{vtk\+Object} subclasses, \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection} has public API that need not modify the MTime for the object. These M-\/\+Time non-\/modifying methods are typically intended for use within the algorithm or reader to populate the \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection} instance with available array names and their default values.
