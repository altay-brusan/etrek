\doxysubsection{Detailed Description}
create and manipulate ordered lists of objects 

\doxylink{classvtk_collection}{vtk\+Collection} is a general object for creating and manipulating lists of objects. \doxylink{requirements_The}{The} lists are ordered and allow duplicate entries. \doxylink{classvtk_collection}{vtk\+Collection} also serves as a base class for lists of specific types of objects.
