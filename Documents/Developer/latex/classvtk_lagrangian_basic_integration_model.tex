\doxysubsection{Detailed Description}
\doxylink{classvtk_function_set}{vtk\+Function\+Set} abstract implementation to be used in the \doxylink{classvtk_lagrangian_particle_tracker}{vtk\+Lagrangian\+Particle\+Tracker} integrator. 

This \doxylink{classvtk_function_set}{vtk\+Function\+Set} abstract implementation is meant to be used as a parameter of \doxylink{classvtk_lagrangian_particle_tracker}{vtk\+Lagrangian\+Particle\+Tracker}. It manages multiple dataset locators in order to evaluate the \doxylink{classvtk_function_set_a932ff84f43b9d84832f3431499f49361}{vtk\+Function\+Set::\+\+Function\+Values} method. \doxylink{requirements_The}{The} actual Function\+Values implementation should be found in the class inheriting this class. Input Arrays to process are expected as follows:\+ Index 0 :\+ "{}\+Surface\+Type"{} array of surface input of the particle tracker

Inherited classes MUST implement int Function\+Values(vtk\+Data\+Set\texorpdfstring{$\ast$}{*} data\+Set, vtk\+Id\+Type cell\+Id, double\texorpdfstring{$\ast$}{*} weights,    double \texorpdfstring{$\ast$}{*} x, double \texorpdfstring{$\ast$}{*} f); to define how the integration works.

Inherited classes could reimplement Interact\+With\+Surface or other surface interaction methods to change the way particles interact with surfaces.

Inherited classes could reimplement Intersect\+With\+Line to use a specific algorithm to intersect particles and surface cells.

Inherited classes could reimplement Check\+Free\+Flight\+Termination to set the way particles terminate in free flight.

Inherited classes could reimplement Initialize\texorpdfstring{$\ast$}{*}\+Data and Insert\texorpdfstring{$\ast$}{*}\+Data in order to customize the output of the tracker
