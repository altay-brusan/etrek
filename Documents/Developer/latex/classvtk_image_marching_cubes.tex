\doxysubsection{Detailed Description}
generate isosurface(s) from volume/\+images 

\doxylink{classvtk_image_marching_cubes}{vtk\+Image\+Marching\+Cubes} is a filter that takes as input images (e.\+g., 3D image region) and generates on output one or more isosurfaces. One or more contour values must be specified to generate the isosurfaces. Alternatively, you can specify a min/\+max scalar range and the number of contours to generate a series of evenly spaced contour values. This filter can stream, so that the entire volume need not be loaded at once. Streaming is controlled using the instance variable Input\+Memory\+Limit, which has units KBytes.

\begin{DoxyWarning}{Warning}
This filter is specialized to volumes. If you are interested in contouring other types of data, use the general \doxylink{classvtk_contour_filter}{vtk\+Contour\+Filter}. If you want to contour an image (i.\+e., a volume slice), use \doxylink{classvtk_marching_squares}{vtk\+Marching\+Squares}. 
\end{DoxyWarning}
