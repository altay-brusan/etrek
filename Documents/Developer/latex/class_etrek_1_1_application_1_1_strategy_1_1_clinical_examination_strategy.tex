\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_application_1_1_strategy}{Strategy} for standard clinical patient examination mode. 

This is the primary examination mode used for real patient exams. It implements the full DICOM workflow including:\+
\begin{DoxyItemize}
\item Creating DICOM Study, Series, and Image objects
\item Persisting images to the database
\item Sending images to configured PACS servers
\item Updating worklist entry status (MWL)
\item Complete audit trail logging
\end{DoxyItemize}
