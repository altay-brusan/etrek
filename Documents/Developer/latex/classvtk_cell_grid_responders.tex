\doxysubsection{Detailed Description}
A container that holds objects able to respond to queries specialized for particular \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} types. 

This class holds sets of responders for \doxylink{classvtk_cell_grid_query}{vtk\+Cell\+Grid\+Query} and for vtk\+Cell\+Attribute\+Query.\hypertarget{classvtk_cell_grid_responders_autotoc_md790}{}\doxysubsubsection{\texorpdfstring{Cell-\/grid query responders}{Cell-\/grid query responders}}\label{classvtk_cell_grid_responders_autotoc_md790}
\doxylink{classvtk_cell_grid_responders}{vtk\+Cell\+Grid\+Responders} holds a list of objects statically registered to the \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} subclass. These objects respond to queries for information (e.\+g., a bounding box) or processing (e.\+g., rendering, picking, generating isocontours) for one cell type (and subclasses of that cell type if no more specific responder is registered).

Application code (such as a plugin) can register subclasses of vtk\+Cell\+Grid\+Response which accept the API of a particular \doxylink{classvtk_cell_grid_query}{vtk\+Cell\+Grid\+Query} for that cell type. Then, when a query is passed to the cell, this collection will identify matching responders for the query and invoke them until one returns true (indicating success). Multiple matches can exist as a responder can be registered to a common base cell class and/\+or to handle common base query classes.

If a given cell type cannot respond to a query, its superclasses are asked to respond. If no superclass can respond to the query, then query\textquotesingle{}s superclasses are searched for responders.

Because queries can be registered to cell types at any time, existing cell types can be extended to support new features by additional libraries.\hypertarget{classvtk_cell_grid_responders_autotoc_md791}{}\doxysubsubsection{\texorpdfstring{Cell-\/attribute calculators}{Cell-\/attribute calculators}}\label{classvtk_cell_grid_responders_autotoc_md791}
In order to support the evaluation of \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute} data on any \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} (cell type), this class also holds "{}calculators"{} grouped by both attribute and cell type. This API is different that \doxylink{classvtk_cell_grid_query}{vtk\+Cell\+Grid\+Query} because \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute} is not subclassed by attribute type but rather uses \doxylink{classvtk_string_token}{vtk\+String\+Token} data to determine the nature of the attribute (e.\+g., Lagrange; Nedelec; Raviart-\/\+Thomas; etc.).

It is also different in that these objects are expected to be used inside \doxylink{classvtk_cell_grid_query}{vtk\+Cell\+Grid\+Query} to evaluate a single cell at a time rather than longer-\/running queries across all cells.
