Detailed Description

Strategy for demonstration and exhibition mode.

This mode is used for exhibitions, sales demos, and training. Instead of performing real X-ray acquisitions, it loads and displays pre-captured sample images from disk.

Key characteristics:

  • No real X-ray exposure
  • Loads sample images from configured directory
  • No database persistence
  • No DICOM object creation
  • No PACS transmission
  • No worklist status updates

This mode is safe to use without a patient and without X-ray equipment being operational.
