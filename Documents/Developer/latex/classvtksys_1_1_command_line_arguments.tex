Find specified arguments with optional options and execute specified methods or set given variables.

\doxylink{requirements_The}{The} two interfaces it knows are callback based and variable based. For callback based, you have to register callback for particular argument using Add\+Callback method. When that argument is passed, the callback will be called with argument, value, and call data. For boolean (NO\+\_\+\+ARGUMENT) arguments, the value is "{}1"{}. If the callback returns 0 the argument parsing will stop with an error.

For the variable interface you associate variable with each argument. When the argument is specified, the variable is set to the specified value casted to the appropriate type. For boolean (NO\+\_\+\+ARGUMENT), the value is "{}1"{}.

Both interfaces can be used at the same time.

Possible argument types are:\+ NO\+\_\+\+ARGUMENT -\/ \doxylink{requirements_The}{The} argument takes no value :\+ --A CONCAT\+\_\+\+ARGUMENT -\/ \doxylink{requirements_The}{The} argument takes value after no space :\+ --Aval SPACE\+\_\+\+ARGUMENT -\/ \doxylink{requirements_The}{The} argument takes value after space :\+ --A val EQUAL\+\_\+\+ARGUMENT -\/ \doxylink{requirements_The}{The} argument takes value after equal :\+ --A=val MULTI\+\_\+\+ARGUMENT -\/ \doxylink{requirements_The}{The} argument takes values after space :\+ --A val1 val2 val3 ...

Example use:\+
