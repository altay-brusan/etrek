Detailed Description

Magnifier tool for examining image details.

When active, displays a magnifying glass overlay that shows a zoomed portion of the image centered on the cursor position.

Interaction:

  • Move mouse: Update magnifier position
  • Left click: Toggle magnification level (2x/3x)
  • Mouse wheel: Also toggles magnification level
