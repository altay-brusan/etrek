Iogs::\+\+Generated\+Mesh::\+\+Generated\+Mesh (\begin{DoxyParamCaption}\item[{const std::\+string \&}]{parameters}{, }\item[{int}]{proc\+\_\+count}{ = {\ttfamily 1}, }\item[{int}]{my\+\_\+proc}{ = {\ttfamily 0}}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [explicit]}}

Generate a cube mesh of size \textquotesingle{}num\+\_\+x\textquotesingle{} by \textquotesingle{}num\+\_\+y\textquotesingle{} by \textquotesingle{}num\+\_\+z\textquotesingle{} elements. By default, the mesh is gen\+\_\+struc on a single processor. If \textquotesingle{}proc\+\_\+count\textquotesingle{} is greater than 1, then the mesh will be distributed over \textquotesingle{}proc\+\_\+count\textquotesingle{} processors and this process will get the portion of the mesh for \textquotesingle{}my\+\_\+proc\textquotesingle{}. \doxylink{requirements_The}{The} mesh will be decomposed along the \textquotesingle{}Z\textquotesingle{} axis so \textquotesingle{}num\+\_\+z\textquotesingle{} must be greater than or equal to \textquotesingle{}proc\+\_\+count\textquotesingle{} and for even distribution of the hexes \textquotesingle{}num\+\_\+z\textquotesingle{} mod \textquotesingle{}proc\+\_\+count\textquotesingle{} should be zero.

\doxylink{requirements_The}{The} mesh can optionally include sidesets along each face of the cube mesh. These are specified via the \textquotesingle{}add\+\_\+sidesets\textquotesingle{} function.

If the \textquotesingle{}parameters\textquotesingle{} string constructor is used, the string is parsed to determine the intervals in each direction and, optionally, additional information. \doxylink{requirements_The}{The} form of the string is "{}\+Ix\+Jx\+K"{} where I, J, and K are the number of intervals in the X, Y, and Z directions respectively and the "{}x"{} are literal \textquotesingle{}x\textquotesingle{} characters. For example, the constructor \doxylink{class_iogs_1_1_generated_mesh}{Generated\+Mesh}("{}10x12x14"{}) will create the same mesh as Generated\+Mesh(10,12,14)

Additional valid options are:\+
\begin{DoxyItemize}
\item help -- no argument, shows valid options
\item show -- no argument, prints out a summary of the Generated\+Mesh() parameters. \doxylink{requirements_The}{The} output will look similar to:\+ 
\begin{DoxyCode}{0}

\end{DoxyCode}

\item sideset -- argument = x\+Xy\+YzZ which specifies whether there is a sideset at that location. \textquotesingle{}x\textquotesingle{} is minimum x face, \textquotesingle{}X\textquotesingle{} is maximum x face, similarly for y and z. Note that the argument string is a single multicharacter string. You can add multiple sidesets to a face, for example, sideset:\+xxx would add three sidesets on the minimum x face. An error is output if a non x\+Xy\+YzZ character is found, but execution continues.
\item zdecomp -- argument = n0, n1, n2, ..., n\+\#proc-\/1 which are the number of intervals in the z direction for each processor in a pallel run. If this option is specified, then the total number of intervals in the z direction is the sum of the n0, n1, ... An interval count must be specified for each processor. If this option is not specified, then the number of intervals on each processor in the z direction is num\+Z/\+num\+Proc with the extras added to the lower numbered processors.
\item scale -- argument = xs, ys, zs which are the scale factors in the x, y, and z directions. All three must be specified if this option is present.
\item offset -- argument = xoff, yoff, zoff which are the offsets in the x, y, and z directions. All three must be specified if this option is present.
\item bbox -- argument = xmin, ymin, zmin, xmax, ymax, zmax which specify the lower left and upper right corners of the bounding box for the gen\+\_\+struc mesh. This will calculate the scale and offset which will fit the mesh in the specified box. All calculations are based on the currently active interval settings. If scale or offset or zdecomp specified later in the option list, you may not get the desired bounding box.
\item rotate -- argument = axis,angle,axis,angle,... where axis is \textquotesingle{}x\textquotesingle{}, \textquotesingle{}y\textquotesingle{}, or \textquotesingle{}z\textquotesingle{} and angle is the rotation angle in degrees. Multiple rotations are cumulative. \doxylink{requirements_The}{The} composite rotation matrix is applied at the time the coordinates are retrieved after scaling and offset are applied.
