\doxysubsection{Detailed Description}
Frustum culling and LOD management. 

This class is used to cull instances based on their transformation matrix. It was designed to improve performances when there is large number of instances in \doxylink{classvtk_open_g_l_glyph3_d_mapper}{vtk\+Open\+GLGlyph3\+DMapper}.

Each instance is tested on the GPU through vertex shader to know if it is inside of the frustum view. If it is, the distance to the camera is computed to select and send to the geometry shader the corresponding LOD index. \doxylink{requirements_The}{The} geometry shader register the instance to the corresponding vertex stream and therefore the corresponding transform feedback buffer in video memory.

\begin{DoxyWarning}{Warning}
GL\+\_\+\+ARB\+\_\+gpu\+\_\+shader5 extension is required.
\end{DoxyWarning}
