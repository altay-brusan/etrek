\doxysubsection{Detailed Description}
An abstract class for obtaining the interpolated velocity values at a point. 

\doxylink{classvtk_composite_interpolated_velocity_field}{vtk\+Composite\+Interpolated\+Velocity\+Field} acts as a continuous velocity field by performing cell interpolation on one or more underlying vtk\+Data\+Sets. That is, composite datasets are combined to create a continuous velocity field. \doxylink{requirements_The}{The} default strategy is to use the closest point strategy.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_composite_interpolated_velocity_field}{vtk\+Composite\+Interpolated\+Velocity\+Field} is not thread safe. A new instance should be created by each thread.
\end{DoxyWarning}
