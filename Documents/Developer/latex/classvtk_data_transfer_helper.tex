\doxysubsection{Detailed Description}
is a helper class that aids in transferring data between CPU memory and GPU memory. 

\doxylink{classvtk_data_transfer_helper}{vtk\+Data\+Transfer\+Helper} is a helper class that aids in transferring data between the CPU memory and the GPU memory. \doxylink{requirements_The}{The} data in GPU memory is stored as textures which that in CPU memory is stored as \doxylink{classvtk_data_array}{vtk\+Data\+Array}. \doxylink{classvtk_data_transfer_helper}{vtk\+Data\+Transfer\+Helper} provides API to transfer only a sub-\/extent of CPU structured data to/\+from the GPU.
