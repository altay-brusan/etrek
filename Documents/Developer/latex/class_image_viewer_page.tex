\doxysubsection{Detailed Description}
Main page for DICOM/\+medical image viewing. 

Layout:\+
\begin{DoxyItemize}
\item Left:\+ \doxylink{class_image_tool_panel}{Image\+Tool\+Panel} (tool selection, layout buttons)
\item Center:\+ \doxylink{class_viewport_grid}{Viewport\+Grid} (1-\/4 image viewports)
\item Right:\+ \doxylink{class_series_thumbnail_panel}{Series\+Thumbnail\+Panel} (optional, collapsible)
\end{DoxyItemize}

Features:\+
\begin{DoxyItemize}
\item Multi-\/viewport layout (1x1, 1x2, 2x2)
\item Drag and drop support for loading files
\item Tool selection (zoom, pan, W/\+L, measurements) 
\end{DoxyItemize}
