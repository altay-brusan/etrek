\doxysubsection{Detailed Description}
representation for a camera path. 

\doxylink{classvtk_camera_path_representation}{vtk\+Camera\+Path\+Representation} is a \doxylink{classvtk_widget_representation}{vtk\+Widget\+Representation} for a camera path. This 3D widget defines a camera path that can be interactively manipulated in a scene. \doxylink{requirements_The}{The} camera path has camera handles, that can be added and deleted, plus they can be picked on the path itself to be translated in the scene. This representation is used with \doxylink{classvtk_camera_path_widget}{vtk\+Camera\+Path\+Widget}. \begin{DoxySeeAlso}{See also}
