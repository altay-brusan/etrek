\doxysubsection{Detailed Description}
A superclass for reading net\+CDF files. Subclass add conventions to the reader. This class just outputs data into a multi block data set with a \doxylink{classvtk_image_data}{vtk\+Image\+Data} at each block. A block is created for each variable except that variables with matching dimensions will be placed in the same block.
