\doxysubsection{Detailed Description}
Tool for measuring distances on images. 

Interaction:\+
\begin{DoxyItemize}
\item Click and drag to draw a measurement line
\item Release to complete the measurement
\item Click on a ruler to select it
\item Drag handles to resize existing rulers
\item Press Delete to remove selected ruler
\item Distance is calculated using pixel spacing 
\end{DoxyItemize}
