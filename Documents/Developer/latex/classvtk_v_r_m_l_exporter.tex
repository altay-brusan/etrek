\doxysubsection{Detailed Description}
export a scene into VRML 2.\+0 format. 

\doxylink{classvtk_v_r_m_l_exporter}{vtk\+VRMLExporter} is a concrete subclass of \doxylink{classvtk_exporter}{vtk\+Exporter} that writes VRML 2.\+0 files. This is based on the VRML 2.\+0 draft \#3 but it should be pretty stable since we aren\textquotesingle{}t using any of the newer features.
