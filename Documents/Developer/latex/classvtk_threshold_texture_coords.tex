\doxysubsection{Detailed Description}
compute 1D, 2D, or 3D texture coordinates based on scalar threshold 

\doxylink{classvtk_threshold_texture_coords}{vtk\+Threshold\+Texture\+Coords} is a filter that generates texture coordinates for any input dataset type given a threshold criterion. \doxylink{requirements_The}{The} criterion can take three forms:\+ 1) greater than a particular value (\doxylink{classvtk_threshold_texture_coords_aaa1fdc1e65880baa08f166181d76bf2a}{Threshold\+By\+Upper()}); 2) less than a particular value (\doxylink{classvtk_threshold_texture_coords_a9bb4d224332b7230bce27fba65b2d152}{Threshold\+By\+Lower()}; or 3) between two values (\doxylink{classvtk_threshold_texture_coords_a2812d1150d7a23ed9bdaa3e5f7fbce79}{Threshold\+Between()}. If the threshold criterion is satisfied, the "{}in"{} texture coordinate will be set (this can be specified by the user). If the threshold criterion is not satisfied the "{}out"{} is set.

\begin{DoxyWarning}{Warning}
There is a texture map -\/ tex\+Thres.\+vtk -\/ that can be used in conjunction with this filter. This map defines a "{}transparent"{} region for texture coordinates 0\texorpdfstring{$<$}{<}=r\texorpdfstring{$<$}{<}0.\+5, and an opaque full intensity map for texture coordinates 0.\+5\texorpdfstring{$<$}{<}r\texorpdfstring{$<$}{<}=1.\+0. There is a small transition region for r=0.\+5.
\end{DoxyWarning}
