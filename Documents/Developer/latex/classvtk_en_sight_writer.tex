\doxysubsection{Detailed Description}
write vtk unstructured grid data as an En\+Sight file 

\doxylink{classvtk_en_sight_writer}{vtk\+En\+Sight\+Writer} is a source object that writes binary unstructured grid data files in En\+Sight format. See En\+Sight Manual for format details

\begin{DoxyWarning}{Warning}
Binary files written on one system may not be readable on other systems. Be sure to specify the endian-\/ness of the file when reading it into En\+Sight
