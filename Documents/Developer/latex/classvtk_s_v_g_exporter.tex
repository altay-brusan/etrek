\doxysubsection{Detailed Description}
Exports \doxylink{classvtk_context2_d}{vtk\+Context2D} scenes to SVG. 

This exporter draws context2D scenes into a SVG file.

Limitations:\+
\begin{DoxyItemize}
\item \doxylink{requirements_The}{The} Nearest/\+\+Linear texture properties are ignored, since SVG doesn\textquotesingle{}t provide any reliable control over interpolation.
\item Embedded fonts are experimental and poorly tested. Viewer support is lacking at the time of writing, hence the feature is largely useless. By default, fonts are not embedded since they\textquotesingle{}re basically useless bloat. (this option is not exposed in \doxylink{classvtk_s_v_g_exporter}{vtk\+SVGExporter}).
\item Text\+As\+Path is enabled by default, since viewers differ wildly in how they handle text objects (eg. Inkscape renders at expected size, but webkit is way too big).
\item Pattern fills and markers are not shown on some viewers, e.\+g. KDE\textquotesingle{}s okular (Webkit seems to work, though).
\item Clipping seems to be broken in most viewers. Webkit is buggy and forces the clip coordinates to object\+Bounding\+Box, even when explicitly set to user\+Space\+On\+Use.
\item Many viewers anti-\/alias the output, leaving thin outlines around the triangles that make up larger polygons. This is a viewer issue and there not much we can do about it from the VTK side of things (and most viewers don\textquotesingle{}t seem to have an antialiasing toggle, either...).
\end{DoxyItemize}

If Active\+Renderer is specified then it exports contents of Active\+Renderer. Otherwise it exports contents of all renderers.

Set the threshold for subdividing gradient-\/shaded polygons/\+line. Default value is 1, and lower values yield higher quality and larger files. Larger values will reduce the number of primitives, but will decrease quality.

A triangle /\+ line will not be subdivided further if all of it\textquotesingle{}s vertices satisfy the equation:\+

\texorpdfstring{$\vert$}{|}v1 -\/ v2\texorpdfstring{$\vert$}{|}\texorpdfstring{$^\wedge$}{\string^}2 \texorpdfstring{$<$}{<} thresh

If true, draw all text as path objects rather than text objects. Enabling this option will:\+


\begin{DoxyItemize}
\item Improve portability (text will look exactly the same everywhere).
\item Increase file size (text objects are much more compact than paths).
\item Prevent text from being easily edited (text metadata is lost).
\end{DoxyItemize}
