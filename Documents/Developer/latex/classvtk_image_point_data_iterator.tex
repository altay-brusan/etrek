\doxysubsection{Detailed Description}
iterate over point data in an image. 

This class will iterate over an image. For each position, it will provide the (I,J,K) index, the point Id, and if a stencil is supplied, it will report whether the point is inside or outside of the stencil. 

For efficiency, this class iterates over spans rather than points. Each span is one image row or partial row, defined by a start position and a size. Within a span, only the X index and the point Id will change. \doxylink{requirements_The}{The} \doxylink{classvtk_image_point_data_iterator}{vtk\+Image\+Point\+Data\+Iterator} and related iterators are the preferred method of iterating over image data within the VTK image filters. \begin{DoxySeeAlso}{See also}
