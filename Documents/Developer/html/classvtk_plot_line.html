Paint legend event for the XY plot, called whenever the legend needs the plot items symbol/mark/line drawn. A rect is supplied with the lower left corner of the rect (elements 0 and 1) and with width x height (elements 2 and 3). The plot can choose how to fill the space supplied.

◆ vtkSetMacro()

vtkPlotLine::vtkSetMacro ( PolyLine ,
bool  )

Turn on/off flag to control whether the points define a poly line (true) or multiple line segments (false). If true (default), a segment is drawn between each points (e.g. [P1P2, P2P3, P3P4...].) If false, a segment is drawn for each pair of points (e.g. [P1P2, P3P4,...].)
