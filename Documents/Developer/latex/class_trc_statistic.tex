\doxysubsection{Detailed Description}
Base class representing a statistic within the "{}\+Tractography Results"{} IOD. A statistic is of a certain type and applies to a specific region of interest. For each Track Set and for each track there may be one or more statistics defined. \doxylink{requirements_The}{The} specializations can be found in classes \doxylink{class_trc_tracks_statistic}{Trc\+Tracks\+Statistic} and \doxylink{class_trc_track_set_statistic}{Trc\+Track\+Set\+Statistic}.
