\doxysubsection{Detailed Description}
Stores a collection of \doxylink{classvtk_array_extents}{vtk\+Array\+Extents} objects. 

\doxylink{classvtk_array_extents_list}{vtk\+Array\+Extents\+List} provides storage for a collection of \doxylink{classvtk_array_extents}{vtk\+Array\+Extents} instances. Constructors are provided for creating collections containing one, two, three, or four slices. To work with larger numbers of slices, use the default constructor, the \doxylink{classvtk_array_extents_list_a9508d3c2e651c8b7df2322010f6e9568}{Set\+Count()} method, and operator\+[]\+.

\doxylink{classvtk_array_extents_list}{vtk\+Array\+Extents\+List} is most commonly used with the vtk\+Interpolate() function, which is used to computed weighted sums of \doxylink{classvtk_array}{vtk\+Array} slices.
