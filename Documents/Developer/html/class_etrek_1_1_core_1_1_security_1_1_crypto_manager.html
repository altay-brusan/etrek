Detailed Description

Provides static methods for AES-based encryption and decryption.

CryptoManager offers utility functions to encrypt and decrypt passwords (or other sensitive data) using AES algorithms. All methods are static and stateless, making this class suitable for use as a general-purpose cryptographic utility. Future extensions may add support for other algorithms or data types.
