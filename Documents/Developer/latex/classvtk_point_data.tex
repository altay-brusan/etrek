\doxysubsection{Detailed Description}
represent and manipulate point attribute data 

\doxylink{classvtk_point_data}{vtk\+Point\+Data} is a class that is used to represent and manipulate point attribute data (e.\+g., scalars, vectors, normals, texture coordinates, etc.) Most of the functionality is handled by \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes}.

By default, {\ttfamily Ghost\+Types\+To\+Skip} is set to {\ttfamily DUPLICATEPOINT \texorpdfstring{$\vert$}{|} HIDDENPOINT}. See {\ttfamily \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes}} for the definition of those constants.
