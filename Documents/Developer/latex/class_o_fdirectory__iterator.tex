\doxysubsection{Detailed Description}
An iterator for iterating over all the files (and folders) contained in a given filesystem location. \doxylink{class_o_fdirectory__iterator}{OFdirectory\+\_\+iterator} implements a subset of the functionality described as std::\+filesystem::\+directory\+\_\+iterator, see \href{http://en.cppreference.com/w/cpp/filesystem/directory_iterator}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+filesystem/\+directory\+\_\+iterator}} for more information.
