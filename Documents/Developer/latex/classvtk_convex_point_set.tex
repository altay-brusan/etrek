\doxysubsection{Detailed Description}
a 3D cell defined by a set of convex points 

\doxylink{classvtk_convex_point_set}{vtk\+Convex\+Point\+Set} is a concrete implementation that represents a 3D cell defined by a convex set of points. An example of such a cell is an octant (from an octree). \doxylink{classvtk_convex_point_set}{vtk\+Convex\+Point\+Set} uses the ordered triangulations approach (\doxylink{classvtk_ordered_triangulator}{vtk\+Ordered\+Triangulator}) to create triangulations guaranteed to be compatible across shared faces. This allows a general approach to processing complex, convex cell types.
