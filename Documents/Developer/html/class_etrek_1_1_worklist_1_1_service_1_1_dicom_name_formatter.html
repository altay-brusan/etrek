Detailed Description

Utility class for formatting names in DICOM Person Name (PN) format.

DICOM PN format: FamilyName^GivenName^MiddleName^NamePrefix^NameSuffix This utility handles the common case: LastName^FirstName^MiddleName and properly handles empty components (no trailing/doubled carets).

Format name in DICOM PN format: LastName^FirstName^MiddleName.

Parameters

middleNameMiddle name (optional, can be empty)
lastNameLast/family name
Returns
QString in DICOM PN format with proper caret delimiters

Examples:

  • ("John", "", "Doe") -> "Doe^John"
  • ("John", "Q", "Doe") -> "Doe^John^Q"
  • ("John", "Q Public", "Doe") -> "Doe^John^Q Public"
  • ("", "", "Doe") -> "Doe"
  • ("John", "", "") -> "^John"
