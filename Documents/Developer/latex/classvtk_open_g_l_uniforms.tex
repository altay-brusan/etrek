\doxysubsection{Detailed Description}
helper class to set custom uniform variables in GLSL shaders. 

This class implements all Set\+Uniform\texorpdfstring{$\ast$}{*} functions supported by \doxylink{classvtk_shader_program}{vtk\+Shader\+Program} but instead of directly calling the underlying Open\+GL functions, it caches the name and value of the variable and provides a mechanism for client mappers to set all cached variables at once in a generic way.

\doxylink{requirements_The}{The} basic types of GLSL uniform variables supported by the class are the following:\+ int, float, vec2i, vec3, vec4, mat3, mat4, int\+[]\+, float\+[]\+, vec2i\+[]\+, vec3\+[]\+, vec4\+[]\+, mat4\+[]\+. All other types supported by Set\texorpdfstring{$\ast$}{*} functions undergo the same type conversions implemented in \doxylink{classvtk_shader_program}{vtk\+Shader\+Program}.
