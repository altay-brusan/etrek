\doxysubsection{Detailed Description}
A claim on input \doxylink{classvtk_cell}{vtk\+Cell} types registered by an output \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} subclass.

\doxylink{requirements_The}{The} \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} subclass with the highest priority replaces any prior entry with itself while subclasses with lower priorities take no action against higher-\/priority claims. Users may pre-\/populate \doxylink{classvtk_unstructured_grid_to_cell_grid}{vtk\+Unstructured\+Grid\+To\+Cell\+Grid}\textquotesingle{}s \doxylink{classvtk_unstructured_grid_to_cell_grid_1_1_transcribe_query}{Transcribe\+Query} with high-\/priority claims to affect the output.

An invalid Cell\+Type token indicates the input cells are unclaimed. \doxylink{requirements_The}{The} filter may be configured to fail, warn, or quietly succeed when unsupported input-\/cell types are present.
