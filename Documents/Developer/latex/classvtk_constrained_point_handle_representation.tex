\doxysubsection{Detailed Description}
point representation constrained to a 2D plane 

This class is used to represent a \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget}. It represents a position in 3D world coordinates that is constrained to a specified plane. \doxylink{requirements_The}{The} default look is to draw a white point when this widget is not selected or active, a thin green circle when it is highlighted, and a thicker cyan circle when it is active (being positioned). Defaults can be adjusted -\/ but take care to define cursor geometry that makes sense for this widget. \doxylink{requirements_The}{The} geometry will be aligned on the constraining plane, with the plane normal aligned with the X axis of the geometry (similar behavior to \doxylink{classvtk_glyph3_d}{vtk\+Glyph3D}).
