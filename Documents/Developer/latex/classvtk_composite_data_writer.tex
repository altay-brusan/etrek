legacy VTK file writer for \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} subclasses. 

\doxylink{classvtk_composite_data_writer}{vtk\+Composite\+Data\+Writer} is a writer for writing legacy VTK files for \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} and subclasses. \begin{DoxyWarning}{Warning}
This is an experimental format. Use XML-\/based formats for writing composite datasets. Saving composite dataset in legacy VTK format is expected to change in future including changes to the file layout.
