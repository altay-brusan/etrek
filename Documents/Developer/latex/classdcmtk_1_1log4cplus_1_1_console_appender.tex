\doxysubsection{Detailed Description}
\doxylink{classdcmtk_1_1log4cplus_1_1_console_appender}{Console\+Appender} appends log events to {\ttfamily STD\+\_\+\+NAMESPACE cout} or {\ttfamily STD\+\_\+\+NAMESPACE cerr} using a layout specified by the user. \doxylink{requirements_The}{The} default target is {\ttfamily STD\+\_\+\+NAMESPACE cout}.

\doxysubsubsubsection*{Properties}


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\ttfamily log\+To\+Std\+Err} }}]\hfill \\
When it is set true, the output stream will be {\ttfamily STD\+\_\+\+NAMESPACE cerr} instead of {\ttfamily STD\+\_\+\+NAMESPACE cout}.


\item[{\parbox[t]{\linewidth}{{\ttfamily Immediate\+Flush} }}]\hfill \\
When it is set true, output stream will be flushed after each appended event.
