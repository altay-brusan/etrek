\doxysubsection{Detailed Description}
provides thread-\/safe access to cells 

\doxylink{classvtk_generic_cell}{vtk\+Generic\+Cell} is a class that provides access to concrete types of cells. It\textquotesingle{}s main purpose is to allow thread-\/safe access to cells, supporting the vtk\+Data\+Set::\+\+Get\+Cell(vtk\+Generic\+Cell \texorpdfstring{$\ast$}{*}) method. \doxylink{classvtk_generic_cell}{vtk\+Generic\+Cell} acts like any type of cell, it just dereferences an internal representation. \doxylink{requirements_The}{The} \doxylink{classvtk_generic_cell_ab9d012c98f3d35fe6791f2756eb860d6}{Set\+Cell\+Type()} methods use \#define constants; these are defined in the file \doxylink{vtk_cell_type_8h_source}{vtk\+Cell\+Type.\+h}.
