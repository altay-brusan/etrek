\doxysubsection{Detailed Description}
Class for drawing 3D primitives to a graphical context. 

This defines the interface for drawing onto a 3D context. \doxylink{requirements_The}{The} context must be set up with a \doxylink{classvtk_context_device3_d}{vtk\+Context\+Device3D} derived class that provides the functions to facilitate the low level calls to the context. Currently only an Open\+GL based device is provided.
