\doxysubsection{Detailed Description}
Read ASCII or binary particle data and (optionally) one scalar value associated with each particle. 

\doxylink{classvtk_particle_reader}{vtk\+Particle\+Reader} reads either a binary or a text file of particles. Each particle can have associated with it an optional scalar value. So the format is:\+ x, y, z, scalar (all floats or doubles). \doxylink{requirements_The}{The} text file can consist of a comma delimited set of values. In most cases \doxylink{classvtk_particle_reader}{vtk\+Particle\+Reader} can automatically determine whether the file is text or binary. \doxylink{requirements_The}{The} data can be either float or double. Progress updates are provided. With respect to binary files, random access into the file to read pieces is supported.
