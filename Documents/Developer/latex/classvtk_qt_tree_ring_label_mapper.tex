\doxysubsection{Detailed Description}
draw text labels on a tree map 

\doxylink{classvtk_qt_tree_ring_label_mapper}{vtk\+Qt\+Tree\+Ring\+Label\+Mapper} is a mapper that renders text on a tree map. A tree map is a \doxylink{classvtk_tree}{vtk\+Tree} with an associated 4-\/tuple array used for storing the boundary rectangle for each vertex in the tree. \doxylink{requirements_The}{The} user must specify the array name used for storing the rectangles.

\doxylink{requirements_The}{The} mapper iterates through the tree and attempts and renders a label inside the vertex\textquotesingle{}s rectangle as long as the following conditions hold:\+
\begin{DoxyEnumerate}
\item \doxylink{requirements_The}{The} vertex level is within the range of levels specified for labeling.
\item \doxylink{requirements_The}{The} label can fully fit inside its box.
\item \doxylink{requirements_The}{The} label does not overlap an ancestor\textquotesingle{}s label.
\end{DoxyEnumerate}
