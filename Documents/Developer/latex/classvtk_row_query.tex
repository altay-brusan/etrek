\doxysubsection{Detailed Description}
abstract interface for queries that return row-\/oriented results. 

\doxylink{requirements_The}{The} abstract superclass of query classes that return row-\/oriented (table) results. A subclass will provide database-\/specific query parameters and implement the \doxylink{classvtk_row_query}{vtk\+Row\+Query} API to return query results:\+

\doxylink{classvtk_row_query_ab0ba19b40366f0f884b28d04e5434d4d}{Execute()} -\/ Execute the query. No results need to be retrieved at this point, unless you are performing caching.

\doxylink{classvtk_row_query_a2e649f564b8022061bf048b97871c09f}{Get\+Number\+Of\+Fields()} -\/ After \doxylink{classvtk_row_query_ab0ba19b40366f0f884b28d04e5434d4d}{Execute()} is performed, returns the number of fields in the query results.

\doxylink{classvtk_row_query_a4c1ebcabf9e388de4bdd4de7cead5eb0}{Get\+Field\+Name()} -\/ \doxylink{requirements_The}{The} name of the field at an index.

\doxylink{classvtk_row_query_a95f480d432048b4faccfe65bbcb49a75}{Get\+Field\+Type()} -\/ \doxylink{requirements_The}{The} data type of the field at an index.

\doxylink{classvtk_row_query_a46bdd49f8333a1554c7e3bcc7fc9838b}{Next\+Row()} -\/ Advances the query results by one row, and returns whether there are more rows left in the query.

\doxylink{classvtk_row_query_a45381c8cba3c83e915e96c24ef81982d}{Data\+Value()} -\/ Extract a single data value from the current row.

This ivar controls whether \doxylink{classvtk_row_query_afaace36abe9e40236b9d9ecda383cad3}{Get\+Field\+Index()} expects field names to be case-\/sensitive. \doxylink{requirements_The}{The} default is OFF, i.\+e. case is not preserved.
