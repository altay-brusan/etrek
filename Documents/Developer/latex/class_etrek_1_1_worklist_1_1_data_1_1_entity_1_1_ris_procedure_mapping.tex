\doxysubsection{Detailed Description}
Represents a mapping from external RIS procedure code to internal view. 

This entity maps procedure codes received from RIS systems (via MWL C-\/\+FIND) to internal view IDs used in the application. Each RIS connection can have its own set of mappings since different RIS systems may use different coding schemes.
