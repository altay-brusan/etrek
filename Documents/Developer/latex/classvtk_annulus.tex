implicit function for a annulus 

\doxylink{classvtk_annulus}{vtk\+Annulus} computes the implicit function and function gradient for an annulus composed of two co-\/axial cylinders. \doxylink{classvtk_annulus}{vtk\+Annulus} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. By default the Annulus is centered at the origin and the axis of rotation is along the y-\/axis. You can redefine the center and axis of rotation by setting the Center and Axis data members. (Note that it is also possible to use the superclass\textquotesingle{} \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function} transformation matrix if necessary to reposition by using \doxylink{classvtk_implicit_function_a4cf810b62220d5ea59c278ed00abdc2d}{Function\+Value()} and \doxylink{classvtk_implicit_function_ae82826d3dbbeb689289bedc5373aef2b}{Function\+Gradient()}.)

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} annulus is infinite in extent. To truncate the annulus in modeling operations use the \doxylink{classvtk_implicit_boolean}{vtk\+Implicit\+Boolean} in combination with clipping planes. 
\end{DoxyWarning}
