\doxysubsection{Detailed Description}
Legend item to display categorical data. 

\doxylink{classvtk_category_legend}{vtk\+Category\+Legend} will display a label and color patch for each value in a categorical data set. To use this class, you must first populate a \doxylink{classvtk_scalars_to_colors}{vtk\+Scalars\+To\+Colors} by using the Set\+Annotation() method. \doxylink{requirements_The}{The} other input to this class is a \doxylink{classvtk_variant_array}{vtk\+Variant\+Array}. This should contain the annotated values from the \doxylink{classvtk_scalars_to_colors}{vtk\+Scalars\+To\+Colors} that you wish to include within the legend.
