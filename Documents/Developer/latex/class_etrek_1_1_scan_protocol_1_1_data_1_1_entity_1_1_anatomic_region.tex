Persistable entity describing a standardized anatomical region. 

Stores display attributes and internal coding values for a body part used across scan protocols, validation, and UI. Equality compares only the surrogate key (\doxylink{class_etrek_1_1_scan_protocol_1_1_data_1_1_entity_1_1_anatomic_region_a3d6a2fb1d372b0b415c93a6b3d9a8702}{Id}).
