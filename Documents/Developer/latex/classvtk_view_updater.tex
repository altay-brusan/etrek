\doxysubsection{Detailed Description}
Updates views automatically. 

\doxylink{classvtk_view_updater}{vtk\+View\+Updater} registers with annotation change events for a set of annotation links, and updates all views when an annotation link fires an annotation changed event. This is often needed when multiple views share a selection with \doxylink{classvtk_annotation_link}{vtk\+Annotation\+Link}.
