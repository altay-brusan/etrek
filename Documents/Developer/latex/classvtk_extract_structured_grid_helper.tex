\doxysubsection{Detailed Description}
helper for extracting/\+sub-\/sampling structured datasets. 

\doxylink{classvtk_extract_structured_grid_helper}{vtk\+Extract\+Structured\+Grid\+Helper} provides some common functionality that is used by filters that extract and sub-\/sample structured data. Specifically, it provides functionality for calculating the mapping from the output extent of each process to the input extent.
