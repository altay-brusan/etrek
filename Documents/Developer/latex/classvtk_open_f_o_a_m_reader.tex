\doxysubsection{Detailed Description}
reads a dataset in Open\+FOAM format 

\doxylink{classvtk_open_f_o_a_m_reader}{vtk\+Open\+FOAMReader} creates a multiblock dataset. It reads mesh information and time dependent data. \doxylink{requirements_The}{The} poly\+Mesh folders contain mesh information. \doxylink{requirements_The}{The} time folders contain transient data for the cells. Each folder can contain any number of data files.
