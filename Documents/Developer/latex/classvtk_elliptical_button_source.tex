\doxysubsection{Detailed Description}
create a ellipsoidal-\/shaped button 

\doxylink{classvtk_elliptical_button_source}{vtk\+Elliptical\+Button\+Source} creates a ellipsoidal shaped button with texture coordinates suitable for application of a texture map. This provides a way to make nice looking 3D buttons. \doxylink{requirements_The}{The} buttons are represented as \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} that includes texture coordinates and normals. \doxylink{requirements_The}{The} button lies in the x-\/y plane.

To use this class you must define the major and minor axes lengths of an ellipsoid (expressed as width (x), height (y) and depth (z)). \doxylink{requirements_The}{The} button has a rectangular mesh region in the center with texture coordinates that range smoothly from (0,1). (This flat region is called the texture region.) \doxylink{requirements_The}{The} outer, curved portion of the button (called the shoulder) has texture coordinates set to a user specified value (by default (0,0). (This results in coloring the button curve the same color as the (s,t) location of the texture map.) \doxylink{requirements_The}{The} resolution in the radial direction, the texture region, and the shoulder region must also be set. \doxylink{requirements_The}{The} button can be moved by specifying an origin.
