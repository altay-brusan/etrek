Detailed Description

objects of this class represent individual RGB pixels. This class is used by the color quantization classes. For efficiency considerations, all methods are declared inline.

unsigned long DcmQuantPixel::hash ( ) const

this method computes an unsigned long hash value for the current pixel. The hash algorithm is taken from Jef Poskanzer's ppm utility library. The return value is guaranteed to be < DcmQuantHashSize.
