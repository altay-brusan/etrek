\doxysubsection{Detailed Description}
Integrate an initial value problem using 2nd order Runge-\/\+Kutta method. 

This is a concrete sub-\/class of \doxylink{classvtk_initial_value_problem_solver}{vtk\+Initial\+Value\+Problem\+Solver}. It uses a 2nd order Runge-\/\+Kutta method to obtain the values of a set of functions at the next time step.
