\doxysubsection{Detailed Description}
Interface for examination mode-\/specific behavior strategies. 

Defines the Strategy pattern interface for handling different examination modes (Clinical, Demo, Calibration, Test). Each mode implements this interface to provide mode-\/specific behavior for image persistence, DICOM creation, and workflow management.
