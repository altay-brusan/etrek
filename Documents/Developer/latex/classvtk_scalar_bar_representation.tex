\doxysubsection{Detailed Description}
represent scalar bar for \doxylink{classvtk_scalar_bar_widget}{vtk\+Scalar\+Bar\+Widget} 

This class represents a scalar bar for a \doxylink{classvtk_scalar_bar_widget}{vtk\+Scalar\+Bar\+Widget}. This class provides support for interactively placing a scalar bar on the 2D overlay plane. \doxylink{requirements_The}{The} scalar bar is defined by an instance of \doxylink{classvtk_scalar_bar_actor}{vtk\+Scalar\+Bar\+Actor}.

One specialty of this class is that if the scalar bar is moved near enough to an edge, it\textquotesingle{}s orientation is flipped to match that edge.
