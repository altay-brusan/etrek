\doxysubsection{Detailed Description}
Collects data from multiple inputs into one image. 

\doxylink{classvtk_image_append}{vtk\+Image\+Append} takes the components from multiple inputs and merges them into one output. \doxylink{requirements_The}{The} output images are append along the "{}\+Append\+Axis"{}. Except for the append axis, all inputs must have the same extent. All inputs must have the same number of scalar components. A future extension might be to pad or clip inputs to have the same extent. \doxylink{requirements_The}{The} output has the same origin and spacing as the first input. \doxylink{requirements_The}{The} origin and spacing of all other inputs are ignored. All inputs must have the same scalar type.
