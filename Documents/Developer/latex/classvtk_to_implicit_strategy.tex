\doxysubsection{Detailed Description}
Pure interface for strategies to transform explicit arrays into implicit arrays. \doxylink{requirements_The}{The} interface has two main components:\+ an {\ttfamily \doxylink{classvtk_to_implicit_strategy_a8db026d07e3bb12424c72bbb7b246980}{Estimate\+Reduction}} method which estimates by how much this strategy can reduce the memory usage of the array and a {\ttfamily \doxylink{classvtk_to_implicit_strategy_aff8a97b46498686c0e53f22225630c55}{Reduce}} method which returns a reduced array.
