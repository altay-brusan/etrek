\doxysubsection{Detailed Description}
keep track of edges (defined by pair of integer id\textquotesingle{}s) 

\doxylink{classvtk_generic_edge_table}{vtk\+Generic\+Edge\+Table} is used to indicate the existence of and hold information about edges. Similar to \doxylink{classvtk_edge_table}{vtk\+Edge\+Table}, this class is more sophisticated in that it uses reference counting to keep track of when information about an edge should be deleted.

\doxylink{classvtk_generic_edge_table}{vtk\+Generic\+Edge\+Table} is a helper class used in the adaptor framework. It is used during the tessellation process to hold information about the error metric on each edge. This avoids recomputing the error metric each time the same edge is visited.
