\doxysubsection{Detailed Description}
A 2D graphics item for rendering a tree and an associated heatmap. 

This item draws a tree and a heatmap as a part of a \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}. \doxylink{requirements_The}{The} input tree\textquotesingle{}s vertex data must contain at least two arrays. \doxylink{requirements_The}{The} first required array is a \doxylink{classvtk_string_array}{vtk\+String\+Array} called "{}node name"{}. This array corresponds to the first column of the input table. \doxylink{requirements_The}{The} second required array is a scalar array called "{}node weight"{}. This array is used by \doxylink{classvtk_tree_layout_strategy}{vtk\+Tree\+Layout\+Strategy} to set any particular node\textquotesingle{}s distance from the root of the tree.

\doxylink{requirements_The}{The} \doxylink{classvtk_newick_tree_reader}{vtk\+Newick\+Tree\+Reader} automatically initializes both of these required arrays in its output tree.
