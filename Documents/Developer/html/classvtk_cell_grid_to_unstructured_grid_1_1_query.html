Detailed Description

A query corresponding to this algorithm.

This query gets run on the input cell-grid.

Member Typedef Documentation

◆ ConnectivityCountType

using vtkCellGridToUnstructuredGrid::Query::ConnectivityCountType = std::map<vtkIdType, int>

This map is used to count the number of references to output points.

During the GenerateConnectivity pass, responders should increment values so each entry corresponds to the number of cells that reference the point ID which serves as the key.

◆ ConnectivityTransformType

using vtkCellGridToUnstructuredGrid::Query::ConnectivityTransformType = std::unordered_map<vtkIdType, vtkIdType>

Return a map of per-cell-type point IDs to unstructured-grid point IDs.

Responders should insert values as they use the incremental point-locator to transform connectivity. These maps can be tested to avoid incremental point insertion when possible.

◆ ConnectivityWeightType

using vtkCellGridToUnstructuredGrid::Query::ConnectivityWeightType = std::vector<float>

The reciprocal of this->GetConnectivityCount().

This vector is only valid during the GeneratePointData pass.

◆ OutputAllocations

using vtkCellGridToUnstructuredGrid::Query::OutputAllocations = std::unordered_map<vtkStringToken, OutputAllocation>

A map used to allocate space for the unstructured-grid's vtkCellArray.

This maps input cell typenames to OutputAllocation structures.

Member Enumeration Documentation

◆ PassType

enum vtkCellGridToUnstructuredGrid::Query::PassType : int

Passes performed by the query.

In between CountOutputs and GenerateConnectivity, the query class will allocate vtkCellArray storage.

In between GenerateConnectivity and GeneratePointData, the query class will allocate array storage for all arrays in the output vtkPointData.

Enumerator
CountOutputs 

Responders should insert into GetOutputAllocations().

GenerateConnectivity 

Responders should insert points into the locator, point-count map, and connectivity.

GeneratePointData 

Responders should populate point-data.
