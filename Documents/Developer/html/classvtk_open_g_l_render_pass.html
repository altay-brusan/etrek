Detailed Description

Abstract render pass with shader modifications.

Allows a render pass to update shader code using a new virtual API.

Member Function Documentation

◆ GetShaderStageMTime()

virtual vtkMTimeType vtkOpenGLRenderPass::GetShaderStageMTime ( )
virtual

For multi-stage render passes that need to change shader code during a single pass, use this method to notify a mapper that the shader needs to be rebuilt (rather than reuse the last cached shader. This method should return the last time that the shader stage changed, or 0 if the shader is single-stage.

Reimplemented in vtkDualDepthPeelingPass, and vtkValuePass.
