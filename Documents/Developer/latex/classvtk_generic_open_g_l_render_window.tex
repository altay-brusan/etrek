\doxysubsection{Detailed Description}
platform independent render window 

\doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window} provides a skeleton for implementing a render window using one\textquotesingle{}s own Open\+GL context and drawable. To be effective, one must register an observer for Window\+Make\+Current\+Event, Window\+Is\+Current\+Event and Window\+Frame\+Event. When this class sends a Window\+Is\+Current\+Event, the call data is an bool\texorpdfstring{$\ast$}{*} which one can use to return whether the context is current.
