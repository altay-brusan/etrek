{\footnotesize\ttfamily \label{class_l_s_dyna_meta_data_a8adf1812f728dc3eb55c918a451e4f38} 
enum \doxymbox{\hyperlink{class_l_s_dyna_meta_data_a8adf1812f728dc3eb55c918a451e4f38}{LSDyna\+Meta\+Data::\+\+LSDYNA\+\_\+\+TYPES}}}

LS-\/\+Dyna cell types. These may be used as values for the {\itshape cell\+Type} argument in member functions. One dataset is created for each cell type so that cells can have different attributes (temperature, pressure, etc.) defined over them. Note that {\itshape NUM\+\_\+\+CELL\+\_\+\+TYPES} is not a cell type, but an enumerant that specifies the total number of cell types. It is used to size arrays.
