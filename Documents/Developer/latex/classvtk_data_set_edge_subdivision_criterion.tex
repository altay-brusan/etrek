\doxysubsection{Detailed Description}
a subclass of \doxylink{classvtk_edge_subdivision_criterion}{vtk\+Edge\+Subdivision\+Criterion} for \doxylink{classvtk_data_set}{vtk\+Data\+Set} objects. 

This is a subclass of \doxylink{classvtk_edge_subdivision_criterion}{vtk\+Edge\+Subdivision\+Criterion} that is used for tessellating cells of a \doxylink{classvtk_data_set}{vtk\+Data\+Set}, particularly nonlinear cells.

It provides functions for setting the current cell being tessellated and a convenience routine, {\itshape \doxylink{classvtk_data_set_edge_subdivision_criterion_a85cd746b39f27d602e13c07943e199b3}{Evaluate\+Fields()}} to evaluate field values at a point. You should call {\itshape \doxylink{classvtk_data_set_edge_subdivision_criterion_a85cd746b39f27d602e13c07943e199b3}{Evaluate\+Fields()}} from inside {\itshape \doxylink{classvtk_data_set_edge_subdivision_criterion_ad4354e62153eaa90dc7ea3d4aa80122c}{Evaluate\+Location\+And\+Fields()}} whenever the result of {\itshape \doxylink{classvtk_data_set_edge_subdivision_criterion_ad4354e62153eaa90dc7ea3d4aa80122c}{Evaluate\+Location\+And\+Fields()}} will be true. Otherwise, do not call {\itshape \doxylink{classvtk_data_set_edge_subdivision_criterion_a85cd746b39f27d602e13c07943e199b3}{Evaluate\+Fields()}} as the midpoint is about to be discarded. ({\itshape Implementor\textquotesingle{}s note}:\+ This isn\textquotesingle{}t true if UGLY\+\_\+\+ASPECT\+\_\+\+RATIO\+\_\+\+HACK has been defined. But in that case, we don\textquotesingle{}t want the exact field values; we need the linearly interpolated ones at the midpoint for continuity.)
