\doxysubsection{Detailed Description}
Centralized context management service implementation. 

\doxylink{requirements_The}{The} \doxylink{class_etrek_1_1_core_1_1_context_1_1_context_manager}{Context\+Manager} maintains application-\/wide context information:\+
\begin{DoxyItemize}
\item Session context:\+ User info, sign-\/in time, workstation, institution
\item Workflow contexts:\+ Transient state for workflows (e.\+g., Examination)
\end{DoxyItemize}

This class is thread-\/safe and can be accessed from multiple threads.

Usage:\+
\begin{DoxyEnumerate}
\item Application\+Service creates and holds the \doxylink{class_etrek_1_1_core_1_1_context_1_1_context_manager}{Context\+Manager} instance
\item After login, Application\+Service sets the session context
\item When user selects a worklist item, the delegate sets workflow context
\item Builders fetch context and inject into \doxylink{struct_delegate_parameter}{Delegate\+Parameter} 
\end{DoxyEnumerate}
