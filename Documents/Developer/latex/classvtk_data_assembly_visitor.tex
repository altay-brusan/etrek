\doxysubsection{Detailed Description}
visitor API for \doxylink{classvtk_data_assembly}{vtk\+Data\+Assembly} 

\doxylink{classvtk_data_assembly_visitor}{vtk\+Data\+Assembly\+Visitor} defines a visitor API for \doxylink{classvtk_data_assembly}{vtk\+Data\+Assembly}. A concrete subclass of \doxylink{classvtk_data_assembly_visitor}{vtk\+Data\+Assembly\+Visitor} can be passed to {\ttfamily \doxylink{classvtk_data_assembly_aaf055b745500c5d291d09242ea91b51a}{vtk\+Data\+Assembly::\+\+Visit}} to execute custom code on each node in the data-\/assembly.

{\ttfamily \doxylink{classvtk_data_assembly_aaf055b745500c5d291d09242ea91b51a}{vtk\+Data\+Assembly::\+\+Visit}} will call {\ttfamily \doxylink{classvtk_data_assembly_visitor_ac9498953a998b324f6866e669e8ab139}{vtk\+Data\+Assembly\+Visitor::\+\+Visit}} on each node in the assembly (or chosen subtree). \doxylink{requirements_The}{The} traversal order, i.\+e. depth-\/first or breadth-\/first, is selected by the arguments passed to {\ttfamily \doxylink{classvtk_data_assembly_aaf055b745500c5d291d09242ea91b51a}{vtk\+Data\+Assembly::\+\+Visit}}. Before traversing a sub-\/tree for a particular node, {\ttfamily \doxylink{classvtk_data_assembly_visitor_af1f1dd42161072332399d346192e8178}{vtk\+Data\+Assembly\+Visitor::\+\+Get\+Traverse\+Subtree}} is called, if it returns false, the subtree is skipped. If it returns true, then then {\ttfamily \doxylink{classvtk_data_assembly_visitor_ace96704e608267b6111825179862d4a5}{vtk\+Data\+Assembly\+Visitor::\+\+Begin\+Sub\+Tree}} is called, followed by calls to {\ttfamily \doxylink{classvtk_data_assembly_visitor_ac9498953a998b324f6866e669e8ab139}{vtk\+Data\+Assembly\+Visitor::\+\+Visit}} for each of the child nodes, and finally {\ttfamily vtk\+Data\+Assembly\+Visitor::\+\+End\+Sub\+Tree} is called.

In depth-\/first order, the subtree traversal is recursive. Thus, after {\ttfamily \doxylink{classvtk_data_assembly_visitor_ace96704e608267b6111825179862d4a5}{Begin\+Sub\+Tree}} is called for specific node, all its children and their subtrees are traversed before {\ttfamily End\+Sub\+Tree} gets called for that node.

In breadth-\/first order, a first-\/in-\/first-\/out queue is used. A node is visited, i.\+e. {\ttfamily \doxylink{classvtk_data_assembly_visitor_ac9498953a998b324f6866e669e8ab139}{vtk\+Data\+Assembly\+Visitor::\+\+Visit}} called on it, then if {\ttfamily \doxylink{classvtk_data_assembly_visitor_af1f1dd42161072332399d346192e8178}{Get\+Traverse\+Subtree}} returns true, {\ttfamily \doxylink{classvtk_data_assembly_visitor_ac9498953a998b324f6866e669e8ab139}{Visit}} gets called on all its immediate children one after another followed by {\ttfamily End\+Sub\+Tree} on the parent node. As each of the child nodes are visited, they get added to the queue. Now, for each node in the queue, the process repeats i.\+e. {\ttfamily \doxylink{classvtk_data_assembly_visitor_af1f1dd42161072332399d346192e8178}{Get\+Traverse\+Subtree}} is called, followed by the subtree traversal for that node. This continues until the queue empty.
