Detailed Description

template<class DType>
class vtkImageStencilIterator< DType >

an image region iterator

This is an image iterator that can be used to iterate over a region of an image.

template<class DType>
vtkImageStencilIterator< DType >::vtkImageStencilIterator ( vtkImageData * image,
vtkImageStencilData * stencil = nullptr,
const int extent[6] = nullptr,
vtkAlgorithm * algorithm = nullptr,
int threadId = 0 )
inline

Create an iterator for the given image, with several options. If a stencil is provided, then the iterator's IsInStencil() method reports whether each span is inside the stencil. If an extent is provided, it iterates over the extent and ignores the rest of the image (the provided extent must be within the image extent). If a pointer to the algorithm is provided and threadId is set to zero, then progress events will provided for the algorithm.
