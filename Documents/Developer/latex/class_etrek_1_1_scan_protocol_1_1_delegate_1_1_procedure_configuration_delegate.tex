\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_scan_protocol_1_1_delegate}{Delegate} for radiographic procedure configuration. 

Implements the \doxylink{namespace_etrek_1_1_scan_protocol_1_1_delegate}{Delegate} pattern to handle business logic for procedure configuration. Connects \doxylink{class_procedure_configuration_widget}{Procedure\+Configuration\+Widget} to \doxylink{class_etrek_1_1_scan_protocol_1_1_delegate_1_1_scan_protocol_repository}{Scan\+Protocol\+Repository} for CRUD operations.

Key responsibilities:\+
\begin{DoxyItemize}
\item Receive procedure settings from the UI widget
\item Validate procedure configuration
\item Persist changes to database via \doxylink{class_etrek_1_1_scan_protocol_1_1_delegate_1_1_scan_protocol_repository}{Scan\+Protocol\+Repository}
\item Handle apply/\+accept/\+reject actions from settings dialog
\end{DoxyItemize}

Procedure configuration includes:\+
\begin{DoxyItemize}
\item Procedure name and code
\item Associated views (multi-\/view procedures)
\item Body part mappings
\item RIS procedure code mappings
\item Default technique presets
\end{DoxyItemize}
