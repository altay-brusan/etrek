\doxysubsection{Detailed Description}
Define the Valid\+Cell field used in \doxylink{classvtk_hyper_tree_grid_generate_fields}{vtk\+Hyper\+Tree\+Grid\+Generate\+Fields}. 

This is a class used by \doxylink{classvtk_hyper_tree_grid_generate_fields}{vtk\+Hyper\+Tree\+Grid\+Generate\+Fields} to add and compute the Valid\+Cell field.

This field has a value of 1 for leaf (non-\/refined) cells that are neither masked nor ghost, and 0 otherwise.
