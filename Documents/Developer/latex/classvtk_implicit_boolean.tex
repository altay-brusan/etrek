\doxysubsection{Detailed Description}
implicit function consisting of boolean combinations of implicit functions 

\doxylink{classvtk_implicit_boolean}{vtk\+Implicit\+Boolean} is an implicit function consisting of boolean combinations of implicit functions. \doxylink{requirements_The}{The} class has a list of functions (Function\+List) that are combined according to a specified operator (VTK\+\_\+\+UNION or VTK\+\_\+\+INTERSECTION or VTK\+\_\+\+DIFFERENCE). You can use nested combinations of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}\textquotesingle{}s (and/\+or \doxylink{classvtk_implicit_boolean}{vtk\+Implicit\+Boolean}) to create elaborate implicit functions. \doxylink{classvtk_implicit_boolean}{vtk\+Implicit\+Boolean} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.

\doxylink{requirements_The}{The} operators work as follows. \doxylink{requirements_The}{The} VTK\+\_\+\+UNION operator takes the minimum value of all implicit functions. \doxylink{requirements_The}{The} VTK\+\_\+\+INTERSECTION operator takes the maximum value of all implicit functions. \doxylink{requirements_The}{The} VTK\+\_\+\+DIFFERENCE operator subtracts the 2nd through last implicit functions from the first. \doxylink{requirements_The}{The} VTK\+\_\+\+UNION\+\_\+\+OF\+\_\+\+MAGNITUDES takes the minimum absolute value of the implicit functions.
