\doxysubsection{Detailed Description}
helper class to transform output of non-\/axis-\/aligned images 

\doxylink{classvtk_image_transform}{vtk\+Image\+Transform} is a helper class to transform the output of image filters (i.\+e., filter that input \doxylink{classvtk_image_data}{vtk\+Image\+Data}) by applying the Index to Physical transformation from the input image, which can include origin, spacing, direction. \doxylink{requirements_The}{The} transformation process is threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools} for performance.

Typically in application the single method \doxylink{classvtk_image_transform_a4ae12d105fa41917bedd21e6f0cbbf3b}{Transform\+Point\+Set()} is invoked to transform the output of an image algorithm (assuming that the image\textquotesingle{}s direction/\+orientation matrix is non-\/identity). Note that vtk\+Point\+Sets encompass \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} as well as vtk\+Unstructured\+Grids. In the future other output types may be added. Note that specific methods for transforming points, normals, and vectors is also provided by this class in case additional output data arrays need to be transformed (since \doxylink{classvtk_image_transform_a4ae12d105fa41917bedd21e6f0cbbf3b}{Transform\+Point\+Set()} only processes data arrays labeled as points, normals, and vectors).

\begin{DoxyWarning}{Warning}
This class assumes that any vectors are gradients, and vector arrays will therefore be transformed by first dividing by the spacing and then applying the inverse transpose of the direction matrix.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly. 
\end{DoxyWarning}
