\doxysubsection{Detailed Description}
lays out tree in stacked boxes or rings 

Performs a tree ring layout or "{}icicle"{} layout on a tree. This involves assigning a sector region to each vertex in the tree, and placing that information in a data array with four components per tuple representing (inner\+Radius, outer\+Radius, start\+Angle, end\+Angle).

This class may be assigned as the layout strategy to \doxylink{classvtk_area_layout}{vtk\+Area\+Layout}.
