\doxysubsection{Detailed Description}
blend images together using alpha or opacity 

\doxylink{classvtk_image_blend}{vtk\+Image\+Blend} takes L, LA, RGB, or RGBA images as input and blends them according to the alpha values and/\+or the opacity setting for each input.

\doxylink{requirements_The}{The} spacing, origin, extent, and number of components of the output are the same as those for the first input. If the input has an alpha component, then this component is copied unchanged into the output. In addition, if the first input has either one component or two components i.\+e. if it is either L (greyscale) or LA (greyscale + alpha) then all other inputs must also be L or LA.

Different blending modes are available:\+

{\itshape Normal} (default) :\+ This is the standard blending mode used by Open\+GL and other graphics packages. \doxylink{requirements_The}{The} output always has the same number of components and the same extent as the first input. \doxylink{requirements_The}{The} alpha value of the first input is not used in the blending computation, instead it is copied directly to the output. If Blend\+Alpha is set, the alpha value of the output is also computed using:\+


\begin{DoxyCode}{0}

\end{DoxyCode}


{\itshape Compound} :\+ Images are compounded together and each component is scaled by the sum of the alpha/\+opacity values. Use the Compound\+Threshold method to set specify a threshold in compound mode. Pixels with opacity\texorpdfstring{$\ast$}{*}alpha less or equal than this threshold are ignored. \doxylink{requirements_The}{The} alpha value of the first input, if present, is NOT copied to the alpha value of the output. \doxylink{requirements_The}{The} output always has the same number of components and the same extent as the first input. If Compound\+Alpha is set, the alpha value of the output is also computed using the alpha weighted blend calculation.
