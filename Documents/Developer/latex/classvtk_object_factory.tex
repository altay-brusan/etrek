\doxysubsection{Detailed Description}
abstract base class for vtk\+Object\+Factories 

\doxylink{classvtk_object_factory}{vtk\+Object\+Factory} is used to create vtk objects. \doxylink{requirements_The}{The} base class \doxylink{classvtk_object_factory}{vtk\+Object\+Factory} contains a static method Create\+Instance which is used to create vtk objects from the list of registered \doxylink{classvtk_object_factory}{vtk\+Object\+Factory} sub-\/classes. \doxylink{requirements_The}{The} first time Create\+Instance is called, all dll\textquotesingle{}s or shared libraries in the environment variable VTK\+\_\+\+AUTOLOAD\+\_\+\+PATH are loaded into the current process. \doxylink{requirements_The}{The} C functions vtk\+Load, and vtk\+Get\+Factory\+Version are called on each dll. To implement these functions in a shared library or dll, use the macro:\+ VTK\+\_\+\+FACTORY\+\_\+\+INTERFACE\+\_\+\+IMPLEMENT. VTK\+\_\+\+AUTOLOAD\+\_\+\+PATH is an environment variable containing a colon separated (semi-\/colon on win32) list of paths.

\doxylink{requirements_The}{The} \doxylink{classvtk_object_factory}{vtk\+Object\+Factory} can be use to override the creation of any object in VTK with a sub-\/class of that object. \doxylink{requirements_The}{The} factories can be registered either at run time with the VTK\+\_\+\+AUTOLOAD\+\_\+\+PATH, or at compile time with the \doxylink{classvtk_object_factory_aea6b8a316ef57bef630f888a7fabd9b5}{vtk\+Object\+Factory::\+\+Register\+Factory} method.
