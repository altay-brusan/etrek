\doxysubsection{Detailed Description}
\doxylink{classdcmtk_1_1log4cplus_1_1_rolling_file_appender}{Rolling\+File\+Appender} extends \doxylink{classdcmtk_1_1log4cplus_1_1_file_appender}{File\+Appender} to backup the log files when they reach a certain size.

\doxysubsubsubsection*{Properties}

Properties additional to {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_file_appender}{File\+Appender}}\textquotesingle{}s properties:\+


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\ttfamily Max\+File\+Size} }}]\hfill \\
This property specifies maximal size of output file. \doxylink{requirements_The}{The} value is in bytes. It is possible to use {\ttfamily MB} and {\ttfamily KB} suffixes to specify the value in megabytes or kilobytes instead.


\item[{\parbox[t]{\linewidth}{{\ttfamily Max\+Backup\+Index} }}]\hfill \\
This property limits the number of backup output files; e.\+g. how many {\ttfamily log.\+1}, {\ttfamily log.\+2} etc. files will be kept. 
\end{DoxyDescription}
