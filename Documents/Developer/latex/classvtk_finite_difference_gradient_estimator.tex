\doxysubsection{Detailed Description}
Use finite differences to estimate gradient. 

\doxylink{classvtk_finite_difference_gradient_estimator}{vtk\+Finite\+Difference\+Gradient\+Estimator} is a concrete subclass of \doxylink{classvtk_encoded_gradient_estimator}{vtk\+Encoded\+Gradient\+Estimator} that uses a central differences technique to estimate the gradient. \doxylink{requirements_The}{The} gradient at some sample location (x,y,z) would be estimated by:\+ \begin{DoxyVerb} nx = (f(x-dx,y,z) - f(x+dx,y,z)) / 2*dx;
 ny = (f(x,y-dy,z) - f(x,y+dy,z)) / 2*dy;
 nz = (f(x,y,z-dz) - f(x,y,z+dz)) / 2*dz;
\end{DoxyVerb}


This value is normalized to determine a unit direction vector and a magnitude. \doxylink{requirements_The}{The} normal is computed in voxel space, and dx = dy = dz = Sample\+Spacing\+In\+Voxels. A scaling factor is applied to convert this normal from voxel space to world coordinates.
