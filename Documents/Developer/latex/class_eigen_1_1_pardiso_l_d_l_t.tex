\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Matrix\+Type, int Options$>$\newline
class Eigen::\+\+Pardiso\+LDLT$<$ Matrix\+Type, Options $>$}
A sparse direct Cholesky (\doxylink{class_eigen_1_1_l_d_l_t}{LDLT}) factorization and solver based on the PARDISO library. 

This class allows to solve for A.\+X = B sparse linear problems via a LDL\texorpdfstring{$^\wedge$}{\string^}T Cholesky factorization using the Intel MKL PARDISO library. \doxylink{requirements_The}{The} sparse matrix A is assumed to be selfajoint and positive definite. For complex matrices, A can also be symmetric only, see the {\itshape Options} template parameter. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.
