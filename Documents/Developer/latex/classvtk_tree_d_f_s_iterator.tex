\doxysubsection{Detailed Description}
depth first iterator through a \doxylink{classvtk_graph}{vtk\+Graph} 

\doxylink{classvtk_tree_d_f_s_iterator}{vtk\+Tree\+DFSIterator} performs a depth first search traversal of a tree.

First, you must set the tree on which you are going to iterate, and then optionally set the starting vertex and mode. \doxylink{requirements_The}{The} mode is either DISCOVER (default), in which case vertices are visited as they are first reached, or FINISH, in which case vertices are visited when they are done, i.\+e. all adjacent vertices have been discovered already.

After setting up the iterator, the normal mode of operation is to set up a {\ttfamily while(iter-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_tree_iterator_a623abb89baaf70363be33c819f8fc3db}{Has\+Next()})} loop, with the statement {\ttfamily vtk\+Id\+Type vertex = iter-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_tree_iterator_a154a66ddfa67dc5cdc1ba33dcd9368e5}{Next()}} inside the loop.
