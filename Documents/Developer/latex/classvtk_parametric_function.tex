\doxysubsection{Detailed Description}
abstract interface for parametric functions 

\doxylink{classvtk_parametric_function}{vtk\+Parametric\+Function} is an abstract interface for functions defined by parametric mapping i.\+e. f(u,v,w)-\/\texorpdfstring{$>$}{>}(x,y,z) where u\+\_\+min \texorpdfstring{$<$}{<}= u \texorpdfstring{$<$}{<} u\+\_\+max, v\+\_\+min \texorpdfstring{$<$}{<}= v \texorpdfstring{$<$}{<} v\+\_\+max, w\+\_\+min \texorpdfstring{$<$}{<}= w \texorpdfstring{$<$}{<} w\+\_\+max. (For notational convenience, we will write f(u)-\/\texorpdfstring{$>$}{>}x and assume that u means (u,v,w) and x means (x,y,z).)

\doxylink{requirements_The}{The} interface contains the pure virtual function, \doxylink{classvtk_parametric_function_a5d13e377b1cff56856b60d10bb66be34}{Evaluate()}, that generates a point and the derivatives at that point which are then used to construct the surface. A second pure virtual function, \doxylink{classvtk_parametric_function_abb043638834315b6f18eb049ab8fdb9e}{Evaluate\+Scalar()}, can be used to generate a scalar for the surface. Finally, the \doxylink{classvtk_parametric_function_a093975fadf60dc8ce3ea0baac1b2ca34}{Get\+Dimension()} virtual function is used to differentiate 1D, 2D, and 3D parametric functions. Since this abstract class defines a pure virtual API, its subclasses must implement the pure virtual functions \doxylink{classvtk_parametric_function_a093975fadf60dc8ce3ea0baac1b2ca34}{Get\+Dimension()}, \doxylink{classvtk_parametric_function_a5d13e377b1cff56856b60d10bb66be34}{Evaluate()} and \doxylink{classvtk_parametric_function_abb043638834315b6f18eb049ab8fdb9e}{Evaluate\+Scalar()}.

This class has also methods for defining a range of parametric values (u,v,w).
