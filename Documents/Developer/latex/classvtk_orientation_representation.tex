\doxysubsection{Detailed Description}
a class defining the representation for the \doxylink{classvtk_orientation_widget}{vtk\+Orientation\+Widget} 

This class is a concrete representation for the \doxylink{classvtk_orientation_widget}{vtk\+Orientation\+Widget}. \doxylink{requirements_The}{The} widget is represented by three flat tori of different colors in each base direction (X/\+\+Y/\+Z). Additional arrows can be added to it for each direction in order to simplify grabbing and understanding. Their default look is a diamond shape, but they can be customized to look like real double arrows.

To use this representation, you can use the \doxylink{classvtk_orientation_representation_a82a1aba1672d4c856ae289520d8672f8}{Place\+Widget()} method to position the widget around an actor and scale it properly. You can retrieve orientation values with component-\/wise getters or through a \doxylink{classvtk_transform}{vtk\+Transform}.
