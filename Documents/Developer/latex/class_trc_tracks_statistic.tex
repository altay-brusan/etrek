\doxysubsection{Detailed Description}
Class representing a statistic for Tracks in Track Set. Besides describing information like type of statistic, region o interest and units of the statistic values, the statistic defines a single statistic value for each track. Thus the number of statistic values must be identical to the number of tracks in the containing Track Set.
