helper for the \doxylink{classvtk_graph}{vtk\+Graph} class that allows the graph to be distributed across multiple memory spaces. 

A distributed graph helper can be attached to an empty \doxylink{classvtk_graph}{vtk\+Graph} object to turn the \doxylink{classvtk_graph}{vtk\+Graph} into a distributed graph, whose vertices and edges are distributed across several different processors. \doxylink{classvtk_distributed_graph_helper}{vtk\+Distributed\+Graph\+Helper} is an abstract class. Use a subclass of \doxylink{classvtk_distributed_graph_helper}{vtk\+Distributed\+Graph\+Helper}, such as vtk\+PBGLDistributed\+Graph\+Helper, to build distributed graphs.

\doxylink{requirements_The}{The} distributed graph helper provides facilities used by \doxylink{classvtk_graph}{vtk\+Graph} to communicate with other processors that store other parts of the same distributed graph. \doxylink{requirements_The}{The} only user-\/level functionality provided by \doxylink{classvtk_distributed_graph_helper}{vtk\+Distributed\+Graph\+Helper} involves this communication among processors and the ability to map between "{}distributed"{} vertex and edge IDs and their component parts (processor and local index). For example, the \doxylink{classvtk_distributed_graph_helper_ae5707938f2f434f6111d3b227b2142e5}{Synchronize()} method provides a barrier that allows all processors to catch up to the same point in the code before any processor can leave that \doxylink{classvtk_distributed_graph_helper_ae5707938f2f434f6111d3b227b2142e5}{Synchronize()} call. For example, one would call \doxylink{classvtk_distributed_graph_helper_ae5707938f2f434f6111d3b227b2142e5}{Synchronize()} after adding many edges to a distributed graph, so that all processors can handle the addition of inter-\/processor edges and continue, after the \doxylink{classvtk_distributed_graph_helper_ae5707938f2f434f6111d3b227b2142e5}{Synchronize()} call, with a consistent view of the distributed graph. For more information about manipulating (distributed) graphs, see the \doxylink{classvtk_graph}{vtk\+Graph} documentation.
