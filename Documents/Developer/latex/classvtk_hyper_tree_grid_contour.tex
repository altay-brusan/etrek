\doxysubsection{Detailed Description}
Extract cells from a hyper tree grid where selected scalar value is within given range. 

This filter extracts cells from a hyper tree grid that satisfy the following contour:\+ a cell is considered to be within range if its value for the active scalar is within a specified range (inclusive). \doxylink{requirements_The}{The} output remains a hyper tree grid.
