\doxysubsection{Detailed Description}
Class for storing the "{}\+Basic Coded Entry Attributes"{}. This class should be used to define code constants since it is a lightweight structure that does not carry any overhead and also does not perform any unnecessary checks on the data passed to it. Furthermore, the individual values cannot be modified after an instance of this class has been constructed. Therefore, the members can be accessed publicly.
