\doxysubsection{Detailed Description}
implicit object to represent cell connectivity 

\doxylink{classvtk_structured_cell_array}{vtk\+Structured\+Cell\+Array} stores dataset topologies as an structured connectivity table listing the point ids that make up each cell.

Internally, the connectivity is stored as a \doxylink{classvtk_implicit_array}{vtk\+Implicit\+Array} that is constructed using the Set\+Data function by providing the dimensions of the dataset and a flag indicating whether the data should use voxel/\+pixel orientation.

This class was designed as a more performant alternative to \doxylink{classvtk_structured_data_a4e76a1d37c32ac11b92bb0fb6ffcb862}{vtk\+Structured\+Data::\+\+Get\+Cell\+Points}.
