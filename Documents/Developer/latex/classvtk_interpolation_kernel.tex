\doxysubsection{Detailed Description}
base class for interpolation kernels 

\doxylink{classvtk_interpolation_kernel}{vtk\+Interpolation\+Kernel} specifies an abstract interface for interpolation kernels. An interpolation kernel is used to produce an interpolated data value at a point X from the points + data in a local neighborhood surrounding X. For example, given the N nearest points surrounding X, the interpolation kernel provides N weights, which when combined with the N data values associated with these nearest points, produces an interpolated data value at point X.

Note that various kernel initialization methods are provided. \doxylink{requirements_The}{The} basic method requires providing a point locator to accelerate neighborhood queries. Some kernels may refer back to the original dataset, or the point attribute data associated with the dataset. \doxylink{requirements_The}{The} initialization method enables different styles of initialization and is kernel-\/dependent.

Typically the kernels are invoked in two parts:\+ first, the basis is computed using the supplied point locator and dataset. This basis is a local footprint of point surrounding a poitnX. In this footprint are the neighboring points used to compute the interpolation weights. Then, the weights are computed from points forming the basis. However, advanced users can develop their own basis, skipping the \doxylink{classvtk_interpolation_kernel_ab53f901edf454be405622810e88a1ca5}{Compute\+Basis()} method, and then invoke \doxylink{classvtk_interpolation_kernel_a92d05d3c94a4a58ba07db667bb97624a}{Compute\+Weights()} directly.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} \doxylink{classvtk_interpolation_kernel_ab53f901edf454be405622810e88a1ca5}{Compute\+Basis()} and \doxylink{classvtk_interpolation_kernel_a92d05d3c94a4a58ba07db667bb97624a}{Compute\+Weights()} methods must be thread safe as they are used in threaded algorithms.
\end{DoxyWarning}

Given a point x (and optional associated point id), determine the points around x which form an interpolation basis. \doxylink{requirements_The}{The} user must provide the \doxylink{classvtk_id_list}{vtk\+Id\+List} p\+Ids, which will be dynamically resized as necessary. \doxylink{requirements_The}{The} method returns the number of points in the basis. Typically this method is called before \doxylink{classvtk_interpolation_kernel_a92d05d3c94a4a58ba07db667bb97624a}{Compute\+Weights()}. Note that pt\+Id is optional in most cases, although in some kernels it is used to facilitate basis computation.
