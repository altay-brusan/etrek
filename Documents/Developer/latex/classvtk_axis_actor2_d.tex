\doxysubsection{Detailed Description}
Create an axis with tick marks and labels. 

\doxylink{classvtk_axis_actor2_d}{vtk\+Axis\+Actor2D} creates an axis with tick marks, labels, and/\+or a title, depending on the particular instance variable settings. \doxylink{classvtk_axis_actor2_d}{vtk\+Axis\+Actor2D} is a 2D actor; that is, it is drawn on the overlay plane and is not occluded by 3D geometry. To use this class, you typically specify two points defining the start and end points of the line (x-\/y definition using \doxylink{classvtk_coordinate}{vtk\+Coordinate} class), the number of labels, and the data range (min,max).\hypertarget{classvtk_axis_actor2_d_autotoc_md784}{}\doxysubsubsection{\texorpdfstring{Display}{Display}}\label{classvtk_axis_actor2_d_autotoc_md784}
You can also control what parts of the axis are visible including the line, the tick marks, the labels, and the title.

You can also specify the label format through the Label\+Text\+Property. A legacy printf style format is still available.

This class decides what font size to use.

Set the text property/\+attributes of the title and the labels through the \doxylink{classvtk_text_property}{vtk\+Text\+Property} objects associated to this actor.

Labels are drawn on the "{}right"{} side of the axis. \doxylink{requirements_The}{The} "{}right"{} side is the side of the axis on the right as you move from Position to Position2. \doxylink{requirements_The}{The} way the labels and title line up with the axis and tick marks depends on whether the line is considered horizontal or vertical.\hypertarget{classvtk_axis_actor2_d_autotoc_md785}{}\doxysubsubsection{\texorpdfstring{Number of ticks and their position}{Number of ticks and their position}}\label{classvtk_axis_actor2_d_autotoc_md785}
When {\ttfamily Adjust\+Labels} is on, \doxylink{classvtk_axis_actor2_d}{vtk\+Axis\+Actor2D} also decides how to create reasonable tick marks and labels. However, it does not follow {\ttfamily Number\+Of\+Labels} target.

{\ttfamily Snap\+Labels\+To\+Grid} is a similar mode and should be preferred. It uses {\ttfamily Number\+Of\+Labels} as a target to produce the list of labels. \doxylink{requirements_The}{The} number of labels and the range of values may not match the number specified, but should be close.

When the computed {\ttfamily Adjusted\+Range} is larger than {\ttfamily Range}, some ticks may be outside of {\ttfamily Range}. They are not displayed.

When {\ttfamily Ruler\+Mode} is on, {\ttfamily Ruler\+Distance} is used to controls the ticks position and thus their number. Otherwise {\ttfamily Number\+Of\+Labels} is used as a target for number of ticks.\hypertarget{classvtk_axis_actor2_d_autotoc_md786}{}\doxysubsubsection{\texorpdfstring{Details}{Details}}\label{classvtk_axis_actor2_d_autotoc_md786}
\doxylink{requirements_The}{The} \doxylink{classvtk_actor2_d}{vtk\+Actor2D} instance variables Position and Position2 are instances of \doxylink{classvtk_coordinate}{vtk\+Coordinate}. Note that the Position2 is an absolute position in that class (it was by default relative to Position in \doxylink{classvtk_actor2_d}{vtk\+Actor2D}).

What this means is that you can specify the axis in a variety of coordinate systems. Also, the axis does not have to be either horizontal or vertical. \doxylink{requirements_The}{The} tick marks are created so that they are perpendicular to the axis.
