\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type, bool Is\+Str\+Sym$>$\newline
class Eigen::\+\+Pastix\+LU$<$ \+\_\+\+Matrix\+Type, Is\+Str\+Sym $>$}
Interface to the Pa\+Stix solver. 

\doxylink{struct_eigen_1_1_sparse}{Sparse} direct LU solver based on Pa\+StiX library.

This class is used to solve the linear systems A.\+X = B via the Pa\+Stix library. \doxylink{requirements_The}{The} matrix can be either real or complex, symmetric or not.

\begin{DoxySeeAlso}{See also}
Tutorial\+Sparse\+Direct\+Solvers
\end{DoxySeeAlso}
This class is used to solve the linear systems A.\+X = B with a supernodal LU factorization in the Pa\+StiX library. \doxylink{requirements_The}{The} matrix A should be squared and nonsingular Pa\+StiX requires that the matrix A has a symmetric structural pattern. This interface can symmetrize the input matrix otherwise. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.
