\doxysubsection{Detailed Description}
This is a very simple filter based on \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} matching, which can be used to reject messages with Log\+Levels outside a certain range.

\doxylink{requirements_The}{The} filter admits three options {\bfseries{Log\+Level\+Min}}, {\bfseries{Log\+Level\+Max}} and {\bfseries{Accept\+On\+Match}}.

If the \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} of the Logging event is not between Min and Max (inclusive), then {\ttfamily \doxylink{dcmtk_2include_2dcmtk_2oflog_2spi_2filter_8h_a0043ad60fd9daa537b91d85c2a1ce6c9a59680204effd058f48bb93b132035f8e}{DENY}} is returned.

If the Logging event \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} is within the specified range, then if {\bfseries{Accept\+On\+Match}} is true, {\ttfamily \doxylink{dcmtk_2include_2dcmtk_2oflog_2spi_2filter_8h_a0043ad60fd9daa537b91d85c2a1ce6c9ac3b66d89b8015da248c5310b7fde82fb}{ACCEPT}} is returned, and if {\bfseries{Accept\+On\+Match}} is false, {\ttfamily \doxylink{dcmtk_2include_2dcmtk_2oflog_2spi_2filter_8h_a0043ad60fd9daa537b91d85c2a1ce6c9a79b975eda15dc706d2d083531a3d664c}{NEUTRAL}} is returned.

If {\ttfamily Log\+Level\+Min} is not defined, then there is no minimum acceptable \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} (ie a \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} is never rejected for being too "{}low"{}/\+unimportant). If {\ttfamily Log\+Level\+Max} is not defined, then there is no maximum acceptable \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} (ie a \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} is never rejected for being too "{}high"{}/\+important).

Refer to the {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_appender_ae345896133340154052dca13ce1dcf20}{set\+Threshold}} method available to {\ttfamily all} appenders for a more convenient way to filter out events by \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level}.
