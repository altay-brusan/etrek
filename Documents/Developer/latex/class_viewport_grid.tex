\doxysubsection{Detailed Description}
Container widget managing multiple \doxylink{class_image_viewport}{Image\+Viewport} widgets in a grid. 

Supports layouts:\+
\begin{DoxyItemize}
\item SINGLE:\+ 1x1 (one viewport)
\item ONE\+\_\+\+BY\+\_\+\+TWO:\+ 1x2 (two viewports side by side)
\item TWO\+\_\+\+BY\+\_\+\+ONE:\+ 2x1 (two viewports stacked)
\item TWO\+\_\+\+BY\+\_\+\+TWO:\+ 2x2 (four viewports) 
\end{DoxyItemize}
