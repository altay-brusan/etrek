\doxysubsection{Detailed Description}
Class managing an SR document tree that is based on an arbitrary SR template. This class provides a more template-\/specific API than the general subtree class and should be used for non-\/root templates only. \begin{DoxyNote}{Note}
\doxylink{requirements_The}{The} main focus of this class currently lies in the creation of SR documents that are based on an SR non-\/root template. Support for reading SR documents into the underlying structures might be added in the future. 
\end{DoxyNote}
