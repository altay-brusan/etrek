\doxysubsection{Detailed Description}
performs collision determination between two polyhedral surfaces 

\doxylink{classvtk_collision_detection_filter}{vtk\+Collision\+Detection\+Filter} performs collision determination between two polyhedral surfaces using two instances of \doxylink{classvtk_o_b_b_tree}{vtk\+OBBTree}. Set the polydata inputs, the tolerance and transforms or matrices. If Collision\+Mode is set to All\+Contacts, the Contacts output will be lines of contact. If Collision\+Mode is First\+Contact or Half\+Contacts then the Contacts output will be vertices. See below for an explanation of these options.

This class can be used to clip one polydata surface with another, using the Contacts output as a loop set in \doxylink{classvtk_select_poly_data}{vtk\+Select\+Poly\+Data}
