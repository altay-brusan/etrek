\doxysubsection{Detailed Description}
Process communication using Sockets. 

This is a concrete implementation of \doxylink{classvtk_communicator}{vtk\+Communicator} which supports interprocess communication using BSD style sockets. It supports byte swapping for the communication of machines with different endianness.

\begin{DoxyWarning}{Warning}
Communication between 32 bit and 64 bit systems is not fully supported. If a type does not have the same length on both systems, this communicator can not be used to transfer data of that type.
\end{DoxyWarning}
