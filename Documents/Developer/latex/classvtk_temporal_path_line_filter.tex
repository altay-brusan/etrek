\doxysubsection{Detailed Description}
Generate a Polydata Pointset from any Dataset. 

\doxylink{classvtk_temporal_path_line_filter}{vtk\+Temporal\+Path\+Line\+Filter} takes any dataset as input, it extracts the point locations of all cells over time to build up a polyline trail. \doxylink{requirements_The}{The} point number (index) is used as the \textquotesingle{}key\textquotesingle{} if the points are randomly changing their respective order in the points list, then you should specify a scalar that represents the unique ID. This is intended to handle the output of a filter such as the \doxylink{classvtk_particle_tracer}{vtk\+Particle\+Tracer}.
