\doxysubsection{Detailed Description}
write Stanford PLY file format 

\doxylink{classvtk_p_l_y_writer}{vtk\+PLYWriter} writes polygonal data in Stanford University PLY format (see \href{http://graphics.stanford.edu/data/3Dscanrep/}{\texttt{http:\+/\+/\+graphics.\+stanford.\+edu/\+data/\+3\+Dscanrep/\+}}). \doxylink{requirements_The}{The} data can be written in either binary (little or big endian) or ASCII representation. As for Point\+Data and Cell\+Data, \doxylink{classvtk_p_l_y_writer}{vtk\+PLYWriter} cannot handle normals or vectors. It only handles RGB Point\+Data and Cell\+Data. You need to set the name of the array (using Set\+Name for the array and Set\+Array\+Name for the writer). If the array is not a \doxylink{classvtk_unsigned_char_array}{vtk\+Unsigned\+Char\+Array} with 3 or 4 components, you need to specify a \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} to map the scalars to RGB.

To enable saving out alpha (opacity) values, you must enable alpha using {\ttfamily vtk\+PLYWriter::\+\+Set\+Enable\+Alpha()}.

\begin{DoxyWarning}{Warning}
PLY does not handle big endian versus little endian correctly.
\end{DoxyWarning}
