\doxysubsection{Detailed Description}
abstract superclass for all graph layout strategies 

All graph layouts should subclass from this class. \doxylink{classvtk_graph_layout_strategy}{vtk\+Graph\+Layout\+Strategy} works as a plug-\/in to the \doxylink{classvtk_graph_layout}{vtk\+Graph\+Layout} algorithm. \doxylink{requirements_The}{The} \doxylink{classvtk_graph_layout_strategy_a14f90ab69c42daa54714afdf45fe0148}{Layout()} function should perform some reasonable "{}chunk"{} of the layout. This allows the user to be able to see the progress of the layout. Use \doxylink{classvtk_graph_layout_strategy_a450d0806be9831a70c76fa179b0cb4d3}{Is\+Layout\+Complete()} to tell the user when there is no more layout to perform.

Thanks to Brian Wylie from Sandia National Laboratories for adding incremental layout capabilities.
