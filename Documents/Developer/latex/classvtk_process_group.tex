\doxysubsection{Detailed Description}
A subgroup of processes from a communicator. 

This class is used for creating groups of processes. A \doxylink{classvtk_process_group}{vtk\+Process\+Group} is initialized by passing the controller or communicator on which the group is based off of. You can then use the group to subset and reorder the processes. Eventually, you can pass the group object to the Create\+Sub\+Controller method of \doxylink{classvtk_multi_process_controller}{vtk\+Multi\+Process\+Controller} to create a controller for the defined group of processes. You must use the same controller (or attached communicator) from which this group was initialized with.
