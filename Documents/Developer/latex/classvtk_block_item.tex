\doxysubsection{Detailed Description}
a \doxylink{classvtk_context_item}{vtk\+Context\+Item} that draws a block (optional label). 

This is a \doxylink{classvtk_context_item}{vtk\+Context\+Item} that can be placed into a \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}. It draws a block of the given dimensions, and reacts to mouse events.

\doxylink{classvtk_block_item}{vtk\+Block\+Item} can also be used to render label in the scene. \doxylink{requirements_The}{The} label properties can be set using {\ttfamily \doxylink{classvtk_text_property}{vtk\+Text\+Property}} accessed via {\ttfamily Get\+Label\+Properties}.
