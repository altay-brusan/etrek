\doxysubsection{Detailed Description}
a node within a VTK scene graph 

This is the superclass for all nodes within a VTK scene graph. It contains the API for a node. It supports the essential operations such as graph creation, state storage and traversal. Child classes adapt this to VTK\textquotesingle{}s major rendering classes. Grandchild classes adapt those to for APIs of different rendering libraries.
