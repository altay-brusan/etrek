\doxysubsection{Detailed Description}
An Elemental data type that holds a definition of a numerical quadrature scheme. \doxylink{requirements_The}{The} definition contains the requisite information to interpolate to the so called quadrature points of the specific scheme. namely:\+


\begin{DoxyPre}
1)
A matrix of shape function weights(shape functions evaluated at parametric coordinates of the quadrature points).

2)
\doxylink{requirements_The}{The} number of quadrature points and cell nodes. These parameters
size the matrix, and allow for convenient evaluation by users
of the definition.
\end{DoxyPre}
