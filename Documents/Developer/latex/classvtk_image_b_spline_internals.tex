\doxysubsection{Detailed Description}
BSpline code from P. Thevenaz. 

\doxylink{classvtk_image_b_spline_internals}{vtk\+Image\+BSpline\+Internals} provides code for image interpolation with b-\/splines of various degrees. This code computes the coefficients from the image, and computes the weights for the b-\/spline kernels.

This class is based on code provided by Philippe Thevenaz of EPFL, Lausanne, Switzerland. Please acknowledge his contribution by citing the following paper:\+ \+[1]\+ P. Thevenaz, T. Blu, M. Unser, "{}\+Interpolation Revisited,"{} IEEE Transactions on Medical Imaging 19(7):\+739-\/758, 2000.

\doxylink{requirements_The}{The} clamped boundary condition (which is the default) is taken from code presented in the following paper:\+ \+[2]\+ D. Ruijters, P. Thevenaz, "{}\+GPU Prefilter for Accurate Cubic B-\/spline Interpolation,"{} \doxylink{requirements_The}{The} Computer Journal, doi:\+ 10.\+1093/\+comjnl/\+bxq086, 2010.
