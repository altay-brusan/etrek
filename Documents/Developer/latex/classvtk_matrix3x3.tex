represent and manipulate 3x3 transformation matrices 

\doxylink{classvtk_matrix3x3}{vtk\+Matrix3x3} is a class to represent and manipulate 3x3 matrices. Specifically, it is designed to work on 3x3 transformation matrices found in 2D rendering using homogeneous coordinates \+[x y w]\+.
