\doxysubsection{Detailed Description}
Default representation for \doxylink{classvtk_parallelopiped_widget}{vtk\+Parallelopiped\+Widget}. 

This class provides the default geometrical representation for \doxylink{classvtk_parallelopiped_widget}{vtk\+Parallelopiped\+Widget}. As a result of interactions of the widget, this representation can take on of the following shapes:\+ 

1) A parallelopiped. (8 handles, 6 faces) 

2) Paralleopiped with a chair depression on any one handle. (A chair is a depression on one of the handles that carves inwards so as to allow the user to visualize cuts in the volume). (14 handles, 9 faces).
