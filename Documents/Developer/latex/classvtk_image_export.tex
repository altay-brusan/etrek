\doxysubsection{Detailed Description}
Export VTK images to third-\/party systems. 

\doxylink{classvtk_image_export}{vtk\+Image\+Export} provides a way of exporting image data at the end of a pipeline to a third-\/party system or to a simple C array. Applications can use this to get direct access to the image data in memory. A callback interface is provided to allow connection of the VTK pipeline to a third-\/party pipeline. This interface conforms to the interface of \doxylink{classvtk_image_import}{vtk\+Image\+Import}. In Python it is possible to use this class to write the image data into a python string that has been pre-\/allocated to be the correct size. \begin{DoxySeeAlso}{See also}
