\doxysubsection{Detailed Description}
Builds the space leaping data structure. 

This is an optimized multi-\/threaded imaging filter that builds the space leaping datastructure, used by \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper}. Empty space leaping is used to skip large empty regions in the scalar opacity and/\+or the gradient opacity transfer functions. Depending on the various options set by \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper}, the class will internally invoke one of the many optimized routines to compute the min/\+max/\+gradient-\/max values within a fixed block size, trying to compute everything in a single multi-\/threaded pass through the data

\doxylink{requirements_The}{The} block size may be changed at compile time. Its ifdef\textquotesingle{}ed to 4 in the CXX file.
