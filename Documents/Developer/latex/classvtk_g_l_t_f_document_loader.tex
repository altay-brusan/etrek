\doxysubsection{Detailed Description}
Deserialize a GLTF model file. 

vtk\+GLTFDocument loader is an internal utility class which defines data structures and functions with the purpose of deserializing a gl\+TF model from a gl\+TF file, loading its data from binary buffers and creating vtk objects with the extracted geometry. It contains an internal \doxylink{structvtk_g_l_t_f_document_loader_1_1_model}{Model} structure into which all loading is performed.

\doxylink{requirements_The}{The} GL Transmission Format (gl\+TF) is an API-\/neutral runtime asset delivery format. A gl\+TF asset is represented by:\+
\begin{DoxyItemize}
\item A JSON-\/formatted file (.gltf) containing a full scene description:\+ node hierarchy, materials, cameras, as well as descriptor information for meshes, animations, and other constructs
\item Binary files (.bin) containing geometry and animation data, and other buffer-\/based data
\item \doxylink{structvtk_g_l_t_f_document_loader_1_1_image}{Image} files (.jpg, .png) for textures
\end{DoxyItemize}

For the full specification, see:\+ \href{https://github.com/KhronosGroup/glTF/tree/master/specification/2.0}{\texttt{https:\+/\+/\+github.\+com/\+\+Khronos\+Group/\+gl\+TF/\+tree/\+master/\+specification/\+2.\+0}}
