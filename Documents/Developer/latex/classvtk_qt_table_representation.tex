\doxysubsection{Detailed Description}
set up a \doxylink{classvtk_table}{vtk\+Table} in a Qt model 

This class is a wrapper around \doxylink{classvtk_qt_table_model_adapter}{vtk\+Qt\+Table\+Model\+Adapter}. It performs the following functions:\+


\begin{DoxyItemize}
\item Keep track of the key column, first data column, and last data column. Populate the appropriate ivars on the Qt adapter. 
\item Assign colors to each of the data series using a \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table}. A default lookup table is provided or the user can supply one using \doxylink{classvtk_qt_table_representation_a535782d0bff7143945e7c42c33b35d2b}{Set\+Color\+Table()}. 
\end{DoxyItemize}

\doxylink{requirements_The}{The} user must supply the following items:\+ 
\begin{DoxyItemize}
\item the name of the column that contains the series names, 
\item the names of the first and last data columns (this range should not contain the key column), and 
\item (optionally) a \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} to use when assigning colors. 
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
Call Set\+Input\+Connection with a table connection BEFORE the representation is added to a view or strange things may happen, including segfaults. 
\end{DoxyWarning}
