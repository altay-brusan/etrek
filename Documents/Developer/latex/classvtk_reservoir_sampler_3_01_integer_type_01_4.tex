\doxysubsection{Detailed Description}
Generate a monotonic sequence of integers that randomly kk-\/sample a range without substitution. 

Given a sequence of size nn, we wish to choose kk random values from the array. This class returns kk (or fewer, if nn \texorpdfstring{$<$}{<} kk) indices in the range \+[0, nn-\/1\+[ that are ordered from smallest to largest.
