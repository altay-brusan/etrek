\doxysubsection{Detailed Description}
This is the structure that is passed to the thread that is created from the Single\+Method\+Execute, Multiple\+Method\+Execute or the Spawn\+Thread method. It is passed in as a void \texorpdfstring{$\ast$}{*}, and it is up to the method to cast correctly and extract the information. \doxylink{requirements_The}{The} Thread\+ID is a number between 0 and Number\+Of\+Threads-\/1 that indicates the id of this thread. \doxylink{requirements_The}{The} Number\+Of\+Threads is this-\/\texorpdfstring{$>$}{>}Number\+Of\+Threads for threads created from Single\+Method\+Execute or Multiple\+Method\+Execute, and it is 1 for threads created from Spawn\+Thread. \doxylink{requirements_The}{The} User\+Data is the (void \texorpdfstring{$\ast$}{*})arg passed into the Set\+Single\+Method, Set\+Multiple\+Method, or Spawn\+Thread method.
