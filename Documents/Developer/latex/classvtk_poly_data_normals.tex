\doxysubsection{Detailed Description}
compute normals for polygonal mesh 

\doxylink{classvtk_poly_data_normals}{vtk\+Poly\+Data\+Normals} is a filter that computes point and/\+or cell normals for a polygonal mesh. \doxylink{requirements_The}{The} user specifies if they would like the point and/\+or cell normals to be computed by setting the Compute\+Cell\+Normals and Compute\+Point\+Normals flags.

\doxylink{requirements_The}{The} computed normals (a \doxylink{classvtk_float_array}{vtk\+Float\+Array}) are set to be the active normals (using Set\+Normals()) of the Point\+Data and/\+or the Cell\+Data (respectively) of the output Poly\+Data. \doxylink{requirements_The}{The} name of these arrays is "{}\+Normals"{}, so they can be retrieved either with vtk\+Array\+Down\+Cast$<$vtk\+Float\+Array$>$(output-\/\texorpdfstring{$>$}{>}Get\+Point\+Data()-\/\texorpdfstring{$>$}{>}Get\+Normals()) or with vtk\+Array\+Down\+Cast$<$vtk\+Float\+Array$>$(output-\/\texorpdfstring{$>$}{>}Get\+Point\+Data()-\/\texorpdfstring{$>$}{>}Get\+Array("{}\+Normals"{}))

\doxylink{requirements_The}{The} filter can reorder polygons to ensure consistent orientation across polygon neighbors. Sharp edges can be split and points duplicated with separate normals to give crisp (rendered) surface definition. It is also possible to globally flip the normal orientation.

\doxylink{requirements_The}{The} algorithm works by determining normals for each polygon and then averaging them at shared points. When sharp edges are present, the edges are split and new points generated to prevent blurry edges (due to Gouraud shading).

\begin{DoxyWarning}{Warning}
Normals are computed only for polygons and triangle strips. Normals are not computed for lines or vertices.

Triangle strips are broken up into triangle polygons. You may want to restrip the triangles.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.
\end{DoxyWarning}
\begin{DoxySeeAlso}{See also}
For high-\/performance rendering, you could use \doxylink{classvtk_triangle_mesh_point_normals}{vtk\+Triangle\+Mesh\+Point\+Normals} if you know that you have a triangle mesh which does not require splitting nor consistency check on the cell orientations.
