\doxysubsection{Detailed Description}
abstract class for filtering a point cloud 

\doxylink{classvtk_point_cloud_filter}{vtk\+Point\+Cloud\+Filter} serves as a base for classes that filter point clouds. It takes as input any \doxylink{classvtk_point_set}{vtk\+Point\+Set} (which represents points explicitly using \doxylink{classvtk_points}{vtk\+Points}) and produces as output an explicit representation of filtered points via a \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}. This output \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} will populate its instance of \doxylink{classvtk_points}{vtk\+Points}, and typically no cells will be defined (i.\+e., no \doxylink{classvtk_vertex}{vtk\+Vertex} or \doxylink{classvtk_poly_vertex}{vtk\+Poly\+Vertex} are contained in the output unless explicitly requested). Also, after filter execution, the user can request a vtk\+Id\+Type\texorpdfstring{$\ast$}{*} point map which indicates how the input points were mapped to the output. A value of Point\+Map\+[i]\+ \texorpdfstring{$<$}{<} 0 (where i is the ith input point) means that the ith input point was removed. Otherwise Point\+Map\+[i]\+ indicates the position in the output \doxylink{classvtk_points}{vtk\+Points} array (point cloud).

Optionally the filter may produce a second output. This second output is another \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} with a \doxylink{classvtk_points}{vtk\+Points} that contains the points that were removed during processing. To produce this second output, you must enable Generate\+Outliers. If this optional, second output is created, then the contents of the Point\+Map are modified as well. In this case, a Point\+Map\+[i]\+ \texorpdfstring{$<$}{<} 0 means that the ith input point has been mapped to the (-\/Point\+Map\+[i]\+)-\/1 position in the second output\textquotesingle{}s \doxylink{classvtk_points}{vtk\+Points}.

\begin{DoxyWarning}{Warning}
This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.

\doxylink{requirements_The}{The} filter copies point attributes from input to output consistent with the filtering operation.

It is convenient to use \doxylink{classvtk_point_gaussian_mapper}{vtk\+Point\+Gaussian\+Mapper} to render the points (since this mapper does not require cells to be defined, and it is quite fast).
\end{DoxyWarning}
