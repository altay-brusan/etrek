\doxysubsection{Detailed Description}
cell represents a parabolic, 9-\/node isoparametric quad 

\doxylink{classvtk_quadratic_quad}{vtk\+Quadratic\+Quad} is a concrete implementation of \doxylink{classvtk_non_linear_cell}{vtk\+Non\+Linear\+Cell} to represent a two-\/dimensional, 9-\/node isoparametric parabolic quadrilateral element with a Centerpoint. \doxylink{requirements_The}{The} interpolation is the standard finite element, quadratic isoparametric shape function. \doxylink{requirements_The}{The} cell includes a mid-\/edge node for each of the four edges of the cell and a center node at the surface. \doxylink{requirements_The}{The} ordering of the eight points defining the cell are point ids (0-\/3,4-\/8) where ids 0-\/3 define the four corner vertices of the quad; ids 4-\/7 define the midedge nodes (0,1), (1,2), (2,3), (3,0) and 8 define the face center node.
