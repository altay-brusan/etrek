\subsubsection*{template$<$class T$>$\newline
class Dcm\+Simple\+Map$<$ T $>$}
this class implements a simple map of key-\/value pairs. No double keys are permitted, the second attempt to insert an element with a key already present will fail. Template type must be copy constructable.
