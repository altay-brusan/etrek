\doxysubsection{Detailed Description}
Meta data that describes the structure of an AMR data set. 

\doxylink{classvtk_a_m_r_information}{vtk\+AMRInformation} encapsulates the following meta information for an AMR data set
\begin{DoxyItemize}
\item a list of \doxylink{classvtk_a_m_r_box}{vtk\+AMRBox} objects
\item Refinement ratio between AMR levels
\item Grid spacing for each level
\item \doxylink{requirements_The}{The} file block index for each block
\item parent child information, if requested
\end{DoxyItemize}
