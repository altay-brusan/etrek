\doxysubsection{Detailed Description}
Picks props behind a selection rectangle on a viewport. 

\doxylink{requirements_The}{The} \doxylink{classvtk_area_picker}{vtk\+Area\+Picker} picks all vtk\+Prop3\+Ds that lie behind the screen space rectangle from x0,y0 and x1,y1. \doxylink{requirements_The}{The} selection is based upon the bounding box of the prop and is thus not exact.

Like \doxylink{classvtk_picker}{vtk\+Picker}, a pick results in a list of Prop3\+Ds because many props may lie within the pick frustum. You can also get an Assembly\+Path, which in this case is defined to be the path to the one particular prop in the Prop3D list that lies nearest to the near plane.

This picker also returns the selection frustum, defined as either a \doxylink{classvtk_planes}{vtk\+Planes}, or a set of eight corner vertices in world space. \doxylink{requirements_The}{The} \doxylink{classvtk_planes}{vtk\+Planes} version is an Implicit\+Function, which is suitable for use with the \doxylink{classvtk_extract_geometry}{vtk\+Extract\+Geometry}. \doxylink{requirements_The}{The} six frustum planes are in order:\+ left, right, bottom, top, near, far

Because this picker picks everything within a volume, the world pick point result is ill-\/defined. Therefore if you ask this class for the world pick position, you will get the centroid of the pick frustum. This may be outside of all props in the prop list.
