Fallback&Fall back to another character set. If this flag is set, the application will try to recover from a conversion failure:\+
\begin{DoxyItemize}
\item If \textquotesingle{}Override\textquotesingle{} is set, the application will try to convert the response to the character set of the request if conversion to the given character set failed.
\item If \textquotesingle{}Override\textquotesingle{} is not set, the application will try to convert the response to the given character set if conversion to the character set of the response failed. If this flag is not set, the response will be left as-\/is, i.\+e. like it is stored in the index file, if conversion to another character set failed. \begin{DoxyNote}{Note}
\doxylink{requirements_The}{The} fall back conversion might also fail, in which case the response will still be left as-\/is, even if a fall back option was given.
