\doxysubsection{Detailed Description}
extract a subset from a \doxylink{classvtk_data_set}{vtk\+Data\+Set}. 

\doxylink{classvtk_extract_selection}{vtk\+Extract\+Selection} extracts some subset of cells and points from its input data object. \doxylink{requirements_The}{The} data object is given on its first input port. \doxylink{requirements_The}{The} subset is described by the contents of the \doxylink{classvtk_selection}{vtk\+Selection} on its second input port. Depending on the contents of the \doxylink{classvtk_selection}{vtk\+Selection} this will create various vtk\+Selectors to identify the selected elements.

This filter supports \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set}, \doxylink{classvtk_data_set}{vtk\+Data\+Set}, \doxylink{classvtk_hyper_tree_grid}{vtk\+Hyper\+Tree\+Grid} and \doxylink{classvtk_table}{vtk\+Table}.


\begin{DoxyEnumerate}
\item If preserve topology is on, the output type is the same as the input.
\item If preserve topology is on.
\begin{DoxyEnumerate}
\item If input is a subclass of \doxylink{classvtk_data_object_tree}{vtk\+Data\+Object\+Tree}, the output is the same subclass.
\item If input is \doxylink{classvtk_uniform_grid_a_m_r}{vtk\+Uniform\+Grid\+AMR}, the output is \doxylink{classvtk_partitioned_data_set_collection}{vtk\+Partitioned\+Data\+Set\+Collection}.
\item If input is \doxylink{classvtk_data_set}{vtk\+Data\+Set}, the output is \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid}.
\item If input is \doxylink{classvtk_hyper_tree_grid}{vtk\+Hyper\+Tree\+Grid}, the output is \doxylink{classvtk_hyper_tree_grid}{vtk\+Hyper\+Tree\+Grid} or \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} depending on the Hyper\+Tree\+Grid\+To\+Unstructured\+Grid flag.
\item If input is \doxylink{classvtk_table}{vtk\+Table}, the output is \doxylink{classvtk_table}{vtk\+Table}.
\end{DoxyEnumerate}
\end{DoxyEnumerate}

Other types of input are not processed and the corresponding output is a default constructed object of the input type.
