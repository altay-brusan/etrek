A sparse direct supernodal Cholesky (\doxylink{class_eigen_1_1_l_l_t}{LLT}) factorization and solver based on the Pa\+StiX library. 

This class is used to solve the linear systems A.\+X = B via a LDL\texorpdfstring{$^\wedge$}{\string^}T supernodal Cholesky factorization available in the Pa\+StiX library. \doxylink{requirements_The}{The} matrix A should be symmetric and positive definite WARNING Selfadjoint complex matrices are not supported in the current version of Pa\+StiX \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse
