Detailed Description

interpolate data values from images using vtkGenericDataArray API

vtkGenericImageInterpolator provides a simple interface for interpolating image data. It provides linear, cubic, and nearest-neighbor interpolation. The only difference between it and vtkImageInterpolator is vtkGenericImageInterpolator does not assume an underlying data structure for its data arrays; instead, it uses the API from vtkGenericDataArray to perform calculations.
