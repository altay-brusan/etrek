\doxysubsection{Detailed Description}
a list of lists of props representing an assembly hierarchy 

\doxylink{classvtk_assembly_paths}{vtk\+Assembly\+Paths} represents an assembly hierarchy as a list of \doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path}. Each path represents the complete path from the top level assembly (if any) down to the leaf prop.
