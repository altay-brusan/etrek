\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T$>$\newline
class vtk\+Weak\+Pointer$<$ T $>$}
a weak reference to a \doxylink{classvtk_object}{vtk\+Object}. 

A weak reference to a \doxylink{classvtk_object}{vtk\+Object}, which means that assigning a \doxylink{classvtk_object}{vtk\+Object} to the \doxylink{classvtk_weak_pointer}{vtk\+Weak\+Pointer} does not affect the reference count of the \doxylink{classvtk_object}{vtk\+Object}. However, when the \doxylink{classvtk_object}{vtk\+Object} is destroyed, the \doxylink{classvtk_weak_pointer}{vtk\+Weak\+Pointer} gets initialized to nullptr, thus avoiding any dangling references.

\end{DoxyCode}


Some time later the table may be deleted, but if it is tested for null then the weak pointer will not leave a dangling pointer.
