\doxysubsection{Detailed Description}
helper class to perform cell tessellation 

\doxylink{classvtk_generic_cell_tessellator}{vtk\+Generic\+Cell\+Tessellator} is a helper class to perform adaptive tessellation of particular cell topologies. \doxylink{requirements_The}{The} major purpose for this class is to transform higher-\/order cell types (e.\+g., higher-\/order finite elements) into linear cells that can then be easily visualized by VTK. This class works in conjunction with the \doxylink{classvtk_generic_data_set}{vtk\+Generic\+Data\+Set} and \doxylink{classvtk_generic_adaptor_cell}{vtk\+Generic\+Adaptor\+Cell} classes.

This algorithm is based on edge subdivision. An error metric along each edge is evaluated, and if the error is greater than some tolerance, the edge is subdivided (as well as all connected 2D and 3D cells). \doxylink{requirements_The}{The} process repeats until the error metric is satisfied.

A significant issue addressed by this algorithm is to ensure face compatibility across neighboring cells. That is, diagonals due to face triangulation must match to ensure that the mesh is compatible. \doxylink{requirements_The}{The} algorithm employs a precomputed table to accelerate the tessellation process. \doxylink{requirements_The}{The} table was generated with the help of \doxylink{classvtk_ordered_triangulator}{vtk\+Ordered\+Triangulator}; the basic idea is that the choice of diagonal is made by considering the relative value of the point ids.
