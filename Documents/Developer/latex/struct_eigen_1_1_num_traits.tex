This class stores enums, typedefs and static methods giving information about a numeric type.

\doxylink{requirements_The}{The} provided data consists of:\+ \begin{DoxyItemize}
\item A typedef {\ttfamily \doxylink{struct_eigen_1_1_num_traits}{Real}}, giving the "{}real part"{} type of {\itshape T}. If {\itshape T} is already real, then {\ttfamily \doxylink{struct_eigen_1_1_num_traits}{Real}} is just a typedef to {\itshape T}. If {\itshape T} is {\ttfamily std::\+complex\uline{} then {\ttfamily \doxylink{struct_eigen_1_1_num_traits}{Real}} is a typedef to {\itshape U}. }\item \uline{ A typedef {\ttfamily \doxylink{struct_eigen_1_1_num_traits}{Non\+Integer}}, giving the type that should be used for operations producing non-\/integral values, such as quotients, square roots, etc. If {\itshape T} is a floating-\/point type, then this typedef just gives {\itshape T} again. Note however that many \doxylink{namespace_eigen}{Eigen} functions such as internal::\+sqrt simply refuse to take integers. Outside of a few cases, \doxylink{namespace_eigen}{Eigen} doesn\textquotesingle{}t do automatic type promotion. Thus, this typedef is only intended as a helper for code that needs to explicitly promote types. }\item \uline{ A typedef {\ttfamily \doxylink{struct_eigen_1_1_num_traits}{Literal}} giving the type to use for numeric literals such as "{}2"{} or "{}0.\+5"{}.
