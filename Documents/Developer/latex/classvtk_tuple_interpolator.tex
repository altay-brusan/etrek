\doxysubsection{Detailed Description}
interpolate a tuple of arbitrary size 

This class is used to interpolate a tuple which may have an arbitrary number of components (but at least one component). \doxylink{requirements_The}{The} interpolation may be linear in form, or via a subclasses of \doxylink{classvtk_spline}{vtk\+Spline}.

To use this class, begin by specifying the number of components of the tuple and the interpolation function to use. Then specify at least one pair of (t,tuple) with the \doxylink{classvtk_tuple_interpolator_a8cf6bbf5185ab90756f3e3047c7b754d}{Add\+Tuple()} method. Next interpolate the tuples with the Interpolate\+Tuple(t,tuple) method, where "{}t"{} must be in the range of (t\+\_\+min,t\+\_\+max) parameter values specified by the \doxylink{classvtk_tuple_interpolator_a8cf6bbf5185ab90756f3e3047c7b754d}{Add\+Tuple()} method (if not then t is clamped), and tuple\+[]\+ is filled in by the method (make sure that tuple \+[]\+ is long enough to hold the interpolated data).

You can control the type of interpolation to use. By default, the interpolation is based on a Kochanek spline. However, other types of splines can be specified. You can also set the interpolation method to linear, in which case the specified spline has no effect on the interpolation.

\begin{DoxyWarning}{Warning}
Setting the number of components or changing the type of interpolation causes the list of tuples to be reset, so any data inserted up to that point is lost. Bisection methods are used to speed up the search for the interpolation interval. 
\end{DoxyWarning}
