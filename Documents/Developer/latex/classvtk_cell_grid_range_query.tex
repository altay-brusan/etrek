\doxysubsection{Detailed Description}
Compute the range of a component of some \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute}. 

If {\itshape Finite\+Range} is true, then the range will omit any NaN or ±\+Inf values present in the data. Otherwise (the default), the range may contain these exceptional values.

If {\itshape Component} is
\begin{DoxyItemize}
\item -\/2 (the default), the range of L₂-\/norms is computed.
\item -\/1, the range of L₁-\/norms is computed.
\item out of bounds, then an invalid range will be returned (\+[1, 0]\+).
\end{DoxyItemize}

Note that this query is intended to be run by vtk\+Cell\+Grid::\+\+Get\+Range() since the cell-\/grid holds a cache of ranges. You may run it outside of this method, but that may cause unnecessary re-\/computation of ranges.
