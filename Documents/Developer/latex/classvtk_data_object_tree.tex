\doxysubsection{Detailed Description}
provides implementation for most abstract methods in the superclass \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} 

\doxylink{classvtk_data_object_tree}{vtk\+Data\+Object\+Tree} is represents a collection of datasets (including other composite datasets). It provides an interface to access the datasets through iterators. \doxylink{classvtk_data_object_tree}{vtk\+Data\+Object\+Tree} provides methods that are used by subclasses to store the datasets. \doxylink{classvtk_data_object_tree}{vtk\+Data\+Object\+Tree} provides the datastructure for a full tree representation. Subclasses provide the semantics for it and control how this tree is built.
