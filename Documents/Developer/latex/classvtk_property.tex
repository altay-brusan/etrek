\doxysubsection{Detailed Description}
represent surface properties of a geometric object 

\doxylink{classvtk_property}{vtk\+Property} is an object that represents lighting and other surface properties of a geometric object. \doxylink{requirements_The}{The} primary properties that can be set are colors (overall, ambient, diffuse, specular, and edge color); specular power; opacity of the object; the representation of the object (points, wireframe, or surface); and the shading method to be used (flat, Gouraud, and Phong). Also, some special graphics features like backface properties can be set and manipulated with this object.
