\doxysubsection{Detailed Description}
A class that implements the different kinds attribute matching. \doxylink{class_dcm_attribute_matching}{Dcm\+Attribute\+Matching} may either be used by directly calling the appropriate matching function, e.\+g. \doxylink{class_dcm_attribute_matching_a4a9191f0ff85c1aacaab85fc6fcf60cd}{wild\+Card\+Matching()} or by creating a \doxylink{class_dcm_attribute_matching}{Dcm\+Attribute\+Matching} object for a specific VR. In the latter case, \doxylink{class_dcm_attribute_matching}{Dcm\+Attribute\+Matching} will choose the appropriate matching function for the VR in its constructor and remember the result during its lifetime.
