\doxysubsection{Detailed Description}
An interactor style for a tree map view. 

\doxylink{requirements_The}{The} \doxylink{classvtk_interactor_style_tree_map_hover}{vtk\+Interactor\+Style\+Tree\+Map\+Hover} specifically works with pipelines that create a tree map. Such pipelines will have a \doxylink{classvtk_tree_map_layout}{vtk\+Tree\+Map\+Layout} filter and a \doxylink{classvtk_tree_map_to_poly_data}{vtk\+Tree\+Map\+To\+Poly\+Data} filter, both of which must be passed to this interactor style for it to function correctly. This interactor style allows only 2D panning and zooming, and additionally provides a balloon containing the name of the vertex hovered over, and allows the user to highlight a vertex by clicking on it.
