\doxysubsection{Detailed Description}
An abstract class for obtaining the interpolated velocity values at a point. 

\doxylink{classvtk_abstract_interpolated_velocity_field}{vtk\+Abstract\+Interpolated\+Velocity\+Field} acts as a continuous velocity field by performing cell interpolation on the underlying \doxylink{classvtk_data_set}{vtk\+Data\+Set} (or in the case of \doxylink{classvtk_composite_interpolated_velocity_field}{vtk\+Composite\+Interpolated\+Velocity\+Field}, vtk\+Composite\+Data\+Sets). This is an abstract sub-\/class of \doxylink{classvtk_function_set}{vtk\+Function\+Set}, Number\+Of\+Independent\+Variables = 4 (x,y,z,t) and Number\+Of\+Functions = 3 (u,v,w). With a brute-\/force scheme, every time an evaluation is performed, the target cell containing point (x,y,z) needs to be found by calling Find\+Cell(); however \doxylink{classvtk_abstract_interpolated_velocity_field}{vtk\+Abstract\+Interpolated\+Velocity\+Field} uses locators to accelerate this operation via an instance of \doxylink{classvtk_find_cell_strategy}{vtk\+Find\+Cell\+Strategy}. Even with the use of locators, the cost of the find cell operation can be large, hence this class performs local caching to reduce the number of invocations of Find\+Cell(). As a result, this class is not thread safe as it contains local state (such as the cache information). Writing a threaded operations requires separate instances of \doxylink{classvtk_abstract_interpolated_velocity_field}{vtk\+Abstract\+Interpolated\+Velocity\+Field} for each thread.

For \doxylink{classvtk_composite_interpolated_velocity_field}{vtk\+Composite\+Interpolated\+Velocity\+Field} with CLOSEST\+\_\+\+POINT strategy, level \#0 begins with intra-\/cell caching. Specifically if the previous cell is valid and the next point is still in it ( i.\+e., \doxylink{classvtk_cell_a188d8c01ab1cc03e1fd8b04e3ec97faf}{vtk\+Cell::\+\+Evaluate\+Position()} returns 1, coupled with newly created parametric coordinates \& weights ), the function values can be interpolated and only \doxylink{classvtk_cell_a188d8c01ab1cc03e1fd8b04e3ec97faf}{vtk\+Cell::\+\+Evaluate\+Position()} is invoked. If this fails, then level \#1 follows by inter-\/cell search for the target cell that contains the next point. By an inter-\/cell search, the previous cell provides an important clue or serves as an immediate neighbor to aid in locating the target cell via \doxylink{classvtk_point_set}{vtk\+Point\+Set}:\+:\+ Find\+Cell(). If this still fails, a global cell location /\+ search is invoked via \doxylink{classvtk_find_cell_strategy}{vtk\+Find\+Cell\+Strategy}. Finally, if this operation fails, the streamline is considered terminated.

Note the particular find cell strategy employed can affect the behavior of this class. If the strategy involved using a point locator (e.\+g., \doxylink{classvtk_static_point_locator}{vtk\+Static\+Point\+Locator} or \doxylink{classvtk_point_locator}{vtk\+Point\+Locator} via \doxylink{classvtk_closest_point_strategy}{vtk\+Closest\+Point\+Strategy} or \doxylink{classvtk_closest_n_points_strategy}{vtk\+Closest\+NPoints\+Strategy}) the performance of the class improves to the detriment of robustness. Using a cell locator (e.\+g., \doxylink{classvtk_static_cell_locator}{vtk\+Static\+Cell\+Locator} or \doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} via \doxylink{classvtk_cell_locator_strategy}{vtk\+Cell\+Locator\+Strategy}) improves robustness at some cost to performance. Originally, these different behaviors (i.\+e., using different locators) was codified into different subclasses of \doxylink{classvtk_abstract_interpolated_velocity_field}{vtk\+Abstract\+Interpolated\+Velocity\+Field}.

Note that topologically structured classes such as \doxylink{classvtk_image_data}{vtk\+Image\+Data} and \doxylink{classvtk_rectilinear_grid}{vtk\+Rectilinear\+Grid} are able to provide fast robust cell location. Hence the specified find cell strategy is only applicable to subclasses of \doxylink{classvtk_point_set}{vtk\+Point\+Set} (such as \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid}).

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_abstract_interpolated_velocity_field}{vtk\+Abstract\+Interpolated\+Velocity\+Field} is not thread safe. A new instance should be created by each thread.
\end{DoxyWarning}
