\doxysubsection{Detailed Description}
sample data values at specified point locations 

\doxylink{classvtk_probe_filter}{vtk\+Probe\+Filter} is a filter that computes point attributes (e.\+g., scalars, vectors, etc.) at specified point positions. \doxylink{requirements_The}{The} filter has two inputs:\+ the Input and Source. \doxylink{requirements_The}{The} Input geometric structure is passed through the filter. \doxylink{requirements_The}{The} point attributes are computed at the Input point positions by interpolating into the source data. For example, we can compute data values on a plane (plane specified as Input) from a volume (Source). \doxylink{requirements_The}{The} cell data of the source data is copied to the output based on in which source cell each input point is. If an array of the same name exists both in source\textquotesingle{}s point and cell data, only the one from the point data is probed.

This filter can be used to resample data, or convert one dataset form into another. For example, an unstructured grid (\doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid}) can be probed with a volume (three-\/dimensional \doxylink{classvtk_image_data}{vtk\+Image\+Data}), and then volume rendering techniques can be used to visualize the results. Another example:\+ a line or curve can be used to probe data to produce x-\/y plots along that line or curve.

\begin{DoxyWarning}{Warning}
A critical algorithmic component of \doxylink{classvtk_probe_filter}{vtk\+Probe\+Filter} is the manner in which it finds the cell containing a probe point. By default, the \doxylink{classvtk_data_set_a2221c10d3c4cca44e82c5ef70e4e1cbd}{vtk\+Data\+Set::\+\+Find\+Cell()} method is used, which in turn uses a \doxylink{classvtk_point_locator}{vtk\+Point\+Locator} (using a default \doxylink{classvtk_closest_point_strategy}{vtk\+Closest\+Point\+Strategy}) to perform an accelerated search. However, it may fail to identify an enclosing cell in some cases. A more robust but slower approach is to use a \doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} to perform the Find\+Cell() operation (via specification of the Cell\+Locator\+Prototype). Finally, more advanced searches can be configured by specifying an instance of \doxylink{classvtk_find_cell_strategy}{vtk\+Find\+Cell\+Strategy}. (Note:\+ image data probing never uses a locator since finding a containing cell is a simple, fast operation. This specifying a \doxylink{classvtk_find_cell_strategy}{vtk\+Find\+Cell\+Strategy} or cell locator prototype has no effect.)

\doxylink{requirements_The}{The} \doxylink{classvtk_probe_filter}{vtk\+Probe\+Filter}, once it finds the cell containing a query point, uses the cell\textquotesingle{}s interpolation functions to perform the interpolate /\+ compute the point attributes. Note that other interpolation processes with different kernels are available:\+ \doxylink{classvtk_point_interpolator}{vtk\+Point\+Interpolator} and \doxylink{classvtk_s_p_h_interpolator}{vtk\+SPHInterpolator}. \doxylink{classvtk_point_interpolator}{vtk\+Point\+Interpolator} supports a variety of generalized kernels, while \doxylink{classvtk_s_p_h_interpolator}{vtk\+SPHInterpolator} supports a variety of SPH interpolation kernels.
\end{DoxyWarning}
