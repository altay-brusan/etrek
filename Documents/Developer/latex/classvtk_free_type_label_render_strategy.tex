\doxysubsection{Detailed Description}
Renders labels with freetype. 

Uses the Free\+Type to render labels and compute label sizes. This strategy may be used with \doxylink{classvtk_label_placement_mapper}{vtk\+Label\+Placement\+Mapper}.
