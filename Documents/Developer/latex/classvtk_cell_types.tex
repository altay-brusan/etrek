\doxysubsection{Detailed Description}
object provides direct access to cells in \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} and type information 

This class is a supplemental object to \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} to allow random access into cells as well as representing cell type information. \doxylink{requirements_The}{The} "{}location"{} field is the location in the \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} list in terms of an integer offset. An integer offset was used instead of a pointer for easy storage and inter-\/process communication. \doxylink{requirements_The}{The} type information is defined in the file \doxylink{vtk_cell_type_8h_source}{vtk\+Cell\+Type.\+h}.

\begin{DoxyWarning}{Warning}
Sometimes this class is used to pass type information independent of the random access (i.\+e., location) information. For example, see \doxylink{classvtk_data_set_a97aed8f2f479842fbef6b91f37c5d94b}{vtk\+Data\+Set::\+\+Get\+Cell\+Types()}. If you use the class in this way, you can use a location value of -\/1.
\end{DoxyWarning}
