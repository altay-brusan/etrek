\doxysubsection{Detailed Description}
Represents a status record for any DICOM entity (\doxylink{class_etrek_1_1_dicom_1_1_repository_1_1_patient}{Patient}, \doxylink{class_etrek_1_1_dicom_1_1_repository_1_1_study}{Study}, \doxylink{class_etrek_1_1_dicom_1_1_data_1_1_entity_1_1_series}{Series}, or \doxylink{class_etrek_1_1_dicom_1_1_data_1_1_entity_1_1_image}{Image}). 

This class provides unified status tracking with full audit trail across the DICOM hierarchy. Multiple status records can exist for each entity, enabling complete status history tracking.
