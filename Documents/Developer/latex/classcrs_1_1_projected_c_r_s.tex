\doxysubsection{Detailed Description}
A derived coordinate reference system which has a geodetic (usually geographic) coordinate reference system as its base \doxylink{classcrs_1_1_c_r_s}{CRS}, thereby inheriting a geodetic reference frame, and is converted using a map projection. 

It has a Cartesian coordinate system, usually two-\/dimensional but may be three-\/dimensional; in the 3D case the base geographic CRSs ellipsoidal height is passed through unchanged and forms the vertical axis of the projected \doxylink{classcrs_1_1_c_r_s}{CRS}\textquotesingle{}s Cartesian coordinate system.
