\doxysubsection{Detailed Description}
abstract class defines the representation for a \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} 

This abstract class is used to specify how the \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} should interact with representations of the \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget}. This class may be subclassed so that alternative representations can be created. \doxylink{requirements_The}{The} class defines an API, and a default implementation, that the \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} interacts with to render itself in the scene.
