\doxysubsection{Detailed Description}
Frequency domain high pass. 

This filter only works on an image after it has been converted to frequency domain by a \doxylink{classvtk_image_f_f_t}{vtk\+Image\+FFT} filter. A \doxylink{classvtk_image_r_f_f_t}{vtk\+Image\+RFFT} filter can be used to convert the output back into the spatial domain. \doxylink{classvtk_image_butterworth_high_pass}{vtk\+Image\+Butterworth\+High\+Pass} the frequency components around 0 are attenuated. Input and output are in doubles, with two components (complex numbers). out(i, j) = 1 /\+ (1 + pow(Cut\+Off/\+\+Freq(i,j), 2\texorpdfstring{$\ast$}{*}\+Order));
