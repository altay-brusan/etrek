\doxysubsection{Detailed Description}
Central orchestration service for application lifecycle. 

Singleton-\/like service that coordinates all aspects of application initialization and lifecycle management.

Initialization order:\+
\begin{DoxyEnumerate}
\item Logger setup (spdlog)
\item Settings loading (\doxylink{class_etrek_1_1_application_1_1_service_1_1_setting_provider}{Setting\+Provider})
\item Database initialization (Qt SQL with My\+SQL)
\item \doxylink{namespace_etrek_1_1_application_1_1_authentication}{Authentication} service setup
\item RIS connections (\doxylink{class_etrek_1_1_application_1_1_service_1_1_modality_worklist_manager}{Modality\+Worklist\+Manager})
\item Device initialization
\item Main window construction
\end{DoxyEnumerate}

\doxylink{requirements_The}{The} service uses the \doxylink{namespace_etrek_1_1_application_1_1_strategy}{Strategy} pattern for different launch modes (main, demo, settings, users) via \doxylink{class_etrek_1_1_application_1_1_service_1_1_i_launch_strategy}{ILaunch\+Strategy}.
