\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen::\+\+Eigen\+Solver$<$ \+\_\+\+Matrix\+Type $>$}
Computes eigenvalues and eigenvectors of general matrices. 

\textbackslash{}eigenvalues\+\_\+module


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the matrix of which we are computing the eigendecomposition; this is expected to be an instantiation of the \doxylink{class_eigen_1_1_matrix}{Matrix} class template. Currently, only real matrices are supported.\\
\hline
\end{DoxyTemplParams}
\doxylink{requirements_The}{The} eigenvalues and eigenvectors of a matrix $ A $ are scalars $ \lambda $ and vectors $ v $ such that $ Av = \lambda v $. If $ D $ is a diagonal matrix with the eigenvalues on the diagonal, and $ V $ is a matrix with the eigenvectors as its columns, then  $ A V =
V D $. \doxylink{requirements_The}{The} matrix $ V $ is almost always invertible, in which case we have $ A = V D V^{-1} $. This is called the eigendecomposition.

\doxylink{requirements_The}{The} eigenvalues and eigenvectors of a matrix may be complex, even when the matrix is real. However, we can choose real matrices $ V $ and  $ D
$ satisfying $ A V = V D $, just like the eigendecomposition, if the matrix $ D $ is not required to be diagonal, but if it is allowed to have blocks of the form \[ \begin{bmatrix} u & v \\ -v & u \end{bmatrix} \] (where $ u $ and $ v $ are real numbers) on the diagonal. These blocks correspond to complex eigenvalue pairs $ u \pm iv $. We call this variant of the eigendecomposition the pseudo-\/eigendecomposition.

Call the function \doxylink{class_eigen_1_1_eigen_solver_aff5c2bd7843aacdcd59b9cbe420752ff}{compute()} to compute the eigenvalues and eigenvectors of a given matrix. Alternatively, you can use the Eigen\+Solver(const Matrix\+Type\&, bool) constructor which computes the eigenvalues and eigenvectors at construction time. Once the eigenvalue and eigenvectors are computed, they can be retrieved with the \doxylink{class_eigen_1_1_eigen_solver_ae33fb99005024f07005ab1e409413c5f}{eigenvalues()} and \doxylink{class_eigen_1_1_eigen_solver_a66288022802172e3ee059283b26201d7}{eigenvectors()} functions. \doxylink{requirements_The}{The} \doxylink{class_eigen_1_1_eigen_solver_a4979eafe0aeef06b19ada7fa5e19db17}{pseudo\+Eigenvalue\+Matrix()} and \doxylink{class_eigen_1_1_eigen_solver_a8e933fb058e8f5f0d7e25d64ffc9b152}{pseudo\+Eigenvectors()} methods allow the construction of the pseudo-\/eigendecomposition.

\doxylink{requirements_The}{The} documentation for Eigen\+Solver(const Matrix\+Type\&, bool) contains an example of the typical use of this class.

Computes eigendecomposition of given matrix. 


\begin{DoxyParams}[1]{Parameters}

This function computes the eigenvalues of the real matrix {\ttfamily matrix}. \doxylink{requirements_The}{The} \doxylink{class_eigen_1_1_eigen_solver_ae33fb99005024f07005ab1e409413c5f}{eigenvalues()} function can be used to retrieve them. If {\ttfamily compute\+Eigenvectors} is true, then the eigenvectors are also computed and can be retrieved by calling \doxylink{class_eigen_1_1_eigen_solver_a66288022802172e3ee059283b26201d7}{eigenvectors()}.

\doxylink{requirements_The}{The} matrix is first reduced to real Schur form using the \doxylink{class_eigen_1_1_real_schur}{Real\+Schur} class. \doxylink{requirements_The}{The} Schur decomposition is then used to compute the eigenvalues and eigenvectors.

\doxylink{requirements_The}{The} cost of the computation is dominated by the cost of the Schur decomposition, which is very approximately $ 25n^3 $ (where $ n $ is the size of the matrix) if {\ttfamily compute\+Eigenvectors} is true, and $ 10n^3 $ if {\ttfamily compute\+Eigenvectors} is false.

This method reuses of the allocated data in the \doxylink{class_eigen_1_1_eigen_solver}{Eigen\+Solver} object.
