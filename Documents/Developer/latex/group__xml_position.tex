\doxysubsubsubsection{Detailed Description}
These are some useful functions when you want to insert a child\+Node, a text or a XMLClear\+Tag in the middle (at a specified position) of a \doxylink{struct_x_m_l_node}{XMLNode} tree already constructed. \doxylink{requirements_The}{The} value returned by these methods is to be used as last parameter (parameter \textquotesingle{}pos\textquotesingle{}) of add\+Child, add\+Text or add\+Clear.
