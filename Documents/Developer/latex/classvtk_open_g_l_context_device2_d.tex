\doxysubsection{Detailed Description}
Class for drawing 2D primitives using Open\+GL 1.\+1+. 

This class takes care of drawing the 2D primitives for the \doxylink{classvtk_context2_d}{vtk\+Context2D} class. In general this class should not be used directly, but called by \doxylink{classvtk_context2_d}{vtk\+Context2D} which takes care of many of the higher level details.
