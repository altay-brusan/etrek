\doxysubsection{Detailed Description}
Tool for adjusting window/\+level (contrast/\+brightness). 

Interaction:\+
\begin{DoxyItemize}
\item Left mouse drag horizontal:\+ Adjust window width
\item Left mouse drag vertical:\+ Adjust window center (level)
\item Mouse wheel:\+ Quick adjustment 
\end{DoxyItemize}
