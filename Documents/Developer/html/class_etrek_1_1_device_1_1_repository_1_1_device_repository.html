Detailed Description

Repository for medical imaging device configuration.

Implements the Repository pattern for device-related data access. Provides CRUD operations for:

  • X-ray generators
  • Digital detectors
  • X-ray tubes
  • Institutions
  • General equipment
  • Environment settings

Uses Qt SQL with MySQL backend. Includes soft-delete support (deactivation) for entities that should not be permanently removed.

Note
Thread-safe for read operations. Write operations should be synchronized by the caller.
