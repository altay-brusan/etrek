\doxysubsection{Detailed Description}
Implicit function that is generated by extrusion of a polyline along the Z axis. 

\doxylink{classvtk_poly_plane}{vtk\+Poly\+Plane} is, as the name suggests, an extrusion of a \doxylink{classvtk_poly_line}{vtk\+Poly\+Line}. \doxylink{requirements_The}{The} extrusion direction is assumed to be the Z vector. It can be used in combination with a \doxylink{classvtk_cutter}{vtk\+Cutter} to cut a dataset with a polyplane. \doxylink{classvtk_poly_plane}{vtk\+Poly\+Plane} is a concrete implementation of the abstract class \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.
