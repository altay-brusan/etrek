\doxysubsection{Detailed Description}
Repository for DICOM tag dictionary lookups with caching. 

This lightweight repository reads from the dicom\+\_\+tags table and provides efficient tag lookups by keyword or tag number (group, element). Uses an internal cache to avoid repeated database hits.
