\doxysubsection{Detailed Description}
provides customizable interaction routines 

\doxylink{requirements_The}{The} most common way to customize user interaction is to write a subclass of \doxylink{classvtk_interactor_style}{vtk\+Interactor\+Style}:\+ \doxylink{classvtk_interactor_style_user}{vtk\+Interactor\+Style\+User} allows you to customize the interaction to without subclassing \doxylink{classvtk_interactor_style}{vtk\+Interactor\+Style}. This is particularly useful for setting up custom interaction modes in scripting languages such as Python. This class allows you to hook into the Mouse\+Move, Button\+Press/\+\+Release, Key\+Press/\+\+Release, etc. events. If you want to hook into just a single mouse button, but leave the interaction modes for the others unchanged, you must use e.\+g. Set\+Middle\+Button\+Press\+Method() instead of the more general Set\+Button\+Press\+Method().
