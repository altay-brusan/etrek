Detailed Description

Abstract interface to pluggable image support for the DICOMDIR class. This is an abstract base class used as an interface to access DICOM images from the DicomDirInterface. The implementation can be found in dcmjpeg/libsrc/ddpiimpl.cc (incl. JPEG support).
