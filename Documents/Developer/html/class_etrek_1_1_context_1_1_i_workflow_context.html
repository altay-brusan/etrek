Detailed Description

Base interface for workflow-specific context information.

Workflow contexts represent transient state that needs to be passed between pages/delegates during a specific workflow (e.g., from Worklist selection to Examination page).

Unlike session context which persists for the entire session, workflow contexts are typically short-lived and may be replaced as the user moves through different workflows.
