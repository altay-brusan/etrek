\doxysubsection{Detailed Description}
Base class for cells that form 2-\/d or 3-\/d De\+Rham complexes. 

This class exists so that cell-\/attributes specific to De\+Rham sequences can register responders and calculators. Only 2-\/d and 3-\/d cell-\/shapes are allowed to subclass \doxylink{classvtk_de_rham_cell}{vtk\+De\+Rham\+Cell} since H(\+Curl) and H(\+Div) function spaces require cells of parametric dimension 2 or greater.

This class inherits the API of \doxylink{classvtk_d_g_cell}{vtk\+DGCell}.
