\doxylink{classvtk_parametric_plucker_conoid}{vtk\+Parametric\+Plucker\+Conoid} generates Plucker\textquotesingle{}s conoid surface parametrically. Plucker\textquotesingle{}s conoid is a ruled surface, named after Julius Plucker. It is possible to set the number of folds in this class via the parameter \textquotesingle{}N\textquotesingle{}.

For more information, see the Wikipedia page on \href{https://en.wikipedia.org/wiki/Pl\%c3\%bccker\%27s_conoid}{\texttt{Plucker\textquotesingle{}s Conoid}}. \begin{DoxyWarning}{Warning}
I haven\textquotesingle{}t done any special checking on the number of folds parameter, N. 
\end{DoxyWarning}

Plucker\textquotesingle{}s conoid surface.

This function performs the mapping $f(u,v) \rightarrow (x,y,x)$, returning it as Pt. It also returns the partial derivatives Du and Dv. $Pt = (x, y, z), D_u\vec{f} = (dx/du, dy/du, dz/du), D_v\vec{f} = (dx/dv, dy/dv, dz/dv)$ . Then the normal is $N = D_u\vec{f} \times D_v\vec{f}$ .
