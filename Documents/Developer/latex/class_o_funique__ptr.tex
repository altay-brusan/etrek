\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class OFunique\+\_\+ptr$<$ T $>$}
\doxylink{class_o_funique__ptr}{OFunique\+\_\+ptr} is a smart pointer that retains sole ownership of an object through a pointer and destroys that object when the unique\+\_\+ptr goes out of scope. No two unique\+\_\+ptr instances can manage the same object.

\doxylink{requirements_The}{The} object is destroyed and its memory deallocated when either of the following happens:\+
\begin{DoxyItemize}
\item unique\+\_\+ptr managing the object is destroyed
\item unique\+\_\+ptr managing the object is assigned another pointer via \doxylink{class_o_funique__ptr_a0d434716f38f89091f8dd262038a78d1}{reset()}.
\end{DoxyItemize}

A unique\+\_\+ptr may also own no objects, in which case it is called empty.

\doxylink{class_o_funique__ptr}{OFunique\+\_\+ptr} is NOT Copy\+Constructible or Copy\+Assignable. 
\begin{DoxyTemplParams}{Template Parameters}
{\em T} & the type of the managed object, e.\+g. int for an \doxylink{class_o_funique__ptr}{OFunique\+\_\+ptr} behaving like an int\texorpdfstring{$\ast$}{*}. \\
\hline
\end{DoxyTemplParams}
\begin{DoxyNote}{Note}
this implementation is meant to be a subset of the c++11\textquotesingle{}s std::\+unique\+\_\+ptr that lacks the following features:\+ swap support, custom deleters, specialized handling of pointers to arrays and some functions like comparing OFunique\+\_\+ptrs or creating a hash key. see \href{http://en.cppreference.com/w/cpp/memory/unique_ptr}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+memory/\+unique\+\_\+ptr}} to compare \doxylink{class_o_funique__ptr}{OFunique\+\_\+ptr} against std::\+unique\+\_\+ptr. 
\end{DoxyNote}
