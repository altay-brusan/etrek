\doxysubsection{Detailed Description}
abstract class for representing widget handles 

This class defines an API for widget handle representations. These representations interact with \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget}. Various representations can be used depending on the nature of the handle. \doxylink{requirements_The}{The} basic functionality of the handle representation is to maintain a position. \doxylink{requirements_The}{The} position is represented via a \doxylink{classvtk_coordinate}{vtk\+Coordinate}, meaning that the position can be easily obtained in a variety of coordinate systems.

Optional features for this representation include an active mode (the widget appears only when the mouse pointer is close to it). \doxylink{requirements_The}{The} active distance is expressed in pixels and represents a circle in display space.

\doxylink{requirements_The}{The} class may be subclassed so that alternative representations can be created. \doxylink{requirements_The}{The} class defines an API and a default implementation that the \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget} interacts with to render itself in the scene.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} separation of the widget event handling and representation enables users and developers to create new appearances for the widget. It also facilitates parallel processing, where the client application handles events, and remote representations of the widget are slaves to the client (and do not handle events).
\end{DoxyWarning}
