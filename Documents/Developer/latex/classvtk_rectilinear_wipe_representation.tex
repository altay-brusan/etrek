\doxysubsection{Detailed Description}
represent a \doxylink{classvtk_rectilinear_wipe_widget}{vtk\+Rectilinear\+Wipe\+Widget} 

This class is used to represent and render a \doxylink{classvtk_rectilinear_wipe_widget}{vtk\+Rectilinear\+Wipe\+Widget}. To use this class, you need to specify an instance of a \doxylink{classvtk_image_rectilinear_wipe}{vtk\+Image\+Rectilinear\+Wipe} and \doxylink{classvtk_image_actor}{vtk\+Image\+Actor}. This provides the information for this representation to construct and place itself.

\doxylink{requirements_The}{The} class may be subclassed so that alternative representations can be created. \doxylink{requirements_The}{The} class defines an API and a default implementation that the \doxylink{classvtk_rectilinear_wipe_widget}{vtk\+Rectilinear\+Wipe\+Widget} interacts with to render itself in the scene.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} separation of the widget event handling and representation enables users and developers to create new appearances for the widget. It also facilitates parallel processing, where the client application handles events, and remote representations of the widget are slaves to the client (and do not handle events).
\end{DoxyWarning}
