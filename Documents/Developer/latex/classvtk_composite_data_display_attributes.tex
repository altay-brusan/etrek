\doxysubsection{Detailed Description}
Rendering attributes for a multi-\/block dataset. 

\doxylink{requirements_The}{The} \doxylink{classvtk_composite_data_display_attributes}{vtk\+Composite\+Data\+Display\+Attributes} class stores display attributes for individual blocks in a multi-\/block dataset. It uses the actual data block\textquotesingle{}s pointer as a key (vtk\+Data\+Object\texorpdfstring{$\ast$}{*}).

\begin{DoxyWarning}{Warning}
It is considered unsafe to dereference key pointers at any time, they should only serve as keys to access the internal map. 
\end{DoxyWarning}
