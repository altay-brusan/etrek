\doxysubsection{Detailed Description}
actor that draws 2D data with texture support 

\doxylink{classvtk_textured_actor2_d}{vtk\+Textured\+Actor2D} is an Actor2D which has additional support for textures, just like \doxylink{classvtk_actor}{vtk\+Actor}. To use textures, the geometry must have texture coordinates, and the texture must be set with \doxylink{classvtk_textured_actor2_d_ae2d01a76939fa5db8675beef3faf755b}{Set\+Texture()}.
