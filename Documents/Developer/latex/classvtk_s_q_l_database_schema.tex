\doxysubsection{Detailed Description}
represent an SQL database schema 

This class stores the information required to create an SQL database from scratch. Information on each table\textquotesingle{}s columns, indices, and triggers is stored. You may also store an arbitrary number of preamble statements, intended to be executed before any tables are created; this provides a way to create procedures or functions that may be invoked as part of a trigger action. Triggers and table options may be specified differently for each backend database type you wish to support.
