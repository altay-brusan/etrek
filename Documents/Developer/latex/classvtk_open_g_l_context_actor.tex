\doxysubsection{Detailed Description}
provides a \doxylink{classvtk_prop}{vtk\+Prop} derived object. 

This object provides the entry point for the \doxylink{classvtk_context_scene}{vtk\+Context\+Scene} to be rendered in a \doxylink{classvtk_renderer}{vtk\+Renderer}. Uses the Render\+Overlay pass to render the 2D \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}.
