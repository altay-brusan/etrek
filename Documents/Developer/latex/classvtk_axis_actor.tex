\doxysubsection{Detailed Description}
Create an axis with tick marks and labels. 

\doxylink{classvtk_axis_actor}{vtk\+Axis\+Actor} creates an axis with tick marks, labels, and/\+or a title, depending on the particular instance variable settings. It is assumed that the axes is part of a bounding box and is orthogonal to one of the coordinate axes. To use this class, you typically specify two points defining the start and end points of the line (xyz definition using \doxylink{classvtk_coordinate}{vtk\+Coordinate} class), the axis type (X, Y or Z), the axis location in relation to the bounding box, the bounding box, the number of labels, and the data range (min,max). You can also control what parts of the axis are visible including the line, the tick marks, the labels, and the title. It is also possible to control gridlines, and specify on which \textquotesingle{}side\textquotesingle{} the tickmarks are drawn (again with respect to the underlying assumed bounding box). You can also specify the label format (a printf style format).

This class decides how to locate the labels, and how to create reasonable tick marks and labels.

Labels follow the camera so as to be legible from any viewpoint.

\doxylink{requirements_The}{The} instance variables Point1 and Point2 are instances of \doxylink{classvtk_coordinate}{vtk\+Coordinate}. All calculations and references are in World Coordinates.
