\doxysubsection{Detailed Description}
create a line defined by two end points 

\doxylink{classvtk_line_source}{vtk\+Line\+Source} is a source object that creates a polyline defined by two endpoints or a collection of connected line segments. To define the line by end points, use {\ttfamily Set\+Point1} and {\ttfamily Set\+Point2} methods. To define a broken line comprising of multiple line segments, use {\ttfamily \doxylink{classvtk_line_source_a06714bf649c93f811a5908e742ec98bc}{Set\+Points}} to provide the corner points that for the line.

Intermediate points within line segment (when specifying end points alone) or each of the individual line segments (when specifying broken line) can be specified in two ways. First, when {\ttfamily Use\+Regular\+Refinement} is true (default), the {\ttfamily Resolution} is used to determine how many intermediate points to add using regular refinement. Thus, if {\ttfamily Resolution} is set to 1, a mid point will be added for each of the line segments resulting in a line with 3 points:\+ the two end points and the mid point. Second, when {\ttfamily Use\+Regular\+Refinement} is false, refinement ratios for points per segment are specified using {\ttfamily Set\+Refinement\+Ratio} and {\ttfamily \doxylink{classvtk_line_source_acba7b28d8719a9fdb22b33c62df1cfee}{Set\+Number\+Of\+Refinement\+Ratios}}. To generate same points as {\ttfamily Resolution} set to 1, the refinement ratios will be {\ttfamily \+[0, 0.\+5, 1.\+0]\+}. To add the end points of the line segment {\ttfamily 0.\+0} and {\ttfamily 1.\+0} must be included in the collection of refinement ratios.\hypertarget{classvtk_line_source_ChangesVTK9}{}\doxysubsection{\texorpdfstring{Changes in VTK 9.\+0}{Changes in VTK 9.\+0}}\label{classvtk_line_source_ChangesVTK9}
Prior to VTK 9.\+0, when broken line was being generated, the texture coordinates for each of the individual breaks in the line ranged from \+[0.\+0, 1.\+0]\+. This has been changed to generate texture coordinates in the range \+[0.\+0, 1.\+0]\+ over the entire output line irrespective of whether the line was generated by simply specifying the end points or multiple line segments.

This class was extended by Philippe Pebay, Kitware SAS 2011, to support broken lines as well as simple lines.
