\doxysubsection{Detailed Description}
map scalar values into colors via a lookup table 

\doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} is an object that is used by mapper objects to map scalar values into RGBA (red-\/green-\/blue-\/alpha) color specification, or RGBA into scalar values. \doxylink{requirements_The}{The} color table can be created by direct insertion of color values, or by specifying a hue, saturation, value, and alpha range and generating a table.

A special color for NaN values in the data can be specified via Set\+Nan\+Color(). In addition, a color for data values below the lookup table range minimum can be specified with Set\+Below\+Range\+Color(), and that color will be used for values below the range minimum when Use\+Below\+Range\+Color is on. Likewise, a color for data values above the lookup table range maximum can be specified with Set\+Above\+Range\+Color(), and it is used when Use\+Above\+Range\+Color is on.

This class behaves differently depending on how {\itshape Indexed\+Lookup} is set. When true, \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} enters a mode for representing categorical color maps. By setting {\itshape Indexed\+Lookup} to true, you indicate that the annotated values are the only valid values for which entries in the color table should be returned. \doxylink{requirements_The}{The} colors in the lookup {\itshape Table} are assigned to annotated values by taking the modulus of their index in the list of annotations. {\itshape Indexed\+Lookup} changes the behavior of {\itshape Get\+Index}, which in turn changes the way {\itshape Map\+Scalars\+Through\+Table2} behaves; when {\itshape Indexed\+Lookup} is true, {\itshape Map\+Scalars\+Through\+Table2} will search for scalar values in {\itshape Annotated\+Values} and use the resulting index to determine the color. If a scalar value is not present in {\itshape Annotated\+Values}, then {\itshape Nan\+Color} will be used.

\begin{DoxyWarning}{Warning}
You need to explicitly call \doxylink{classvtk_lookup_table_ae573ed9fd852edbeb57b537f8977be1b}{Build()} when constructing the LUT by hand.
\end{DoxyWarning}
