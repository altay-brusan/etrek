\doxysubsection{Detailed Description}
Stores a half-\/open range of array coordinates. 

\doxylink{classvtk_array_range}{vtk\+Array\+Range} stores a half-\/open range of array coordinates along a single dimension of a vtk\+Array\+Slice object.
