\doxysubsection{Detailed Description}
spline abstract class for interpolating splines 

\doxylink{classvtk_spline}{vtk\+Spline} interpolates a set of data points (i.\+e., interpolation means that the spline passes through the points). \doxylink{classvtk_spline}{vtk\+Spline} is an abstract class:\+ its subclasses \doxylink{classvtk_cardinal_spline}{vtk\+Cardinal\+Spline} and \doxylink{classvtk_kochanek_spline}{vtk\+Kochanek\+Spline} do the interpolation. Note that this spline maps the 1D parametric coordinate t into a single value x. Thus if you want to use the spline to interpolate points (i.\+e. x\+[3]\+), you have to create three splines for each of the x-\/y-\/z coordinates. Fortunately, the \doxylink{classvtk_parametric_spline}{vtk\+Parametric\+Spline} class does this for you.

Typically a spline is used by adding a sequence of parametric coordinate /\+ data (t,x) values followed by use of an evaluation function (e.\+g., \doxylink{classvtk_cardinal_spline_a8f82653dd0bed2ef1ca5bcba7af85c7f}{vtk\+Cardinal\+Spline::\+\+Evaluate()}). Since these splines are 1D, a point in this context is an independent /\+ dependent variable pair.

Splines can also be set up to be closed or open. Closed splines continue from the last point to the first point with continuous function and derivative values. (You don\textquotesingle{}t need to duplicate the first point to close the spline, just set Closed\+On.)

This implementation of splines does not use a normalized parametric coordinate. If the spline is open, then the parameter space is (t\+Min \texorpdfstring{$<$}{<}= t \texorpdfstring{$<$}{<}= t\+Max) where t\+Min and t\+Max are the minimum and maximum parametric values seen when performing \doxylink{classvtk_spline_ae7435296c9f39e4bf2dc61ea5fe08587}{Add\+Point()}. If the spline is closed, then the parameter space is (t\+Min \texorpdfstring{$<$}{<}= t \texorpdfstring{$<$}{<}= (t\+Max+1)) where t\+Min and t\+Max are the minimum and maximum parametric values seen when performing \doxylink{classvtk_spline_ae7435296c9f39e4bf2dc61ea5fe08587}{Add\+Point()}. Note, however, that this behavior can be changed by explicitly setting the Parametric\+Range(t\+Min,t\+Max). If set, the parameter space remains (t\+Min \texorpdfstring{$<$}{<}= t \texorpdfstring{$<$}{<}= t\+Max), except that additions of data with parametric values outside this range are clamped within this range.
