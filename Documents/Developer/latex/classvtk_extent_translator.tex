\doxysubsection{Detailed Description}
Generates a structured extent from unstructured. 

\doxylink{classvtk_extent_translator}{vtk\+Extent\+Translator} generates a structured extent from an unstructured extent. It uses a recursive scheme that splits the largest axis. A hard coded extent can be used for a starting point.
