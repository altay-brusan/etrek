\doxysubsection{Detailed Description}
draw text labels at dataset points 

\doxylink{classvtk_fast_labeled_data_mapper}{vtk\+Fast\+Labeled\+Data\+Mapper} is a mapper that renders text at dataset points quickly. \doxylink{requirements_The}{The} API is similar to but the implementation is different from \doxylink{classvtk_labeled_data_mapper}{vtk\+Labeled\+Data\+Mapper} which this class is meant to replace. This new class is faster than its predecessor because it renders all of the labels at once via shaders instead of deferring to helper instances for each individual label.
