\doxysubsection{Detailed Description}
A derived coordinate reference system which has either a geodetic or a geographic coordinate reference system as its base \doxylink{classcrs_1_1_c_r_s}{CRS}, thereby inheriting a geodetic reference frame, and an ellipsoidal coordinate system. 

A derived geographic \doxylink{classcrs_1_1_c_r_s}{CRS} can be based on a geodetic \doxylink{classcrs_1_1_c_r_s}{CRS} only if that geodetic \doxylink{classcrs_1_1_c_r_s}{CRS} definition includes an ellipsoid.
