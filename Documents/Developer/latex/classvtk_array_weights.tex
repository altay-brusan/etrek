\doxysubsection{Detailed Description}
Stores a collection of weighting factors. 

\doxylink{classvtk_array_weights}{vtk\+Array\+Weights} provides storage for a collection of weights to be used when merging /\+ interpolating N-\/way arrays. Convenience constructors are provided for working with one, two, three, and four weighting factors. For arbitrary collections of weights, use \doxylink{classvtk_array_weights_a2bdcf3146d7e951a78fc6c0511f2b5f5}{Set\+Count()} and operator\+[]\+ to assign values.

\doxylink{classvtk_array_weights}{vtk\+Array\+Weights} is most commonly used with the vtk\+Interpolate() function to compute weighted sums of \doxylink{classvtk_array}{vtk\+Array} objects.
