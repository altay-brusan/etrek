\doxysubsection{Detailed Description}
Implement Screen Space Anti Aliasing pass. 

Render to a larger image and then sample down

This pass expects an initialized depth buffer and color buffer. Initialized buffers means they have been cleared with farthest z-\/value and background color/\+gradient/\+transparent color.

\doxylink{requirements_The}{The} delegate is used once.

Its delegate is usually set to a \doxylink{classvtk_camera_pass}{vtk\+Camera\+Pass} or to a post-\/processing pass.

\begin{DoxyParagraph}{Implementation:\+}
As the filter is separable, it first blurs the image horizontally and then vertically. This reduces the number of texture samples taken.
\end{DoxyParagraph}
