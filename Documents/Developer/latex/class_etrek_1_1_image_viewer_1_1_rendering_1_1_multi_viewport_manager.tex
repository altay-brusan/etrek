\doxysubsection{Detailed Description}
Manages multiple viewport renderers (up to 4 viewports). 

Handles:\+
\begin{DoxyItemize}
\item Layout configuration (1x1, 1x2, 2x1, 2x2)
\item Active viewport selection
\item Optional synchronized operations (linked viewports)
