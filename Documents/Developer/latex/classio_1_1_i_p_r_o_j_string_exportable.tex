It should be noted that the export of a CRS as a PROJ string may cause loss of many important aspects of a CRS definition. It is only compatible of a few CRS objects. \doxylink{requirements_The}{The} PROJ string will also contain a +type=crs parameter to disambiguate the nature of the string from a Coordinate\+Operation.
