\doxysubsection{Detailed Description}
Provides configuration from an external file. See \doxylink{classdcmtk_1_1log4cplus_1_1_property_configurator_a8424be722d052671a555901d06a56ddc}{configure()} for the expected format.

{\itshape All option values admit variable substitution.} For example, if {\ttfamily userhome} environment property is set to {\ttfamily /\+home/\+xyz} and the File option is set to the string {\ttfamily \$\{userhome\}/\+test.log}, then File option will be interpreted as the string {\ttfamily /\+home/\+xyz/\+test.log}.

\doxylink{requirements_The}{The} syntax of variable substitution is similar to that of UNIX shells. \doxylink{requirements_The}{The} string between an opening {\bfseries{"{}\$\{"{}}} and closing {\bfseries{"{}\}"{}}} is interpreted as a key. Its value is searched in the environment properties. \doxylink{requirements_The}{The} corresponding value replaces the \$\{variable\+Name\} sequence.

\doxysubsubsubsection*{\doxylink{classdcmtk_1_1log4cplus_1_1_appender}{Appender} configuration}

\doxylink{classdcmtk_1_1log4cplus_1_1_appender}{Appender} configuration syntax is:\+ 
\begin{DoxyPre}
\# For appender named {\itshape appenderName}, set its class.
\# Note: \doxylink{requirements_The}{The} appender name can contain dots.
log4cplus.appender.appenderName=fully.qualified.name.of.appender.class

\# Set appender specific options.
log4cplus.appender.appenderName.option1=value1
...
log4cplus.appender.appenderName.optionN=valueN
\end{DoxyPre}


For each named appender you can configure its {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_layout}{Layout}}. \doxylink{requirements_The}{The} syntax for configuring an appender\textquotesingle{}s layout is:\+ 
\begin{DoxyPre}
log4cplus.appender.appenderName.layout=fully.qualified.name.of.layout.class
log4cplus.appender.appenderName.layout.option1=value1
....
log4cplus.appender.appenderName.layout.optionN=valueN
\end{DoxyPre}


\doxysubsubsubsection*{Configuring loggers}

\doxylink{requirements_The}{The} syntax for configuring the root logger is:\+ 
\begin{DoxyPre}
log4cplus.rootLogger=[\doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{LogLevel}], appenderName, appenderName, ...
\end{DoxyPre}


This syntax means that an optional {\itshape \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value} can be supplied followed by appender names separated by commas.

\doxylink{requirements_The}{The} \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value can consist of the string values FATAL, ERROR, WARN, INFO, DEBUG or a {\itshape custom \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level}} value.

If a \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value is specified, then the root \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} is set to the corresponding \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level}. If no \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value is specified, then the root \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} remains untouched.

\doxylink{requirements_The}{The} root logger can be assigned multiple appenders.

Each {\itshape appender\+Name} (separated by commas) will be added to the root logger. \doxylink{requirements_The}{The} named appender is defined using the appender syntax defined above.

For non-\/root loggers the syntax is almost the same:\+ 
\begin{DoxyPre}
log4cplus.logger.logger\_name=[LogLevel|INHERITED], appenderName, appenderName, ...
\end{DoxyPre}


\doxylink{requirements_The}{The} meaning of the optional \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value is discussed above in relation to the root logger. In addition however, the value INHERITED can be specified meaning that the named logger should inherit its \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} from the logger hierarchy.

By default loggers inherit their \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} from the hierarchy. However, if you set the \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} of a logger and later decide that that logger should inherit its \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level}, then you should specify INHERITED as the value for the \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value.

Similar to the root logger syntax, each {\itshape appender\+Name} (separated by commas) will be attached to the named logger.

See the \href{../../../../manual.html\#additivity}{\texttt{appender additivity rule}} in the user manual for the meaning of the {\ttfamily additivity} flag.

\doxylink{requirements_The}{The} user can override any of the {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_hierarchy_ac670dc010d9be3b2fa7319cedeea26a5}{Hierarchy\+\#disable}} family of methods by setting the a key "{}log4cplus.\+disable\+Override"{} to {\ttfamily true} or any value other than false. As in 
\begin{DoxyPre}log4cplus.disableOverride=true \end{DoxyPre}


\doxysubsubsubsection*{Example}

An example configuration is given below.


\begin{DoxyPre}

\# Set options for appender named "{}A1"{}.
\# \doxylink{classdcmtk_1_1log4cplus_1_1_appender}{Appender} "{}A1"{} will be a SyslogAppender
log4cplus.appender.A1=log4cplus::SyslogAppender

\# \doxylink{requirements_The}{The} syslog daemon resides on www.abc.net
log4cplus.appender.A1.SyslogHost=www.abc.net

\# A1's layout is a \doxylink{classdcmtk_1_1log4cplus_1_1_pattern_layout}{PatternLayout}, using the conversion pattern
\# {\bfseries{r \%-\/5p c\{2\} M.L x -\/ m~\newline
}}. Thus, the log output will
\# include \# the relative time since the start of the application in
\# milliseconds, followed by the \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{LogLevel} of the log request,
\# followed by the two rightmost components of the logger name,
\# followed by the callers method name, followed by the line number,
\# the nested diagnostic context and finally the message itself.
\# Refer to the documentation of {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_pattern_layout}{PatternLayout}} for further information
\# on the syntax of the ConversionPattern key.
log4cplus.appender.A1.layout=\doxylink{classdcmtk_1_1log4cplus_1_1_pattern_layout}{log4cplus::PatternLayout}
log4cplus.appender.A1.layout.ConversionPattern=\%-\/4r \%-\/5p c\{2\} M.L x -\/ m~\newline

\# Set options for appender named "{}A2"{}
\# A2 should be a \doxylink{classdcmtk_1_1log4cplus_1_1_rolling_file_appender}{RollingFileAppender}, with maximum file size of 10 MB
\# using at most one backup file. A2's layout is TTCC, using the
\# ISO8061 date format with context printing enabled.
log4cplus.appender.A2=\doxylink{classdcmtk_1_1log4cplus_1_1_rolling_file_appender}{log4cplus::RollingFileAppender}
log4cplus.appender.A2.MaxFileSize=10MB
log4cplus.appender.A2.MaxBackupIndex=1
log4cplus.appender.A2.layout=\doxylink{classdcmtk_1_1log4cplus_1_1_t_t_c_c_layout}{log4cplus::TTCCLayout}
log4cplus.appender.A2.layout.ContextPrinting=enabled
log4cplus.appender.A2.layout.DateFormat=ISO8601

\# Root logger set to DEBUG using the A2 appender defined above.
log4cplus.rootLogger=DEBUG, A2

\# \doxylink{classdcmtk_1_1log4cplus_1_1_logger}{Logger} definitions:
\# \doxylink{requirements_The}{The} SECURITY logger inherits is \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{LogLevel} from root. However, it's output
\# will go to A1 appender defined above. It's additivity is non-\/cumulative.
log4cplus.logger.SECURITY=INHERIT, A1
log4cplus.additivity.SECURITY=false

\# Only warnings or above will be logged for the logger "{}SECURITY.access"{}.
\# Output will go to A1.
log4cplus.logger.SECURITY.access=WARN


\# \doxylink{requirements_The}{The} logger "{}class.of.the.day"{} inherits its \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{LogLevel} from the
\# logger hierarchy.  Output will go to the appender's of the root
\# logger, A2 in this case.
log4cplus.logger.class.of.the.day=INHERIT
\end{DoxyPre}
