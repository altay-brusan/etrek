\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class OFshared\+\_\+ptr$<$ T $>$}
\doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} is a smart pointer that retains shared ownership of an object through a pointer. Several \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} objects may own the same object; the object is destroyed when the last remaining \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} referring to it is destroyed or reset.

An \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} may also own no objects, in which case it is called empty.

\doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} meets the requirements of Copy\+Constructible and Copy\+Assignable. 
\begin{DoxyTemplParams}{Template Parameters}
{\em T} & the type of the managed object, e.\+g. int for an \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} behaving like an int\texorpdfstring{$\ast$}{*}. \\
\hline
\end{DoxyTemplParams}
\begin{DoxyNote}{Note}
this implementation is meant to be a subset of the c++11\textquotesingle{}s std::\+shared\+\_\+ptr that lacks the following features:\+ swap support, support for weak references, atomic access to the managed object, custom deleters and some functions like comparing OFshared\+\_\+ptrs or read access to the reference counter. see \href{http://en.cppreference.com/w/cpp/memory/shared_ptr}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+memory/\+shared\+\_\+ptr}} to compare \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} against std::\+shared\+\_\+ptr. 
\end{DoxyNote}
