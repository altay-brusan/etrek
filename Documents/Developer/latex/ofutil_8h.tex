Obtains an rvalue reference to its argument and converts it to an xvalue. OFmove is meant to \textquotesingle{}mark\textquotesingle{} an object for a move operation, e.\+g. to move an \doxylink{class_o_f_vector}{OFVector} object into another \doxylink{class_o_f_vector}{OFVector} instance instead of copying it. \begin{DoxyNote}{Note}
OFmove will be an alias for std::\+move when native move semantics are supported (C++11 support is available). Otherwise DCMTK\textquotesingle{}s move emulation will be used. This means you will have to specify rvalues (e.\+g. function return values) employing the \doxylink{struct_o_frvalue}{OFrvalue} class template. 
\end{DoxyNote}

T \& OFrvalue\+\_\+access (\begin{DoxyParamCaption}\item[{OFrvalue\+\_\+ref(T)}]{rv}{}\end{DoxyParamCaption})}

Obtain an lvalue reference from an rvalue reference. DCMTK\textquotesingle{}s move emulations does restrict write access to rvalue references due to compiler limitations. This method enables you to workaround this restriction by converting DCMTK\textquotesingle{}s emulated rvalue references to lvalue references. \begin{DoxyNote}{Note}
Native rvalue references from C++11 don\textquotesingle{}t need this workaround, therefore {\itshape OFrvalue\+\_\+access} has no effect when C++11 support is available. 
\end{DoxyNote}

void OFswap (\begin{DoxyParamCaption}\item[{T \&}]{t0}{, }\item[{T \&}]{t1}{}\end{DoxyParamCaption})}

Exchanges the given values. OFswap is an alias for std::\+swap if C++11 is supported. Otherwise OFswap simply creates a temporary copy of one argument to exchange both values. \begin{DoxyNote}{Note}
As intended for std::\+swap, there are some specializations for OFswap available, e.\+g. for \doxylink{class_o_foptional}{OFoptional}, which specializes OFswap to exchange optional objects more efficiently. When creating your own specializations for OFswap, make sure to specialize std::\+swap instead when C++11 support is available. 
\end{DoxyNote}
