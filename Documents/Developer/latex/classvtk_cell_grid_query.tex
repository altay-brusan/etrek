\doxysubsection{Detailed Description}
Perform an operation on cells in a \doxylink{classvtk_cell_metadata}{vtk\+Cell\+Metadata} instance. 

This is an empty base class that all query types must inherit.

\doxylink{requirements_The}{The} {\ttfamily \doxylink{classvtk_cell_grid_a6a055f6f703b9dd9cc83c9eb5a601021}{vtk\+Cell\+Grid::\+\+Query()}} method calls the query\textquotesingle{}s {\ttfamily \doxylink{classvtk_cell_grid_query_a7cf8a93bd7270780221c997ea2786292}{Initialize()}} implementation; then loops over all its cell-\/types (calling the best-\/matching responder\textquotesingle{}s {\ttfamily Query()} method for that cell-\/type); then calls {\ttfamily \doxylink{classvtk_cell_grid_query_ae6dc03698778466a55a4f30f69dd8c3a}{Finalize()}}.

\doxylink{requirements_The}{The} responders have an opportunity to modify the state of the query object, so these methods are a chance to prepare your query\textquotesingle{}s state and then perform reduce-\/like computations after all the cells have been handled.
