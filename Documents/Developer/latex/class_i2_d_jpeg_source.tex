\doxysubsection{Detailed Description}
This is a \doxylink{class_i2_d_img_source}{I2\+DImg\+Source} implementation that can parse JPEG files and convert them into DICOM images. This includes files using the original JPEG encoding (ITU-\/T Recommendation T.\+81) and JPEG-\/\+LS encoding (ITU-\/T Recommendation T.\+87).
