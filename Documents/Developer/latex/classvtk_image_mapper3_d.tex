\doxysubsection{Detailed Description}
abstract class for mapping images to the screen 

\doxylink{classvtk_image_mapper3_d}{vtk\+Image\+Mapper3D} is a mapper that will draw a 2D image, or a slice of a 3D image. \doxylink{requirements_The}{The} slice plane can be set automatically follow the camera, so that it slices through the focal point and faces the camera. \begin{DoxyParagraph}{Thanks:\+}
Thanks to David Gobbi at the Seaman Family MR Centre and Dept. of Clinical Neurosciences, Foothills Medical Centre, Calgary, for providing this class.
