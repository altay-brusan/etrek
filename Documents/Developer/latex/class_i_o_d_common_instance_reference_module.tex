\doxysubsection{Detailed Description}
Class representing the Common Instance Reference Module:\+

Referenced Series Sequence:\+ (SQ, VM 1-\/n, Type 1C) \begin{quote}
Series Instance UID:\+ (UI, 1, 1) Referenced Instance Sequence:\+ (SQ, 1-\/n, 1) \begin{quote}
SOP Instance Reference Macro Studies Containing Other Referenced Instances Sequence:\+ (SQ, 1-\/n, 1C) \end{quote}
Study Instance UID (UI, 1, 1) Series and Instance Reference Macro \end{quote}


Thus the Common Instance Reference Module lists references to other SOP instances and divides them between those instances that are in the same study, and those that are inside another study.
