\doxysubsection{Detailed Description}
topologically regular array of data 

\doxylink{classvtk_structured_grid}{vtk\+Structured\+Grid} is a data object that is a concrete implementation of \doxylink{classvtk_data_set}{vtk\+Data\+Set}. \doxylink{classvtk_structured_grid}{vtk\+Structured\+Grid} represents a geometric structure that is a topologically regular array of points. \doxylink{requirements_The}{The} topology is that of a cube that has been subdivided into a regular array of smaller cubes. Each point/\+cell can be addressed with i-\/j-\/k indices. Examples include finite difference grids.

\doxylink{requirements_The}{The} order and number of points must match that specified by the dimensions of the grid. \doxylink{requirements_The}{The} point order increases in i fastest (from 0\texorpdfstring{$<$}{<}=i\texorpdfstring{$<$}{<}dims\+[0]\+), then j (0\texorpdfstring{$<$}{<}=j\texorpdfstring{$<$}{<}dims\+[1]\+), then k (0\texorpdfstring{$<$}{<}=k\texorpdfstring{$<$}{<}dims\+[2]\+) where dims\+[]\+ are the dimensions of the grid in the i-\/j-\/k topological directions. \doxylink{requirements_The}{The} number of points is dims\+[0]\+\texorpdfstring{$\ast$}{*}dims\+[1]\+\texorpdfstring{$\ast$}{*}dims\+[2]\+. \doxylink{requirements_The}{The} same is true for the cells of the grid. \doxylink{requirements_The}{The} order and number of cells must match that specified by the dimensions of the grid. \doxylink{requirements_The}{The} cell order increases in i fastest (from 0\texorpdfstring{$<$}{<}=i\texorpdfstring{$<$}{<}(dims\+[0]\+-\/1)), then j (0\texorpdfstring{$<$}{<}=j\texorpdfstring{$<$}{<}(dims\+[1]\+-\/1)), then k (0\texorpdfstring{$<$}{<}=k\texorpdfstring{$<$}{<}(dims\+[2]\+-\/1)) \doxylink{requirements_The}{The} number of cells is (dims\+[0]\+-\/1)\texorpdfstring{$\ast$}{*}(dims\+[1]\+-\/1)\texorpdfstring{$\ast$}{*}(dims\+[2]\+-\/1).

\doxylink{classvtk_structured_grid}{vtk\+Structured\+Grid} has the ability to blank, or "{}turn-\/off"{} points and cells in the dataset. This is done by setting vtk\+Data\+Set\+Attributes::\+\+HIDDENPOINT or vtk\+Data\+Set\+Attributes::\+\+HIDDENCELL in the ghost array for each point /\+ cell that needs to be blanked.
