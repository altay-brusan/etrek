\doxysubsection{Detailed Description}
A view containing a renderer. 

\doxylink{classvtk_render_view}{vtk\+Render\+View} is a view which contains a \doxylink{classvtk_renderer}{vtk\+Renderer}. You may add vtk\+Actors directly to the renderer, or add certain \doxylink{classvtk_data_representation}{vtk\+Data\+Representation} subclasses to the renderer. \doxylink{requirements_The}{The} render view supports drag selection with the mouse to select cells.

This class is also the parent class for any more specialized view which uses a renderer.
