\doxysubsection{Detailed Description}
Exports \doxylink{classvtk_context2_d}{vtk\+Context2D} scenes to PDF. 

This exporter draws context2D scenes into a PDF file.

If Active\+Renderer is specified then it exports contents of Active\+Renderer. Otherwise it exports contents of all renderers.
