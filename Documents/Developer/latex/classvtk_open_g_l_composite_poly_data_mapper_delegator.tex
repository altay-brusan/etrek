\doxysubsection{Detailed Description}
An Open\+GL delegator for batched rendering of multiple polydata with similar structure. 

This class delegates work to \doxylink{classvtk_open_g_l_batched_poly_data_mapper}{vtk\+Open\+GLBatched\+Poly\+Data\+Mapper} which can do batched rendering of many polydata.
