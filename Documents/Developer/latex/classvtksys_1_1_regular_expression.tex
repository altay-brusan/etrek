\doxysubsection{Detailed Description}
Implements pattern matching with regular expressions. 

This is the header file for the regular expression class. An object of this class contains a regular expression, in a special "{}compiled"{} format. This compiled format consists of several slots all kept as the objects private data. \doxylink{requirements_The}{The} \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} class provides a convenient way to represent regular expressions. It makes it easy to search for the same regular expression in many different strings without having to compile a string to regular expression format more than necessary.

This class implements pattern matching via regular expressions. A regular expression allows a programmer to specify complex patterns that can be searched for and matched against the character string of a string object. In its simplest form, a regular expression is a sequence of characters used to search for exact character matches. However, many times the exact sequence to be found is not known, or only a match at the beginning or end of a string is desired. \doxylink{requirements_The}{The} \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} regu-\/ lar expression class implements regular expression pattern matching as is found and implemented in many UNIX commands and utilities.

Example:\+ \doxylink{requirements_The}{The} perl code

\$filename =\texorpdfstring{$\sim$}{\string~} m"{}(\+[a-\/z]\++)\textbackslash{}.\+cc"{}; print \$1;

Is written as follows in C++

\doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} re("{}(\+[a-\/z]\++)\textbackslash{}\textbackslash{}.\+cc"{}); re.\+find(filename); cerr \texorpdfstring{$<$}{<}\texorpdfstring{$<$}{<} re.\+match(1);

\doxylink{requirements_The}{The} regular expression class provides a convenient mechanism for specifying and manipulating regular expressions. \doxylink{requirements_The}{The} regular expression object allows specification of such pat-\/ terns by using the following regular expression metacharac-\/ ters:\+

\texorpdfstring{$^\wedge$}{\string^} Matches at beginning of a line

\$ Matches at end of a line

. Matches any single character

\+[ ]\+ Matches any character(s) inside the brackets

\+[\texorpdfstring{$^\wedge$}{\string^} ]\+ Matches any character(s) not inside the brackets


\begin{DoxyItemize}
\item Matches any character in range on either side of a dash
\item Matches preceding pattern zero or more times
\item Matches preceding pattern one or more times
\end{DoxyItemize}

? Matches preceding pattern zero or once only

() Saves a matched expression and uses it in a later match

Note that more than one of these metacharacters can be used in a single regular expression in order to create complex search patterns. For example, the pattern \+[\texorpdfstring{$^\wedge$}{\string^}ab1-\/9]\+ says to match any character sequence that does not begin with the characters "{}ab"{} followed by numbers in the series one through nine.

There are three constructors for \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression}. One just creates an empty \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} object. Another creates a \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} object and initializes it with a regular expression that is given in the form of a char\texorpdfstring{$\ast$}{*}. \doxylink{requirements_The}{The} third takes a reference to a \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} object as an argument and creates an object initialized with the information from the given \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} object.

\doxylink{requirements_The}{The} find member function finds the first occurrence of the regular expression of that object in the string given to find as an argument. Find returns a boolean, and if true, mutates the private data appropriately. Find sets pointers to the beginning and end of the thing last found, they are pointers into the actual string that was searched. \doxylink{requirements_The}{The} start and end member functions return indices into the searched string that correspond to the beginning and end pointers respectively. \doxylink{requirements_The}{The} compile member function takes a char\texorpdfstring{$\ast$}{*} and puts the compiled version of the char\texorpdfstring{$\ast$}{*} argument into the object\textquotesingle{}s private data fields. \doxylink{requirements_The}{The} == and != operators only check the to see if the compiled regular expression is the same, and the deep\+\_\+equal functions also checks to see if the start and end pointers are the same. \doxylink{requirements_The}{The} is\+\_\+valid function returns false if program is set to nullptr, (i.\+e. there is no valid compiled expression). \doxylink{requirements_The}{The} set\+\_\+invalid function sets the program to nullptr (Warning:\+ this deletes the compiled expression). \doxylink{requirements_The}{The} following examples may help clarify regular expression usage:\+


\begin{DoxyItemize}
\item \doxylink{requirements_The}{The} regular expression "{}\texorpdfstring{$^\wedge$}{\string^}hello"{} matches a "{}hello"{} only at the beginning of a line. It would match "{}hello  there"{} but not "{}hi,      hello there"{}.
\item \doxylink{requirements_The}{The} regular expression "{}long\$"{} matches a "{}long"{} only at the end of a line. It would match "{}so long\textbackslash{}0"{}, but not "{}long ago"{}.
\item \doxylink{requirements_The}{The} regular expression "{}t..\+t..\+g"{} will match anything that has a "{}t"{} then any two characters, another "{}t"{}, any two characters and then a "{}g"{}. It will match "{}testing"{}, or "{}test again"{} but would not match "{}toasting"{}
\item \doxylink{requirements_The}{The} regular expression "{}\+[1-\/9ab]\+"{} matches any number one through nine, and the characters "{}a"{} and "{}b"{}. It would match "{}hello 1"{} or "{}begin"{}, but would not match "{}no-\/match"{}.
\item \doxylink{requirements_The}{The} regular expression "{}\+[\texorpdfstring{$^\wedge$}{\string^}1-\/9ab]\+"{} matches any character that is not a number one through nine, or an "{}a"{} or "{}b"{}. It would NOT match "{}hello 1"{} or "{}begin"{}, but would match "{}no-\/match"{}.
\item \doxylink{requirements_The}{The} regular expression "{}br\texorpdfstring{$\ast$}{*} "{} matches something that begins with a "{}b"{}, is followed by zero or more "{}r"{}s, and ends in a space. It would match "{}brrrrr "{}, and "{}b "{}, but would not match "{}brrh "{}.
\item \doxylink{requirements_The}{The} regular expression "{}br+ "{} matches something that begins with a "{}b"{}, is followed by one or more "{}r"{}s, and ends in a space. It would match "{}brrrrr "{}, and "{}br "{}, but would not match "{}b  "{} or "{}brrh "{}.
\item \doxylink{requirements_The}{The} regular expression "{}br? "{} matches something that begins with a "{}b"{}, is followed by zero or one "{}r"{}s, and ends in a space. It would match "{}br "{}, and "{}b  "{}, but would not match "{}brrrr "{} or "{}brrh "{}.
\item \doxylink{requirements_The}{The} regular expression "{}(..\+p)b"{} matches something ending with pb and beginning with whatever the two characters before the first p encountered in the line were. It would find "{}repb"{} in "{}rep drepa      qrepb"{}. \doxylink{requirements_The}{The} regular expression "{}(..\+p)a"{} would find "{}repa qrepb"{} in "{}rep drepa qrepb"{}
\item \doxylink{requirements_The}{The} regular expression "{}d(..\+p)"{} matches something ending with p, beginning with d, and having two characters in between that are the same as the two characters before the first p encountered in the line. It would match "{}drepa qrepb"{} in "{}rep drepa qrepb"{}.
\end{DoxyItemize}

All methods of \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression} can be called simultaneously from different threads but only if each invocation uses an own instance of \doxylink{classvtksys_1_1_regular_expression}{Regular\+Expression}.
