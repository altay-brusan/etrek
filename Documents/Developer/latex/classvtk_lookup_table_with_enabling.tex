\doxysubsection{Detailed Description}
A lookup table that allows for an optional array to be provided that specifies which scalars to "{}enable"{} and which to "{}disable"{}. 

\doxylink{classvtk_lookup_table_with_enabling}{vtk\+Lookup\+Table\+With\+Enabling} "{}disables"{} or "{}grays out"{} output colors based on whether the given value in Enabled\+Array is "{}0"{} or not.

\begin{DoxyWarning}{Warning}
You must set the Enabled\+Array before \doxylink{classvtk_scalars_to_colors_a0311230ca7c8d3b8e68fd9acaeb9c8e3}{Map\+Scalars()} is called. Indices of Enabled\+Array must map directly to those of the array passed to \doxylink{classvtk_scalars_to_colors_a0311230ca7c8d3b8e68fd9acaeb9c8e3}{Map\+Scalars()}. 
\end{DoxyWarning}
