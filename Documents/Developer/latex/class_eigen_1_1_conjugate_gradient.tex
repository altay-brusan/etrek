\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type, int \+\_\+\+Up\+Lo, typename \+\_\+\+Preconditioner$>$\newline
class Eigen::\+\+Conjugate\+Gradient$<$ \+\_\+\+Matrix\+Type, \+\_\+\+Up\+Lo, \+\_\+\+Preconditioner $>$}
A conjugate gradient solver for sparse (or dense) self-\/adjoint problems. 

This class allows to solve for A.\+x = b linear problems using an iterative conjugate gradient algorithm. \doxylink{requirements_The}{The} matrix A must be selfadjoint. \doxylink{requirements_The}{The} matrix A and the vectors x and b can be either dense or sparse.


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the matrix A, can be a dense or a sparse matrix. \\
\hline
{\em \+\_\+\+Up\+Lo} & the triangular part that will be used for the computations. It can be Lower, {\ttfamily Upper}, or {\ttfamily Lower\texorpdfstring{$\vert$}{|}\+Upper} in which the full matrix entries will be considered. Default is {\ttfamily Lower}, best performance is {\ttfamily Lower\texorpdfstring{$\vert$}{|}\+Upper}. \\
\hline
{\em \+\_\+\+Preconditioner} & the type of the preconditioner. Default is \doxylink{class_eigen_1_1_diagonal_preconditioner}{Diagonal\+Preconditioner}\\
\hline
\end{DoxyTemplParams}
\textbackslash{}implsparsesolverconcept

\doxylink{requirements_The}{The} maximal number of iterations and tolerance value can be controlled via the \doxylink{class_eigen_1_1_iterative_solver_base_a1bbaf86b7df6d54e78ced4da6ed2dac1}{set\+Max\+Iterations()} and \doxylink{class_eigen_1_1_iterative_solver_base_ac43c50c69a5b621cb5a9991a1005750d}{set\+Tolerance()} methods. \doxylink{requirements_The}{The} defaults are the size of the problem for the maximal number of iterations and Num\+Traits$<$\+Scalar$>$::\+epsilon() for the tolerance.

\doxylink{requirements_The}{The} tolerance corresponds to the relative residual error:\+ \texorpdfstring{$\vert$}{|}\+Ax-\/b\texorpdfstring{$\vert$}{|}/\+\texorpdfstring{$\vert$}{|}b\texorpdfstring{$\vert$}{|}

{\bfseries{Performance:\+}} Even though the default value of {\ttfamily \+\_\+\+Up\+Lo} is {\ttfamily Lower}, significantly higher performance is achieved when using a complete matrix and {\bfseries{Lower\texorpdfstring{$\vert$}{|}\+Upper}} as the {\itshape \+\_\+\+Up\+Lo} template parameter. Moreover, in this case multi-\/threading can be exploited if the user code is compiled with Open\+MP enabled. See Topic\+Multi\+Threading for details.
