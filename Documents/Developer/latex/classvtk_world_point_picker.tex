\doxysubsection{Detailed Description}
find world x,y,z corresponding to display x,y,z 

\doxylink{classvtk_world_point_picker}{vtk\+World\+Point\+Picker} is used to find the x,y,z world coordinate of a screen x,y,z. This picker cannot pick actors and/\+or mappers, it simply determines an x-\/y-\/z coordinate in world space. (It will always return a x-\/y-\/z, even if the selection point is not over a prop/\+actor.)

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} Pick\+Method() is not invoked, but Start\+Pick\+Method() and End\+Pick\+Method() are.
\end{DoxyWarning}
