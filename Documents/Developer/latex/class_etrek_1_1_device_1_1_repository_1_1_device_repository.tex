\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_device_1_1_repository}{Repository} for medical imaging device configuration. 

Implements the \doxylink{namespace_etrek_1_1_device_1_1_repository}{Repository} pattern for device-\/related data access. Provides CRUD operations for:\+
\begin{DoxyItemize}
\item X-\/ray generators
\item Digital detectors
\item X-\/ray tubes
\item Institutions
\item General equipment
\item Environment settings
\end{DoxyItemize}

Uses Qt SQL with My\+SQL backend. Includes soft-\/delete support (deactivation) for entities that should not be permanently removed.

\begin{DoxyNote}{Note}
Thread-\/safe for read operations. Write operations should be synchronized by the caller.
\end{DoxyNote}
