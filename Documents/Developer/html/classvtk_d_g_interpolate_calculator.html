void vtkDGInterpolateCalculator::EvaluateDerivative ( vtkIdType cellId,
const vtkVector3d & rst,
std::vector< double > & jacobian,
double neighborhood )
overridevirtual

Return the derivative of the function at rst.

The derivative should be ordered as d/dx, d/dy, then d/dz.

If you do not override AnalyticDerivative and EvaluateDerivative, this class will approximate the derivative by perturbing along each axis to compute a finite difference.

In the case of a non-analytic derivative, you can control the magnitude of the difference along each axis by passing a different neighborhood value.
