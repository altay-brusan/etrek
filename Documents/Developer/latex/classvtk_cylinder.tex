\doxysubsection{Detailed Description}
implicit function for a cylinder 

\doxylink{classvtk_cylinder}{vtk\+Cylinder} computes the implicit function and function gradient for a cylinder using F(r)=r\texorpdfstring{$^\wedge$}{\string^}2-\/\+Radius\texorpdfstring{$^\wedge$}{\string^}2. \doxylink{classvtk_cylinder}{vtk\+Cylinder} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. By default the Cylinder is centered at the origin and the axis of rotation is along the y-\/axis. You can redefine the center and axis of rotation by setting the Center and Axis data members. (Note that it is also possible to use the superclass\textquotesingle{} \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function} transformation matrix if necessary to reposition by using \doxylink{classvtk_implicit_function_a4cf810b62220d5ea59c278ed00abdc2d}{Function\+Value()} and \doxylink{classvtk_implicit_function_ae82826d3dbbeb689289bedc5373aef2b}{Function\+Gradient()}.)

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} cylinder is infinite in extent. To truncate the cylinder in modeling operations use the \doxylink{classvtk_implicit_boolean}{vtk\+Implicit\+Boolean} in combination with clipping planes.
\end{DoxyWarning}
