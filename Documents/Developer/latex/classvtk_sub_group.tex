\doxysubsection{Detailed Description}
scalable collective communication for a subset of members of a parallel VTK application 

\begin{DoxyVerb}This class provides scalable broadcast, reduce, etc. using
only a vtkMultiProcessController. It does not require MPI.
Users are vtkPKdTree and vtkDistributedDataFilter.
\end{DoxyVerb}


\begin{DoxyAttention}{Attention}
This class will be deprecated soon. Instead of using this class, use the collective and subgrouping operations now built into \doxylink{classvtk_multi_process_controller}{vtk\+Multi\+Process\+Controller}. \doxylink{requirements_The}{The} only reason this class is not deprecated already is because \doxylink{classvtk_p_kd_tree}{vtk\+PKd\+Tree} relies heavily on this class in ways that are not easy to work around. Since \doxylink{classvtk_p_kd_tree}{vtk\+PKd\+Tree} is due for a major overhaul anyway, we are leaving things the way they are for now.
\end{DoxyAttention}
