\doxysubsection{Detailed Description}
a nonlinear warp transformation 

\doxylink{classvtk_grid_transform}{vtk\+Grid\+Transform} describes a nonlinear warp transformation as a set of displacement vectors sampled along a uniform 3D grid. \begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} inverse grid transform is calculated using an iterative method, and is several times more expensive than the forward transform. 
\end{DoxyWarning}
