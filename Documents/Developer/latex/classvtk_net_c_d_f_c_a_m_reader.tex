\doxysubsection{Detailed Description}
Read unstructured Net\+CDF CAM files. 

Reads in a Net\+CDF CAM (Community Atmospheric Model) file and produces and unstructured grid. \doxylink{requirements_The}{The} grid is actually unstructured in the X and Y directions and rectilinear in the Z direction. If we read one layer we produce quad cells otherwise we produce hex cells. \doxylink{requirements_The}{The} reader requires 2 Net\+CDF files:\+ the main file has all attributes, the connectivity file has point positions and cell connectivity information.
