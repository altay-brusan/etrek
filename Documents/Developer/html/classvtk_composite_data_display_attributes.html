Detailed Description

Rendering attributes for a multi-block dataset.

The vtkCompositeDataDisplayAttributes class stores display attributes for individual blocks in a multi-block dataset. It uses the actual data block's pointer as a key (vtkDataObject*).

Warning
It is considered unsafe to dereference key pointers at any time, they should only serve as keys to access the internal map.
