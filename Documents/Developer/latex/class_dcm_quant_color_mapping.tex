class Dcm\+Quant\+Color\+Mapping$<$ T1, T2 $>$}
template class that maps a color image into a palette color image with given color palette. \doxylink{requirements_The}{The} two template parameters define the error diffusion class used to implement e.\+g. Floyd-\/\+Steinberg error diffusion and the output type of the color index values, which may be 8 bit or 16 bit unsigned integers.
