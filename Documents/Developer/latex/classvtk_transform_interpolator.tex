\doxysubsection{Detailed Description}
interpolate a series of transformation matrices 

This class is used to interpolate a series of 4x4 transformation matrices. Position, scale and orientation (i.\+e., rotations) are interpolated separately, and can be interpolated linearly or with a spline function. Note that orientation is interpolated using quaternions via SLERP (spherical linear interpolation) or the special vtk\+Quaternion\+Spline class.

To use this class, specify at least two pairs of (t,transformation matrix) with the \doxylink{classvtk_transform_interpolator_a2f6a9633df647da4091bef2d58b10e33}{Add\+Transform()} method. Then interpolated the transforms with the Interpolate\+Transform(t,transform) method, where "{}t"{} must be in the range of (min,max) times specified by the \doxylink{classvtk_transform_interpolator_a2f6a9633df647da4091bef2d58b10e33}{Add\+Transform()} method.

By default, spline interpolation is used for the interpolation of the transformation matrices. \doxylink{requirements_The}{The} position, scale and orientation of the matrices are interpolated with instances of the classes \doxylink{classvtk_tuple_interpolator}{vtk\+Tuple\+Interpolator} (position,scale) and \doxylink{classvtk_quaternion_interpolator}{vtk\+Quaternion\+Interpolator} (rotation). \doxylink{requirements_The}{The} user can override the interpolation behavior by gaining access to these separate interpolation classes. These interpolator classes (\doxylink{classvtk_tuple_interpolator}{vtk\+Tuple\+Interpolator} and \doxylink{classvtk_quaternion_interpolator}{vtk\+Quaternion\+Interpolator}) can be modified to perform linear versus spline interpolation, and/\+or different spline basis functions can be specified.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} interpolator classes are initialized when the \doxylink{classvtk_transform_interpolator_a48811d0be10077be98c55cdd6b4a7992}{Interpolate\+Transform()} is called. Any changes to the interpolators, or additions to the list of transforms to be interpolated, causes a reinitialization of the interpolators the next time \doxylink{classvtk_transform_interpolator_a48811d0be10077be98c55cdd6b4a7992}{Interpolate\+Transform()} is invoked. Thus the best performance is obtained by 1) configuring the interpolators, 2) adding all the transforms, and 3) finally performing interpolation. 
\end{DoxyWarning}
