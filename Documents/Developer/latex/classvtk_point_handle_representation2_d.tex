\doxysubsection{Detailed Description}
represent the position of a point in display coordinates 

This class is used to represent a \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget}. It represents a position in 2D world coordinates using a x-\/y cursor (the cursor defined by an instance of \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} and generated by a \doxylink{classvtk_poly_data_algorithm}{vtk\+Poly\+Data\+Algorithm}).
