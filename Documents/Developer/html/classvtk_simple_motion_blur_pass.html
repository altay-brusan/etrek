Detailed Description

Avergae frames to simulate motion blur.

A slow and simple approach that simply renders multiple frames and accumulates them before displaying them. As such it causes the render process to be SubFrames times slower than normal but handles all types of motion correctly as it is actually rendering all the sub frames.

vtkRenderPass

◆ vtkGetMacro()

vtkSimpleMotionBlurPass::vtkGetMacro ( SubFrames ,
int  )

Set the number of sub frames for doing motion blur. Once this is set greater than one, you will no longer see a new frame for every Render(). If you set this to five, you will need to do five Render() invocations before seeing the result. This isn't very impressive unless something is changing between the Renders. Changing this value may reset the current subframe count.
