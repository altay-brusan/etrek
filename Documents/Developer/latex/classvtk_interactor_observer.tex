\doxysubsection{Detailed Description}
an abstract superclass for classes observing events invoked by \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} 

\doxylink{classvtk_interactor_observer}{vtk\+Interactor\+Observer} is an abstract superclass for subclasses that observe events invoked by \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor}. These subclasses are typically things like 3D widgets; objects that interact with actors in the scene, or interactively probe the scene for information.

\doxylink{classvtk_interactor_observer}{vtk\+Interactor\+Observer} defines the method \doxylink{classvtk_interactor_observer_a7f52f3d776dbe073d690ee100ab685b4}{Set\+Interactor()} and enables and disables the processing of events by the \doxylink{classvtk_interactor_observer}{vtk\+Interactor\+Observer}. Use the methods Enabled\+On() or Set\+Enabled(1) to turn on the interactor observer, and the methods Enabled\+Off() or Set\+Enabled(0) to turn off the interactor. Initial value is 0.

To support interactive manipulation of objects, this class (and subclasses) invoke the events Start\+Interaction\+Event, Interaction\+Event, and End\+Interaction\+Event. These events are invoked when the \doxylink{classvtk_interactor_observer}{vtk\+Interactor\+Observer} enters a state where rapid response is desired:\+ mouse motion, etc. \doxylink{requirements_The}{The} events can be used, for example, to set the desired update frame rate (Start\+Interaction\+Event), operate on data or update a pipeline (Interaction\+Event), and set the desired frame rate back to normal values (End\+Interaction\+Event). Two other events, Enable\+Event and Disable\+Event, are invoked when the interactor observer is enabled or disabled.
