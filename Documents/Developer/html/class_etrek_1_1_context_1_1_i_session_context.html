Detailed Description

Interface for session/user context information.

Provides access to information about the current user session including:

  • Logged-in user details
  • Sign-in timestamp
  • Workstation information
  • Institution/health center details

This context is typically created after successful authentication and remains valid for the duration of the user's session.
