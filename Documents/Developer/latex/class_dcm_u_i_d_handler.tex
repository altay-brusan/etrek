\doxysubsection{Detailed Description}
helper class that manages a single DICOM UID. Unlike class \doxylink{class_dcm_unique_identifier}{Dcm\+Unique\+Identifier}, this class does not manage an attribute tag or means of encoding/\+decoding UIDs. Instead it allows to convert between numeric and symbolic representation of a UID and implements a syntactical check.

This class supports two special Transfer Syntax names, "{}\+Local\+Endian\+Explicit"{} and "{}\+Opposite\+Endian\+Explicit"{}. These are resolved to the explicit VR transfer syntaxes of the local byte order and the opposite byte order of the system the application is running on.
