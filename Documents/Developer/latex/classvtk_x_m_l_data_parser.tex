\doxysubsection{Detailed Description}
Used by \doxylink{classvtk_x_m_l_reader}{vtk\+XMLReader} to parse VTK XML files. 

\doxylink{classvtk_x_m_l_data_parser}{vtk\+XMLData\+Parser} provides a subclass of \doxylink{classvtk_x_m_l_parser}{vtk\+XMLParser} that constructs a representation of an XML data format\textquotesingle{}s file using \doxylink{classvtk_x_m_l_data_element}{vtk\+XMLData\+Element} to represent each XML element. This representation is then used by \doxylink{classvtk_x_m_l_reader}{vtk\+XMLReader} and its subclasses to traverse the structure of the file and extract data.
