\doxysubsection{Detailed Description}
ray-\/cast picker enhanced for volumes 

\doxylink{classvtk_volume_picker}{vtk\+Volume\+Picker} is a subclass of \doxylink{classvtk_cell_picker}{vtk\+Cell\+Picker}. It has one advantage over \doxylink{classvtk_cell_picker}{vtk\+Cell\+Picker} for volumes:\+ it will be able to correctly perform picking when Cropping\+Planes are present. This isn\textquotesingle{}t possible for \doxylink{classvtk_cell_picker}{vtk\+Cell\+Picker} since it doesn\textquotesingle{}t link to the Volume\+Rendering classes and hence cannot access information about the Cropping\+Planes.
