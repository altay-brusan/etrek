\doxysubsection{Detailed Description}
\subsubsection*{template$<$OFVARIADIC\+\_\+\+DECLARE\+\_\+\+TEMPLATE\+\_\+\+PARAMETER\+\_\+\+PACK\+\_\+\+WITH\+\_\+\+DEFAULTS(T)$>$\newline
class Dcm\+IODImage$<$$>$}
Class for managing common image IOD attributes. At the moment support for the palette-\/related attributes and the smallest/\+largest image pixel value attributes is still missing. Also, pixel data must be handled separately. However, pixel-\/data related attributes are provided by the Image Pixel Module, the Floating Point Image Pixel Module or the Double Floating Point Image Pixel Module, based on the provided template parameter. Modules supported on top of \doxylink{class_dcm_i_o_d_common}{Dcm\+IODCommon}:\+ General Image Module and Image Pixel Module.
