\doxysubsection{Detailed Description}
read a digital elevation model (DEM) file 

\doxylink{classvtk_d_e_m_reader}{vtk\+DEMReader} reads digital elevation files and creates image data. Digital elevation files are produced by the \href{http://www.usgs.gov}{\texttt{US Geological Survey}}. A complete description of the DEM file is located at the USGS site. \doxylink{requirements_The}{The} reader reads the entire dem file and create a \doxylink{classvtk_image_data}{vtk\+Image\+Data} that contains a single scalar component that is the elevation in meters. \doxylink{requirements_The}{The} spacing is also expressed in meters. A number of get methods provide access to fields on the header.
