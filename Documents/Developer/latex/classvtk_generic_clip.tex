\doxysubsection{Detailed Description}
clip any dataset with an implicit function or scalar data 

\doxylink{classvtk_generic_clip}{vtk\+Generic\+Clip} is a filter that any type of dataset using either any subclass of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}, or the input scalar data. Clipping means that it actually "{}cuts"{} through the cells of the dataset, returning everything inside of the specified implicit function (or greater than the scalar value) including "{}pieces"{} of a cell. (Compare this with \doxylink{classvtk_extract_geometry}{vtk\+Extract\+Geometry}, which pulls out entire, uncut cells.) \doxylink{requirements_The}{The} output of this filter is an unstructured grid.

To use this filter, you must decide if you will be clipping with an implicit function, or whether you will be using the input scalar data. If you want to clip with an implicit function, you must:\+ 1) define an implicit function 2) set it with the Set\+Clip\+Function method 3) apply the Generate\+Clip\+Scalars\+On method If a Clip\+Function is not specified, or Generate\+Clip\+Scalars is off (the default), then the input\textquotesingle{}s scalar data will be used to clip the polydata.

You can also specify a scalar value, which is used to decide what is inside and outside of the implicit function. You can also reverse the sense of what inside/\+outside is by setting the Inside\+Out instance variable. (\doxylink{requirements_The}{The} clipping algorithm proceeds by computing an implicit function value or using the input scalar data for each point in the dataset. This is compared to the scalar value to determine inside/\+outside.)

This filter can be configured to compute a second output. \doxylink{requirements_The}{The} second output is the part of the cell that is clipped away. Set the Generate\+Clipped\+Data boolean on if you wish to access this output data.

This filter has been implemented to operate on generic datasets, rather than the typical \doxylink{classvtk_data_set}{vtk\+Data\+Set} (and subclasses). \doxylink{classvtk_generic_data_set}{vtk\+Generic\+Data\+Set} is a more complex cousin of \doxylink{classvtk_data_set}{vtk\+Data\+Set}, typically consisting of nonlinear, higher-\/order cells. To process this type of data, generic cells are automatically tessellated into linear cells prior to isocontouring.
