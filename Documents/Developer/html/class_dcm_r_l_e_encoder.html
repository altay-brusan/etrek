Detailed Description

this class implements an RLE compressor conforming to the DICOM standard. The class is loosely based on an implementation by Phil Norman.

◆ flush()

void DcmRLEEncoder::flush ( )
inline

this method finalizes the compressed RLE stream, i.e. flushes all pending literal or repeat runs. This method can be called at any time; however, it must be called before size() or write() can be used. Intermediate calls should be avoided since they possibly decrease the compression ratio.

◆ size()

size_t DcmRLEEncoder::size ( ) const
inline

returns the size of compressed RLE stream in bytes. The size is guaranteed to be an even number of bytes (padded with a trailing zero byte as required by DICOM if necessary). This method may only be called after flush() has been executed to finalize the compressed stream.
