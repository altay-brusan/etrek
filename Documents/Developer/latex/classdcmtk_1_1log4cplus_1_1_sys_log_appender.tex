\doxysubsection{Detailed Description}
Appends log events to a file.

\doxysubsubsubsection*{Properties}


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\ttfamily ident} }}]\hfill \\
First argument to {\ttfamily openlog()}, a string that will be prepended to every message.


\item[{\parbox[t]{\linewidth}{{\ttfamily facility} }}]\hfill \\
Facility is used in combination with syslog level in first argument to syslog(). It can be one of the supported facility names (case insensitive), e.\+g. auth, cron, kern, mail, news etc.


\item[{\parbox[t]{\linewidth}{{\ttfamily host} }}]\hfill \\
Destination syslog host. When this property is specified, messages are sent using UDP to destination host, otherwise messages are logged to local syslog.


\item[{\parbox[t]{\linewidth}{{\ttfamily port} }}]\hfill \\
Destination port of syslog service on host specified by the {\ttfamily host} property. \doxylink{requirements_The}{The} default value is port 514. 
\end{DoxyDescription}

\begin{DoxyNote}{Note}
Messages sent to remote syslog using UDP are conforming to RFC5424. 
\end{DoxyNote}
