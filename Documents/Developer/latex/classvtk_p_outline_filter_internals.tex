\doxysubsection{Detailed Description}
create wireframe outline (or corners) for arbitrary data set 

\doxylink{classvtk_p_outline_filter_internals}{vtk\+POutline\+Filter\+Internals} has common code for \doxylink{classvtk_outline_filter}{vtk\+Outline\+Filter} and \doxylink{classvtk_outline_corner_filter}{vtk\+Outline\+Corner\+Filter}. It assumes the filter is operated in a data parallel pipeline.

This class does not inherit from \doxylink{classvtk_object}{vtk\+Object} and is not intended to be used outside of VTK.
