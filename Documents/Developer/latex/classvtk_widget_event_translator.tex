\doxysubsection{Detailed Description}
map VTK events into widget events 

\doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator} maps VTK events (defined on \doxylink{classvtk_command}{vtk\+Command}) into widget events (defined in \doxylink{vtk_widget_event_8h_source}{vtk\+Widget\+Event.\+h}). This class is typically used in combination with \doxylink{classvtk_widget_callback_mapper}{vtk\+Widget\+Callback\+Mapper}, which is responsible for translating widget events into method callbacks, and then invoking the callbacks.

This class can be used to define different mappings of VTK events into the widget events. Thus widgets can be reconfigured to use different event bindings.
