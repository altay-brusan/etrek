\doxysubsection{Detailed Description}
is a helper object used by \doxylink{classvtk_grid_axes_actor2_d}{vtk\+Grid\+Axes\+Actor2D}, \doxylink{classvtk_grid_axes_actor3_d}{vtk\+Grid\+Axes\+Actor3D}, and vtk\+Grid\+Axes\+Plane2\+DActor. 

\doxylink{classvtk_grid_axes_actor2_d}{vtk\+Grid\+Axes\+Actor2D}, \doxylink{classvtk_grid_axes_actor3_d}{vtk\+Grid\+Axes\+Actor3D}, and vtk\+Grid\+Axes\+Plane2\+DActor shares a lot of the computations and logic. This class makes it possible to share all such information between these classes. This class works with a single face of the bounding box specified using the Grid\+Bounds.
