\doxysubsection{Detailed Description}
a dataset that is topologically regular with variable spacing in the three coordinate directions 

\doxylink{classvtk_rectilinear_grid}{vtk\+Rectilinear\+Grid} is a data object that is a concrete implementation of \doxylink{classvtk_data_set}{vtk\+Data\+Set}. \doxylink{classvtk_rectilinear_grid}{vtk\+Rectilinear\+Grid} represents a geometric structure that is topologically regular with variable spacing in the three coordinate directions x-\/y-\/z.

To define a \doxylink{classvtk_rectilinear_grid}{vtk\+Rectilinear\+Grid}, you must specify the dimensions of the data and provide three arrays of values specifying the coordinates along the x-\/y-\/z axes. \doxylink{requirements_The}{The} coordinate arrays are specified using three \doxylink{classvtk_data_array}{vtk\+Data\+Array} objects (one for x, one for y, one for z).

\begin{DoxyWarning}{Warning}
Make sure that the dimensions of the grid match the number of coordinates in the x-\/y-\/z directions. If not, unpredictable results (including program failure) may result. Also, you must supply coordinates in all three directions, even if the dataset topology is 2D, 1D, or 0D. 
\end{DoxyWarning}
