\doxysubsection{Detailed Description}
a actor that draws 2D data 

\doxylink{classvtk_actor2_d}{vtk\+Actor2D} is similar to \doxylink{classvtk_actor}{vtk\+Actor}, but it is made to be used with two dimensional images and annotation. \doxylink{classvtk_actor2_d}{vtk\+Actor2D} has a position but does not use a transformation matrix like \doxylink{classvtk_actor}{vtk\+Actor} (see the superclass \doxylink{classvtk_prop}{vtk\+Prop} for information on positioning \doxylink{classvtk_actor2_d}{vtk\+Actor2D}). \doxylink{classvtk_actor2_d}{vtk\+Actor2D} has a reference to a \doxylink{classvtk_mapper2_d}{vtk\+Mapper2D} object which does the rendering.
