\begin{DoxyItemize}
\item {\bfseries{Patient demographics}} and medical imaging data (DICOM hierarchy)
\item {\bfseries{Device configurations}} (generators, X-\/ray tubes, detectors, positioners)
\item {\bfseries{DICOM Modality Worklist (MWL)}} entries and DICOM tag definitions
\item {\bfseries{Imaging procedures}} and technique parameters
\item {\bfseries{User accounts}}, roles, and authentication
\item {\bfseries{System settings}} and institutional metadata
\item {\bfseries{PACS/\+\+MPPS connections}}
