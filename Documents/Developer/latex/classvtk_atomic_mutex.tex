\doxysubsection{Detailed Description}
mutual exclusion locking class using atomic operations 

\doxylink{classvtk_atomic_mutex}{vtk\+Atomic\+Mutex} allows the locking of variables which are accessed through different threads using atomic operations. An atomic mutex might be preferable over std::\+mutex, because it is faster when you want to spin lock and the probability of acquiring the lock is high. \doxylink{requirements_The}{The} benefit of \doxylink{classvtk_atomic_mutex}{vtk\+Atomic\+Mutex} over std::\+atomic$<$bool$>$ is that it is copy constructible, and that is has predefined optimized lock/\+unlock functions that can be used as a drop in replacement instead of std::\+mutex.
