\doxysubsection{Detailed Description}
keep track of edges (edge is pair of integer id\textquotesingle{}s) 

\doxylink{classvtk_edge_table}{vtk\+Edge\+Table} is a general object for keeping track of lists of edges. An edge is defined by the pair of point id\textquotesingle{}s (p1,p2). Methods are available to insert edges, check if edges exist, and traverse the list of edges. Also, it\textquotesingle{}s possible to associate attribute information with each edge. \doxylink{requirements_The}{The} attribute information may take the form of vtk\+Id\+Type id\textquotesingle{}s, void\texorpdfstring{$\ast$}{*} pointers, or points. To store attributes, make sure that \doxylink{classvtk_edge_table_a45f1fef0525f02fca2abdf2b36a526d8}{Init\+Edge\+Insertion()} is invoked with the store\+Attributes flag set properly. If points are inserted, use the methods \doxylink{classvtk_edge_table_a368ba8a5ddc6470b1e5a3e8a6e5e3623}{Init\+Point\+Insertion()} and \doxylink{classvtk_edge_table_ac7e77f21d0d86233d3557fe8f844647a}{Insert\+Unique\+Point()}.
