\doxysubsection{Detailed Description}
class describing a molecule 

\doxylink{classvtk_molecule}{vtk\+Molecule} and the convenience classes \doxylink{classvtk_atom}{vtk\+Atom} and \doxylink{classvtk_bond}{vtk\+Bond} describe the geometry and connectivity of a molecule. \doxylink{requirements_The}{The} molecule can be constructed using the \doxylink{classvtk_molecule_a07fd54958090423759d6a64950569297}{Append\+Atom()} and \doxylink{classvtk_molecule_a962b83342893316d900d8e80110b228f}{Append\+Bond()} methods in one of two ways; either by fully specifying the atom/\+bond in a single call, or by incrementally setting the various attributes using the convenience \doxylink{classvtk_atom}{vtk\+Atom} and \doxylink{classvtk_bond}{vtk\+Bond} classes:\+

\end{DoxyCode}


Incremental:\+ 
\begin{DoxyCode}{0}

\end{DoxyCode}


Both of the above methods will produce the same molecule, two hydrogens connected with a 1.\+0 Angstrom single bond, aligned to the z-\/axis. \doxylink{requirements_The}{The} second example also demonstrates the use of VTK\textquotesingle{}s \doxylink{classvtk_vector}{vtk\+Vector} class, which is fully supported by the Chemistry kit.

\doxylink{requirements_The}{The} \doxylink{classvtk_molecule}{vtk\+Molecule} object is intended to be used with the \doxylink{classvtk_molecule_mapper}{vtk\+Molecule\+Mapper} class for visualizing molecular structure using common rendering techniques.

\begin{DoxyWarning}{Warning}
While direct use of the underlying \doxylink{classvtk_undirected_graph}{vtk\+Undirected\+Graph} structure is possible due to \doxylink{classvtk_molecule}{vtk\+Molecule}\textquotesingle{}s public inheritance, this should not be relied upon and may change in the future.

If the normal is not orthogonal to the bond, a new normal will be constructed in such a way that the plane will be orthogonal to the plane spanned by the bond vector and the input normal vector.

* |  n = (n_i - proj[n_j]_v)

* |  |   /
* |  |  / n_i
* |  | /
* |  |/
* \end{DoxyVerb}
