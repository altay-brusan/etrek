\doxysubsection{Detailed Description}
Represents an XML element and those nested inside. 

\doxylink{classvtk_x_m_l_data_element}{vtk\+XMLData\+Element} is used by \doxylink{classvtk_x_m_l_data_parser}{vtk\+XMLData\+Parser} to represent an XML element. It provides methods to access the element\textquotesingle{}s attributes and nested elements in a convenient manner. This allows easy traversal of an input XML file by \doxylink{classvtk_x_m_l_reader}{vtk\+XMLReader} and its subclasses.
