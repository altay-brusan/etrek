\doxysubsection{Detailed Description}
Pipeline data object that contains multiple \doxylink{classvtk_array}{vtk\+Array} objects. 

Because \doxylink{classvtk_array}{vtk\+Array} cannot be stored as attributes of data objects (yet), a "{}carrier"{} object is needed to pass \doxylink{classvtk_array}{vtk\+Array} through the pipeline. \doxylink{classvtk_array_data}{vtk\+Array\+Data} acts as a container of zero-\/to-\/many \doxylink{classvtk_array}{vtk\+Array} instances, which can be retrieved via a zero-\/based index. Note that a collection of arrays stored in \doxylink{classvtk_array_data}{vtk\+Array\+Data} may-\/or-\/may-\/not have related types, dimensions, or extents.
