\doxysubsection{Detailed Description}
Facade for application-\/level logging. 

\doxylink{class_etrek_1_1_dicom_1_1_repository_1_1_app_logger}{App\+Logger} provides a simplified, domain-\/specific interface for logging messages within the application. It wraps the underlying spdlog logger and exposes methods for logging at various levels (debug, info, warning, error, exception).

\doxylink{requirements_The}{The} facade pattern is used to shield application code from direct dependency on spdlog and to provide a consistent logging API. \doxylink{class_etrek_1_1_dicom_1_1_repository_1_1_app_logger}{App\+Logger} also supports message formatting and integration with other services (e.\+g., translation).
