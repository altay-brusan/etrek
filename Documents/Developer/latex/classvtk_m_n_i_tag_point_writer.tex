\doxysubsection{Detailed Description}
A writer for MNI tag point files. 

\doxylink{requirements_The}{The} MNI .tag file format is used to store tag points, for use in either registration or labeling of data volumes. This file format was developed at the Mc\+Connell Brain Imaging Centre at the Montreal Neurological Institute and is used by their software. Tag points can be stored for either one volume or two volumes, and this filter can take one or two inputs. Alternatively, the points to be written can be specified by calling \doxylink{classvtk_m_n_i_tag_point_writer_a9c1e3707d6e3f01d3caccd191d0c67a7}{Set\+Points()}. \begin{DoxySeeAlso}{See also}
