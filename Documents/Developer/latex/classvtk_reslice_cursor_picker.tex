\doxysubsection{Detailed Description}
ray-\/cast cell picker for the reslice cursor 

This class is used by the \doxylink{classvtk_reslice_cursor_widget}{vtk\+Reslice\+Cursor\+Widget} to pick reslice axes drawn by a \doxylink{classvtk_reslice_cursor_actor}{vtk\+Reslice\+Cursor\+Actor}. \doxylink{requirements_The}{The} class returns the axes picked if any, whether one has picked the center. It takes as input an instance of \doxylink{classvtk_reslice_cursor_poly_data_algorithm}{vtk\+Reslice\+Cursor\+Poly\+Data\+Algorithm}. This is all done internally by \doxylink{classvtk_reslice_cursor_widget}{vtk\+Reslice\+Cursor\+Widget} and as such users are not expected to use this class directly, unless they are overriding the behaviour of \doxylink{classvtk_reslice_cursor_widget}{vtk\+Reslice\+Cursor\+Widget}. \begin{DoxySeeAlso}{See also}
\doxylink{classvtk_reslice_cursor}{vtk\+Reslice\+Cursor} \doxylink{classvtk_reslice_cursor_widget}{vtk\+Reslice\+Cursor\+Widget}
