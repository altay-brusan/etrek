\doxysubsection{Detailed Description}
Store zero or more \doxylink{classvtk_information}{vtk\+Information} instances. 

\doxylink{classvtk_information_vector}{vtk\+Information\+Vector} stores a vector of zero or more \doxylink{classvtk_information}{vtk\+Information} objects corresponding to the input or output information for a \doxylink{classvtk_algorithm}{vtk\+Algorithm}. An instance of this class is passed to \doxylink{classvtk_algorithm_a4562e3c326792eff6ddac398c170b2a5}{vtk\+Algorithm::\+\+Process\+Request} calls.
