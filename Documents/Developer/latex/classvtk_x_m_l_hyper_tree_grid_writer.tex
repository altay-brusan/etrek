\doxysubsection{Detailed Description}
Write VTK XML Hyper\+Tree\+Grid files. 

\doxylink{classvtk_x_m_l_hyper_tree_grid_writer}{vtk\+XMLHyper\+Tree\+Grid\+Writer} writes the VTK XML Hyper\+Tree\+Grid file format. \doxylink{requirements_The}{The} standard extension for this writer\textquotesingle{}s file format is "{}htg"{}.

Note for developers:\+ \doxylink{requirements_The}{The} VTK XML Hyper\+Tree\+Grid file format is versioned. Any evolution of the format must lead to:\+
\begin{DoxyItemize}
\item a move to a higher major version number, X+1.0, if the evolution is incompatible with the previous versions either at the level of the description of the information or the semantic understanding made by the reader;
\item a move to a higher minor version number, X.\+y+1, if its consists of adding information without calling into question the general interpretation.
\end{DoxyItemize}

Version 0.\+0 (P. Fasel and D. De\+Marle) ... Version 1.\+0 (J-\/B Lekien CEA, DAM, DIF, F-\/91297 Arpajon, France)
\begin{DoxyItemize}
\item writing by Hyper\+Tree description and fields;
\item saving the minimal tree (a hidden refined node becomes a hidden leaf node);
\item saving the tree by level of refinement (course in width);
\item the last null values in the binary description of the tree or mask (if defined) may not /\+ are not explicitly described. \doxylink{requirements_The}{The} size of the table given elsewhere is authentic;
\item all fields are copied to be saved in the implicit order, so even if an explicit global index map exists, it disappears;
\item writing in this version requires more memory and CPU;
\item reading of a part is accelerated (non iterative construction of the tree) and consumes potentially less memory (suppression of the global index map explicit);
\item expanded possibility at the reader level, today these options allow to accelerate the obtaining of a result which will be less precise and to allow the loading of a part of a mesh which would not hold in memory:\+
\begin{DoxyItemize}
\item loading by limiting the maximum level to load;
\item loading by selecting (different description possibilities are offered) the HTs to take into account.
\end{DoxyItemize}
\end{DoxyItemize}

\doxylink{requirements_The}{The} default version of the VTK XML Hyper\+Tree\+Grid file format is the latest version, now version 1.\+0.

For developers:\+ To ensure the durability of this storage format over time, at least, the drive must continue to support playback of previous format.
