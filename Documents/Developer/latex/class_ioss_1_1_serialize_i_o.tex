\doxysubsection{Detailed Description}
Class {\ttfamily \doxylink{class_ioss_1_1_serialize_i_o}{Serialize\+IO}} is a sentry class which performs serialization for mesh database I/\+O. 

This sentry guards serialization of parallel I/\+O routines. At construction, it blocks the processes via an MPI barrier, releasing them to execute in groups specified by {\ttfamily s\+\_\+group\+Size}. At destruction, it continues to block via MPI barriers until all the processor have been released by the constructor.

In the case where the constructor is called, and the sentry is already active and owned by the processes group, the constructor and destructor simply fall through since the serialization is already in place at a higher level.

\begin{DoxyNote}{Note}
All ranks must call the \doxylink{class_ioss_1_1_serialize_i_o}{Serialize\+IO} constructor synchronously. 

It is recommended to use RAII and keep the area protected by the \doxylink{class_ioss_1_1_serialize_i_o}{Serialize\+IO} as small as possible.
\end{DoxyNote}
\doxylink{requirements_The}{The} flow is that the ranks are split into groups of the specified size. Assume 3 ranks of group size 1.


\begin{DoxyItemize}
\item First time through,
\begin{DoxyItemize}
\item rank 0 falls through and
\item ranks 1, 2 sit at the barrier
\item rank 0 hits the destructor and then all 3 ranks are in the barrier so they all go to next step
\item (rank 1,2 in constructor, rank 0 in destructor)
\end{DoxyItemize}
\item {\ttfamily s\+\_\+owner} is now equal to {\ttfamily m\+\_\+group\+Rank} on rank 1, so it falls out of the do while;
\begin{DoxyItemize}
\item rank 2 still in the constructor do while Barrier
\item rank 0 in the destructor do while Barrier
\item rank 1 does its work and calls destructor;
\item all ranks in Barrier, so they go to next step.
\end{DoxyItemize}
\item {\ttfamily s\+\_\+owner} now equal to {\ttfamily m\+\_\+group\+Rank} on rank 2, so if falls out of the do while;
\begin{DoxyItemize}
\item ranks 0,1 in destructor do while at the Barrier
\item rank 2 does it work and calls destructor
\item all ranks are now in the destructor Barrier, so they go to next step
\item all ranks clear the Destructor and go to next step. 
\end{DoxyItemize}
\end{DoxyItemize}
