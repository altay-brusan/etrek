\doxysubsection{Detailed Description}
represent a contour drawn on the focal plane. 

\doxylink{requirements_The}{The} contour will stay on the focal plane irrespective of camera position/\+orientation changes. \doxylink{requirements_The}{The} class was written in order to be able to draw contours on a volume widget and have the contours overlaid on the focal plane in order to do contour segmentation. \doxylink{requirements_The}{The} superclass, \doxylink{classvtk_contour_representation}{vtk\+Contour\+Representation} handles contours that are drawn in actual world position coordinates, so they would rotate with the camera position/\+ orientation changes
