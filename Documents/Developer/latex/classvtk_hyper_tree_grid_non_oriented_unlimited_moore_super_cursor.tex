\doxysubsection{Detailed Description}
Specific Moore super cursor that can subdivied neighborhood. 

This supercursor behave like the Moore supercursor but relies on the \doxylink{classvtk_hyper_tree_grid_non_oriented_unlimited_super_cursor}{vtk\+Hyper\+Tree\+Grid\+Non\+Oriented\+Unlimited\+Super\+Cursor} so the neighborhood can be refined to reach the level of the current cell in any case.
