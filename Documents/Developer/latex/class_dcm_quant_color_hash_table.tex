\doxysubsection{Detailed Description}
this class implements a hash table for colors. Each entry of the hash table consists of an RGB color (\doxylink{class_dcm_quant_pixel}{Dcm\+Quant\+Pixel} object) and an integer value (e. g. counter). This class is used during the quantization of a color image.
