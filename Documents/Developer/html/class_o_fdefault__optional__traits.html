Detailed Description

template<typename T>
class OFdefault_optional_traits< T >

Default storage traits of OFoptional<T>. OFdefault_optional_traits manages the state and storage of the contained object in a portable manner. You may use this class as base when defining custom traits for a specific type T, so you won't have to re-implement this functionality entirely.

Template Parameters
Tthe content type of the respective OFoptional instance.
