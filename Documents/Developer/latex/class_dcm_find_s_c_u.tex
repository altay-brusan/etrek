\doxysubsection{Detailed Description}
This class implements a complete DICOM C-\/\+FIND SCU, including association set-\/up, execution of the C-\/\+FIND transaction including processing of results, and closing of the association. By default, incoming C-\/\+FIND-\/\+RSP messages will be displayed on console and, optionally, the attached dataset is stored in files. By providing a user-\/defined callback, other types of processing are possible.
