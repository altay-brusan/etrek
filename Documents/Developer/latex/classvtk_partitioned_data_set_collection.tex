\doxysubsection{Detailed Description}
Composite dataset that groups datasets as a collection. 

\doxylink{classvtk_partitioned_data_set_collection}{vtk\+Partitioned\+Data\+Set\+Collection} is a \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} that stores a collection of non-\/null vtk\+Partitioned\+Data\+Sets. These items can represent different concepts depending on the context. For example, they can represent region of different materials in a simulation or parts in an assembly. It is not requires that items have anything in common. For example, they can have completely different point or cell arrays.
