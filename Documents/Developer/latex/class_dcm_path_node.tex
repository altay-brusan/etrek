\doxysubsection{Detailed Description}
Class representing a node in \doxylink{class_dcm_path}{Dcm\+Path}. A node contains just a pointer to a \doxylink{class_dcm_object}{Dcm\+Object} (e.\+g. a sequence or an item). Additionally an item number is stored which also makes sense in case that the object pointed to is an item. \doxylink{requirements_The}{The} item number is necessary because when having only a pointer to a \doxylink{class_dcm_item}{Dcm\+Item} there is no way to find out at which position the item actually has in the surrounding sequence.
