\doxysubsection{Detailed Description}
draw the chart legend 

\doxylink{requirements_The}{The} \doxylink{classvtk_chart_legend}{vtk\+Chart\+Legend} is drawn in screen coordinates. It is usually one of the last elements of a chart to be drawn. It renders the mark/\+line for each plot, and the plot labels.
