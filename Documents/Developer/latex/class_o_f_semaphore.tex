\doxysubsection{Detailed Description}
provides an operating system independent abstraction for semaphores. A semaphore is a non-\/negative integer counter that is used to coordinate access to resources. \doxylink{requirements_The}{The} initial and maximum value of the counter is defined by the constructor. Each call to \doxylink{class_o_f_semaphore_a9834870ee5a3c9de01f7a89819651cc1}{wait()} decreases the counter by one and each call to \doxylink{class_o_f_semaphore_ac574c4d02b8efdcb0fdcc7268ade800f}{post()} increases the count by one. If a thread calls \doxylink{class_o_f_semaphore_a9834870ee5a3c9de01f7a89819651cc1}{wait()} while the counter is zero, the thread is blocked until another thread has increased the counter using \doxylink{class_o_f_semaphore_ac574c4d02b8efdcb0fdcc7268ade800f}{post()}.
