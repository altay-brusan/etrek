\doxysubsection{Detailed Description}
Fast, simple class for representing and operating on 3D bounds. 

\doxylink{classvtk_bounding_box}{vtk\+Bounding\+Box} maintains and performs operations on a 3D axis aligned bounding box. It is very light weight and many of the member functions are in-\/lined so it is very fast. It is not derived from \doxylink{classvtk_object}{vtk\+Object} so it can be allocated on the stack.
