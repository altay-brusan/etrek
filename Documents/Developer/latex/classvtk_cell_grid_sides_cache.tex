\doxysubsection{Detailed Description}
Hold a map from hash-\/ids (representing sides of cells of multiple types) to details on the cells that claim the corresponding side. 

This class is created by filters such as \doxylink{classvtk_cell_grid_compute_sides}{vtk\+Cell\+Grid\+Compute\+Sides} and vtk\+Cell\+Grid\+Extract\+Crinkle; it can be reused by the same filter and any others that process the same input (since it is stored in a cache available to them).

void vtk\+Cell\+Grid\+Sides\+Cache::\+\+Add\+Side (\begin{DoxyParamCaption}\item[{\doxymbox{\hyperlink{classvtk_string_token}{vtk\+String\+Token}}}]{cell\+Type}{, }\item[{vtk\+Id\+Type}]{cell}{, }\item[{int}]{side}{, }\item[{\doxymbox{\hyperlink{classvtk_string_token}{vtk\+String\+Token}}}]{shape}{, }\item[{const C \&}]{conn}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [inline]}}

Add a {\itshape side} with the given {\itshape shape} and connectivity to the request\textquotesingle{}s state.

\doxylink{requirements_The}{The} {\itshape shape}, {\itshape conn} size, and {\itshape conn} entries are hashed together into a key which is mapped to a set of all the matching sides. \doxylink{requirements_The}{The} {\itshape cell\+Type} and {\itshape cell} ID are also stored with each matching side; these are used during Finalize() to generate the output map-\/of-\/maps returned by Get\+Sides() so that the sides are reported by cell type, cell ID, and then side ID.

Note that the {\itshape conn} entries are hashed in a particular canonical order so that the same hash is generated for sides with point IDs that have been shifted and/\+or reversed. \doxylink{requirements_The}{The} hash always starts at the smallest entry of {\itshape conn} and goes in the direction that has the largest next entry. Examples:\+ (3, 2, 0, 1) → starts at index 2 (0) and hashes backwards:\+ (0, 2, 3, 1) (4, 5, 6, 7) → starts at index 0 (4) and hashes backwards:\+ (4, 7, 6, 5) (7, 3, 6, 2) → starts at index 3 (2) and hashes forwards:\+ (2, 7, 3, 6) By storing the {\itshape cell\+Type}, we avoid requiring a global-\/to-\/local cell numbering in \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid} instances (as \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} incurs) which may hold multiple types of cells. \Hypertarget{classvtk_cell_grid_sides_cache_aa2cc9d4b71671e38fee55392301e6d86}\index{vtkCellGridSidesCache@{vtkCellGridSidesCache}!PrintSelf@{PrintSelf}}
