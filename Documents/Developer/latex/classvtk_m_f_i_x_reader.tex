\doxysubsection{Detailed Description}
reads a dataset in MFIX file format 

\doxylink{classvtk_m_f_i_x_reader}{vtk\+MFIXReader} creates an unstructured grid dataset. It reads a restart file and a set of sp files. \doxylink{requirements_The}{The} restart file contains the mesh information. MFIX meshes are either cylindrical or rectilinear, but this reader will convert them to an unstructured grid. \doxylink{requirements_The}{The} sp files contain transient data for the cells. Each sp file has one or more variables stored inside it.
