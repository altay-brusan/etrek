\doxysubsection{Detailed Description}
A class holding colors and their names. 

For a web page showcasing VTK Named Colors and their RGB values, see:\+ \href{https://htmlpreview.github.io/?https://github.com/Kitware/vtk-examples/blob/gh-pages/VTKNamedColorPatches.html}{\texttt{VTKNamed\+Color\+Patches}}; \href{https://kitware.github.io/vtk-examples/site/Python/Visualization/NamedColorPatches/}{\texttt{Named\+Color\+Patches}} was used to generate this table.

Color names are case insensitive and are stored as lower-\/case names along with a 4-\/element array whose elements are red, green, blue and alpha, in that order, corresponding to the RGBA value of the color.

It is assumed that if the RGBA values are unsigned char then each element lies in the range 0...255 and if the RGBA values are double then each element lies in the range 0...1.

\doxylink{requirements_The}{The} colors and names are those in \href{https://en.wikipedia.org/wiki/Web_colors}{\texttt{Web colors}} that are derived from the CSS3 specification:\+ \href{https://www.w3.org/TR/css-color-3/}{\texttt{CSS Color Module Level 3}} In this table common synonyms such as cyan/\+aqua and magenta/\+fuchsia are also included.

Also included in this class are names and colors taken from {\itshape Wrapping/\+\+Python/\+vtkmodules/\+util/\+colors.\+py} that were originally taken from {\itshape Wrapping/\+\+Tcl/\+vtktesting/\+colors.\+tcl} (no longer in the VTK source files -\/ deleted 06-\/Dec-\/2017).

Web colors and names in \href{https://en.wikipedia.org/wiki/Web_colors}{\texttt{Web colors}} take precedence over those in {\itshape colors.\+py}. One consequence of this is that while {\itshape colors.\+py} specifies green as equivalent to (0,255,0), the web color standard defines it as (0,128,0).

\doxylink{requirements_The}{The} {\itshape Set\+Color} methods will overwrite existing colors if the name of the color being set matches an existing color. Note that \doxylink{classvtk_named_colors_ad58dbc57df0e923afbb9f762fb417666}{Color\+Exists()} can be used to test for existence of the color being set.

In the case of the {\itshape Get\+Color} methods returning doubles, alternative versions, identified by the letters RGB in the names, are provided. These get functions return just the red, green and blue components of a color.

\doxylink{requirements_The}{The} class also provides methods for defining a color through an HTML color string. \doxylink{requirements_The}{The} following formats are supported:\+


\begin{DoxyItemize}
\item \#RGB (3-\/digit hexadecimal number, where \#4F2 is a shortcut for \#44FF22)
\item \#RRGGBB (6-\/digit hexadecimal number)
\item \doxylink{structrgb}{rgb(r, g, b)} (where r, g, b are in 0..255 or percentage values)
\item rgba(r, g, b, a) (where r, g, b, are in 0..255 or percentage values, a is in 0.\+0..1.\+0)
\item a CSS3 color name (e.\+g. "{}steelblue"{}) 
\end{DoxyItemize}
