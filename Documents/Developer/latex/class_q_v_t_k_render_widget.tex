\doxysubsection{Detailed Description}
Generic QWidget for displaying a \doxylink{classvtk_render_window}{vtk\+Render\+Window} in a Qt Application. 

\doxylink{class_q_v_t_k_render_widget}{QVTKRender\+Widget} is intended as a generic widget for displaying VTK rendering results in a Qt application. It is only a wrapper around other specific classes. For now, this only wraps the \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} which is the most versatile implementation. This may evolve in the future. See \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} for implementation details.

For Quad-\/buffer stereo support, please use directly the \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget}.

\begin{DoxyNote}{Note}
\doxylink{class_q_v_t_k_render_widget}{QVTKRender\+Widget} requires Qt version 5.\+9 and above.
