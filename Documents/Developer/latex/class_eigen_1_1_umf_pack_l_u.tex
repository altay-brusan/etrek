\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen::\+\+Umf\+Pack\+LU$<$ \+\_\+\+Matrix\+Type $>$}
A sparse LU factorization and solver based on Umf\+Pack. 

This class allows to solve for A.\+X = B sparse linear problems via a LU factorization using the Umf\+Pack library. \doxylink{requirements_The}{The} sparse matrix A must be squared and full rank. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} input matrix A should be in a {\bfseries{compressed}} and {\bfseries{column-\/major}} form. Otherwise an expensive copy will be made. You can call the inexpensive make\+Compressed() to get a compressed matrix. 
\end{DoxyWarning}
