\doxysubsection{Detailed Description}
implicit function for a cone 

\doxylink{classvtk_cone}{vtk\+Cone} computes the implicit function and function gradient for a cone. \doxylink{classvtk_cone}{vtk\+Cone} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. By default, the cone vertex is located at the origin with axis of rotation coincident with x-\/axis. You can use the superclass\textquotesingle{} \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function} transformation matrix to reposition. You can alternatively use the accessors provided by this class, which will cause the transform to be recomputed. to reposition/\+orient the cone. \doxylink{requirements_The}{The} angle specifies the angle between the axis of rotation and the side of the cone.
