\doxysubsection{Detailed Description}
Executive supporting partial updates. 

\doxylink{classvtk_streaming_demand_driven_pipeline}{vtk\+Streaming\+Demand\+Driven\+Pipeline} is an executive that supports updating only a portion of the data set in the pipeline. This is the style of pipeline update that is provided by the old-\/style VTK 4.\+x pipeline. Instead of always updating an entire data set, this executive supports asking for pieces or sub-\/extents.

It effectively tells the downstream algorithms integrating over all the timesteps that the current set of available timesteps is not necessarily complete.
