\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_application_1_1_strategy}{Strategy} for demonstration and exhibition mode. 

This mode is used for exhibitions, sales demos, and training. Instead of performing real X-\/ray acquisitions, it loads and displays pre-\/captured sample images from disk.

Key characteristics:\+
\begin{DoxyItemize}
\item No real X-\/ray exposure
\item Loads sample images from configured directory
\item No database persistence
\item No DICOM object creation
\item No PACS transmission
\item No worklist status updates
\end{DoxyItemize}

This mode is safe to use without a patient and without X-\/ray equipment being operational.
