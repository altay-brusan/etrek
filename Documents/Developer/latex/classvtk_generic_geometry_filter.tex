\doxysubsection{Detailed Description}
extract geometry from data (or convert data to polygonal type) 

\doxylink{classvtk_generic_geometry_filter}{vtk\+Generic\+Geometry\+Filter} is a general-\/purpose filter to extract geometry (and associated data) from any type of dataset. Geometry is obtained as follows:\+ all 0D, 1D, and 2D cells are extracted. All 2D faces that are used by only one 3D cell (i.\+e., boundary faces) are extracted. It also is possible to specify conditions on point ids, cell ids, and on bounding box (referred to as "{}\+Extent"{}) to control the extraction process.

This filter also may be used to convert any type of data to polygonal type. \doxylink{requirements_The}{The} conversion process may be less than satisfactory for some 3D datasets. For example, this filter will extract the outer surface of a volume or structured grid dataset. (For structured data you may want to use \doxylink{classvtk_image_data_geometry_filter}{vtk\+Image\+Data\+Geometry\+Filter}, \doxylink{classvtk_structured_grid_geometry_filter}{vtk\+Structured\+Grid\+Geometry\+Filter}, \doxylink{classvtk_extract_unstructured_grid}{vtk\+Extract\+Unstructured\+Grid}, \doxylink{classvtk_rectilinear_grid_geometry_filter}{vtk\+Rectilinear\+Grid\+Geometry\+Filter}, or \doxylink{classvtk_extract_v_o_i}{vtk\+Extract\+VOI}.)

\begin{DoxyWarning}{Warning}
When \doxylink{classvtk_generic_geometry_filter}{vtk\+Generic\+Geometry\+Filter} extracts cells (or boundaries of cells) it will (by default) merge duplicate vertices. This may cause problems in some cases. For example, if you\textquotesingle{}ve run \doxylink{classvtk_poly_data_normals}{vtk\+Poly\+Data\+Normals} to generate normals, which may split meshes and create duplicate vertices, \doxylink{classvtk_generic_geometry_filter}{vtk\+Generic\+Geometry\+Filter} will merge these points back together. Turn merging off to prevent this from occurring.
\end{DoxyWarning}
