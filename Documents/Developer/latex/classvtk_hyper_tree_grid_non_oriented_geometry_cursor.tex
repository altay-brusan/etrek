\doxysubsection{Detailed Description}
Objects for traversal a Hyper\+Tree\+Grid. 

Non\+Oriented ne peut pas remonter plus haut qu\textquotesingle{}a sa creation. Objects that can perform depth traversal of a hyper tree grid, take into account more parameters (related to the grid structure) than the compact hyper tree cursor implemented in \doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree} can. This is an abstract class. Cursors are created by the Hyper\+Tree\+Grid implementation.

Geometry cursors allow to retrieve origin, size, bounds and central points
