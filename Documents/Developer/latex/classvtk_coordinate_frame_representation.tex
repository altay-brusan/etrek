\doxysubsection{Detailed Description}
a class defining the representation for a \doxylink{classvtk_coordinate_frame_widget}{vtk\+Coordinate\+Frame\+Widget} 

This class is a concrete representation for the \doxylink{classvtk_coordinate_frame_widget}{vtk\+Coordinate\+Frame\+Widget}. It represents a coordinate frame with an origin, 3 axis and 3 axis lockers. Through interaction with the widget, the coordinate frame can be manipulated by adjusting the axis normals, locking them, or moving/\+picking the origin point.

\doxylink{requirements_The}{The} Place\+Widget() method is also used to initially position the representation.

\begin{DoxyWarning}{Warning}
This class, and \doxylink{classvtk_coordinate_frame_widget}{vtk\+Coordinate\+Frame\+Widget}, are next generation VTK widgets. 
\end{DoxyWarning}

Get/\+set which axis (if any) is locked.

At most, a single axis can be locked at a time.

\doxylink{requirements_The}{The} axis must be one of the following values:\+ \{ -\/1, 0, 1, 2 \}. -\/1 indicates that no axis is locked; 0 corresponds to the X axis; 1 to Y; and 2 to Z.
