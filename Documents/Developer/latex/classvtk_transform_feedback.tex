\doxysubsection{Detailed Description}
Manages a Transform\+Feedback buffer. 

Open\+GL\textquotesingle{}s Transform\+Feedback allows varying attributes from a vertex/\+geometry shader to be captured into a buffer for later processing. This is used in VTK to capture vertex information during GL2\+PS export when using the Open\+GL2 backend as a replacement for the deprecated Open\+GL feedback buffer.
