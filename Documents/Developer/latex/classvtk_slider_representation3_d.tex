provide the representation for a \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} with a 3D skin 

This class is used to represent and render a \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget}. To use this class, you must at a minimum specify the end points of the slider. Optional instance variable can be used to modify the appearance of the widget.
