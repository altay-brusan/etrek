\doxysubsection{Detailed Description}
abstract superclass for all actors, volumes and annotations 

\doxylink{classvtk_prop}{vtk\+Prop} is an abstract superclass for any objects that can exist in a rendered scene (either 2D or 3D). Instances of \doxylink{classvtk_prop}{vtk\+Prop} may respond to various render methods (e.\+g., \doxylink{classvtk_prop_a4d7c8be45744400fba096728ce81f33a}{Render\+Opaque\+Geometry()}). \doxylink{classvtk_prop}{vtk\+Prop} also defines the API for picking, LOD manipulation, and common instance variables that control visibility, picking, and dragging. \begin{DoxySeeAlso}{See also}
