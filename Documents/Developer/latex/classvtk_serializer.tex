void vtk\+Serializer::\+\+Set\+Serializer\+Log\+Verbosity (\begin{DoxyParamCaption}\item[{vtk\+Logger::\+\+Verbosity}]{verbosity}{}\end{DoxyParamCaption})}

Set/\+\+Get the log verbosity of messages that are emitted when data is uploaded to GPU memory. \doxylink{requirements_The}{The} Get\+Serializer\+Log\+Verbosity looks up system environment for {\ttfamily VTK\+\_\+\+SERIALIZER\+\_\+\+LOG\+\_\+\+VERBOSITY} that shall be used to set initial logger verbosity. \doxylink{requirements_The}{The} default value is TRACE.

Accepted string values are OFF, ERROR, WARNING, INFO, TRACE, MAX, INVALID or ASCII representation for an integer in the range \+[-\/9,9]\+.

\begin{DoxyNote}{Note}
This method internally uses \doxylink{classvtk_logger_a8b6a63111533efb01d995e3dafead06e}{vtk\+Logger::\+\+Convert\+To\+Verbosity(const char\texorpdfstring{$\ast$}{*})} to parse the value from environment variable. 
\end{DoxyNote}
