Default implementation of \doxylink{classvtk_text_renderer}{vtk\+Text\+Renderer}.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} Math\+Text backend does not currently support UTF16 strings, thus UTF16 strings passed to the Math\+Text renderer will be converted to UTF8.
