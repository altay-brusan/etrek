Calling this method will {\itshape safely} close and remove all appenders in all the loggers including root contained in the default hierarchy.

Some appenders such as \doxylink{classdcmtk_1_1log4cplus_1_1_socket_appender}{Socket\+Appender} need to be closed before the application exits. Otherwise, pending logging events might be lost.

\doxylink{requirements_The}{The} {\ttfamily shutdown} method is careful to close nested appenders before closing regular appenders. This is allows configurations where a regular appender is attached to a logger and again to a nested appender.
