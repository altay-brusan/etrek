\doxysubsection{Detailed Description}
create an x3d file 

\doxylink{classvtk_x3_d_exporter}{vtk\+X3\+DExporter} is a render window exporter which writes out the rendered scene into an X3D file. X3D is an XML-\/based format for representation 3D scenes (similar to VRML). Check out \href{http://www.web3d.org/x3d/}{\texttt{http:\+/\+/\+www.\+web3d.\+org/\+x3d/\+}} for more details. \begin{DoxyParagraph}{Thanks:\+}
X3\+DExporter is contributed by Christophe Mouton at EDF. 
\end{DoxyParagraph}
