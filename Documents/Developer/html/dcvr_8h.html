Enumeration Type Documentation

◆ DcmEVR

enum DcmEVR

VR Enumerations. NB: The order of entries has to conform to the order in DcmVRDict (see dcmvr.cc)! If not an error message is reported and the program aborts (only in DEBUG mode).

Global function that disables the generation of "new" value representations, i.e. the ones that have been introduced after the first edition of the DICOM standard (1993). See above dcmEnableXXXVRGeneration() flags for details.
