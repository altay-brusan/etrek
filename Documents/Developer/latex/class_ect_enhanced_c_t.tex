\doxysubsection{Detailed Description}
Class representing an object of the "{}\+Enhanced CT SOP Class"{}. Supported Modules:\+
\begin{DoxyItemize}
\item Patient (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item Patient Study (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item General Study (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item General Series (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item Enhanced CT Series (via this class)
\item Frame of Reference (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item Synchronization (via \doxylink{modsynchronization_8h_source}{modsynchronization.\+h})
\item General Equipment (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item Enhanced General Equipment (via \doxylink{modenhequipment_8h_source}{modenhequipment.\+h})
\item Image Pixel (via this class)
\item Multi-\/frame Functional Groups (via \doxylink{modmultiframefg_8h_source}{modmultiframefg.\+h})
\item Multi-\/frame Dimension (via \doxylink{modmultiframedimension_8h_source}{modmultiframedimension.\+h})
\item Acquisition Context (via \doxylink{modacquisitioncontext_8h_source}{modacquisitioncontext.\+h})
\item Enhanced CT (via mod\+\_\+enhanced\+\_\+ct.\+h)
\item SOP Common (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\item Common Instance Reference (via \doxylink{iodimage_8h_source}{iodimage.\+h})
\end{DoxyItemize}

Modules that are not supported:\+
\begin{DoxyItemize}
\item Enhanced Contrast/\+\+Bolus
\item Cardiac Synchronization
\item Respiratory Synchronization
\item Supplemental Palette Color Lookup Table
\item Device
\item Specimen
\item Enhanced Multi-\/energy CT Acquisition
\item ICC Profile
\item Frame Extraction 
\end{DoxyItemize}
