Detailed Description

Base class representing a statistic within the "Tractography Results" IOD. A statistic is of a certain type and applies to a specific region of interest. For each Track Set and for each track there may be one or more statistics defined. The specializations can be found in classes TrcTracksStatistic and TrcTrackSetStatistic.
