Detailed Description

Class representing a node in DcmPath. A node contains just a pointer to a DcmObject (e.g. a sequence or an item). Additionally an item number is stored which also makes sense in case that the object pointed to is an item. The item number is necessary because when having only a pointer to a DcmItem there is no way to find out at which position the item actually has in the surrounding sequence.
