\doxysubsection{Detailed Description}
a curve or overlay activation layer in a presentation state (internal use only). This class manages the data structures comprising a single curve activation layer or overlay activation layer (one instance of the Curve Activation Layer Module or Overlay Activation Layer Module repeating elements) contained in a Presentation State object.
