Detailed Description

a quintic SPH interpolation kernel

vtkWendlandQuinticKernel is an smooth particle hydrodynamics interpolation kernel as described by D.J. Price. This is a quintic formulation.

Warning
FOr more information see D.J. Price, Smoothed particle hydrodynamics and magnetohydrodynamics, J. Comput. Phys. 231:759-794, 2012. Especially equation 49.
