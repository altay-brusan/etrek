\doxysubsection{Detailed Description}
Base class for all \textquotesingle{}grouping\textquotesingle{} entities. \doxylink{requirements_The}{The} following derived classes are typical:\+ 

-- \doxylink{class_ioss_1_1_node_set}{Node\+Set} -- grouping of nodes (0d topology)

-- \doxylink{class_ioss_1_1_edge_set}{Edge\+Set} -- grouping of edges (1d topology)

-- \doxylink{class_ioss_1_1_face_set}{Face\+Set} -- grouping of faces (2d topology) \+[Surface]\+

Similarly, there is:\+

-- \doxylink{class_ioss_1_1_node_block}{Node\+Block} -- grouping of \textquotesingle{}similar\textquotesingle{} nodes (same degree of freedom, ...)

-- \doxylink{class_ioss_1_1_element_block}{Element\+Block} -- grouping of \textquotesingle{}similar\textquotesingle{} elements (same element topology, attributes, ...) 0d, 1d, 2d, 3d topology possible -- e.\+g., sphere, bar, quad, hex

A \doxylink{class_ioss_1_1_region}{Region} is also a grouping entity, except that its list of subentites are other Grouping\+Entities. That is, it maintains a list of Node\+Blocks, Element\+Blocks, Node\+Lists, Comm\+Lists and Surfaces. \+[Similar to the "{}\+Composite Pattern"{} in Design Patterns]\+ All interface to Grouping\+Entities is through the \doxylink{class_ioss_1_1_region}{Region} class; clients of the IO subsystem have no direct access to the underlying Grouping\+Entities (other than the \doxylink{class_ioss_1_1_region}{Region}).

Each \doxylink{class_ioss_1_1_grouping_entity}{Grouping\+Entity} contains:\+

-- name

-- Mesh\+Entities of the specified topological dimension

-- Optional attributes, either global (applied to the groupingentity), or unique value(s) to be applied to each subentity.
