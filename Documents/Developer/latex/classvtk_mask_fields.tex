\doxysubsection{Detailed Description}
Allow control of which fields get passed to the output. 

\doxylink{classvtk_mask_fields}{vtk\+Mask\+Fields} is used to mark which fields in the input dataset get copied to the output. \doxylink{requirements_The}{The} output will contain only those fields marked as on by the filter.
