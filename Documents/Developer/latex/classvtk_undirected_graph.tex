\doxysubsection{Detailed Description}
An undirected graph. 

\doxylink{classvtk_undirected_graph}{vtk\+Undirected\+Graph} is a collection of vertices along with a collection of undirected edges (they connect two vertices in no particular order). \doxylink{classvtk_graph_a981281cff554790bee0bdf05fb236540}{Shallow\+Copy()}, \doxylink{classvtk_graph_aac4d6daae82193ac6c5835225677a0e1}{Deep\+Copy()}, \doxylink{classvtk_graph_a93c80d654a851b754342cc0f81a4ad28}{Checked\+Shallow\+Copy()}, \doxylink{classvtk_graph_a3733a589dd1446186715259671912b10}{Checked\+Deep\+Copy()} accept instances of \doxylink{classvtk_undirected_graph}{vtk\+Undirected\+Graph} and \doxylink{classvtk_mutable_undirected_graph}{vtk\+Mutable\+Undirected\+Graph}. Get\+Out\+Edges(v, it) and Get\+In\+Edges(v, it) return the same list of edges, which is the list of all edges which have a v as an endpoint. Get\+In\+Degree(v), Get\+Out\+Degree(v) and Get\+Degree(v) all return the full degree of vertex v.

\doxylink{classvtk_undirected_graph}{vtk\+Undirected\+Graph} is read-\/only. To create an undirected graph, use an instance of \doxylink{classvtk_mutable_undirected_graph}{vtk\+Mutable\+Undirected\+Graph}, then you may set the structure to a \doxylink{classvtk_undirected_graph}{vtk\+Undirected\+Graph} using \doxylink{classvtk_graph_a981281cff554790bee0bdf05fb236540}{Shallow\+Copy()}.
