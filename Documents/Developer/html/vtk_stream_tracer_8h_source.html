175 // The previously-supported TIME_UNIT is excluded in this current
176 // enumeration definition because the underlying step size is ALWAYS in
177 // arc length unit (LENGTH_UNIT) while the 'real' time interval (virtual
178 // for steady flows) that a particle actually takes to trave in a single
179 // step is obtained by dividing the arc length by the LOCAL speed. The
180 // overall elapsed time (i.e., the life span) of the particle is the sum
181 // of those individual step-wise time intervals. The arc-length-to-time
182 // conversion only occurs for vorticity computation and for generating a
183 // point data array named 'IntegrationTime'.
184 enum Units
185 {
186 LENGTH_UNIT = 1,
187 CELL_LENGTH_UNIT = 2
188 };
