\doxysubsection{Detailed Description}
supports legacy function callbacks for VTK 

\doxylink{classvtk_old_style_callback_command}{vtk\+Old\+Style\+Callback\+Command} is a callback that supports the legacy callback methods found in VTK. For example, the legacy method vtk\+Process\+Object::\+\+Set\+Start\+Method() is actually invoked using the command/\+observer design pattern of VTK, and the \doxylink{classvtk_old_style_callback_command}{vtk\+Old\+Style\+Callback\+Command} is used to provide the legacy functionality. \doxylink{requirements_The}{The} callback function should have the form void func(void \texorpdfstring{$\ast$}{*}clientdata), where clientdata is special data that should is associated with this instance of \doxylink{classvtk_callback_command}{vtk\+Callback\+Command}.

\begin{DoxyWarning}{Warning}
This is legacy glue. Please do not use; it will be eventually eliminated.
\end{DoxyWarning}
