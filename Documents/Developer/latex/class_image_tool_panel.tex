\doxysubsection{Detailed Description}
Left toolbar panel with imaging tool buttons and layout selection. 

Contains:\+
\begin{DoxyItemize}
\item Tool selection buttons (zoom, pan, window/\+level, ruler, angle, reset)
\item Layout selection buttons (1x1, 1x2, 2x2)
\item Additional action buttons (open file, invert, etc.)
\end{DoxyItemize}

Use \doxylink{struct_image_tool_panel_config}{Image\+Tool\+Panel\+Config} to customize which buttons are visible.
