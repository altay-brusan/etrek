\doxysubsection{Detailed Description}
Iterates through all outgoing edges from a vertex. 

\doxylink{classvtk_out_edge_iterator}{vtk\+Out\+Edge\+Iterator} iterates through all edges whose source is a particular vertex. Instantiate this class directly and call \doxylink{classvtk_out_edge_iterator_afb52b465f24b3c5c81af775e1e842b12}{Initialize()} to traverse the vertex of a graph. Alternately, use Get\+In\+Edges() on the graph to initialize the iterator. it-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_out_edge_iterator_adf98b4814d797daca46f90b4e4cf90b8}{Next()} returns a \doxylink{structvtk_out_edge_type}{vtk\+Out\+Edge\+Type} structure, which contains Id, the edge\textquotesingle{}s id, and Target, the edge\textquotesingle{}s target vertex.
