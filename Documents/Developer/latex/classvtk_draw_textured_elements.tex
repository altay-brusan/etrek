\doxysubsection{Detailed Description}
A base class for mappers or render responders that need to draw primitives via vertex-\/pulling. 

Since this class is intended to be inherited by other classes that must {\itshape also} inherit a VTK mapper or responder class, it is not a subclass of \doxylink{classvtk_object}{vtk\+Object}; instead, it provides methods your subclass can invoke during rendering.

This currently handles hexahedra and tetrahedra.
