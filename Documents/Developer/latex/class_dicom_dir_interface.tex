An interface class for simplified creation of a DICOMDIR. \begin{DoxyNote}{Note}
Please make sure that for all \doxylink{class_o_f_filename}{OFFilename} parameters, passed to the various methods of this class, at least the 8-\/bit version of the string value is present since in some cases only this version is (can be) used. 
\end{DoxyNote}
