\doxysubsection{Detailed Description}
Class for handling coded entry values, i.\+e. unambiguous machine-\/readable codes. This class supports both the "{}\+Basic Coded Entry Attributes"{} and the "{}\+Enhanced Encoding \+Mode"{}. There are also some basic checks that make sure that a given code is valid.
