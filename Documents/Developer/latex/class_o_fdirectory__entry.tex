\doxysubsection{Detailed Description}
A class representing an directory entry. \doxylink{class_o_fdirectory__entry}{OFdirectory\+\_\+entry} implements a subset of the functionality described as std::\+filesystem::\+directory\+\_\+entry, see \href{http://en.cppreference.com/w/cpp/filesystem/directory_entry}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+filesystem/\+directory\+\_\+entry}} for more information. \begin{DoxyNote}{Note}
currently, \doxylink{class_o_fdirectory__entry}{OFdirectory\+\_\+entry} only contains a single \doxylink{class_o_fpath}{OFpath} object (no file meta information as the real std::\+filesystem::\+directory\+\_\+entry would). It is currently only a placeholder that exists because \doxylink{class_o_fdirectory__iterator}{OFdirectory\+\_\+iterator} is expected to refer to an directory entry instead of directly referring to an \doxylink{class_o_fpath}{OFpath} object. 
\end{DoxyNote}
