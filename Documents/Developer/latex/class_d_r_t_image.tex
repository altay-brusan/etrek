\doxysubsection{Detailed Description}
Helper class for working with radio therapy image objects. This class provides a binding between \doxylink{class_dicom_image}{Dicom\+Image} and \doxylink{class_d_r_t_image_i_o_d}{DRTImage\+IOD}. \doxylink{requirements_The}{The} information from the dataset are managed by the \doxylink{class_d_r_t_image_i_o_d}{DRTImage\+IOD} base class, but the image itself is represented through \doxylink{class_dicom_image}{Dicom\+Image}.

\begin{DoxyNote}{Note}
These functions hopefully simplify working with \doxylink{class_d_r_t_image_i_o_d}{DRTImage\+IOD}. This is a work in progress, please propose any improvements which would make working with this class easier for you and that you consider useful. 
\end{DoxyNote}
