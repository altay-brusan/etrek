\doxysubsection{Detailed Description}
A helper that generates composite images for the volume ray cast mapper. 

This is one of the helper classes for the \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper}. It will generate composite images using an alpha blending operation. This class should not be used directly, it is a helper class for the mapper and has no user-\/level API.
