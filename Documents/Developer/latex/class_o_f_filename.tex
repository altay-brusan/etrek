\doxysubsection{Detailed Description}
class for managing filenames consisting either of conventional (8-\/bit) or wide (e.\+g. 16-\/bit) characters. \doxylink{requirements_The}{The} wide character support is currently Windows-\/specific because most other operating systems use UTF-\/8, which is compatible with conventional 8-\/bit character strings.
