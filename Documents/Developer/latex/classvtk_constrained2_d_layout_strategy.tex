\doxysection{vtk\+Constrained2\+DLayout\+Strategy Class Reference}
\hypertarget{classvtk_constrained2_d_layout_strategy}{}\label{classvtk_constrained2_d_layout_strategy}\index{vtkConstrained2DLayoutStrategy@{vtkConstrained2DLayoutStrategy}}


a simple fast 2D graph layout that looks for a \textquotesingle{}constraint\textquotesingle{} array (\doxylink{classvtk_double_array}{vtk\+Double\+Array}). Any entry in the constraint array will indicate the level of impedance a node has to the force calculations during the layout optimization. \doxylink{requirements_The}{The} array is assumed to be normalized between zero and one, with one being totally constrained, so no force will be applied to the node (i.\+e. no movement), and zero being full range of movement (no constraints).

\doxysubsection{Detailed Description}
a simple fast 2D graph layout that looks for a \textquotesingle{}constraint\textquotesingle{} array (\doxylink{classvtk_double_array}{vtk\+Double\+Array}). Any entry in the constraint array will indicate the level of impedance a node has to the force calculations during the layout optimization. \doxylink{requirements_The}{The} array is assumed to be normalized between zero and one, with one being totally constrained, so no force will be applied to the node (i.\+e. no movement), and zero being full range of movement (no constraints). 

This class is a density grid based force directed layout strategy. Also please note that \textquotesingle{}fast\textquotesingle{} is relative to quite slow. :\+) \doxylink{requirements_The}{The} layout running time is O(V+E) with an extremely high constant. \begin{DoxyParagraph}{Thanks:\+}
