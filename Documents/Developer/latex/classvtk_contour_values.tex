\doxysubsection{Detailed Description}
helper object to manage setting and generating contour values 

\doxylink{classvtk_contour_values}{vtk\+Contour\+Values} is a general class to manage the creation, generation, and retrieval of contour values. This class serves as a helper class for contouring classes, or those classes operating on lists of contour values.
