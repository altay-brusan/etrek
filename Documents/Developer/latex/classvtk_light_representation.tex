represent a \doxylink{classvtk_light}{vtk\+Light} 

\doxylink{requirements_The}{The} \doxylink{classvtk_light_representation}{vtk\+Light\+Representation} is a representation for the \doxylink{classvtk_light}{vtk\+Light}. This representation consists of a Light\+Position sphere with an automatically resized radius so it is always visible, a line between the Light\+Position and the Focal\+Point and a cone of angle Cone\+Angle when using Positional.
