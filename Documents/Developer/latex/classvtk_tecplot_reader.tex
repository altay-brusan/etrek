\doxysubsection{Detailed Description}
A concrete class to read an ASCII Tecplot file. 

\doxylink{classvtk_tecplot_reader}{vtk\+Tecplot\+Reader} parses an ASCII Tecplot file to get a \doxylink{classvtk_multi_block_data_set}{vtk\+Multi\+Block\+Data\+Set} object made up of several \doxylink{classvtk_data_set}{vtk\+Data\+Set} objects, of which each is of type either \doxylink{classvtk_structured_grid}{vtk\+Structured\+Grid} or \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid}. Each \doxylink{classvtk_data_set}{vtk\+Data\+Set} object maintains the geometry, topology, and some associated attributes describing physical properties.

Tecplot treats 3D coordinates (only one or two coordinates might be explicitly specified in a file) as variables too, whose names (e.\+g., \textquotesingle{}X\textquotesingle{} /\+ \textquotesingle{}x\textquotesingle{} /\+ \textquotesingle{}I\textquotesingle{}, \textquotesingle{}Y\textquotesingle{} /\+ \textquotesingle{}y\textquotesingle{} /\+ \textquotesingle{}J\textquotesingle{}, \textquotesingle{}Z\textquotesingle{} /\+ \textquotesingle{}z\textquotesingle{} /\+ \textquotesingle{}K\textquotesingle{}) are provided in the variables list (the \textquotesingle{}VARIABLES\textquotesingle{} section). These names are then followed in the list by those of other traditional variables or attributes (node-\/ based and /\+ or cell-\/based data with the mode specified via token \textquotesingle{}VAR LOCATION\textquotesingle{}, to be extracted to create \doxylink{classvtk_point_data}{vtk\+Point\+Data} and /\+ or \doxylink{classvtk_cell_data}{vtk\+Cell\+Data}). Each zone described afterwards (in the \textquotesingle{}ZONE\textquotesingle{}s section) provides the specific values of the aforementioned variables (including 3D coordinates), in the same order as indicated by the variable-\/names list, through either POINT-\/packing (i.\+e., tuple-\/based storage) or BLOCK-\/packing (component-\/based storage). In particular, the first /\+ description line of each zone tells the type of all the constituent cells as the connectivity /\+ topology information. In other words, the entire dataset is made up of multiple zones (blocks), of which each maintains a set of cells of the same type (\textquotesingle{}BRICK\textquotesingle{}, \textquotesingle{}TRIANGLE\textquotesingle{}, \textquotesingle{}QUADRILATERAL\textquotesingle{}, \textquotesingle{}TETRAHEDRON\textquotesingle{}, and \textquotesingle{}POINT\textquotesingle{} in Tecplot terms). In addition, the description line of each zone specifies the zone name, dimensionality information (size of each dimension for a structured zone), number of nodes, and number of cells. Information about the file format is available at \href{http://download.tecplot.com/360/dataformat.pdf}{\texttt{http:\+/\+/\+download.\+tecplot.\+com/\+360/\+dataformat.\+pdf}}.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_tecplot_reader}{vtk\+Tecplot\+Reader} is currently a simplified ASCII Tecplot reader and some functionalities (e.\+g., extraction of sections \textquotesingle{}GEOMETRY\textquotesingle{}, \textquotesingle{}TEXT\textquotesingle{}, and \textquotesingle{}DATA SETAUXDATA\textquotesingle{}, access to multiple time steps, in addition to the construction of \doxylink{classvtk_rectilinear_grid}{vtk\+Rectilinear\+Grid} and \doxylink{classvtk_image_data}{vtk\+Image\+Data} objects) are not supported.
\end{DoxyWarning}
\begin{DoxyParagraph}{Thanks:\+}
This class is a VTK implementation of Vis\+It\textquotesingle{}s ASCII Tecplot reader.
