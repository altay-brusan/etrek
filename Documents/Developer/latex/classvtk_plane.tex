\doxysubsection{Detailed Description}
perform various plane computations 

\doxylink{classvtk_plane}{vtk\+Plane} provides methods for various plane computations. These include projecting points onto a plane, evaluating the plane equation, and returning plane normal. \doxylink{classvtk_plane}{vtk\+Plane} is a concrete implementation of the abstract class \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.
