\doxysubsection{Detailed Description}
Entries are cache data for cursors. 

Entries are relevant for cursor/\+supercursor developers. Filters developers should have a look at cursors/\+supercursors documentation. (cf. \doxylink{classvtk_hyper_tree_grid_non_oriented_cursor}{vtk\+Hyper\+Tree\+Grid\+Non\+Oriented\+Cursor}). When writing a new cursor or supercursor the choice of the entry is very important:\+ it will drive the performance and memory cost. This is even more important for supercursors which have several neighbors:\+ 6x for Von\+Neuman and 26x for Moore.

Several types of Entries exist:\+
\begin{DoxyEnumerate}
\item \doxylink{classvtk_hyper_tree_grid_entry}{vtk\+Hyper\+Tree\+Grid\+Entry} This cache only memorizes the current cell index in one Hyper\+Tree. Using the index, this entry provides several services such as:\+ is the cell coarse or leaf, get or set global index (to access field value, cf. \doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree}), descend into selected child, subdivise the cell. Equivalent services are available for all entries.
\item \doxylink{classvtk_hyper_tree_grid_geometry_entry}{vtk\+Hyper\+Tree\+Grid\+Geometry\+Entry} This cache adds the origin coordinates of the cell atop \doxylink{classvtk_hyper_tree_grid_entry}{vtk\+Hyper\+Tree\+Grid\+Entry}. Getter is provided, as well as services related to the bounding box and cell center.
\item \doxylink{classvtk_hyper_tree_grid_level_entry}{vtk\+Hyper\+Tree\+Grid\+Level\+Entry} This cache adds the following information with their getters atop \doxylink{classvtk_hyper_tree_grid_entry}{vtk\+Hyper\+Tree\+Grid\+Entry}:\+ pointer to the Hyper\+Tree, level of the current cell.
\item \doxylink{classvtk_hyper_tree_grid_geometry_level_entry}{vtk\+Hyper\+Tree\+Grid\+Geometry\+Level\+Entry} This cache is a combination of \doxylink{classvtk_hyper_tree_grid_level_entry}{vtk\+Hyper\+Tree\+Grid\+Level\+Entry} and \doxylink{classvtk_hyper_tree_grid_level_entry}{vtk\+Hyper\+Tree\+Grid\+Level\+Entry}:\+ it provides all combined services.
\end{DoxyEnumerate}
