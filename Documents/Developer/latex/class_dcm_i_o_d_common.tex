\doxysubsection{Detailed Description}
Interface class to those modules and data attributes are common for many DICOM IODs. \doxylink{requirements_The}{The} class offers a dedicated API for getting and settings those attributes. Modules included:\+ Patient Module, General Study Module, General Equipment Module, General Series Module, Frame of Reference Module, SOP Common Module.
