\doxysubsection{Detailed Description}
class defining a representation for the \doxylink{classvtk_tensor_widget}{vtk\+Tensor\+Widget} 

This class is a concrete representation for the \doxylink{classvtk_tensor_widget}{vtk\+Tensor\+Widget}. In summary, it allows the editing of a tensor glyph (by modifying the underlying tensor value). This includes controlling the position, scaling, and rotation of the glyph. \doxylink{requirements_The}{The} representation is simply an oriented, scaled box which can be manipulated to transform the tensor. Optionally, an ellipsoid defined by the tensor eigenvectors can be shown for informational purposes.

To use this representation, specify a 3x3 real, symmetric matrix defining the tensor. (This implicitly defines an orthogonal basis from the three tensor eigenvectors.) Then use \doxylink{classvtk_tensor_representation_ac347efdac8bf38b5592a015d2671e7c5}{Place\+Widget()} to define a bounding box:\+ the bounding box defines a position for the tensor from its center point, and the representation is scaled to fit in the bounding box.

Note:\+ typical usage is to place a tensor glyph inside of the representation (i.\+e., the box) which is updated as the representation is manipulated by the user. \doxylink{requirements_The}{The} built-\/in ellipsoid can be used for this; alternatively through callbacks and such, it is possible to place other glyph types such as superquadrics.
