\doxysubsection{Detailed Description}
transfer data from a graph representation to a tree representation using direct mapping or pedigree ids. 

\doxylink{requirements_The}{The} filter requires both a \doxylink{classvtk_graph}{vtk\+Graph} and \doxylink{classvtk_tree}{vtk\+Tree} as input. \doxylink{requirements_The}{The} tree vertices must be a superset of the graph vertices. A common example is when the graph vertices correspond to the leaves of the tree, but the internal vertices of the tree represent groupings of graph vertices. \doxylink{requirements_The}{The} algorithm matches the vertices using the array "{}\+Pedigree\+Id"{}. \doxylink{requirements_The}{The} user may alternately set the Direct\+Mapping flag to indicate that the two structures must have directly corresponding offsets (i.\+e. node i in the graph must correspond to node i in the tree).
