\doxysubsection{Detailed Description}
This looks for symmetric tensors of a given rank and dimension. 

All array names must be identical except for the last {\itshape rank} characters which must be taken from the {\itshape dim} -\/length character array {\itshape seq}, specified as dimension indicators.
