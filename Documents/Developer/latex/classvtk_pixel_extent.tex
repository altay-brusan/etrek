\doxysubsection{Detailed Description}
Representation of a cartesian pixel plane and common operations on it. \doxylink{requirements_The}{The} implementation is intended to be fast and light so that it may be used in place of int\+[4]\+ with little or no performance penalty.

NOTE in most cases operation on an empty object produces incorrect results. If it an issue query \doxylink{classvtk_pixel_extent_ab2bf93b04191a5113248c1ab22d84221}{Empty()} first.
