\doxysubsection{Detailed Description}
Passing data to and from liblzma. 

\doxylink{requirements_The}{The} \doxylink{structlzma__stream}{lzma\+\_\+stream} structure is used for
\begin{DoxyItemize}
\item passing pointers to input and output buffers to liblzma;
\item defining custom memory handler functions; and
\item holding a pointer to coder-\/specific internal data structures.
\end{DoxyItemize}

Typical usage:\+


\begin{DoxyItemize}
\item After allocating \doxylink{structlzma__stream}{lzma\+\_\+stream} (on stack or with malloc()), it must be initialized to LZMA\+\_\+\+STREAM\+\_\+\+INIT (see LZMA\+\_\+\+STREAM\+\_\+\+INIT for details).
\item Initialize a coder to the \doxylink{structlzma__stream}{lzma\+\_\+stream}, for example by using lzma\+\_\+easy\+\_\+encoder() or lzma\+\_\+auto\+\_\+decoder(). Some notes:\+
\begin{DoxyItemize}
\item In contrast to zlib, strm-\/\texorpdfstring{$>$}{>}next\+\_\+in and strm-\/\texorpdfstring{$>$}{>}next\+\_\+out are ignored by all initialization functions, thus it is safe to not initialize them yet.
\item \doxylink{requirements_The}{The} initialization functions always set strm-\/\texorpdfstring{$>$}{>}total\+\_\+in and strm-\/\texorpdfstring{$>$}{>}total\+\_\+out to zero.
\item If the initialization function fails, no memory is left allocated that would require freeing with lzma\+\_\+end() even if some memory was associated with the \doxylink{structlzma__stream}{lzma\+\_\+stream} structure when the initialization function was called.
\end{DoxyItemize}
\item Use lzma\+\_\+code() to do the actual work.
\item Once the coding has been finished, the existing \doxylink{structlzma__stream}{lzma\+\_\+stream} can be reused. It is OK to reuse \doxylink{structlzma__stream}{lzma\+\_\+stream} with different initialization function without calling lzma\+\_\+end() first. Old allocations are automatically freed.
\item Finally, use lzma\+\_\+end() to free the allocated memory. lzma\+\_\+end() never frees the \doxylink{structlzma__stream}{lzma\+\_\+stream} structure itself.
\end{DoxyItemize}

Application may modify the values of total\+\_\+in and total\+\_\+out as it wants. They are updated by liblzma to match the amount of data read and written but aren\textquotesingle{}t used for anything else except as a possible return values from lzma\+\_\+get\+\_\+progress().
