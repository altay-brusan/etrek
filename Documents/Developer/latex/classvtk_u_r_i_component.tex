\doxysubsection{Detailed Description}
Represent an URI component. 

An URI can have an empty but defined component. This applies to authority, path, query and fragment. This is mainly used for strong string reconstruction, example:\+ {\ttfamily \doxylink{classvtk_u_r_i_afa8affe6568269b70a11727e0035d99b}{vtk\+URI::\+\+Parse}("{}\href{file://?}{\texttt{file:\+/\+/\+?}}\#"{})-\/\texorpdfstring{$>$}{>}To\+String()} must return {\ttfamily "{}\href{file://?}{\texttt{file:\+/\+/\+?}}\#"{}}, all components are empty, but defined, so they must be restored when recomposition the URI string representation. URI path is always defined for a valid URI.
