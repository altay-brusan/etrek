\doxysubsection{Detailed Description}
A one-\/dimensional coordinate system used to record time in date\+Time representation as defined in ISO 8601. 

A \doxylink{classcs_1_1_date_time_temporal_c_s}{Date\+Time\+Temporal\+CS} shall have one axis association. It does not use axis\+Unit\+ID; the temporal quantities are defined through the ISO 8601 representation.
