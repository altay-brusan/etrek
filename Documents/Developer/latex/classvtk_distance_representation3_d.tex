\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_distance_widget}{vtk\+Distance\+Widget} 

\doxylink{requirements_The}{The} \doxylink{classvtk_distance_representation3_d}{vtk\+Distance\+Representation3D} is a representation for the \doxylink{classvtk_distance_widget}{vtk\+Distance\+Widget}. This representation consists of a measuring line (axis) and two vtk\+Handle\+Widgets to place the end points of the line. Note that this particular widget draws its representation in 3D space, so the widget can be occluded.
