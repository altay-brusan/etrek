\doxysubsection{Detailed Description}
Representation of the \doxylink{classvtk3_d_cursor_widget}{vtk3\+DCursor\+Widget}. 

Internally, the class uses a \doxylink{classvtk_hardware_picker}{vtk\+Hardware\+Picker} to pick the position of the cursor in the scene given a display position (in pixels). If the mouse hovers an actor, the cursor is placed on its surface. If not, it\textquotesingle{}s placed on the focal plane of the camera. Because of the current state of pickers in VTK, this cursor do not support volumetric data.

\doxylink{requirements_The}{The} cursor itself can be considered as a self-\/employed widget handle. For resizing the cursor, use the Set\+Handle\+Size method of this widget.

Current limitations :\+
\begin{DoxyItemize}
\item Do not work with volumes (for now no pickers handles them properly)
\item Unsteady placement on other widgets (manipulation and cursor actualization remain fine)
\item When zooming the cursor do not follows the mouse until moving it again
\end{DoxyItemize}
