\begin{DoxyEnumerate}

\item {\bfseries{Test RIS connections}} -\/ Use DICOM echo to verify connectivity before going live
\item {\bfseries{Monitor log files}} -\/ Adjust {\ttfamily File\+Size\+MB} and {\ttfamily Max\+File\+Count} based on disk space
\item {\bfseries{Set appropriate refresh intervals}} -\/ Balance between freshness and network load 
\end{DoxyEnumerate}
