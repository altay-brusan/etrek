\doxysubsection{Detailed Description}
define API for picking subclasses 

\doxylink{classvtk_abstract_picker}{vtk\+Abstract\+Picker} is an abstract superclass that defines a minimal API for its concrete subclasses. \doxylink{requirements_The}{The} minimum functionality of a picker is to return the x-\/y-\/z global coordinate position of a pick (the pick itself is defined in display coordinates).

\doxylink{requirements_The}{The} API to this class is to invoke the \doxylink{classvtk_abstract_picker_a2a0b3479c5e079d2a22fa59e7af828e7}{Pick()} method with a selection point (in display coordinates -\/ pixels) and a renderer. Then get the resulting pick position in global coordinates with the Get\+Pick\+Position() method.

\doxylink{classvtk_picker}{vtk\+Picker} fires events during the picking process. These events are Start\+Pick\+Event, Pick\+Event, and End\+Pick\+Event which are invoked prior to picking, when something is picked, and after all picking candidates have been tested. Note that during the pick process the Pick\+Event of \doxylink{classvtk_prop}{vtk\+Prop} (and its subclasses such as \doxylink{classvtk_actor}{vtk\+Actor}) is fired prior to the Pick\+Event of \doxylink{classvtk_picker}{vtk\+Picker}.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_abstract_picker}{vtk\+Abstract\+Picker} and its subclasses will not pick props that are "{}unpickable"{} (see \doxylink{classvtk_prop}{vtk\+Prop}) or are fully transparent (if transparency is a property of the \doxylink{classvtk_prop}{vtk\+Prop}).

There are two classes of pickers:\+ those that pick using geometric methods (typically a ray cast); and those that use rendering hardware. Geometric methods return more information but are slower. Hardware methods are much faster and return minimal information. Examples of geometric pickers include \doxylink{classvtk_picker}{vtk\+Picker}, \doxylink{classvtk_cell_picker}{vtk\+Cell\+Picker}, and \doxylink{classvtk_point_picker}{vtk\+Point\+Picker}. Examples of hardware pickers include \doxylink{classvtk_world_point_picker}{vtk\+World\+Point\+Picker} and \doxylink{classvtk_prop_picker}{vtk\+Prop\+Picker}.
\end{DoxyWarning}
\begin{DoxySeeAlso}{See also}
\doxylink{classvtk_prop_picker}{vtk\+Prop\+Picker} uses hardware acceleration to pick an instance of \doxylink{classvtk_prop}{vtk\+Prop}. (This means that 2D and 3D props can be picked, and it\textquotesingle{}s relatively fast.) If you need to pick cells or points, you might wish to use \doxylink{classvtk_cell_picker}{vtk\+Cell\+Picker} or \doxylink{classvtk_point_picker}{vtk\+Point\+Picker}. \doxylink{classvtk_world_point_picker}{vtk\+World\+Point\+Picker} is the fastest picker, returning an x-\/y-\/z coordinate value using the hardware z-\/buffer. \doxylink{classvtk_picker}{vtk\+Picker} can be used to pick the bounding box of 3D props. 
\end{DoxySeeAlso}
