\doxysubsection{Detailed Description}
Fill a \doxylink{classvtk_blue_obelisk_data}{vtk\+Blue\+Obelisk\+Data} container with data from the BODR XML dataset. 

\doxylink{requirements_The}{The} Blue Obelisk Data Repository is a free, open repository of chemical information. This class extracts the BODR information into vtk arrays, which are stored in a \doxylink{classvtk_blue_obelisk_data}{vtk\+Blue\+Obelisk\+Data} object.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} \doxylink{classvtk_blue_obelisk_data_parser}{vtk\+Blue\+Obelisk\+Data\+Parser} class should never need to be used directly. For convenient access to the BODR data, use \doxylink{classvtk_periodic_table}{vtk\+Periodic\+Table}. For access to the raw arrays produced by this parser, see the \doxylink{classvtk_blue_obelisk_data}{vtk\+Blue\+Obelisk\+Data} class. A static \doxylink{classvtk_blue_obelisk_data}{vtk\+Blue\+Obelisk\+Data} object is accessible via vtk\+Periodic\+Table::\+\+Get\+Blue\+Obelisk\+Data().
\end{DoxyWarning}
