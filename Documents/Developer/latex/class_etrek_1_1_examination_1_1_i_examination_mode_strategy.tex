\doxysubsection{Detailed Description}
Strategy interface for examination mode-\/specific behavior. 

This interface defines hooks that are called at key points during an examination workflow. Each examination mode (Clinical, Demo, Calibration, Test) implements this interface with mode-\/specific logic.

\doxylink{requirements_The}{The} delegate calls these hooks instead of hardcoding mode-\/specific behavior, allowing clean separation between workflow orchestration and mode logic.
