\doxysubsection{Detailed Description}
actor for a cube-\/axes like prop in the 3D view. 

\doxylink{classvtk_grid_axes_actor3_d}{vtk\+Grid\+Axes\+Actor3D} is an alternate implementation for something like the \doxylink{classvtk_cube_axes_actor}{vtk\+Cube\+Axes\+Actor} which can be used to render a 3D grid in a scene. It uses \doxylink{classvtk_grid_axes_actor3_d}{vtk\+Grid\+Axes\+Actor3D} to render individual axes planes for the box.
