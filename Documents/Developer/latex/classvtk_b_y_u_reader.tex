read MOVIE.\+BYU polygon files 

\doxylink{classvtk_b_y_u_reader}{vtk\+BYUReader} is a source object that reads MOVIE.\+BYU polygon files. These files consist of a geometry file (.g), a scalar file (.s), a displacement or vector file (.d), and a 2D texture coordinate file (.t).
