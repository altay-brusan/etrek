\doxysubsection{Detailed Description}
iterate over all data points in an image. 

This class will iterate over an image. For each position, it provides the (x,y,z) position, the (I,J,K) index, and the point Id. If a stencil is provided, then it also reports, for each point, whether the point is inside the stencil. 

\doxylink{requirements_The}{The} iterator can go through the image point-\/by-\/point or span-\/by-\/span. \doxylink{requirements_The}{The} \doxylink{classvtk_image_point_iterator_a925e1b535e6bd8357cfab6b84ec540df}{Next()} method advances to the next point, while the \doxylink{classvtk_image_point_iterator_ae07578c2a5fa30dfa19e4cad591da4df}{Next\+Span()} method skips to the beginning of the next span, where a span is defined as a start position and point count within an image row. \begin{DoxySeeAlso}{See also}
