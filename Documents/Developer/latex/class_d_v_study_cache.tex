\doxysubsection{Detailed Description}
A class to handle a study cache (list of items). This is the highest level in the hierarchical cache structure. This class is used by \doxylink{class_d_v_interface}{DVInterface}. \doxylink{requirements_The}{The} internal structure is a list of \doxylink{class_d_v_series_cache}{DVSeries\+Cache}.
