\doxysubsection{Detailed Description}
Convenience container for internal structures specific to a volume input. 

This class stores together \doxylink{classvtk_volume_texture}{vtk\+Volume\+Texture}, Lookup tables internal and other input specific parameters. It also provides convenience methods to manage the lookup tables.

\begin{DoxyWarning}{Warning}
This is an internal class of \doxylink{classvtk_open_g_l_g_p_u_volume_ray_cast_mapper}{vtk\+Open\+GLGPUVolume\+Ray\+Cast\+Mapper}. It assumes there is an active Open\+GL context in methods involving GL calls (Make\+Current() is expected to be called in the mapper beforehand).
\end{DoxyWarning}
