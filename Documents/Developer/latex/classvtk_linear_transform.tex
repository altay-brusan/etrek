\doxysubsection{Detailed Description}
abstract superclass for linear transformations 

\doxylink{classvtk_linear_transform}{vtk\+Linear\+Transform} provides a generic interface for linear (affine or 12 degree-\/of-\/freedom) geometric transformations.

\begin{DoxyWarning}{Warning}
Portions of this class (i.\+e., when transforming arrays of points and/\+or associated attributes such as normals and vectors) has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.
\end{DoxyWarning}
