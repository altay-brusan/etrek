\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type, typename \+\_\+\+Preconditioner$>$\newline
class Eigen::\+\+Bi\+CGSTAB$<$ \+\_\+\+Matrix\+Type, \+\_\+\+Preconditioner $>$}
A bi conjugate gradient stabilized solver for sparse square problems. 

This class allows to solve for A.\+x = b sparse linear problems using a bi conjugate gradient stabilized algorithm. \doxylink{requirements_The}{The} vectors x and b can be either dense or sparse.


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the sparse matrix A, can be a dense or a sparse matrix. \\
\hline
{\em \+\_\+\+Preconditioner} & the type of the preconditioner. Default is \doxylink{class_eigen_1_1_diagonal_preconditioner}{Diagonal\+Preconditioner}\\
\hline
\end{DoxyTemplParams}
\textbackslash{}implsparsesolverconcept

\doxylink{requirements_The}{The} maximal number of iterations and tolerance value can be controlled via the \doxylink{class_eigen_1_1_iterative_solver_base_a1bbaf86b7df6d54e78ced4da6ed2dac1}{set\+Max\+Iterations()} and \doxylink{class_eigen_1_1_iterative_solver_base_ac43c50c69a5b621cb5a9991a1005750d}{set\+Tolerance()} methods. \doxylink{requirements_The}{The} defaults are the size of the problem for the maximal number of iterations and Num\+Traits$<$\+Scalar$>$::\+epsilon() for the tolerance.

\doxylink{requirements_The}{The} tolerance corresponds to the relative residual error:\+ \texorpdfstring{$\vert$}{|}\+Ax-\/b\texorpdfstring{$\vert$}{|}/\+\texorpdfstring{$\vert$}{|}b\texorpdfstring{$\vert$}{|}

{\bfseries{Performance:\+}} when using sparse matrices, best performance is achied for a row-\/major sparse matrix format. Moreover, in this case multi-\/threading can be exploited if the user code is compiled with Open\+MP enabled. See Topic\+Multi\+Threading for details.

This class can be used as the direct solver classes. Here is a typical usage example:\+
