\doxysubsection{Detailed Description}
convenience class to quickly generate a pool of random numbers 

\doxylink{classvtk_random_pool}{vtk\+Random\+Pool} generates random numbers, and can do so using multithreading. It supports parallel applications where generating random numbers on the fly is difficult (i.\+e., non-\/deterministic). Also, it can be used to populate vtk\+Data\+Arrays in an efficient manner. By default it uses an instance of \doxylink{classvtk_mersenne_twister}{vtk\+Mersenne\+Twister} to generate random sequences, but any subclass of \doxylink{classvtk_random_sequence}{vtk\+Random\+Sequence} may be used. It also supports simple methods to generate, access, and pass random memory pools between objects.

In threaded applications, these class may be conveniently used to pre-\/generate a sequence of random numbers, followed by the use of deterministic accessor methods to produce random sequences without problems etc. due to unpredictable work load and order of thread execution.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} class uses \doxylink{classvtk_multi_threader}{vtk\+Multi\+Threader} if the size of the pool is larger than the specified chunk size. Also, \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools} may be used to scale the components in the method \doxylink{classvtk_random_pool_a7a483447d951844c265251c160500086}{Populate\+Data\+Array()}. 
\end{DoxyWarning}
