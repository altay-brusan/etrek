\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_scan_protocol_1_1_repository}{Repository} for scan protocol configuration. 

Implements the \doxylink{namespace_etrek_1_1_scan_protocol_1_1_repository}{Repository} pattern for scan protocol data access. Provides CRUD operations for:\+
\begin{DoxyItemize}
\item Anatomic regions and body parts
\item Radiographic views
\item Radiographic procedures (multi-\/view sequences)
\item Technique parameters (KVP, mA, time settings)
\item View-\/technique associations
\item Procedure-\/view associations
\end{DoxyItemize}

Supports soft-\/delete for views and procedures to maintain historical integrity while removing from active use.
