\doxysubsection{Detailed Description}
Display a 2d image. 

\doxylink{classvtk_image_viewer}{vtk\+Image\+Viewer} is a convenience class for displaying a 2d image. It packages up the functionality found in \doxylink{classvtk_render_window}{vtk\+Render\+Window}, \doxylink{classvtk_renderer}{vtk\+Renderer}, \doxylink{classvtk_actor2_d}{vtk\+Actor2D} and \doxylink{classvtk_image_mapper}{vtk\+Image\+Mapper} into a single easy to use class. Behind the scenes these four classes are actually used to to provide the required functionality. \doxylink{classvtk_image_viewer}{vtk\+Image\+Viewer} is simply a wrapper around them.
