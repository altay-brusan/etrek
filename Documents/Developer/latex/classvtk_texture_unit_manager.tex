\doxysubsection{Detailed Description}
allocate/\+free texture units. 

\doxylink{classvtk_texture_unit_manager}{vtk\+Texture\+Unit\+Manager} is a central place used by shaders to reserve a texture unit ( \doxylink{classvtk_texture_unit_manager_aecfd1f82553ffeecdd913c9e6a666777}{Allocate()} ) or release it ( \doxylink{classvtk_texture_unit_manager_a27ca6b3a74a4a371eed4ae7ec935d531}{Free()} ).

Don\textquotesingle{}t create a \doxylink{classvtk_texture_unit_manager}{vtk\+Texture\+Unit\+Manager}, query it from the \doxylink{classvtk_open_g_l_render_window}{vtk\+Open\+GLRender\+Window}
