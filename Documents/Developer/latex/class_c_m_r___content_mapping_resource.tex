\begin{DoxyNote}{Note}
In case of multi-\/threaded applications, this function could be called before any context group is actually used. This might be easier than calling the initialize() function of the respective context group classes separately. However, since the list of supported context groups is increasing over time, the additional resource requirements should be considered. That means, if only a few context groups are used, it is recommended to call the individual initialize() functions instead.
