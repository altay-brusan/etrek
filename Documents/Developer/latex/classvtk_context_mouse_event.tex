\doxysubsection{Detailed Description}
data structure to represent mouse events. 

Provides a convenient data structure to represent mouse events in the \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}. Passed to \doxylink{classvtk_abstract_context_item}{vtk\+Abstract\+Context\+Item} objects.
