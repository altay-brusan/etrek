\doxysubsection{Detailed Description}
actor for an axes plane in a 3D view. 

\doxylink{classvtk_grid_axes_actor2_d}{vtk\+Grid\+Axes\+Actor2D} is a \doxylink{classvtk_prop3_d}{vtk\+Prop3D} that renders a single axes plane (or face). Despite the name, it renders a prop in 3D with ability to render lines for the axes bounds along with labels on them.

To use this, one sets the {\ttfamily Grid\+Bounds} and then the {\ttfamily Face} which identifies the face of the cube defined by the {\ttfamily Grid\+Bounds} along which this prop will render the grid. Parameters available allow additional controls including labeling, grid rendering, edge rendering etc.
