\doxysubsection{Detailed Description}
Controls sorting of sparse array coordinates. 

\doxylink{classvtk_array_sort}{vtk\+Array\+Sort} stores an ordered set of dimensions along which the values stored in a sparse array should be sorted.

Convenience constructors are provided for specifying one, two, and three dimensions. To sort along more than three dimensions, use the default constructor, \doxylink{classvtk_array_sort_a858f7ee95c501c37188f86da7aa13a71}{Set\+Dimensions()}, and operator\+[]\+ to assign each dimension to be sorted.
