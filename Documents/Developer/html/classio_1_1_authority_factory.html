Detailed Description

Builds object from an authority database.

A AuthorityFactory should be used only by one thread at a time.

Remarks
Implements [AuthorityFactory] (http://www.geoapi.org/3.0/javadoc/org/opengis/referencing/AuthorityFactory.html) from GeoAPI
