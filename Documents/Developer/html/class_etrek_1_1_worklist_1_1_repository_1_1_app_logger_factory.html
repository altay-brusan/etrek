Detailed Description

Factory for creating application-specific loggers.

AppLoggerFactory encapsulates the creation logic for AppLogger instances. It allows services and components to obtain loggers with consistent configuration and dependency injection of the underlying LoggerProvider.

The factory pattern is used to decouple logger creation from usage, enabling future extension (e.g., different logger types or providers).
