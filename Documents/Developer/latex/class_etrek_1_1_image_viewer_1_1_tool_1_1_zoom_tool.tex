\doxysubsection{Detailed Description}
Magnifier tool for examining image details. 

When active, displays a magnifying glass overlay that shows a zoomed portion of the image centered on the cursor position.

Interaction:\+
\begin{DoxyItemize}
\item Move mouse:\+ Update magnifier position
\item Left click:\+ Toggle magnification level (2x/\+3x)
\item Mouse wheel:\+ Also toggles magnification level 
\end{DoxyItemize}
