\doxysubsection{Detailed Description}
reduce the number of tetrahedra in a mesh 

\doxylink{classvtk_unstructured_grid_quadric_decimation}{vtk\+Unstructured\+Grid\+Quadric\+Decimation} is a class that simplifies tetrahedral meshes using randomized multiple choice edge collapses. \doxylink{requirements_The}{The} input to this filter is a \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} object with a single scalar field (specifying in the Scalars\+Name attribute). Users can determine the size of the output mesh by either setting the value of Target\+Reduction or Number\+Of\+Tets\+Output. \doxylink{requirements_The}{The} Boundary\+Weight can be set to control how well the mesh boundary should be preserved. \doxylink{requirements_The}{The} implementation uses Michael Garland\textquotesingle{}s generalized Quadric Error Metrics, the Corner Table representation and the Standard Conjugate Gradient Method to order the edge collapse sequence.

Instead of using the traditional priority queue, the algorithm uses a randomized approach to yield faster performance with comparable quality. At each step, a set of 8 random candidate edges are examined to select the best edge to collapse. This number can also be changed by users through Number\+Of\+Candidates.

For more information as well as the streaming version of this algorithm see:\+

"{}\+Streaming Simplification of Tetrahedral Meshes"{} by H. T. Vo, S. P. Callahan, P. Lindstrom, V. Pascucci and C. T. Silva, IEEE Transactions on Visualization and Computer Graphics, 13(1):\+145-\/155, 2007.
