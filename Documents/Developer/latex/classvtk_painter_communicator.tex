\doxysubsection{Detailed Description}
A communicator that can safely be used inside a painter. 

A simple container holding a handle to an MPI communicator. This API is sufficient to allow for control flow with/\+without MPI. \doxylink{requirements_The}{The} parallel parts of the code should use the derived class vtk\+PPainter\+Communicator.
