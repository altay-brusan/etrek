\doxysubsection{Detailed Description}
Contour interpolator for to place points on polygonal surfaces. 

\doxylink{classvtk_polygonal_surface_contour_line_interpolator}{vtk\+Polygonal\+Surface\+Contour\+Line\+Interpolator} interpolates and places contour points on polygonal surfaces. \doxylink{requirements_The}{The} class interpolates nodes by computing a {\itshape graph} {\itshape geodesic} laying on the polygonal data. By {\itshape graph} {\itshape Geodesic}, we mean that the line interpolating the two end points traverses along on the mesh edges so as to form the shortest path. A Dijkstra algorithm is used to compute the path. See \doxylink{classvtk_dijkstra_graph_geodesic_path}{vtk\+Dijkstra\+Graph\+Geodesic\+Path}.

\doxylink{requirements_The}{The} class is mean to be used in conjunction with \doxylink{classvtk_polygonal_surface_point_placer}{vtk\+Polygonal\+Surface\+Point\+Placer}. \doxylink{requirements_The}{The} reason for this weak coupling is a performance issue, both classes need to perform a cell pick, and coupling avoids multiple cell picks (cell picks are slow).

\begin{DoxyWarning}{Warning}
You should have computed cell normals for the input polydata.
\end{DoxyWarning}
