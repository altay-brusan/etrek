\doxysubsection{Detailed Description}
draw text labels at dataset points 

\doxylink{classvtk_labeled_data_mapper}{vtk\+Labeled\+Data\+Mapper} is a mapper that renders text at dataset points. Various items can be labeled including point ids, scalars, vectors, normals, texture coordinates, tensors, and field data components.

\doxylink{requirements_The}{The} format with which the label is drawn is specified using a printf style format string. \doxylink{requirements_The}{The} font attributes of the text can be set through the \doxylink{classvtk_text_property}{vtk\+Text\+Property} associated to this mapper.

By default, all the components of multi-\/component data such as vectors, normals, texture coordinates, tensors, and multi-\/component scalars are labeled. However, you can specify a single component if you prefer. (Note:\+ the label format specifies the format to use for a single component. \doxylink{requirements_The}{The} label is creating by looping over all components and using the label format to render each component.) \doxylink{requirements_The}{The} character separator between components can be set. By default, it is set to a single whitespace.

\begin{DoxyWarning}{Warning}
Use this filter in combination with \doxylink{classvtk_select_visible_points}{vtk\+Select\+Visible\+Points} if you want to label only points that are visible. If you want to label cells rather than points, use the filter \doxylink{classvtk_cell_centers}{vtk\+Cell\+Centers} to generate points at the center of the cells. Also, you can use the class \doxylink{classvtk_generate_ids}{vtk\+Generate\+Ids} to generate ids as scalars or field data, which can then be labeled.
\end{DoxyWarning}
