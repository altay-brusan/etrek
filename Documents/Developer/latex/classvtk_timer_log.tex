\doxysubsection{Detailed Description}
Timer support and logging. 

\doxylink{classvtk_timer_log}{vtk\+Timer\+Log} contains walltime and cputime measurements associated with a given event. These results can be later analyzed when "{}dumping out"{} the table.

In addition, \doxylink{classvtk_timer_log}{vtk\+Timer\+Log} allows the user to simply get the current time, and to start/\+stop a simple timer separate from the timing table logging.
