\doxysubsection{Detailed Description}
Contour interpolator for placing points on an image. 

\doxylink{classvtk_dijkstra_image_contour_line_interpolator}{vtk\+Dijkstra\+Image\+Contour\+Line\+Interpolator} interpolates and places contour points on images. \doxylink{requirements_The}{The} class interpolates nodes by computing a graph laying on the image data. By graph, we mean that the line interpolating the two end points traverses along pixels so as to form a shortest path. A Dijkstra algorithm is used to compute the path.

\doxylink{requirements_The}{The} class is meant to be used in conjunction with \doxylink{classvtk_image_actor_point_placer}{vtk\+Image\+Actor\+Point\+Placer}. One reason for this coupling is a performance issue:\+ both classes need to perform a cell pick, and coupling avoids multiple cell picks (cell picks are slow). Another issue is that the interpolator may need to set the image input to its \doxylink{classvtk_dijkstra_image_geodesic_path}{vtk\+Dijkstra\+Image\+Geodesic\+Path} ivar.
