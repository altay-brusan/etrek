\doxysubsection{Detailed Description}
Use a \doxylink{classvtk_window}{vtk\+Window} as input to image pipeline. 

\doxylink{classvtk_window_to_image_filter}{vtk\+Window\+To\+Image\+Filter} provides methods needed to read the data in a \doxylink{classvtk_window}{vtk\+Window} and use it as input to the imaging pipeline. This is useful for saving an image to a file for example. \doxylink{requirements_The}{The} window can be read as either RGB or RGBA pixels; in addition, the depth buffer can also be read. RGB and RGBA pixels are of type unsigned char, while Z-\/\+Buffer data is returned as floats. Use this filter to convert Render\+Windows or Image\+Windows to an image format.

\begin{DoxyWarning}{Warning}
A \doxylink{classvtk_window}{vtk\+Window} doesn\textquotesingle{}t behave like other parts of the VTK pipeline:\+ its modification time doesn\textquotesingle{}t get updated when an image is rendered. As a result, naive use of \doxylink{classvtk_window_to_image_filter}{vtk\+Window\+To\+Image\+Filter} will produce an image of the first image that the window rendered, but which is never updated on subsequent window updates. This behavior is unexpected and in general undesirable.

To force an update of the output image, call \doxylink{classvtk_window_to_image_filter}{vtk\+Window\+To\+Image\+Filter}\textquotesingle{}s Modified method after rendering to the window.

In VTK versions 4 and later, this filter is part of the canonical way to output an image of a window to a file (replacing the obsolete Save\+Image\+As\+PPM method for vtk\+Render\+Windows that existed in 3.\+2 and earlier). Connect this filter to the output of the window, and filter\textquotesingle{}s output to a writer such as \doxylink{classvtk_p_n_g_writer}{vtk\+PNGWriter}.

Reading back alpha planes is dependent on the correct operation of the render window\textquotesingle{}s Get\+RGBAChar\+Pixel\+Data method, which in turn is dependent on the configuration of the window\textquotesingle{}s alpha planes. As of VTK 4.\+4+, machine-\/independent behavior is not automatically assured because of these dependencies.
\end{DoxyWarning}
