\doxysubsection{Detailed Description}
abstract class to write a scene to a file 

\doxylink{classvtk_exporter}{vtk\+Exporter} is an abstract class that exports a scene to a file. It is very similar to \doxylink{classvtk_writer}{vtk\+Writer} except that a writer only writes out the geometric and topological data for an object, where an exporter can write out material properties, lighting, camera parameters etc. \doxylink{requirements_The}{The} concrete subclasses of this class may not write out all of this information. For example \doxylink{classvtk_o_b_j_exporter}{vtk\+OBJExporter} writes out Wavefront obj files which do not include support for camera parameters.

\doxylink{classvtk_exporter}{vtk\+Exporter} provides the convenience methods Start\+Write() and End\+Write(). These methods are executed before and after execution of the \doxylink{classvtk_exporter_a508ab84e517fe2840c342608ea4f705b}{Write()} method. You can also specify arguments to these methods. This class defines Set\+Input and Get\+Input methods which take or return a \doxylink{classvtk_render_window}{vtk\+Render\+Window}. \begin{DoxyWarning}{Warning}
Every subclass of \doxylink{classvtk_exporter}{vtk\+Exporter} must implement a Write\+Data() method.
\end{DoxyWarning}
