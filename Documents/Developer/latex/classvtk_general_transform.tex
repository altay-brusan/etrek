\doxysubsection{Detailed Description}
allows operations on any transforms 

\doxylink{classvtk_general_transform}{vtk\+General\+Transform} is like \doxylink{classvtk_transform}{vtk\+Transform} and \doxylink{classvtk_perspective_transform}{vtk\+Perspective\+Transform}, but it will work with any \doxylink{classvtk_abstract_transform}{vtk\+Abstract\+Transform} as input. It is not as efficient as the other two, however, because arbitrary transformations cannot be concatenated by matrix multiplication. Transform concatenation is simulated by passing each input point through each transform in turn. \begin{DoxySeeAlso}{See also}
\doxylink{classvtk_transform}{vtk\+Transform} \doxylink{classvtk_perspective_transform}{vtk\+Perspective\+Transform}
