\doxysubsection{Detailed Description}
Converts elements of a VTK scene graph into vtk-\/js elements. 

\doxylink{classvtk_vtk_j_s_scene_graph_serializer}{vtk\+Vtk\+JSScene\+Graph\+Serializer} accepts nodes and their renderables from a scene graph and a) composes the elements\textquotesingle{} data and topology into a \doxylink{namespace_json}{Json} data structure and b) correlates unique identifiers for data objects in the \doxylink{namespace_json}{Json} data structure to the data objects themselves. It is designed to operate with \doxylink{classvtk_vtk_j_s_view_node_factory}{vtk\+Vtk\+JSView\+Node\+Factory}, which handles the logic for scene graph traversal.

When constructing the \doxylink{namespace_json}{Json} description for a single scene graph node and its renderable, the Add(node, renderable) step processes the renderable into its corresponding vtk-\/js form. For many renderables this is a no-\/op, but current restrictions in vtk-\/js (such as the lack of support for composite mappers and the requirement for data conversion to \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}) require a nontrival conversion step for certain renderable types. \doxylink{requirements_The}{The} subsequent To\+Json(renderable) is a straightforward conversion of the renderable\textquotesingle{}s data members into a vtk-\/js \doxylink{namespace_json}{Json} format.
