\doxysubsection{Detailed Description}
assigner for use with DIY 

\doxylink{classvtk_d_i_y_explicit_assigner}{vtk\+DIYExplicit\+Assigner} is a \doxylink{classdiy_1_1_static_assigner}{diy::\+\+Static\+Assigner} specialization that be used where the block assignment is not strictly round-\/robin or contiguous which assumes blocks equally split among ranks. This supports the case where each rank has arbitrary number of blocks per rank. \doxylink{requirements_The}{The} constructor is provided the mpi communicator and the number of local blocks. It performs parallel communication to exchange information about blocks with all participating ranks.

\doxylink{classvtk_d_i_y_explicit_assigner}{vtk\+DIYExplicit\+Assigner} also supports ability to pad each rank such that the total number of blocks across all ranks is a power of two.
