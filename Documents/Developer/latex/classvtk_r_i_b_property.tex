\doxysubsection{Detailed Description}
RIP Property. 

\doxylink{classvtk_r_i_b_property}{vtk\+RIBProperty} is a subclass of \doxylink{classvtk_property}{vtk\+Property} that allows the user to specify named shaders for use with Render\+Man. Both surface and displacement shaders can be specified. Parameters for the shaders can be declared and set.
