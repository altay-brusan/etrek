\doxysubsection{Detailed Description}
performs ray integration with pre-\/integration tables. 

\doxylink{classvtk_unstructured_grid_pre_integration}{vtk\+Unstructured\+Grid\+Pre\+Integration} performs ray integration by looking into a precomputed table. \doxylink{requirements_The}{The} result should be equivalent to that computed by \doxylink{classvtk_unstructured_grid_linear_ray_integrator}{vtk\+Unstructured\+Grid\+Linear\+Ray\+Integrator} and \doxylink{classvtk_unstructured_grid_partial_pre_integration}{vtk\+Unstructured\+Grid\+Partial\+Pre\+Integration}, but faster than either one. \doxylink{requirements_The}{The} pre-\/integration algorithm was first introduced by Roettger, Kraus, and Ertl in "{}\+Hardware-\/\+Accelerated Volume And Isosurface Rendering Based \+On Cell-\/\+Projection."{}

Due to table size limitations, a table can only be indexed by independent scalars. Thus, dependent scalars are not supported.
