\doxysubsection{Detailed Description}
A class for managing and converting between different character encodings. \doxylink{requirements_The}{The} implementation relies on ICONV (native implementation or libiconv) or ICU, depending on the configuration. \begin{DoxyRemark}{Remarks}
An encoder might be shared by copy constructing an \doxylink{class_o_f_character_encoding}{OFCharacter\+Encoding} object from an existing one. Both objects will refer to the same encoder once this is done, which will only be destroyed after both objects are, using \doxylink{class_o_fshared__ptr}{OFshared\+\_\+ptr} internally. 
\end{DoxyRemark}

Constants to control encoder behavior, e.\+g. regarding illegal character sequences. Currently defined constants may be used to control the implementation\textquotesingle{}s behavior regarding illegal character sequences. An illegal character sequence is a sequence of characters in the source string that is only valid in the context of the source string\textquotesingle{}s character set and has no valid representation in the character set of the destination string. Use these constants to control the transcoding behavior in case an illegal sequence is encountered. \begin{DoxyNote}{Note}
You may set a single one of the constants as the encoder behavior or even a combination (bitwise OR), however, it depends on the underlying implementation which flags/\+combinations are supported. Use \doxylink{class_o_f_character_encoding_a24d52f3cb756385f178341ade70547f1}{supports\+Conversion\+Flags()} to query this information at runtime. 
\end{DoxyNote}
