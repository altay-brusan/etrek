\doxysubsection{Detailed Description}
OS independent class for access and manipulation of system directories. 

\doxylink{classvtk_directory}{vtk\+Directory} provides a portable way of finding the names of the files in a system directory. It also provides methods of manipulating directories.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_directory}{vtk\+Directory} works with windows and unix only. 
\end{DoxyWarning}
