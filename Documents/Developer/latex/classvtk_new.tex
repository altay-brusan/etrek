\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T$>$\newline
class vtk\+New$<$ T $>$}
Allocate and hold a VTK object. 

\doxylink{classvtk_new}{vtk\+New} is a class template that on construction allocates and initializes an instance of its template argument using T::\+\+New(). It assumes ownership of one reference during its lifetime, and calls T-\/\texorpdfstring{$>$}{>}Delete() on destruction.

Automatic casting to raw pointer is available for convenience, but users of this method should ensure that they do not return this pointer if the \doxylink{classvtk_new}{vtk\+New} will go out of scope without incrementing its reference count.
