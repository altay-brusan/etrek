\doxysubsection{Detailed Description}
Superclass for all pipeline executives in VTK. 

\doxylink{classvtk_executive}{vtk\+Executive} is the superclass for all pipeline executives in VTK. A VTK executive is responsible for controlling one instance of \doxylink{classvtk_algorithm}{vtk\+Algorithm}. A pipeline consists of one or more executives that control data flow. Every reader, source, writer, or data processing algorithm in the pipeline is implemented in an instance of \doxylink{classvtk_algorithm}{vtk\+Algorithm}.
