Detailed Description

template<class T>
class OFGlobal< T >

Template class which allows to declare global objects that are protected by a Read/Write Lock if used in multi-thread applications. Must be compiled with -DWITH_THREADS for multi-thread-operation. Template class T must have copy constructor and assignment operator.
