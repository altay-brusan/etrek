\doxysubsection{Detailed Description}
draw symbols with text 

\doxylink{classvtk_legend_box_actor}{vtk\+Legend\+Box\+Actor} is used to associate a symbol with a text string. \doxylink{requirements_The}{The} user specifies a \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} to use as the symbol, and a string associated with the symbol. \doxylink{requirements_The}{The} actor can then be placed in the scene in the same way that any other \doxylink{classvtk_actor2_d}{vtk\+Actor2D} can be used.

To use this class, you must define the position of the legend box by using the superclasses\textquotesingle{} vtk\+Actor2\+D::\+\+Position coordinate and Position2 coordinate. Then define the set of symbols and text strings that make up the menu box. \doxylink{requirements_The}{The} font attributes of the entries can be set through the \doxylink{classvtk_text_property}{vtk\+Text\+Property} associated to this actor. \doxylink{requirements_The}{The} class will scale the symbols and text to fit in the legend box defined by (Position,Position2). Optional features like turning on a border line and setting the spacing between the border and the symbols/\+text can also be set.
