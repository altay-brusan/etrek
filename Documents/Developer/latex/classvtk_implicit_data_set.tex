\doxysubsection{Detailed Description}
treat a dataset as if it were an implicit function 

\doxylink{classvtk_implicit_data_set}{vtk\+Implicit\+Data\+Set} treats any type of dataset as if it were an implicit function. This means it computes a function value and gradient. \doxylink{classvtk_implicit_data_set}{vtk\+Implicit\+Data\+Set} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.

\doxylink{classvtk_implicit_data_set}{vtk\+Implicit\+Data\+Set} computes the function (at the point x) by performing cell interpolation. That is, it finds the cell containing x, and then uses the cell\textquotesingle{}s interpolation functions to compute an interpolated scalar value at x. (A similar approach is used to find the gradient, if requested.) Points outside of the dataset are assigned the value of the ivar Out\+Value, and the gradient value Out\+Gradient.

\begin{DoxyWarning}{Warning}
Any type of dataset can be used as an implicit function as long as it has scalar data associated with it.
\end{DoxyWarning}
