\subsubsection*{template$<$typename Matrix\+Type, int \+\_\+\+Up\+Lo$>$\newline
class Eigen::\+\+Pardiso\+LLT$<$ Matrix\+Type, \+\_\+\+Up\+Lo $>$}
A sparse direct Cholesky (\doxylink{class_eigen_1_1_l_l_t}{LLT}) factorization and solver based on the PARDISO library. 

This class allows to solve for A.\+X = B sparse linear problems via a LL\texorpdfstring{$^\wedge$}{\string^}T Cholesky factorization using the Intel MKL PARDISO library. \doxylink{requirements_The}{The} sparse matrix A must be selfajoint and positive definite. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.
