\begin{DoxyCompactList}\small\item\em Get\+Shader\+MTime returns the last time a modification was made that affected the code of the shader (either code replacement was changed or one or more uniform variables were added or removed. This timestamp can be used by mappers to determine if the shader must be recompiled. Simply changing the value of an existing uniform variable doesn\textquotesingle{}t affect this timestamp as it doesn\textquotesingle{}t change the shader code. \end{DoxyCompactList}\end{DoxyCompactItemize}

Get\+Shader\+MTime returns the last time a modification was made that affected the code of the shader (either code replacement was changed or one or more uniform variables were added or removed. This timestamp can be used by mappers to determine if the shader must be recompiled. Simply changing the value of an existing uniform variable doesn\textquotesingle{}t affect this timestamp as it doesn\textquotesingle{}t change the shader code.
