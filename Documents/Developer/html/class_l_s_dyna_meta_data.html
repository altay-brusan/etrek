enum LSDynaMetaData::LSDYNA_TYPES

LS-Dyna cell types. These may be used as values for the cellType argument in member functions. One dataset is created for each cell type so that cells can have different attributes (temperature, pressure, etc.) defined over them. Note that NUM_CELL_TYPES is not a cell type, but an enumerant that specifies the total number of cell types. It is used to size arrays.
