\doxysubsection{Detailed Description}
represents an image in a 3D scene 

\doxylink{classvtk_image_slice}{vtk\+Image\+Slice} is used to represent an image in a 3D scene. It displays the image either as a slice or as a projection from the camera\textquotesingle{}s perspective. Adjusting the position and orientation of the slice is done by adjusting the focal point and direction of the camera, or alternatively the slice can be set manually in \doxylink{classvtk_image_mapper3_d}{vtk\+Image\+Mapper3D}. \doxylink{requirements_The}{The} lookup table and window/\+level are set in \doxylink{classvtk_image_property}{vtk\+Image\+Property}. Prop3D methods such as \doxylink{classvtk_prop3_d_a00933972e4127c629194f6a0238eeb3b}{Set\+Position()} and \doxylink{classvtk_prop3_d_a4773bccb845cb9880d75222484ee1982}{Rotate\+WXYZ()} change the position and orientation of the data with respect to VTK world coordinates. \begin{DoxyParagraph}{Thanks:\+}
Thanks to David Gobbi at the Seaman Family MR Centre and Dept. of Clinical Neurosciences, Foothills Medical Centre, Calgary, for providing this class.
