\doxysubsection{Detailed Description}
A 3D cell defined by a set of polygonal faces. 

\hypertarget{classvtk_polyhedron_Instantiation}{}\doxysubsection{\texorpdfstring{Instantiation}{Instantiation}}\label{classvtk_polyhedron_Instantiation}
\doxylink{classvtk_polyhedron}{vtk\+Polyhedron} is a concrete implementation of \doxylink{classvtk_cell}{vtk\+Cell} that represents a 3D cell defined by a set of polygonal faces.

To instantiate a \doxylink{classvtk_polyhedron}{vtk\+Polyhedron}, like any \doxylink{classvtk_cell}{vtk\+Cell}, one needs to define the following structures:\+
\begin{DoxyItemize}
\item A list of point coordinates
\item A list of global point IDs
\end{DoxyItemize}

Note that the ordering of points coordinates or IDs is not important. However, it MUST be consistent between the two lists.

Unlike other kinds of cells (e.\+g. \doxylink{classvtk_voxel}{vtk\+Voxel}), the topology is not directly deduced from points coordinates or point IDs ordering; it must be explicitly defined by providing a list of faces (see the \doxylink{classvtk_polyhedron_a3013c03f61c3ab3cb4fe10fb3ee68c01}{Set\+Faces()} method). Each face is represented as a sequence of global point Ids.

Once point coordinates, point IDs and faces are defined, the \doxylink{classvtk_polyhedron_afcb0e7982610f642f95c97da122d10bd}{Initialize()} method should be called in order to setup the internal structures and finalize the construction of the polyhedron.

\hypertarget{classvtk_polyhedron_Specifications}{}\doxysubsection{\texorpdfstring{Specifications}{Specifications}}\label{classvtk_polyhedron_Specifications}
Polyhedrons described by this class must conform to some criteria in order to avoid errors and guarantee good results in terms of visualization and processing.

These specifications are described as follows. Polyhedrons must:\+
\begin{DoxyItemize}
\item be watertight :\+ the faces describing the polyhedron should define an enclosed volume i.\+e. define the “inside” and the “outside” of the cell
\item have planar faces :\+ all points defining a face should be in the same 2D plane
\item not be self-\/intersecting :\+ for example, a face of the polyhedron can’t intersect other ones
\item not contain zero-\/thickness portions :\+ adjacent faces should not overlap each other even partially
\item not contain disconnected elements :\+ detached vertice(s), edge(s) or face(s)
\item be simply connected :\+ \doxylink{classvtk_polyhedron}{vtk\+Polyhedron} must describe a single polyhedron
\item not contain duplicate elements :\+ each point index and each face description should be unique
\item not contain “internal” or “external” faces :\+ for each face, one side should be “inside” the cell, the other side “outside”
\end{DoxyItemize}

In a more global perspective, polyhedrons must be watertight and manifold. In particular, each edge of the polyhedron must be adjacent to exactly two faces. Several algorithms like contour, clip or slice will assume that each edge of the polyhedron is adjacent to exactly two faces and will definitely lead to bad results (and generate numerous warnings) if this criterion is not fulfilled.\hypertarget{classvtk_polyhedron_Limitations}{}\doxysubsection{\texorpdfstring{Limitations}{Limitations}}\label{classvtk_polyhedron_Limitations}
\doxylink{requirements_The}{The} class does not require the polyhedron to be convex. However, the support of concave polyhedrons is currently limited. Concavity can lead to bad results with some filters, including:\+
\begin{DoxyItemize}
\item Contour:\+ the contour (surface) can be constructed outside of the cell,
\item Triangulate:\+ the current tetrahedralization algorithm can modify the initial shape of the polygon (created tetrahedrons can change concave portions of the shape to convex ones).
\end{DoxyItemize}\hypertarget{classvtk_polyhedron_OtherDetails}{}\doxysubsection{\texorpdfstring{Other details}{Other details}}\label{classvtk_polyhedron_OtherDetails}
Interpolation functions and weights are defined /\+ computed using the method of Mean Value Coordinates (MVC). See the VTK class \doxylink{classvtk_mean_value_coordinates_interpolator}{vtk\+Mean\+Value\+Coordinates\+Interpolator} for more information.
