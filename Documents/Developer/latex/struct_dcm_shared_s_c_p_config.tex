\doxysubsection{Detailed Description}
Enables sharing configurations by multiple Dcm\+SCPs. \doxylink{struct_dcm_shared_s_c_p_config}{Dcm\+Shared\+SCPConfig} allows multiple \doxylink{class_dcm_s_c_p}{Dcm\+SCP} objects to share a single \doxylink{class_dcm_s_c_p_config}{Dcm\+SCPConfig} object as their configuration. \doxylink{struct_dcm_shared_s_c_p_config}{Dcm\+Shared\+SCPConfig} is implemented using reference counting, so the underlying \doxylink{class_dcm_s_c_p}{Dcm\+SCP} config object is destroyed only after the last reference to it is removed.
