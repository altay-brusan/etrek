\doxysubsection{Detailed Description}
abstract class to quickly locate points in 3-\/space 

\doxylink{classvtk_abstract_point_locator}{vtk\+Abstract\+Point\+Locator} is an abstract spatial search object to quickly locate points in 3D. \doxylink{classvtk_abstract_point_locator}{vtk\+Abstract\+Point\+Locator} works by dividing a specified region of space into "{}rectangular"{} buckets, and then keeping a list of points that lie in each bucket. Typical operation involves giving a position in 3D and finding the closest point. \doxylink{requirements_The}{The} points are provided from the specified dataset input.
