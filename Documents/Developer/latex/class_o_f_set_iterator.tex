\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T$>$\newline
class OFSet\+Iterator$<$ T $>$}
This template class represents an iterator class for corresponding set data structures in ofstd. Note the following properties of this class:\+
\begin{DoxyItemize}
\item even if the underlying set is unordered, it does have an internal order which can be used for iteration purposes
\item a reference to the set which shall be iterated over will be remembered inside an object of \doxylink{class_o_f_set_iterator}{OFSet\+Iterator$<$\+T$>$}; the set will NOT be copied
\item it is possible to iterate from beginning to end or from end to beginning of the underlying set using \doxylink{class_o_f_set_iterator_adc2f38d039685721a70f5a7140aedbd1}{Next()} or \doxylink{class_o_f_set_iterator_aa9c67c44b9458f2c4b4da68ce668131c}{Prev()} (see below)
\item if an element from the set is removed during the iteration, the iteration process has to be canceled and restarted
\item two OFSet\+Iterators can be compared through operators == and !=; two iterators are considered to be identical, if and only if they operate on the exact same set (identical memory addresses) and they currently refer to the same element 
\end{DoxyItemize}
