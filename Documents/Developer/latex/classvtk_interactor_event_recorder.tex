\doxysubsection{Detailed Description}
record and play VTK events passing through a \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} 

\doxylink{classvtk_interactor_event_recorder}{vtk\+Interactor\+Event\+Recorder} records all VTK events invoked from a \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor}. \doxylink{requirements_The}{The} events are recorded to a file. \doxylink{classvtk_interactor_event_recorder}{vtk\+Interactor\+Event\+Recorder} can also be used to play those events back and invoke them on an \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor}. (Note:\+ the events can also be played back from a file or string.)

Event client data can be recorded as args and will be provided on replay. \doxylink{requirements_The}{The} following event current support data to be recorded:\+
\begin{DoxyItemize}
\item Drop\+Files\+Events:\+ record a string array
\end{DoxyItemize}

\doxylink{requirements_The}{The} format of the event file is simple. It is:\+ Event\+Name X Y ctrl shift keycode repeat\+Count key\+Sym data\+Type \+[data\+Num]\+ \+[data\+Val]\+ \+[data\+Val]\+ \doxylink{requirements_The}{The} format also allows "{}\+\#"{} comments. data\+Type is defined as follows:\+
\begin{DoxyItemize}
\item 0 -\/\texorpdfstring{$>$}{>} None
\item 1 -\/\texorpdfstring{$>$}{>} String\+Array
\end{DoxyItemize}
