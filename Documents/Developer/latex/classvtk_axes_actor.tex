\doxysubsection{Detailed Description}
a 3D axes representation 

\doxylink{classvtk_axes_actor}{vtk\+Axes\+Actor} is a hybrid 2D/\+3D actor used to represent 3D axes in a scene. \doxylink{requirements_The}{The} user can define the geometry to use for the shaft or the tip, and the user can set the text for the three axes. \doxylink{requirements_The}{The} text will appear to follow the camera since it is implemented by means of \doxylink{classvtk_caption_actor2_d}{vtk\+Caption\+Actor2D}. All of the functionality of the underlying \doxylink{classvtk_caption_actor2_d}{vtk\+Caption\+Actor2D} objects are accessible so that, for instance, the font attributes of the axes text can be manipulated through \doxylink{classvtk_text_property}{vtk\+Text\+Property}. Since this class inherits from \doxylink{classvtk_prop3_d}{vtk\+Prop3D}, one can apply a user transform to the underlying geometry and the positioning of the labels. For example, a rotation transform could be used to generate a left-\/handed axes representation.

\begin{DoxyParagraph}{Thanks:\+}
Thanks to Goodwin Lawlor for posting a tcl script which featured the use of \doxylink{classvtk_caption_actor2_d}{vtk\+Caption\+Actor2D} to implement the text labels. This class is based on Paraview\textquotesingle{}s vtk\+PVAxes\+Actor.
\end{DoxyParagraph}
\begin{DoxyWarning}{Warning}
\doxylink{classvtk_axes_actor}{vtk\+Axes\+Actor} is primarily intended for use with \doxylink{classvtk_orientation_marker_widget}{vtk\+Orientation\+Marker\+Widget}. \doxylink{requirements_The}{The} bounds of this actor are calculated as though the geometry of the axes were symmetric:\+ that is, although only positive axes are visible, bounds are calculated as though negative axes are present too. This is done intentionally to implement functionality of the camera update mechanism in \doxylink{classvtk_orientation_marker_widget}{vtk\+Orientation\+Marker\+Widget}.
