\doxysubsection{Detailed Description}
bin source cell data into input cells. 

\doxylink{classvtk_bin_cell_data_filter}{vtk\+Bin\+Cell\+Data\+Filter} takes a source mesh containing scalar cell data, an input mesh and a set of bin values and bins the source mesh\textquotesingle{}s scalar cell data into the cells of the input mesh. \doxylink{requirements_The}{The} resulting output mesh is identical to the input mesh, with an additional cell data field, with tuple size equal to the number of bins + 1, that represents a histogram of the cell data values for all of the source cells whose centroid lie within the input cell.

This filter is useful for analyzing the efficacy of an input mesh\textquotesingle{}s ability to represent the cell data of the source mesh.
