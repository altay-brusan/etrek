\doxysubsection{Detailed Description}
a representation for a \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2} which reslices a volume 

This class is a specialization of the \doxylink{classvtk_implicit_plane_representation}{vtk\+Implicit\+Plane\+Representation}. It is specialized to resample volumes across a plane. It is similar to \doxylink{classvtk_image_plane_widget}{vtk\+Image\+Plane\+Widget}, except the combination of \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2} and \doxylink{classvtk_implicit_image_representation}{vtk\+Implicit\+Image\+Representation} is a second generation widget design, with a much simpler and intuitive plane manipulation.

See the documentation for \doxylink{classvtk_implicit_plane_widget2}{vtk\+Implicit\+Plane\+Widget2} and \doxylink{classvtk_implicit_plane_representation}{vtk\+Implicit\+Plane\+Representation} for usage information. One notable difference is that the methods \doxylink{classvtk_implicit_image_representation_ae977b2c00793bd6ee02c08e8504800f0}{Place\+Image()} are preferred to the superclasses\textquotesingle{} Place\+Widget() method.
