class Eigen::\+\+SPQR$<$ \+\_\+\+Matrix\+Type $>$}
\doxylink{struct_eigen_1_1_sparse}{Sparse} QR factorization based on Suite\+Sparse\+QR library. 

This class is used to perform a multithreaded and multifrontal rank-\/revealing QR decomposition of sparse matrices. \doxylink{requirements_The}{The} result is then used to solve linear leasts\+\_\+square systems. Clearly, a QR factorization is returned such that A\texorpdfstring{$\ast$}{*}P = Q\texorpdfstring{$\ast$}{*}R where :\+

P is the column permutation. Use \doxylink{class_eigen_1_1_s_p_q_r_ab1b7f54ba1cd8d77506ae676fea4fec0}{cols\+Permutation()} to get it.

Q is the orthogonal matrix represented as Householder reflectors. Use \doxylink{class_eigen_1_1_s_p_q_r_ab1e43f45b2b92623725b572793873f13}{matrix\+Q()} to get an expression and \doxylink{class_eigen_1_1_s_p_q_r_ab1e43f45b2b92623725b572793873f13}{matrix\+Q()}.transpose() to get the transpose. You can then apply it to a vector.

R is the sparse triangular factor. Use matrix\+QR() to get it as \doxylink{class_eigen_1_1_sparse_matrix}{Sparse\+Matrix}. NOTE :\+ \doxylink{requirements_The}{The} \doxylink{namespace_eigen_a62e77e0933482dafde8fe197d9a2cfde}{Index} type of R is always Suite\+Sparse\+\_\+long. You can get it with SPQR::\+\+Index
