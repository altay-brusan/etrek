\doxysubsection{Detailed Description}
Factory for creating application-\/specific loggers. 

\doxylink{class_etrek_1_1_core_1_1_repository_1_1_app_logger_factory}{App\+Logger\+Factory} encapsulates the creation logic for \doxylink{class_etrek_1_1_core_1_1_log_1_1_app_logger}{App\+Logger} instances. It allows services and components to obtain loggers with consistent configuration and dependency injection of the underlying \doxylink{class_etrek_1_1_core_1_1_repository_1_1_logger_provider}{Logger\+Provider}.

\doxylink{requirements_The}{The} factory pattern is used to decouple logger creation from usage, enabling future extension (e.\+g., different logger types or providers).
