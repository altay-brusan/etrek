\doxysubsection{Detailed Description}
outline of volume cropping region 

\doxylink{classvtk_volume_outline_source}{vtk\+Volume\+Outline\+Source} generates a wireframe outline that corresponds to the cropping region of a \doxylink{classvtk_volume_mapper}{vtk\+Volume\+Mapper}. It requires a \doxylink{classvtk_volume_mapper}{vtk\+Volume\+Mapper} as input. \doxylink{requirements_The}{The} Generate\+Faces option turns on the solid faces of the outline, and the Generate\+Scalars option generates color scalars. When Generate\+Scalars is on, it is possible to set an "{}\+Active\+Plane\+Id"{} value in the range \+[0..6]\+ to highlight one of the six cropping planes. \begin{DoxyParagraph}{Thanks:\+}
Thanks to David Gobbi for contributing this class to VTK. 
\end{DoxyParagraph}
