\doxysubsection{Detailed Description}
Point\+Placer to constrain validity within a set of convex planes. 

This placer takes a set of bounding planes and constraints the validity within the supplied convex planes. It is used by the Parallelop\+Piped\+Representation to place constraints on the motion the handles within the parallelopiped.
