\doxysubsection{Detailed Description}
map cell data to point data 

\doxylink{classvtk_cell_data_to_point_data}{vtk\+Cell\+Data\+To\+Point\+Data} is a filter that transforms cell data (i.\+e., data specified per cell) into point data (i.\+e., data specified at cell points). \doxylink{requirements_The}{The} method of transformation is based on averaging the data values of all cells using each point. For large datasets with several cell data arrays, the filter optionally supports selective processing to speed up processing. Optionally, the input cell data can be passed through to the output as well.

Options exist to control which cells are used to perform the averaging operation. Since unstructured grids and polydata can contain cells of different dimensions, in some cases it is desirable to perform cell averaging using cells of a specified dimension. \doxylink{requirements_The}{The} available options to control this functionality are All (default), Patch and Data\+Set\+Max. Patch uses only the highest dimension cells attached to a point. Data\+Set\+Max uses the highest cell dimension in the entire data set.

\begin{DoxyWarning}{Warning}
This filter is an abstract filter, that is, the output is an abstract type (i.\+e., \doxylink{classvtk_data_set}{vtk\+Data\+Set}). Use the convenience methods (e.\+g., \doxylink{classvtk_data_set_algorithm_ab3ab740d5e49866c2bd56a64bb270cb6}{Get\+Poly\+Data\+Output()}, \doxylink{classvtk_data_set_algorithm_afc49e270e1a8056d6abccc37a7e45559}{Get\+Structured\+Points\+Output()}, etc.) to get the type of output you want.

For maximum performance, use the Contributing\+Cell\+Option=All. Other options significantly, negatively impact performance (on the order of \texorpdfstring{$>$}{>}10x).

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential execution type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.
\end{DoxyWarning}
