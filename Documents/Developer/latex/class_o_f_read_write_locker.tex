\doxysubsection{Detailed Description}
This class aims to provide an easy way for making sure OFRead\+Write\+Locks are unlocked in an exception safe way. You can just create a local instance of this class and lock the \doxylink{class_o_f_read_write_lock}{OFRead\+Write\+Lock} through it. When it is destructed it will make sure that the lock is unlocked if necessary.
