\doxysubsection{Detailed Description}
Tool for measuring angles on images. 

Interaction:\+
\begin{DoxyItemize}
\item Click to place first point (arm 1 endpoint)
\item Click to place vertex (middle point where angle is measured)
\item Click to place third point (arm 2 endpoint) to complete
\item Click on an angle to select it
\item Drag handles to resize existing angles
\item Press Delete to remove selected angle 
\end{DoxyItemize}
