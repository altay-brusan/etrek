\doxysubsection{Detailed Description}
Display an image along with a reslice cursor. 

This class is similar to \doxylink{classvtk_image_viewer2}{vtk\+Image\+Viewer2}. It displays the image along with a two cross hairs for reslicing. \doxylink{requirements_The}{The} cross hairs may be interactively manipulated and are typically used to reslice two other views of \doxylink{classvtk_reslice_image_viewer}{vtk\+Reslice\+Image\+Viewer}. See Qt\+VTKRender\+Windows for an example. \doxylink{requirements_The}{The} reslice cursor is used to perform thin or thick MPR through data. \doxylink{requirements_The}{The} class can also default to the behaviour of \doxylink{classvtk_image_viewer2}{vtk\+Image\+Viewer2} if the Reslice mode is set to RESLICE\+\_\+\+AXIS\+\_\+\+ALIGNED. \begin{DoxySeeAlso}{See also}
