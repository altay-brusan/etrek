\doxysubsection{Detailed Description}
Interface for the centralized context management service. 

\doxylink{requirements_The}{The} Context\+Manager is responsible for:\+
\begin{DoxyItemize}
\item Maintaining session context (user, sign-\/in time, workstation, institution)
\item Maintaining workflow contexts (e.\+g., current examination context)
\item Providing access to contexts for consumers (delegates, services)
\end{DoxyItemize}

Contexts are accessed through this interface to avoid tight coupling between producers and consumers. Builders fetch contexts from the Context\+Manager and inject them into delegates via \doxylink{struct_delegate_parameter}{Delegate\+Parameter}.

Usage:\+
\begin{DoxyItemize}
\item Producers call \doxylink{class_etrek_1_1_context_1_1_i_context_manager_a7e0897da1621d008e26f57e5c07bbbba}{set\+Session\+Context()} or \doxylink{class_etrek_1_1_context_1_1_i_context_manager_a62c62e7f6b206e52c5822c924bbd9800}{set\+Workflow\+Context()} to register context
\item Consumers receive context via \doxylink{struct_delegate_parameter}{Delegate\+Parameter} injection from builders
\item Direct access via get\+Session\+Context() or get\+Workflow\+Context() is also available 
\end{DoxyItemize}
