\doxysubsection{Detailed Description}
This class represents an axis-\/aligned Binary Spatial Partitioning of a 3D space. 

This class converts between the \doxylink{classvtk_kd_tree}{vtk\+Kd\+Tree} representation of a tree of vtk\+Kd\+Nodes (used by \doxylink{classvtk_distributed_data_filter}{vtk\+Distributed\+Data\+Filter}) and a compact array representation that might be provided by a graph partitioning library like Zoltan. Such a representation could be used in message passing.
