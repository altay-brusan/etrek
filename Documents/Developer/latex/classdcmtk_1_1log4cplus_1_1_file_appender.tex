\doxysubsection{Detailed Description}
Appends log events to a file.

\doxysubsubsubsection*{Properties}


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\ttfamily File} }}]\hfill \\
This property specifies output file name.


\item[{\parbox[t]{\linewidth}{{\ttfamily Immediate\+Flush} }}]\hfill \\
When it is set true, output stream will be flushed after each appended event.


\item[{\parbox[t]{\linewidth}{{\ttfamily Append} }}]\hfill \\
When it is set true, output file will be appended to instead of being truncated at opening.


\item[{\parbox[t]{\linewidth}{{\ttfamily Reopen\+Delay} }}]\hfill \\
This property sets a delay after which the appender will try to reopen log file again, after last logging failure. 


\item[{\parbox[t]{\linewidth}{{\ttfamily Buffer\+Size} }}]\hfill \\
Non-\/zero value of this property sets up buffering of output stream using a buffer of given size. 


\item[{\parbox[t]{\linewidth}{{\ttfamily Use\+Lock\+File} }}]\hfill \\
Set this property to {\ttfamily true} if you want your output to go into a log file shared by multiple processes. When this property is set to true then log4cplus uses OS specific facilities (e.\+g., {\ttfamily lockf()}) to provide inter-\/process file locking. \begin{DoxySeeAlso}{See also}
\doxylink{classdcmtk_1_1log4cplus_1_1_appender}{Appender} 
\end{DoxySeeAlso}

\item[{\parbox[t]{\linewidth}{{\ttfamily Lock\+File} }}]\hfill \\
This property specifies lock file, file used for inter-\/process synchronization of log file access. When this property is not specified, the value is derived from {\ttfamily File} property by addition of "{}.\+lock"{} suffix. \doxylink{requirements_The}{The} property is only used when {\ttfamily Use\+Lock\+File} is set to true. \begin{DoxySeeAlso}{See also}
\doxylink{classdcmtk_1_1log4cplus_1_1_appender}{Appender} 
\end{DoxySeeAlso}

\item[{\parbox[t]{\linewidth}{{\ttfamily Locale} }}]\hfill \\
This property specifies a locale name that will be imbued into output stream. Locale can be specified either by system specific locale name, e.\+g., {\ttfamily en\+\_\+\+US.\+UTF-\/8}, or by one of four recognized keywords:\+ {\ttfamily GLOBAL}, {\ttfamily DEFAULT} (which is an alias for {\ttfamily GLOBAL}), {\ttfamily USER} and {\ttfamily CLASSIC}. When specified locale is not available, {\ttfamily GLOBAL} is used instead. It is possible to register additional locale keywords by registering an instance of {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1spi_1_1_locale_factory}{spi::\+\+Locale\+Factory}} in {\ttfamily spi::\+\+Locale\+Factory\+Registry}. \begin{DoxySeeAlso}{See also}

\end{DoxySeeAlso}

\doxysubsubsection{\texorpdfstring{immediateFlush}{immediateFlush}}
{\footnotesize\ttfamily \label{classdcmtk_1_1log4cplus_1_1_file_appender_a957b27fe0307b9766715e9e23072a385} 
bool dcmtk::\+log4cplus::\+\+File\+Appender::\+immediate\+Flush\hspace{0.3cm}{\ttfamily [protected]}}

Immediate flush means that the underlying writer or output stream will be flushed at the end of each append operation. Immediate flush is slower but ensures that each append request is actually written. If {\ttfamily immediate\+Flush} is set to {\ttfamily false}, then there is a good chance that the last few logs events are not actually written to persistent media if and when the application crashes.

int dcmtk::\+log4cplus::\+\+File\+Appender::\+reopen\+Delay\hspace{0.3cm}{\ttfamily [protected]}}

When any append operation fails, {\ttfamily reopen\+Delay} says for how many seconds the next attempt to re-\/open the log file and resume logging will be delayed. If {\ttfamily reopen\+Delay} is zero, each failed append operation will cause log file to be re-\/opened. By default, {\ttfamily reopen\+Delay} is 1 second.
