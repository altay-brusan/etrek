\doxylink{classvtk_single_v_t_p_exporter}{vtk\+Single\+VTPExporter} is a concrete subclass of \doxylink{classvtk_exporter}{vtk\+Exporter} that writes a .vtp file and a .png file containing the polydata and texture elements of the scene.

If Active\+Renderer is specified then it exports contents of Active\+Renderer. Otherwise it exports contents of all renderers.
