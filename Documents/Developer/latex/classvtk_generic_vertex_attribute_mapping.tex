\doxysubsection{Detailed Description}
stores mapping for data arrays to generic vertex attributes. 

\doxylink{classvtk_generic_vertex_attribute_mapping}{vtk\+Generic\+Vertex\+Attribute\+Mapping} stores mapping between data arrays and generic vertex attributes. It is used by vtk\+Painter\+Poly\+Data\+Mapper to pass the mappings to the painter which rendering the attributes. \begin{DoxyParagraph}{Thanks:\+}
Support for generic vertex attributes in VTK was contributed in collaboration with Stephane Ploix at EDF. 
\end{DoxyParagraph}
