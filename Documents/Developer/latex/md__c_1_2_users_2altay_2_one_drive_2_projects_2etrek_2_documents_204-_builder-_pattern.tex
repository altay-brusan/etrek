{\bfseries{Key Design Decisions}}:\+


\begin{DoxyEnumerate}
\item {\bfseries{Template-\/based}}:\+ Type safety and flexibility
\item {\bfseries{Returns {\ttfamily std::\+pair}}}:\+ Both widget and delegate in single call
\item {\bfseries{Raw pointers}}:\+ Leverage Qt\textquotesingle{}s parent-\/child lifetime management
\item {\bfseries{\doxylink{struct_delegate_parameter}{Delegate\+Parameter}}}:\+ Centralized dependency injection container

{\bfseries{Architectural Pattern}}:\+


\begin{DoxyItemize}
\item {\bfseries{\doxylink{struct_delegate_parameter}{Delegate\+Parameter} contains ONLY {\ttfamily db\+Connection}}}, NOT repositories
\item Builders receive {\ttfamily \doxylink{struct_delegate_parameter}{Delegate\+Parameter}} and create repositories from {\ttfamily db\+Connection}
\item Builders pass repository instances to delegates
\item Delegates NEVER receive {\ttfamily db\+Connection}, only repositories
\item Each builder independently creates its required repositories

\doxylink{requirements_The}{The} Builder pattern in Etrek provides:\+


\begin{DoxyEnumerate}
\item {\bfseries{Template-\/based standardization}}:\+ All builders follow {\ttfamily \doxylink{class_i_widget_delegate_builder}{IWidget\+Delegate\+Builder}\texorpdfstring{$<$}{<}Widget, Delegate\texorpdfstring{$>$}{>}}
\item {\bfseries{Centralized dependency injection}}:\+ {\ttfamily \doxylink{struct_delegate_parameter}{Delegate\+Parameter}} carries all dependencies
\item {\bfseries{Repository creation responsibility}}:\+ Builders create repositories, delegates receive them
\item {\bfseries{Lazy construction}}:\+ Components built on-\/demand, not at startup
\item {\bfseries{Hierarchical composition}}:\+ Parent builders orchestrate child builders (System\+Setting\+Page\+Builder)
\item {\bfseries{Qt integration}}:\+ Leverages parent-\/child ownership for automatic memory management
\item {\bfseries{Stateless builders}}:\+ No builder state, can be instantiated per-\/use
\item {\bfseries{17 builder classes}}:\+ Across Application, Device, Worklist, PACS, Scan\+Protocol, and Dicom modules
\end{DoxyEnumerate}

This architecture enables:\+


\begin{DoxyItemize}
\item {\bfseries{Testability}}:\+ Mock repositories can be injected
\item {\bfseries{Maintainability}}:\+ Clear construction logic separate from runtime behavior
\item {\bfseries{Scalability}}:\+ New builders easily added following established pattern
\item {\bfseries{Performance}}:\+ Lazy loading reduces startup time and memory usage
\item {\bfseries{Type safety}}:\+ Template-\/based approach catches errors at compile time
\end{DoxyItemize}
