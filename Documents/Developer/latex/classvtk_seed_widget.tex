\doxysubsection{Detailed Description}
place multiple seed points 

\doxylink{requirements_The}{The} \doxylink{classvtk_seed_widget}{vtk\+Seed\+Widget} is used to placed multiple seed points in the scene. \doxylink{requirements_The}{The} seed points can be used for operations like connectivity, segmentation, and region growing.

To use this widget, specify an instance of \doxylink{classvtk_seed_widget}{vtk\+Seed\+Widget} and a representation (a subclass of \doxylink{classvtk_seed_representation}{vtk\+Seed\+Representation}). \doxylink{requirements_The}{The} widget is implemented using multiple instances of \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget} which can be used to position the seed points (after they are initially placed). \doxylink{requirements_The}{The} representations for these handle widgets are provided by the \doxylink{classvtk_seed_representation}{vtk\+Seed\+Representation}.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
  LeftButtonPressEvent -\/ add a point or select a handle (i.e., seed)
  RightButtonPressEvent -\/ finish adding the seeds
  MouseMoveEvent -\/ move a handle (i.e., seed)
  LeftButtonReleaseEvent -\/ release the selected handle (seed)
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_seed_widget}{vtk\+Seed\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::AddPoint -\/-\/ add one point; depending on the state
                              it may the first or second point added. Or,
                              if near handle, select handle.
  vtkWidgetEvent::Completed -\/-\/ finished adding seeds.
  vtkWidgetEvent::Move -\/-\/ move the second point or handle depending on the state.
  vtkWidgetEvent::EndSelect -\/-\/ the handle manipulation process has completed.
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
This widget invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (beginning to interact)
  vtkCommand::EndInteractionEvent (completing interaction)
  vtkCommand::InteractionEvent (moving after selecting something)
  vtkCommand::PlacePointEvent (after point is positioned;
                               call data includes handle id (0,1))
  vtkCommand::DeletePointEvent (before point is deleted;
                               call data includes handle id (0,1))
\end{DoxyPre}

\end{DoxyParagraph}
