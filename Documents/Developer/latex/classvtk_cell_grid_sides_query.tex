\doxysubsection{Detailed Description}
A cell-\/grid query for enumerating sides of cells. 

This query runs in 3 passes (see \doxylink{classvtk_cell_grid_sides_query_a0b0157058683918a2a9427ea0a0a6e97}{vtk\+Cell\+Grid\+Sides\+Query::\+\+Pass\+Work}):\+


\begin{DoxyItemize}
\item In the first pass, responders invoke the Add\+Sides() method on this query, entries are added to this-\/\texorpdfstring{$>$}{>}Hashes storage indicating the cells which are bounded by a given shape + connectivity.
\item In the second pass, responders mark the entries created above and add entries in this-\/\texorpdfstring{$>$}{>}Sides. This reorganizes the hashes into groups more amenable to output as side arrays. This pass is called "{}\+Summarization,"{} since not every input side identified will be output.
\item In the third and final pass, responders create new cells in the output cell-\/grid that correspond to the selected sides of the input. 
\end{DoxyItemize}
