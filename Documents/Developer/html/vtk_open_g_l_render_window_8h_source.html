540 // the GPU with `glReadPixels`.
541 // This method reads the depth buffer bits.
542 // The depth attachment size can be 8,16,24 or 32. The values are split into 4 8-bit numbers.
543 // These are stored in the form of an RGBA color attachment in DepthFrameBuffer.
544 // `glReadPixels` can read that RGBA format and reconstruct full 8,16,24 or 32-bit integer
