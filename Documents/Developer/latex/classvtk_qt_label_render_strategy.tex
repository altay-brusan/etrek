\doxysubsection{Detailed Description}
Renders labels with Qt. 

This class uses Qt to render labels and compute sizes. \doxylink{requirements_The}{The} labels are rendered to a QImage, then \doxylink{classvtk_qt_label_render_strategy_a2a29393ffc499889f14edfa48c2096a0}{End\+Frame()} converts that image to a \doxylink{classvtk_image_data}{vtk\+Image\+Data} and textures the image onto a quad spanning the render area.
