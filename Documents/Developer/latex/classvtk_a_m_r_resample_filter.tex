\doxysubsection{Detailed Description}
This filter is a concrete instance of \doxylink{classvtk_multi_block_data_set_algorithm}{vtk\+Multi\+Block\+Data\+Set\+Algorithm} and provides functionality for extracting portion of the AMR dataset, specified by a bounding box, in a uniform grid of the desired level of resolution. \doxylink{requirements_The}{The} resulting uniform grid is stored in a \doxylink{classvtk_multi_block_data_set}{vtk\+Multi\+Block\+Data\+Set} where the number of blocks correspond to the number of processors utilized for the operation.

\begin{DoxyWarning}{Warning}
Data of the input AMR dataset is assumed to be cell-\/centered.
\end{DoxyWarning}
