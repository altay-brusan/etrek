\doxysubsection{Detailed Description}
Theora bitstream information. This contains the basic playback parameters for a stream, and corresponds to the initial \textquotesingle{}info\textquotesingle{} header packet. To initialize an encoder, the application fills in this structure and passes it to th\+\_\+encode\+\_\+alloc(). A default encoding mode is chosen based on the values of the \doxylink{structth__info_aa4cdcf96cb46b256821993e9a830ee02}{quality} and \doxylink{structth__info_a1d9c8d768a4ae623269f5bd8f6f7a015}{target\+\_\+bitrate} fields. On decode, it is filled in by th\+\_\+decode\+\_\+headerin(), and then passed to th\+\_\+decode\+\_\+alloc().

Encoded Theora frames must be a multiple of 16 in size; this is what the \doxylink{structth__info_a6b8087a4d831da53011a43b8d74087a0}{frame\+\_\+width} and \doxylink{structth__info_a6b1adc3a16a8336a72692b0a5937214c}{frame\+\_\+height} members represent. To handle arbitrary picture sizes, a crop rectangle is specified in the \doxylink{structth__info_a5b3f834bcf141564e7bb14f49101870f}{pic\+\_\+x}, \doxylink{structth__info_a8aacc575cab2dfe3735001c2ad32aa14}{pic\+\_\+y}, \doxylink{structth__info_a5048edf77b141dd3e9a92ca85e317345}{pic\+\_\+width} and \doxylink{structth__info_a775178474283c5990ba73f9ba7f6b88b}{pic\+\_\+height} members.

All frame buffers contain pointers to the full, padded frame. However, the current encoder {\itshape will not} reference pixels outside of the cropped picture region, and the application does not need to fill them in. \doxylink{requirements_The}{The} decoder {\itshape will} allocate storage for a full frame, but the application {\itshape should not} rely on the padding containing sensible data.

It is also generally recommended that the offsets and sizes should still be multiples of 2 to avoid chroma sampling shifts when chroma is sub-\/sampled. See \href{http://www.theora.org/doc/Theora.pdf}{\texttt{the Theora specification}}, Section 4.\+4, for more details.

Frame rate, in frames per second, is stored as a rational fraction, as is the pixel aspect ratio. Note that this refers to the aspect ratio of the individual pixels, not of the overall frame itself. \doxylink{requirements_The}{The} frame aspect ratio can be computed from pixel aspect ratio using the image dimensions.
