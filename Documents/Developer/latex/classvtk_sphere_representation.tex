\doxysubsection{Detailed Description}
a class defining the representation for the \doxylink{classvtk_sphere_widget2}{vtk\+Sphere\+Widget2} 

This class is a concrete representation for the \doxylink{classvtk_sphere_widget2}{vtk\+Sphere\+Widget2}. It represents a sphere with an optional handle. Through interaction with the widget, the sphere can be arbitrarily positioned and scaled in 3D space; and the handle can be moved on the surface of the sphere. Typically the vtk\+Sphere\+Widget2/\+vtk\+Sphere\+Representation are used to position a sphere for the purpose of extracting, cutting or clipping data; or the handle is moved on the sphere to position a light or camera.

To use this representation, you normally use the \doxylink{classvtk_sphere_representation_aada4afa3f1666f2e9e600592b5c27c1a}{Place\+Widget()} method to position the widget at a specified region in space. It is also possible to set the center of the sphere, a radius, and/\+or a handle position.

\begin{DoxyWarning}{Warning}
Note that the representation is overconstrained in that the center and radius of the sphere can be defined, this information plus the handle direction defines the geometry of the representation. Alternatively, the user may specify the center of the sphere plus the handle position.

This class, and \doxylink{classvtk_sphere_widget2}{vtk\+Sphere\+Widget2}, are second generation VTK widgets. An earlier version of this functionality was defined in the class \doxylink{classvtk_sphere_widget}{vtk\+Sphere\+Widget}.
\end{DoxyWarning}
