\subsubsection*{template$<$typename Matrix\+Type$>$\newline
class Eigen::\+\+Pardiso\+LU$<$ Matrix\+Type $>$}
A sparse direct LU factorization and solver based on the PARDISO library. 

This class allows to solve for A.\+X = B sparse linear problems via a direct LU factorization using the Intel MKL PARDISO library. \doxylink{requirements_The}{The} sparse matrix A must be squared and invertible. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.
