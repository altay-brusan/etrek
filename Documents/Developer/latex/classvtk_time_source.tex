\doxysubsection{Detailed Description}
creates a simple time varying data set. 

Creates a small easily understood time varying data set for testing. \doxylink{requirements_The}{The} output is a vtk\+Untructured\+Grid in which the point and cell values vary over time in a sin wave. \doxylink{requirements_The}{The} analytic ivar controls whether the output corresponds to a step function over time or is continuous. \doxylink{requirements_The}{The} X and Y Amplitude ivars make the output move in the X and Y directions over time. \doxylink{requirements_The}{The} Growing ivar makes the number of cells in the output grow and then shrink over time.
