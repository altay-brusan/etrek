\doxysubsection{Detailed Description}
A reader for MINC files. 

MINC is a Net\+CDF-\/based medical image file format that was developed at the Montreal Neurological Institute in 1992. This class will read a MINC file into VTK, rearranging the data to match the VTK x, y, and z dimensions, and optionally rescaling real-\/valued data to VTK\+\_\+\+FLOAT if Rescale\+Real\+Values\+On() is set. If Rescale\+Real\+Values is off, then the data will be stored in its original data type and the \doxylink{classvtk_m_i_n_c_image_reader_a48adf79a5802e839a4209d55b8262f3a}{Get\+Rescale\+Slope()}, Get\+Rescale\+Intercept() method can be used to retrieve global rescaling parameters. If the original file had a time dimension, the Set\+Time\+Step() method can be used to specify a time step to read. All of the original header information can be accessed though the \doxylink{classvtk_m_i_n_c_image_reader_a39a7348b6ac0b56efdcc831dba4eb622}{Get\+Image\+Attributes()} method. \begin{DoxySeeAlso}{See also}
