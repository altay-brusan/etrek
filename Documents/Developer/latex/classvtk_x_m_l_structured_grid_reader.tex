\doxysubsection{Detailed Description}
Read VTK XML Structured\+Grid files. 

\doxylink{classvtk_x_m_l_structured_grid_reader}{vtk\+XMLStructured\+Grid\+Reader} reads the VTK XML Structured\+Grid file format. One structured grid file can be read to produce one output. Streaming is supported. \doxylink{requirements_The}{The} standard extension for this reader\textquotesingle{}s file format is "{}vts"{}. This reader is also used to read a single piece of the parallel file format.
