\doxysubsection{Detailed Description}
TTCC layout format consists of time, thread, \doxylink{classdcmtk_1_1log4cplus_1_1_logger}{Logger} and nested diagnostic context information, hence the name.

\doxylink{requirements_The}{The} time format depends on the {\ttfamily Date\+Format} used. Use the {\ttfamily Use\+\_\+gmtime} to specify whether messages should be logged using {\ttfamily localtime} or {\ttfamily gmtime}.

\doxylink{requirements_The}{The} first field is the number of milliseconds elapsed since the start of the program. \doxylink{requirements_The}{The} second field is the thread outputting the log statement. \doxylink{requirements_The}{The} third field is the \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level}, the fourth field is the logger to which the statement belongs.

\doxylink{requirements_The}{The} fifth field (just before the \textquotesingle{}-\/\textquotesingle{}) is the nested diagnostic context. Note the nested diagnostic context may be empty as in the first two statements. \doxylink{requirements_The}{The} text after the \textquotesingle{}-\/\textquotesingle{} is the message of the statement.
