\doxysubsection{Detailed Description}
DCMTK-\/based DICOM file parser for extracting metadata and pixel data. 

Features:\+
\begin{DoxyItemize}
\item Parse DICOM files from disk or memory
\item Extract comprehensive metadata (patient, study, series, image)
\item Extract pixel data as raw bytes
\item Auto-\/detect bit depth, signed/\+unsigned
\item Handle various transfer syntaxes 
\end{DoxyItemize}
