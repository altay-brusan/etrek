\doxysubsection{Detailed Description}
Represents a world axis-\/aligned bounding-\/box containing a set of volumes in a rendered scene. 

\doxylink{classvtk_volume}{vtk\+Volume} instances registered in this class can be overlapping. They are intended to be all rendered simultaneously by a \doxylink{classvtk_g_p_u_volume_ray_cast_mapper}{vtk\+GPUVolume\+Ray\+Cast\+Mapper} (inputs should be set directly in the mapper).

This class holds the full transformation of a bounding-\/box containing all of the registered volumes. \begin{DoxyVerb} + TexToBBox : Texture-to-Data (scaling)
 + Matrix : Data-to-World (translation)
\end{DoxyVerb}


\begin{DoxyNote}{Note}
This class is intended to be used only by mappers supporting multiple inputs.
\end{DoxyNote}
