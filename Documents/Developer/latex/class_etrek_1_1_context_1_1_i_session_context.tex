\doxysubsection{Detailed Description}
Interface for session/\+user context information. 

Provides access to information about the current user session including:\+
\begin{DoxyItemize}
\item Logged-\/in user details
\item Sign-\/in timestamp
\item Workstation information
\item Institution/\+health center details
\end{DoxyItemize}

This context is typically created after successful authentication and remains valid for the duration of the user\textquotesingle{}s session.
