An octree cursor. 

Unlike an iterator, an octree cursor does not provide an order in which to traverse nodes. Instead, it provides 2 primitive operations:\+ up() and down() that can be used to traverse the tree in any order. There are also some utility routines named over(), axis\+\_\+partner(), and neighbor() that call up() followed by down() with specific arguments to help traverse nodes that are children of the same parent.

A cursor contains no storage beyond its base class, \doxylink{classoctree__path}{octree\+\_\+path}, so you may assign to a cursor from any descendant of \doxylink{classoctree__path}{octree\+\_\+path} including \doxylink{classoctree__iterator}{octree\+\_\+iterator}.
