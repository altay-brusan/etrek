\doxysubsection{Detailed Description}
extract points inside of a closed polygonal surface 

\doxylink{classvtk_extract_enclosed_points}{vtk\+Extract\+Enclosed\+Points} is a filter that evaluates all the input points to determine whether they are contained within an enclosing surface. Those within the surface are sent to the output. \doxylink{requirements_The}{The} enclosing surface is specified through a second input to the filter.

Note:\+ as a derived class of \doxylink{classvtk_point_cloud_filter}{vtk\+Point\+Cloud\+Filter}, additional methods are available for generating an in/\+out mask, and also extracting points outside of the enclosing surface.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} filter assumes that the surface is closed and manifold. A boolean flag can be set to force the filter to first check whether this is true. If false, all points will be marked outside. Note that if this check is not performed and the surface is not closed, the results are undefined.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.

\doxylink{requirements_The}{The} filter \doxylink{classvtk_select_enclosed_points}{vtk\+Select\+Enclosed\+Points} marks points as to in/\+out of the enclosing surface, and operates on any dataset type, producing an output dataset of the same type as the input. Then, thresholding and masking filters can be used to extract parts of the dataset. This filter (\doxylink{classvtk_extract_enclosed_points}{vtk\+Extract\+Enclosed\+Points}) is meant to operate on point clouds represented by \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}, and produces \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} on output, so it is more efficient for point processing. Note that this filter delegates many of its methods to \doxylink{classvtk_select_enclosed_points}{vtk\+Select\+Enclosed\+Points}.
\end{DoxyWarning}
