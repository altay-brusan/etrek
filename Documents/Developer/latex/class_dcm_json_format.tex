\doxysubsection{Detailed Description}
Class for handling JSON format options. Base class to implement custom formatting. Purpose:\+
\begin{DoxyItemize}
\item individual output formatting
\item normalization of Decimal\+String and Integer\+String e.\+g. normalization of leading zeros
\item escaping of special JSON control characters
\item outputting the correct indention and symbols for "{}\+Value"{}, "{}\+Bulk\+Data\+URI"{}, etc.
\end{DoxyItemize}
