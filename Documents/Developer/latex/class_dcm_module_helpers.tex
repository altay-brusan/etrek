\doxysubsection{Detailed Description}
This class contains helper functions that permit copying common modules from DICOM standard part 3 between DICOM datasets. \begin{DoxyNote}{Note}
\doxylink{requirements_The}{The} attribute lists per module are taken from the final text version of DICOM 2013. 
\end{DoxyNote}
