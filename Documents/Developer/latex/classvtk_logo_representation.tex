\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_logo_widget}{vtk\+Logo\+Widget} 

This class provides support for interactively positioning a logo. A logo is defined by an instance of vtk\+Image. \doxylink{requirements_The}{The} properties of the image, including transparency, can be set with an instance of \doxylink{classvtk_property2_d}{vtk\+Property2D}. To position the logo, use the superclass\textquotesingle{}s Position and Position2 coordinates.
