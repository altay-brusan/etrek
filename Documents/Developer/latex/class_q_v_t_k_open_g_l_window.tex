\doxysubsection{Detailed Description}
display a \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window} in a Qt QOpen\+GLWindow. 

\doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} is one of the mechanisms for displaying VTK rendering results in a Qt application. \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} extends QOpen\+GLWindow to display the rendering results of a \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window}.

Since \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} is based on QOpen\+GLWindow it is intended for rendering in a top-\/level window. \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} can be embedded in a another QWidget using {\ttfamily QWidget::\+create\+Window\+Container} or by using \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} instead. However, developers are encouraged to check Qt documentation for {\ttfamily QWidget::\+create\+Window\+Container} idiosyncrasies. Using \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} instead is generally a better choice for causes where you want to embed VTK rendering results in a QWidget. \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} or \doxylink{class_q_v_t_k_open_g_l_stereo_widget}{QVTKOpen\+GLStereo\+Widget} is still preferred for applications that want to support quad-\/buffer based stereo rendering.

To request a specific configuration for the context, use {\ttfamily QWindow::\+set\+Format()} like for any other QWindow. This allows, among others, requesting a given Open\+GL version and profile. Use {\ttfamily QOpen\+GLWindow::\+default\+Format()} to obtain a QSurface\+Format with appropriate Open\+GL version configuration. To enable quad-\/buffer stereo, you\textquotesingle{}ll need to call {\ttfamily QSurface\+Format::\+set\+Stereo(true)}.

VTK Rendering features like multi-\/sampling, double buffering etc. are enabled/\+disabled by directly setting the corresponding attributes on \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window} and not when specifying the Open\+GL context format in {\ttfamily set\+Format}. If not specified, then {\ttfamily QSurface\+Format::\+default\+Format} will be used.

\begin{DoxyNote}{Note}
\doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} requires Qt version 5.\+9 and above. 
\end{DoxyNote}
