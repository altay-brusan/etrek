\doxysubsection{Detailed Description}
Abstract class for drawing 3D primitives. 

This defines the interface for a \doxylink{classvtk_context_device3_d}{vtk\+Context\+Device3D}. In this sense a Context\+Device is a class used to paint 3D primitives onto a device, such as an Open\+GL context.

This is private API, and should not be used outside of the \doxylink{classvtk_context3_d}{vtk\+Context3D}.
