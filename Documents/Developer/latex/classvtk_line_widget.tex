\doxysubsection{Detailed Description}
3D widget for manipulating a line 

This 3D widget defines a line that can be interactively placed in a scene. \doxylink{requirements_The}{The} line has two handles (at its endpoints), plus the line can be picked to translate it in the scene. A nice feature of the object is that the \doxylink{classvtk_line_widget}{vtk\+Line\+Widget}, like any 3D widget, will work with the current interactor style and any other widgets present in the scene. That is, if \doxylink{classvtk_line_widget}{vtk\+Line\+Widget} does not handle an event, then all other registered observers (including the interactor style) have an opportunity to process the event. Otherwise, the \doxylink{classvtk_line_widget}{vtk\+Line\+Widget} will terminate the processing of the event that it handles.

To use this object, just invoke \doxylink{classvtk_interactor_observer_a7f52f3d776dbe073d690ee100ab685b4}{Set\+Interactor()} with the argument of the method a \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor}. You may also wish to invoke "{}\+Place\+Widget()"{} to initially position the widget. \doxylink{requirements_The}{The} interactor will act normally until the "{}i"{} key (for "{}interactor"{}) is pressed, at which point the \doxylink{classvtk_line_widget}{vtk\+Line\+Widget} will appear. (See superclass documentation for information about changing this behavior.) By grabbing one of the two end point handles (use the left mouse button), the line can be oriented and stretched (the other end point remains fixed). By grabbing the line itself, or using the middle mouse button, the entire line can be translated. Scaling (about the center of the line) is achieved by using the right mouse button. By moving the mouse "{}up"{} the render window the line will be made bigger; by moving "{}down"{} the render window the widget will be made smaller. Turn off the widget by pressing the "{}i"{} key again (or invoke the Off() method). (Note:\+ picking the line or either one of the two end point handles causes a \doxylink{classvtk_point_widget}{vtk\+Point\+Widget} to appear. This widget has the ability to constrain motion to an axis by pressing the "{}shift"{} key while moving the mouse.)

\doxylink{requirements_The}{The} \doxylink{classvtk_line_widget}{vtk\+Line\+Widget} has several methods that can be used in conjunction with other VTK objects. \doxylink{requirements_The}{The} Set/\+\+Get\+Resolution() methods control the number of subdivisions of the line; the \doxylink{classvtk_line_widget_af8596cb1d9130f521a8c22d92d7c4748}{Get\+Poly\+Data()} method can be used to get the polygonal representation and can be used for things like seeding streamlines. Typical usage of the widget is to make use of the Start\+Interaction\+Event, Interaction\+Event, and End\+Interaction\+Event events. \doxylink{requirements_The}{The} Interaction\+Event is called on mouse motion; the other two events are called on button down and button up (either left or right button).

Some additional features of this class include the ability to control the properties of the widget. You can set the properties of the selected and unselected representations of the line. For example, you can set the property for the handles and line. In addition there are methods to constrain the line so that it is aligned along the x-\/y-\/z axes.
