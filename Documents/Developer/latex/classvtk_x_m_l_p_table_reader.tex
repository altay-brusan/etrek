\doxysubsection{Detailed Description}
Read PVTK XML Table files. 

\doxylink{classvtk_x_m_l_p_table_reader}{vtk\+XMLPTable\+Reader} reads the PVTK XML Table file format. This reads the parallel format\textquotesingle{}s summary file and then uses \doxylink{classvtk_x_m_l_table_reader}{vtk\+XMLTable\+Reader} to read data from the individual Table piece files. Streaming is supported. \doxylink{requirements_The}{The} standard extension for this reader\textquotesingle{}s file format is "{}pvtt"{}.
