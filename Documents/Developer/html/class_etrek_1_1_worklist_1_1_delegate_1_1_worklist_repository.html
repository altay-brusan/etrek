Detailed Description

Provides data access and management for DICOM worklist entries, profiles, and attributes.

WorklistRepository encapsulates all database operations related to DICOM worklist management, including CRUD operations for worklist entries, profiles, DICOM tags, and attributes. It supports querying by profile, status, source, and time, and provides signals for entry changes. Logging and translation support are integrated for error handling and diagnostics.
