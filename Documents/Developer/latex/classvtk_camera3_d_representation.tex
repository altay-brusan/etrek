\doxysubsection{Detailed Description}
a class defining the representation for the \doxylink{classvtk_camera3_d_widget}{vtk\+Camera3\+DWidget} 

This class is a concrete representation for the \doxylink{classvtk_camera3_d_widget}{vtk\+Camera3\+DWidget}. \doxylink{requirements_The}{The} camera is represented by a box and a cone. \doxylink{requirements_The}{The} first one allows camera movement, the second allows view angle update. There are three more handles to rotate the view up, and move the target position. It also has a frustum representation.

To use this representation, you can use the \doxylink{classvtk_camera3_d_representation_a2bd9bc3b766a9db3000c7d8876749ea2}{Place\+Widget()} method to position the widget looking at a specified region in space. This is optional as you may want to not move the camera at setup.
