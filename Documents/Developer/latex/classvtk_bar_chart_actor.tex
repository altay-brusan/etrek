\doxysubsection{Detailed Description}
create a bar chart from an array 

\doxylink{classvtk_bar_chart_actor}{vtk\+Bar\+Chart\+Actor} generates a bar chart from an array of numbers defined in field data (a \doxylink{classvtk_data_object}{vtk\+Data\+Object}). To use this class, you must specify an input data object. You\textquotesingle{}ll probably also want to specify the position of the plot be setting the Position and Position2 instance variables, which define a rectangle in which the plot lies. There are also many other instance variables that control the look of the plot includes its title and legend.

Set the text property/\+attributes of the title and the labels through the \doxylink{classvtk_text_property}{vtk\+Text\+Property} objects associated with these components.
