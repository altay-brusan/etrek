\doxysubsection{Detailed Description}
class representing a DICOM Sequence of Items (SQ). This class is derived from class \doxylink{class_dcm_element}{Dcm\+Element} (and not from \doxylink{class_dcm_object}{Dcm\+Object}) despite the fact that sequences have no value field as such, they maintain a list of items. However, all APIs in class \doxylink{class_dcm_item}{Dcm\+Item} and class \doxylink{class_dcm_dataset}{Dcm\+Dataset} accept Dcm\+Elements. This is ugly and causes some \doxylink{class_dcm_element}{Dcm\+Element} API methods to be useless with Dcm\+Sequence.

calculate the length of this DICOM element when encoded with the given transfer syntax and the given encoding type for sequences. For elements, the length includes the length of the tag, length field, VR field and the value itself, for items and sequences it returns the length of the complete item or sequence including delimitation tags if applicable. \begin{DoxyWarning}{Warning}
Since \doxylink{class_dcm_sequence_of_items_aded6f3f5bfbcc2f31652b6abafbfb913}{calc\+Element\+Length()} returns a 32 bit integer, an overflow during calculation is possible for some derived classes that actually represent a compound value (e.\+g. items like \doxylink{class_dcm_pixel_item}{Dcm\+Pixel\+Item}). Such overflows will be detected, in which case the maximum possible value will be returned instead, coinciding with DCM\+\_\+\+Undefined\+Length. 

\doxylink{requirements_The}{The} implementation in \doxylink{class_dcm_pixel_data}{Dcm\+Pixel\+Data} may return zero if no conforming representation exists and set the EC\+\_\+\+Representation\+Not\+Found error flag to indicated it. 

When calculation the length of a sequence or an item containing multiple attributes, the implementation may return DCM\+\_\+\+Undefined\+Length to indicate a value that can not be encoded as a 32 bit length field. It will even do so if "{}dcm\+Write\+Oversized\+Seqs\+And\+Items\+Undefined"{} is disabled, but then also set the EC\+\_\+\+Seq\+Or\+Item\+Content\+Overflow error flag (inside \doxylink{class_dcm_sequence_of_items_a0f3a80f7236a97d331dbbba0adb6d58b}{get\+Length()}) to indicated it. 
\end{DoxyWarning}
\begin{DoxyNote}{Note}
Just check for zero or DCM\+\_\+\+Undefined\+Length return value and then have a look at the error flag in either case.
