\doxysubsection{Detailed Description}
Implementation of DCMR Template:\+ TID 1500 -\/ Measurement Report (and included templates 1204, 1001, 1600, 1411, 1501). All added content items are annotated with a text in the format "{}\+TID 1500 -\/ Row \+[n]\+"{}. \begin{DoxyNote}{Note}
Please note that currently only the mandatory and some optional/\+conditional content items and included templates are supported. 
\end{DoxyNote}
