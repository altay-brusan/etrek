\doxysubsection{Detailed Description}
implicit function for a Superquadric 

\doxylink{classvtk_superquadric}{vtk\+Superquadric} computes the implicit function and function gradient for a superquadric. \doxylink{classvtk_superquadric}{vtk\+Superquadric} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. \doxylink{requirements_The}{The} superquadric is centered at Center and axes of rotation is along the y-\/axis. (Use the superclass\textquotesingle{} \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function} transformation matrix if necessary to reposition.) Roundness parameters (Phi\+Roundness and Theta\+Roundness) control the shape of the superquadric. \doxylink{requirements_The}{The} Toroidal boolean controls whether a toroidal superquadric is produced. If so, the Thickness parameter controls the thickness of the toroid:\+ 0 is the thinnest allowable toroid, and 1 has a minimum sized hole. \doxylink{requirements_The}{The} Scale parameters allow the superquadric to be scaled in x, y, and z (normal vectors are correctly generated in any case). \doxylink{requirements_The}{The} Size parameter controls size of the superquadric.

This code is based on "{}\+Rigid physically based superquadrics"{}, A. H. Barr, in "{}\+Graphics Gems III"{}, David Kirk, ed., Academic Press, 1992.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} Size and Thickness parameters control coefficients of superquadric generation, and may do not exactly describe the size of the superquadric. 
\end{DoxyWarning}
