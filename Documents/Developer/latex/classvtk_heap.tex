\doxysubsection{Detailed Description}
replacement for malloc/\+free and new/\+delete 

This class is a replacement for malloc/\+free and new/\+delete for software that has inherent memory leak or performance problems. For example, external software such as the PLY library (\doxylink{classvtk_p_l_y}{vtk\+PLY}) and VRML importer (\doxylink{classvtk_v_r_m_l_importer}{vtk\+VRMLImporter}) are often written with lots of malloc() calls but without the corresponding free() invocations. \doxylink{requirements_The}{The} class \doxylink{classvtk_ordered_triangulator}{vtk\+Ordered\+Triangulator} may create and delete millions of new/\+delete calls. This class allows the overloading of the C++ new operator (or other memory allocation requests) by using the method \doxylink{classvtk_heap_aa8bdb6e6d4cea7839b2fb14216a34d75}{Allocate\+Memory()}. Memory is deleted with an invocation of Clean\+All() (which deletes ALL memory; any given memory allocation cannot be deleted). Note:\+ a block size can be used to control the size of each memory allocation. Requests for memory are fulfilled from the block until the block runs out, then a new block is created.

\begin{DoxyWarning}{Warning}
Do not use this class as a general replacement for system memory allocation. This class should be used only as a last resort if memory leaks cannot be tracked down and eliminated by conventional means. Also, deleting memory from \doxylink{classvtk_heap}{vtk\+Heap} is not supported. Only the deletion of the entire heap is. (A \doxylink{classvtk_heap_a17246da6a9f052a0aa8ec09f5200ffcd}{Reset()} method allows you to reuse previously allocated memory.)
\end{DoxyWarning}
