\doxysubsection{Detailed Description}
Vertex or Fragment shader, combined into a Shader\+Program. 

encapsulate a glsl shader

This class creates a Vertex, Fragment, Geometry or Compute shader, that can be attached to a Shader\+Program in order to render geometry etc.
