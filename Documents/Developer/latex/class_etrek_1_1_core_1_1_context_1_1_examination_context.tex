\doxysubsection{Detailed Description}
Concrete implementation of examination workflow context. 

This context is created when a user selects a Modality Worklist item and navigates to the Examination page. It extracts relevant data from the Worklist\+Entry\textquotesingle{}s DICOM attributes for easy access.
