\doxysubsection{Detailed Description}
represent a \doxylink{classvtk_border_widget}{vtk\+Border\+Widget} 

This class is used to represent and render a vt\+Border\+Widget. To use this class, you need to specify the two corners of a rectangular region.

\doxylink{requirements_The}{The} class is typically subclassed so that specialized representations can be created. \doxylink{requirements_The}{The} class defines an API and a default implementation that the \doxylink{classvtk_border_representation}{vtk\+Border\+Representation} interacts with to render itself in the scene.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} separation of the widget event handling (e.\+g., \doxylink{classvtk_border_widget}{vtk\+Border\+Widget}) from the representation (\doxylink{classvtk_border_representation}{vtk\+Border\+Representation}) enables users and developers to create new appearances for the widget. It also facilitates parallel processing, where the client application handles events, and remote representations of the widget are slaves to the client (and do not handle events).
\end{DoxyWarning}
