Detailed Description

Renders a flagpole (line) with a label at the top that faces the camera.

This class draws a line from the base to the top of the flagpole. It then places a text annotation at the top, centered horizontally. The text is always oriented with the flagpole but will rotate aroundthe flagpole to face the camera.
