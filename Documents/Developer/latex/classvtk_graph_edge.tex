\doxysubsection{Detailed Description}
Representation of a single graph edge. 

A heavy-\/weight (\doxylink{classvtk_object}{vtk\+Object} subclass) graph edge object that may be used instead of the \doxylink{structvtk_edge_type}{vtk\+Edge\+Type} struct, for use with wrappers. \doxylink{requirements_The}{The} edge contains the source and target vertex ids, and the edge id.
