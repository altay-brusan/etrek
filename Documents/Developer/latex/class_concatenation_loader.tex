\doxysubsection{Detailed Description}
Class for scanning files for concatenations and if desired, load one of them. If successful, loading produces the merged SOP Instance as a single dataset plus its frames in a separate data structure. \doxylink{requirements_The}{The} following workflow must be used:\+ 
\begin{DoxyItemize}
\item Call to one of the \doxylink{class_concatenation_loader_a5a7eb4455d4dc0b68261865164b5fbff}{scan()} methods. 
\item If scanning was successful, call \doxylink{class_concatenation_loader_a38ac2cc97cea48072249c3ea5a400372}{get\+Info()} to get information about the concatenations found by \doxylink{class_concatenation_loader_a5a7eb4455d4dc0b68261865164b5fbff}{scan()}. \doxylink{class_concatenation_loader_ae3c2f7506a58c901f092b3a352d38caf}{get\+Failed\+Files()} will return those files who could not be read, do not provide Concatenation information or had other errors. 
\item Call to the \doxylink{class_concatenation_loader_a8213888038bad15a0c3c147e834d6ee7}{load()} method in order to load of the the Concatenations found during \doxylink{class_concatenation_loader_a5a7eb4455d4dc0b68261865164b5fbff}{scan()}. Selection is done via the Concatenations Concatenation UID. \doxylink{requirements_The}{The} result is made available as a single, merged dataset without Pixel Data attribute and a vector containing all frames of the merged instance. 
\end{DoxyItemize}
