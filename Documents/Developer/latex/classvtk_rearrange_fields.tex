\doxysubsection{Detailed Description}
Move/\+copy fields between field data, point data and cell data. 

\doxylink{classvtk_rearrange_fields}{vtk\+Rearrange\+Fields} is used to copy/\+move fields (vtk\+Data\+Arrays) between data object\textquotesingle{}s field data, point data and cell data. To specify which fields are copied/\+moved, the user adds operations. There are two types of operations:\+ 1. the type which copies/\+moves an attribute\textquotesingle{}s data (i.\+e. the field will be copied but will not be an attribute in the target), 2. the type which copies/\+moves fields by name. For example:\+ \begin{DoxyVerb}* rf->AddOperation(vtkRearrangeFields::COPY, "foo",
*                  vtkRearrangeFields::DATA_OBJECT,
*                  vtkRearrangeFields::POINT_DATA);
* \end{DoxyVerb}
 adds an operation which copies a field (data array) called foo from the data object\textquotesingle{}s field data to point data. \doxylink{requirements_The}{The} same can be done using Python and Java bindings by passing strings as arguments. \begin{DoxyVerb}* Operation types: COPY, MOVE
* AttributeTypes: SCALARS, VECTORS, NORMALS, TCOORDS, TENSORS
* Field data locations: DATA_OBJECT, POINT_DATA, CELL_DATA
* \end{DoxyVerb}


\begin{DoxyWarning}{Warning}
When using Java, Python or Visual Basic bindings, the array name can not be one of the Attribute\+Types when calling \doxylink{classvtk_rearrange_fields_ad42a4ca88d5c3760b0725c39e15a53d9}{Add\+Operation()} which takes strings as arguments. \doxylink{requirements_The}{The} wrapped command will always assume the string corresponds to an attribute type when the argument is one of the Attribute\+Types. In this situation, use the \doxylink{classvtk_rearrange_fields_ad42a4ca88d5c3760b0725c39e15a53d9}{Add\+Operation()} which takes enums.
\end{DoxyWarning}
