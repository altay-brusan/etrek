\doxysubsection{Detailed Description}
Manages key types in vtk\+Common. 

\doxylink{classvtk_common_information_key_manager}{vtk\+Common\+Information\+Key\+Manager} is included in the header of any subclass of \doxylink{classvtk_information_key}{vtk\+Information\+Key} defined in the vtk\+Common library. It makes sure that the table of keys is created before and destroyed after it is used.
