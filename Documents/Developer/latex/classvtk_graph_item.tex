\doxysubsection{Detailed Description}
A 2D graphics item for rendering a graph. 

This item draws a graph as a part of a \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}. This simple class has minimal state and delegates the determination of visual vertex and edge properties like color, size, width, etc. to a set of virtual functions. To influence the rendering of the graph, subclass this item and override the property functions you wish to customize.
