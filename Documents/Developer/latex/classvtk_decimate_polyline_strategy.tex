\doxysubsection{Detailed Description}
abstract class to define a decimation strategy for the \doxylink{classvtk_decimate_polyline_filter}{vtk\+Decimate\+Polyline\+Filter} 

Parent class for the polyline decimation strategies. It defines a pure virtual method {\ttfamily \doxylink{classvtk_decimate_polyline_strategy_acbd9ba1050946eef5f018198fbd7e743}{Compute\+Error}} that requires an implementation for each strategy inheriting this class. It also requires to be given a dataset on which it will gather the points to perform the error computation.
