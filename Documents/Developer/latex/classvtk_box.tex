\doxysubsection{Detailed Description}
implicit function for a bounding box 

\doxylink{classvtk_box}{vtk\+Box} computes the implicit function and/\+or gradient for a axis-\/aligned bounding box. (\doxylink{requirements_The}{The} superclasses transform can be used to modify this orientation.) Each side of the box is orthogonal to all other sides meeting along shared edges and all faces are orthogonal to the x-\/y-\/z coordinate axes. (If you wish to orient this box differently, recall that the superclass \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function} supports a transformation matrix.) \doxylink{classvtk_box}{vtk\+Box} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.
