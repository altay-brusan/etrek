\doxysubsection{Detailed Description}
Class to interface an application to a \doxylink{class_d_i_c_o_m_parser}{DICOMParser}. 

\doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} assists an application in communicating with a \doxylink{class_d_i_c_o_m_parser}{DICOMParser}. \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} registers a series of callbacks to the \doxylink{class_d_i_c_o_m_parser}{DICOMParser} which allows it to cache the information from a DICOM file in a format that is appropriate for an application to use. Once a DICOM file is read, an application can query the \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} for the resolution, pixel size, and pixel data.

If a \doxylink{class_d_i_c_o_m_parser}{DICOMParser} scans more than one file, the \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} will group filenames by Series\+UID. This allows an application to pass a series of DICOM files to the \doxylink{class_d_i_c_o_m_parser}{DICOMParser} (which via the callback mechanism allows the \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} to cache information) and then query the \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} for the files that are from the same series. \doxylink{requirements_The}{The} application can request the filenames for a particular series to be sorted based on image number, slice location, or patient position. This allows the \doxylink{class_d_i_c_o_m_app_helper}{DICOMApp\+Helper} to assist an application is collecting all the images from one series into a volume.
