◆ interleaveMode

enum DJLSCodecParameter::interleaveMode

Constants describing the interleave mode which the encoder will use

Enumerator
interleaveDefault 

Use same interleave mode as the DICOM header says in planarConfiguration, if possible. The cooked encoder will force interleaveLine.

interleaveSample 

Sample-interleaved (color-by-pixel).

interleaveLine 

Line-interleaved (color-by-line).
