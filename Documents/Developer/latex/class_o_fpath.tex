\doxysubsection{Detailed Description}
A class representing paths on a filesystem. \doxylink{class_o_fpath}{OFpath} implements a subset of the functionality described as std::\+filesystem::\+path, see \href{http://en.cppreference.com/w/cpp/filesystem/path}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+filesystem/\+path}} for more information. \begin{DoxyWarning}{Warning}
One major difference of the current \doxylink{class_o_fpath}{OFpath} implementation and the real std::\+filesystem::\+path is that std::\+filesystem::\+path native string type is expected to be std::\+wstring on Windows, whereas \doxylink{class_o_fpath}{OFpath} currently always uses \doxylink{class_o_f_string}{OFString}, since something like OFWString does currently not exist. This will be addressed before making \doxylink{class_o_fpath}{OFpath} interchangeable with std::\+filesystem::\+path. 
\end{DoxyWarning}
