\doxysubsection{Detailed Description}
This struct describes a gl\+TF material object. gl\+TF materials are defined using the metallic-\/roughness model. \doxylink{requirements_The}{The} values for most properties can be defined using either factors or textures (via texture\+Info). Materials also define normal, occlusion and emissive maps.
