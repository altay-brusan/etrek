\doxysubsection{Detailed Description}
A set of parallel (multi-\/threaded) utility functions. 

\doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools} provides a set of utility functions that can be used to parallelize parts of VTK code using multiple threads. There are several back-\/end implementations of parallel functionality (currently Sequential, TBB, Open\+MP and STDThread) that actual execution is delegated to.
