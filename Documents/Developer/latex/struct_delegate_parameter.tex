\doxysubsection{Detailed Description}
Parameters passed to builders during construction. 

This structure carries configuration and context information that builders need to operate. Builders are responsible for creating repositories from db\+Connection and passing them to delegates if needed.

\doxylink{requirements_The}{The} structure includes:\+
\begin{DoxyItemize}
\item Database connection for builders to create repositories
\item References to other delegates (for inter-\/delegate communication)
\item Context manager for accessing session and workflow contexts
\item Pre-\/fetched contexts for immediate use
\end{DoxyItemize}

IMPORTANT ARCHITECTURAL PATTERN:\+
\begin{DoxyItemize}
\item \doxylink{struct_delegate_parameter}{Delegate\+Parameter} ONLY contains db\+Connection (NO repositories)
\item Builders receive \doxylink{struct_delegate_parameter}{Delegate\+Parameter} and create repositories from db\+Connection
\item Builders pass repository instances to delegates if delegates need them
\item Delegates NEVER receive db\+Connection, only repositories
\item Each builder is independent and creates its own repository instances 
\end{DoxyItemize}
