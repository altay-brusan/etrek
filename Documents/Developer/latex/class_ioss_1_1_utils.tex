Tries to shorten long variable names to an acceptable length, and converts to lowercase and spaces to {\ttfamily \+\_\+}. 

Many databases have a maximum length for variable names which can cause a problem with variable name length.

This routine tries to shorten long variable names to an acceptable length ({\ttfamily max\+\_\+var\+\_\+len} characters max). If the name is already less than this length, it is returned unchanged...

Since there is a (good) chance that two shortened names will match, a 2-\/letter {\ttfamily hash} code is appended to the end of the variable name.

So, we shorten the name to a maximum of {\ttfamily max\+\_\+var\+\_\+len}-\/3 characters and append a 2 character hash+separator.
