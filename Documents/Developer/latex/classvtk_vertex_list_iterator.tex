\doxysubsection{Detailed Description}
Iterates all vertices in a graph. 

\doxylink{classvtk_vertex_list_iterator}{vtk\+Vertex\+List\+Iterator} iterates through all vertices in a graph. Create an instance of this and call graph-\/\texorpdfstring{$>$}{>}Get\+Vertices(it) to initialize this iterator. You may alternately call \doxylink{classvtk_vertex_list_iterator_a501db871432ff8d7ee0a79eaa7c689a5}{Set\+Graph()} to initialize the iterator.
