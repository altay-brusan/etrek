\doxysubsection{Detailed Description}
implicit function for a set of spheres 

\doxylink{classvtk_spheres}{vtk\+Spheres} computes the implicit function and function gradient for a set of spheres. \doxylink{requirements_The}{The} spheres are combined via a union operation (i.\+e., the minimum value from the evaluation of all spheres is taken).

\doxylink{requirements_The}{The} function value is the distance of a point to the closest sphere, with negative values interior to the spheres, positive outside the spheres, and distance=0 on the spheres surface. \doxylink{requirements_The}{The} function gradient is the sphere normal at the function value.
