\doxysubsection{Detailed Description}
Abstract base class for Find SCU callbacks. During a C-\/\+FIND operation, the \doxylink{class_dcm_find_s_c_u_callback_ac2c0eeaf410680a39b38ed8fe555b04b}{callback()} method of a callback handler object derived from this class is called once for each incoming C-\/\+FIND-\/\+RSP message. \doxylink{requirements_The}{The} callback method has access to the original C-\/\+FIND-\/\+RQ message (but not the request dataset), the current C-\/\+FIND-\/\+RSP message including its dataset, the number of the current request, the association over which the request is received and the presentation context ID. \doxylink{requirements_The}{The} callback is needed to process the incoming message (e.\+g., display on screen, add to some list, store to file). \doxylink{requirements_The}{The} callback may also issue a C-\/\+FIND-\/\+CANCEL message if needed. Implementations may provide their own callbacks, which must be derived from this base class.
