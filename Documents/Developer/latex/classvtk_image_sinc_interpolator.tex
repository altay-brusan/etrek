\doxysubsection{Detailed Description}
perform sinc interpolation on images 

\doxylink{classvtk_image_sinc_interpolator}{vtk\+Image\+Sinc\+Interpolator} provides various windowed sinc interpolation methods for image data. \doxylink{requirements_The}{The} default is a five-\/lobed Lanczos interpolant, with a kernel size of 6. \doxylink{requirements_The}{The} interpolator can also bandlimit the image, which can be used for antialiasing. \doxylink{requirements_The}{The} interpolation kernels are evaluated via a lookup table for efficiency. \begin{DoxyParagraph}{Thanks:\+}
Thanks to David Gobbi at the Seaman Family MR Centre and Dept. of Clinical Neurosciences, Foothills Medical Centre, Calgary, for providing this class.
