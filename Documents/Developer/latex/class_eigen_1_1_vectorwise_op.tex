This class represents a pseudo expression with broadcasting and partial reduction features. It is the return type of \doxylink{class_eigen_1_1_dense_base_abfbb90acef01249a37f7d1323a414896}{Dense\+Base::\+colwise()} and \doxylink{class_eigen_1_1_dense_base_ac1fbfd5b45f2b4b9bff9d1994e335863}{Dense\+Base::\+rowwise()} and most of the time this is the only way it is explicitly used.

For a partial reduction on an empty input, some rules apply. For the sake of clarity, let\textquotesingle{}s consider a vertical reduction:\+
\begin{DoxyItemize}
\item If the number of columns is zero, then a 1x0 row-\/major vector expression is returned.
\item Otherwise, if the number of rows is zero, then
\begin{DoxyItemize}
\item a row vector of zeros is returned for sum-\/like reductions (sum, squared\+Norm, norm, etc.)
\item a row vector of ones is returned for a product reduction (e.\+g., {\ttfamily Matrix\+Xd(n,0).colwise().\doxylink{class_eigen_1_1_vectorwise_op_a6863499c3e7ea8635784376806abcf9f}{prod()}})
