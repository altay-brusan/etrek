\doxysubsection{Detailed Description}
Repository for DICOM Modality Worklist (MWL) data access. 

Provides comprehensive data access for worklist management including CRUD operations for worklist entries, profiles, DICOM tags, and attributes. Supports querying by various criteria and emits signals for entry changes.
