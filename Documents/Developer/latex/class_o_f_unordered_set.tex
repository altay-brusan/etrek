\doxysubsection{Detailed Description}
\subsubsection*{template$<$class T$>$\newline
class OFUnordered\+Set$<$ T $>$}
This template class provides a data structure and operations for administrating an unordered set of elements of an arbitrary type. Note the following properties of this class:\+
\begin{DoxyItemize}
\item an element which is inserted into the set will be copied
\item the datatype of the set\textquotesingle{}s elements has to support operator== so that it is possible to find a certain element
\item it is allowed to insert identical elements into the set
\item if a user requires to remove a certain element and if there are several elements which are identical to this element, only one element will be removed from the set
\item after removing an element of a set, the indices of the set\textquotesingle{}s elements might have changed; hence, looping over all elements of a set must be restarted if an element was removed from the set within the loop
\item the order of the elements is arbitrary, but it will not be changed unless an element is removed from the set 
\end{DoxyItemize}
