\doxysubsection{Detailed Description}
the list of curve and overlay activation layers contained in a presentation state (internal use only). This class manages the data structures comprising the list of curve activation layers and overlay activation layers (all instances of the Curve Activation Layer Module and Overlay Activation Layer Module repeating elements) contained in a Presentation State object.
