\doxysubsection{Detailed Description}
Contour interpolator for DEM data. 

\doxylink{classvtk_terrain_contour_line_interpolator}{vtk\+Terrain\+Contour\+Line\+Interpolator} interpolates nodes on height field data. \doxylink{requirements_The}{The} class is meant to be used in conjunciton with a \doxylink{classvtk_contour_widget}{vtk\+Contour\+Widget}, enabling you to draw paths on terrain data. \doxylink{requirements_The}{The} class internally uses a \doxylink{classvtk_projected_terrain_path}{vtk\+Projected\+Terrain\+Path}. Users can set kind of interpolation desired between two node points by setting the modes of the this filter. For instance:\+

You are required to set the Image\+Data to this class as the height-\/field image.
