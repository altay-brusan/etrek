\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type, int \+\_\+\+Up\+Lo, typename \+\_\+\+Ordering$>$\newline
class Eigen::\+\+Simplicial\+LLT$<$ \+\_\+\+Matrix\+Type, \+\_\+\+Up\+Lo, \+\_\+\+Ordering $>$}
A direct sparse \doxylink{class_eigen_1_1_l_l_t}{LLT} Cholesky factorizations. 

This class provides a LL\texorpdfstring{$^\wedge$}{\string^}T Cholesky factorizations of sparse matrices that are selfadjoint and positive definite. \doxylink{requirements_The}{The} factorization allows for solving A.\+X = B where X and B can be either dense or sparse.

In order to reduce the fill-\/in, a symmetric permutation P is applied prior to the factorization such that the factorized matrix is P A P\texorpdfstring{$^\wedge$}{\string^}-\/1.


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the sparse matrix A, it must be a \doxylink{class_eigen_1_1_sparse_matrix}{Sparse\+Matrix$<$$>$} \\
\hline
{\em \+\_\+\+Up\+Lo} & the triangular part that will be used for the computations. It can be Lower or Upper. Default is Lower. \\
\hline
{\em \+\_\+\+Ordering} & \doxylink{requirements_The}{The} ordering method to use, either \doxylink{class_eigen_1_1_a_m_d_ordering}{AMDOrdering$<$$>$} or \doxylink{class_eigen_1_1_natural_ordering}{Natural\+Ordering$<$$>$}. Default is \doxylink{class_eigen_1_1_a_m_d_ordering}{AMDOrdering$<$$>$}\\
