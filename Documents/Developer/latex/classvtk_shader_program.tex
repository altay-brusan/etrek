\doxysubsection{Detailed Description}
\doxylink{requirements_The}{The} Shader\+Program uses one or more Shader objects. 

a glsl shader program

This class creates a shader program using the given shader objects. It can be a rendering program in which case a vertex and fragment shader must be provided (plus an optional geometry shader). It can also be a compute program in which case a compute shader must be provided.

This class contains the vertex, fragment, geometry shaders that combine to make a rendering shader program. Alternatively, it can also contain a compute shader to make a compute shader program (Open\+GL \texorpdfstring{$>$}{>}= 4.\+3 required).

vtk\+Shader\+Program::\+vtk\+Set\+File\+Path\+Macro (\begin{DoxyParamCaption}\item[{File\+Name\+Prefix\+For\+Debugging}]{}{}\end{DoxyParamCaption})}

When developing shaders, it\textquotesingle{}s often convenient to tweak the shader and re-\/render incrementally. This provides a mechanism to do the same. To debug any shader program, set {\ttfamily File\+Name\+Prefix\+For\+Debugging} to a file path e.\+g. {\ttfamily /\+tmp/\+myshaders}. Subsequently, when {\ttfamily \doxylink{classvtk_shader_program_a26ecbeb0bf8ba5f1b2e090b2d5ca0aff}{Bind()}} is called on the shader program, it will check for files named {\ttfamily \texorpdfstring{$<$}{<}File\+Name\+Prefix\+For\+Debugging\texorpdfstring{$>$}{>}VS.\+glsl}, {\ttfamily \texorpdfstring{$<$}{<}File\+Name\+Prefix\+For\+Debugging\texorpdfstring{$>$}{>}GS.\+glsl} and {\ttfamily \texorpdfstring{$<$}{<}File\+Name\+Prefix\+For\+Debugging\texorpdfstring{$>$}{>}FS.\+glsl} for vertex shader, geometry shader and fragment shader codes respectively. If a file doesn\textquotesingle{}t exist, then it dumps out the current code to that file. If the file exists, then the shader is recompiled to use the contents of that file. Thus, after the files have been dumped in the first render, you can open the files in a text editor and update as needed. On following render, the modified contexts from the file will be used.

This is only intended for debugging during development and should not be used in production.
