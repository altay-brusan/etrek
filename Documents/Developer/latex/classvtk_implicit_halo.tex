\doxysubsection{Detailed Description}
implicit function for an halo 

\doxylink{classvtk_implicit_halo}{vtk\+Implicit\+Halo} evaluates to 1.\+0 for each position in the sphere of a given center and radius Radius\texorpdfstring{$\ast$}{*}(1-\/Fade\+Out). It evaluates to 0.\+0 for each position out the sphere of a given Center and radius Radius. It fades out linearly from 1.\+0 to 0.\+0 for points in a radius from Radius\texorpdfstring{$\ast$}{*}(1-\/Fade\+Out) to Radius. \doxylink{classvtk_implicit_halo}{vtk\+Implicit\+Halo} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}. It is useful as an input to \doxylink{classvtk_sample_function}{vtk\+Sample\+Function} to generate an 2D image of an halo. It is used this way by \doxylink{classvtk_shadow_map_pass}{vtk\+Shadow\+Map\+Pass}. \begin{DoxyWarning}{Warning}
It does not implement the gradient. 
\end{DoxyWarning}
