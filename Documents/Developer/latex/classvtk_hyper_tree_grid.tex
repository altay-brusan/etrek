\doxysubsection{Detailed Description}
A dataset containing a grid of \doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree} instances arranged as a rectilinear grid. 

An hypertree grid is a dataset containing a rectilinear grid of root nodes, each of which can be refined as a \doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree} grid. This organization of the root nodes allows for the definition of tree-\/based AMR grids that do not have uniform geometry. Some filters can be applied on this dataset:\+ contour, outline, geometry.

\doxylink{requirements_The}{The} order and number of points must match that specified by the dimensions of the grid. \doxylink{requirements_The}{The} point order increases in i fastest (from 0\texorpdfstring{$<$}{<}=i\texorpdfstring{$<$}{<}dims\+[0]\+), then j (0\texorpdfstring{$<$}{<}=j\texorpdfstring{$<$}{<}dims\+[1]\+), then k (0\texorpdfstring{$<$}{<}=k\texorpdfstring{$<$}{<}dims\+[2]\+) where dims\+[]\+ are the dimensions of the grid in the i-\/j-\/k topological directions. \doxylink{requirements_The}{The} number of points is dims\+[0]\+\texorpdfstring{$\ast$}{*}dims\+[1]\+\texorpdfstring{$\ast$}{*}dims\+[2]\+. \doxylink{requirements_The}{The} same is true for the cells of the grid. \doxylink{requirements_The}{The} order and number of cells must match that specified by the dimensions of the grid. \doxylink{requirements_The}{The} cell order increases in i fastest (from 0\texorpdfstring{$<$}{<}=i\texorpdfstring{$<$}{<}(dims\+[0]\+-\/1)), then j (0\texorpdfstring{$<$}{<}=j\texorpdfstring{$<$}{<}(dims\+[1]\+-\/1)), then k (0\texorpdfstring{$<$}{<}=k\texorpdfstring{$<$}{<}(dims\+[2]\+-\/1)) \doxylink{requirements_The}{The} number of cells is (dims\+[0]\+-\/1)\texorpdfstring{$\ast$}{*}(dims\+[1]\+-\/1)\texorpdfstring{$\ast$}{*}(dims\+[2]\+-\/1).

Dimensions :\+ number of points by direction of rectilinear grid Cell\+Dims :\+ number of cells by directions of rectilinear grid (1 for each dimensions 1)

Interface :\+ plane that cuts a HTG cell. It is defined (for each cell) by a normal and the distance between the origin and the plane along that normal (i.\+e. the orthogonal distance). \doxylink{requirements_The}{The} name of the arrays containing each information is specified in {\ttfamily Interface\+Intercepts\+Name} and {\ttfamily Interface\+Normals\+Name} \doxylink{requirements_The}{The} normals array is a 3D array that contains the 3D normal for each cell\textquotesingle{}s interface (for lower dimensions, some values are ignored). \doxylink{requirements_The}{The} intercepts (or distances) array is also a 3D array containing:\+
\begin{DoxyItemize}
\item the distance to the first plane (if exists, otherwise ignored)
\item the distance to the second plane (if exists, otherwise ignored)
\item the type of cell (mixed/\+pure, cf. vtk\+Hyper\+Tree\+Grid\+Geometry\+Impl.\+h:\+Cell\+Interface\+Type)
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
It is not a spatial search object. If you are looking for this kind of octree see \doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} instead. Extent support is not finished yet.
\end{DoxyWarning}

Get or create pure material mask

Pure\+Mask is a boolean array size to the number of cells which describes, for each cell, if it is pure material mask (PMM), a mask which is true if the cell is not pure. \doxylink{requirements_The}{The} PMM of a cell is true:\+
\begin{DoxyItemize}
\item if the cell is hidden; we do not take into account if the cell is leaf or coarse;
\item if the fine/\+leaf cell is mixed (Has\+Interface is true, Interface\+Intercepts\+Name and Interface\+Normals\+Name are the vector value field names with 3 components); the description of its type at the interface (the third component of the field named Interface\+Intercepts\+Name) is \texorpdfstring{$<$}{<} 2 (2 indicates that this cell contains only one material, cell is pure);
\item if the coarse cell has at least one of its child cells which has set PMM to true.
\end{DoxyItemize}
