\doxysubsection{Detailed Description}
A class to create small proxy objects that ease indention handling. Each \doxylink{class_dcm_json_format_1_1_indention}{Indention} object only contains a reference to the \doxylink{class_dcm_json_format}{Dcm\+Json\+Format} object that created it and its only purpose is to call the respective methods of that object when one of its overloaded operators is used.
