\doxysubsection{Detailed Description}
a cell that represents a 2D quadrilateral 

\doxylink{classvtk_quad}{vtk\+Quad} is a concrete implementation of \doxylink{classvtk_cell}{vtk\+Cell} to represent a 2D quadrilateral. \doxylink{classvtk_quad}{vtk\+Quad} is defined by the four points (0,1,2,3) in counterclockwise order. \doxylink{classvtk_quad}{vtk\+Quad} uses the standard isoparametric interpolation functions for a linear quadrilateral.
