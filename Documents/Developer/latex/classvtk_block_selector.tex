\doxysubsection{Detailed Description}
selector for blocks 

Selects cells or points contained in a block as defined in the \doxylink{classvtk_selection_node}{vtk\+Selection\+Node} used to initialize this operator.

This selector supports vtk\+Selection\+Node::\+\+BLOCKS and vtk\+Selection\+Node::\+\+BLOCK\+\_\+\+SELECTORS.

{\footnotesize\ttfamily \label{classvtk_block_selector_a80fdc68e4561390e607f547ca0394c0e} 
bool vtk\+Block\+Selector::\+\+Compute\+Selected\+Elements (\begin{DoxyParamCaption}\item[{\doxymbox{\hyperlink{classvtk_data_object}{vtk\+Data\+Object}} \texorpdfstring{$\ast$}{*}}]{input}{, }\item[{\doxymbox{\hyperlink{classvtk_signed_char_array}{vtk\+Signed\+Char\+Array}} \texorpdfstring{$\ast$}{*}}]{insidedness\+Array}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [override]}, {\ttfamily [protected]}, {\ttfamily [virtual]}}

This method computes whether or not each element in the dataset is inside the selection and populates the given array with 0 (outside the selection) or 1 (inside the selection).

\doxylink{requirements_The}{The} \doxylink{classvtk_data_object}{vtk\+Data\+Object} passed in will never be a {\ttfamily \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set}} subclass.

What type of elements are operated over is determined by the \doxylink{classvtk_selection_node}{vtk\+Selection\+Node}\textquotesingle{}s field association. \doxylink{requirements_The}{The} insidedness\+Array passed in should have the correct number of elements for that field type or it will be resized.

Returns true for successful completion. \doxylink{requirements_The}{The} operator should only return false when it cannot operate on the inputs. In which case, it is assumed that the insidedness\+Array may have been left untouched by this method and the calling code will fill it with 0.
