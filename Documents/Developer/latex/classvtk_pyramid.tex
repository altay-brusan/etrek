\doxysubsection{Detailed Description}
a 3D cell that represents a linear pyramid 

\doxylink{classvtk_pyramid}{vtk\+Pyramid} is a concrete implementation of \doxylink{classvtk_cell}{vtk\+Cell} to represent a 3D pyramid. A pyramid consists of a rectangular base with four triangular faces. \doxylink{classvtk_pyramid}{vtk\+Pyramid} uses the standard isoparametric shape functions for a linear pyramid. \doxylink{requirements_The}{The} pyramid is defined by the five points (0-\/4) where (0,1,2,3) is the base of the pyramid which, using the right hand rule, forms a quadrilaterial whose normal points in the direction of the pyramid apex at vertex \#4. \doxylink{requirements_The}{The} parametric location of vertex \#4 is \+[0, 0, 1]\+.
