\doxysubsection{Detailed Description}
threaded (high-\/performance) cutting of a \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} with a plane 

\doxylink{classvtk_poly_data_plane_cutter}{vtk\+Poly\+Data\+Plane\+Cutter} cuts an input \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} with a plane to produce an output \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}. (Here cutting means slicing through the polydata to generates lines of intersection.) \doxylink{requirements_The}{The} input \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} must consist of convex polygons -\/ vertices, lines, and triangle strips are ignored. (Note:\+ use \doxylink{classvtk_triangle_filter}{vtk\+Triangle\+Filter} to triangulate non-\/convex input polygons if necessary. If the input cells are non-\/convex, then the cutting operation will likely produce erroneous results.)

\doxylink{requirements_The}{The} main difference between this filter and other cutting filters is that \doxylink{classvtk_poly_data_plane_cutter}{vtk\+Poly\+Data\+Plane\+Cutter} is tuned for performance on \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} with convex polygonal cells.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} method \doxylink{classvtk_poly_data_plane_cutter_ae633b26636a4f78099d77f0039f7c57b}{Can\+Fully\+Process\+Data\+Object()} is available to see whether the input data can be successfully processed by this filter. Use this method sparingly because it can be slow.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.
\end{DoxyWarning}
