\doxysubsection{Detailed Description}
Encapsulate the state required to evaluate DG cell-\/attributes.

This object holds input \doxylink{classvtk_d_g_operator_entry}{vtk\+DGOperator\+Entry} objects, input array pointers, and working-\/space tuples ({\ttfamily std::\+vector} and {\ttfamily std::\+array} ivars) required to evaluate a single \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute} on cells corresponding to a single \doxylink{structvtk_d_g_cell_1_1_source}{vtk\+DGCell::\+\+Source} entry. \doxylink{classvtk_d_g_operation}{vtk\+DGOperation} holds one instance of \doxylink{classvtk_d_g_operation_state}{vtk\+DGOperation\+State} for each \doxylink{structvtk_d_g_cell_1_1_source}{vtk\+DGCell::\+\+Source} entry in a particular \doxylink{classvtk_d_g_cell}{vtk\+DGCell} instance with arrays populated by a single \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute}.
