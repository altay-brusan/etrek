\doxysubsection{Detailed Description}
Helper class for building a directed or directed graph. 

\doxylink{classvtk_mutable_graph_helper}{vtk\+Mutable\+Graph\+Helper} has helper methods Add\+Vertex and Add\+Edge which add vertices/\+edges to the underlying mutable graph. This is helpful in filters which need to (re)construct graphs which may be either directed or undirected.
