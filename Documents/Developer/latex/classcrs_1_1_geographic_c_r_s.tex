\doxysubsection{Detailed Description}
A coordinate reference system associated with a geodetic reference frame and a two-\/ or three-\/dimensional ellipsoidal coordinate system. 

If the geodetic reference frame is dynamic or if the geographic \doxylink{classcrs_1_1_c_r_s}{CRS} has an association to a velocity model then the geodetic \doxylink{classcrs_1_1_c_r_s}{CRS} is dynamic, else it is static.
