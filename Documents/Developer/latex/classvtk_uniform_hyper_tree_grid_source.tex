\doxysubsection{Detailed Description}
Create a synthetic grid of uniform hypertrees. 

This class uses input parameters, most notably a string descriptor, to generate a \doxylink{classvtk_hyper_tree_grid}{vtk\+Hyper\+Tree\+Grid} instance representing the corresponding tree-\/based AMR grid with uniform root cell sizes along each axis.
