\doxysubsection{Detailed Description}
This struct describes a gl\+TF node object. A node represents an object within a scene. Nodes can contain transform properties (stored as \doxylink{classvtk_matrix4x4}{vtk\+Matrix4x4} objects) as well as indices to children nodes, forming a hierarchy. No node may be a direct descendant of more than one node.
