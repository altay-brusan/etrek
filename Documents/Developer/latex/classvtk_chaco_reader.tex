\doxysubsection{Detailed Description}
Read a Chaco file and create a \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid}. 

\doxylink{classvtk_chaco_reader}{vtk\+Chaco\+Reader} is an unstructured grid source object that reads Chaco files. \doxylink{requirements_The}{The} reader DOES NOT respond to piece requests. Chaco is a graph partitioning package developed at Sandia National Laboratories in the early 1990s. (\href{http://www.cs.sandia.gov/~bahendr/chaco.html}{\texttt{http:\+/\+/\+www.\+cs.\+sandia.\+gov/\+\texorpdfstring{$\sim$}{\string~}bahendr/\+chaco.\+html}})

Note that the Chaco "{}edges"{} become VTK "{}cells"{}, and the Chaco "{}vertices"{} become VTK "{}points"{}.
