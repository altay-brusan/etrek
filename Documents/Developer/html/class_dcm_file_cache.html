Detailed Description

This class implements a simple container that stores an input stream, the position of that input stream corresponding to the start of a DICOM element value field contained in the stream and the current "owner" object. It is used to keep a single file handle open during multiple calls to DcmElement::getPartialValue(), thus speeding up the reading.
