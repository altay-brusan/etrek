STL-\/style random access iterator for vtk\+Typed\+Data\+Arrays. 

\doxylink{classvtk_typed_data_array_iterator}{vtk\+Typed\+Data\+Array\+Iterator} provides an STL-\/style iterator that can be used to interact with instances of \doxylink{classvtk_typed_data_array}{vtk\+Typed\+Data\+Array}. It is intended to provide an alternative to using vtk\+Data\+Array::\+\+Get\+Void\+Pointer() that only uses \doxylink{classvtk_typed_data_array}{vtk\+Typed\+Data\+Array} API functions to retrieve values. It is especially helpful for safely iterating through subclasses of \doxylink{classvtk_mapped_data_array}{vtk\+Mapped\+Data\+Array}, which may not use the same memory layout as a typical \doxylink{classvtk_data_array}{vtk\+Data\+Array}.
