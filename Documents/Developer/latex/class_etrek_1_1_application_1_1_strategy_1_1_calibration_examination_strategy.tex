\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_application_1_1_strategy}{Strategy} for detector and generator calibration mode. 

This mode is used for equipment calibration procedures including:\+
\begin{DoxyItemize}
\item Flat-\/field (gain) calibration
\item Dark-\/field (offset) calibration
\item Defect pixel mapping
\item Generator output verification
\end{DoxyItemize}

Key characteristics:\+
\begin{DoxyItemize}
\item Local persistence of calibration images for analysis
\item No DICOM patient objects created
\item No PACS transmission
\item No worklist status updates
\item Separate calibration data storage
\end{DoxyItemize}

Calibration data is stored locally and used by the detector and image processing systems to ensure optimal image quality.
