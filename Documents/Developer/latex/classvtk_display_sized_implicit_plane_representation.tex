\doxysubsection{Detailed Description}
a class defining the representation for a \doxylink{classvtk_display_sized_implicit_plane_widget}{vtk\+Display\+Sized\+Implicit\+Plane\+Widget} 

This class is a concrete representation for the \doxylink{classvtk_display_sized_implicit_plane_widget}{vtk\+Display\+Sized\+Implicit\+Plane\+Widget}. It represents an display sized disk plane defined by a normal and point. Through interaction with the widget, the plane can be manipulated by adjusting the plane normal, disk radius or moving/\+picking the origin point.

To use this representation, you normally define a (plane) origin and (plane) normal. \doxylink{requirements_The}{The} Place\+Widget() method is also used to initially position the representation.

\begin{DoxyWarning}{Warning}
This class, and \doxylink{classvtk_display_sized_implicit_plane_widget}{vtk\+Display\+Sized\+Implicit\+Plane\+Widget}, are next generation VTK widgets.
\end{DoxyWarning}
