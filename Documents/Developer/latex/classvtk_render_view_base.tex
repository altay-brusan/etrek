\doxysubsection{Detailed Description}
A base view containing a renderer. 

\doxylink{classvtk_render_view_base}{vtk\+Render\+View\+Base} is a view which contains a \doxylink{classvtk_renderer}{vtk\+Renderer}. You may add vtk\+Actors directly to the renderer.

This class is also the parent class for any more specialized view which uses a renderer.
