\doxysubsection{Detailed Description}
selectively filter points 

\doxylink{classvtk_mask_points}{vtk\+Mask\+Points} is a filter that passes through points and point attributes from input dataset. (Other geometry is not passed through.) It is possible to mask every nth point, and to specify an initial offset to begin masking from. It is possible to also generate different random selections (jittered strides, real random samples, and spatially stratified random samples) from the input data. \doxylink{requirements_The}{The} filter can also generate vertices (topological primitives) as well as points. This is useful because vertices are rendered while points are not.
