\doxysubsection{Detailed Description}
Lays out and displays a graph. 

\doxylink{classvtk_graph_layout_view}{vtk\+Graph\+Layout\+View} performs graph layout and displays a \doxylink{classvtk_graph}{vtk\+Graph}. You may color and label the vertices and edges using fields in the graph. If coordinates are already assigned to the graph vertices in your graph, set the layout strategy to Pass\+Through in this view. \doxylink{requirements_The}{The} default layout is Fast2D which is fast but not that good, for better layout set the layout to Simple2D or Force\+Directed. There are also tree and circle layout strategies. :\+)
