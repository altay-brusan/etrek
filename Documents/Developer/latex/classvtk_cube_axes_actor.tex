\doxysubsection{Detailed Description}
create a plot of a bounding box edges -\/ used for navigation 

\doxylink{classvtk_cube_axes_actor}{vtk\+Cube\+Axes\+Actor} is a composite actor that draws axes of the bounding box of an input dataset. \doxylink{requirements_The}{The} axes include labels and titles for the x-\/y-\/z axes. \doxylink{requirements_The}{The} algorithm selects which axes to draw based on the user-\/defined \textquotesingle{}fly\textquotesingle{} mode. (STATIC is default). \textquotesingle{}STATIC\textquotesingle{} constructs axes from all edges of the bounding box. \textquotesingle{}CLOSEST\+\_\+\+TRIAD\textquotesingle{} consists of the three axes x-\/y-\/z forming a triad that lies closest to the specified camera. \textquotesingle{}FURTHEST\+\_\+\+TRIAD\textquotesingle{} consists of the three axes x-\/y-\/z forming a triad that lies furthest from the specified camera. \textquotesingle{}OUTER\+\_\+\+EDGES\textquotesingle{} is constructed from edges that are on the "{}exterior"{} of the bounding box, exterior as determined from examining outer edges of the bounding box in projection (display) space.

To use this object you must define a bounding box and the camera used to render the \doxylink{classvtk_cube_axes_actor}{vtk\+Cube\+Axes\+Actor}. You can optionally turn on/\+off labels, ticks, gridlines, and set tick location, number of labels, and text to use for axis-\/titles. A \textquotesingle{}corner offset\textquotesingle{} can also be set. This allows the axes to be set partially away from the actual bounding box to perhaps prevent overlap of labels between the various axes.

\doxylink{requirements_The}{The} Bounds instance variable (an array of six doubles) is used to determine the bounding box.
