\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_worklist_1_1_service}{Service} for registering new patients into the local MWL (Modality Worklist). 

This service handles the complete workflow of creating MWL entries from patient data:\+
\begin{DoxyItemize}
\item Creates mwl\+\_\+entries with source=\textquotesingle{}LOCAL\textquotesingle{} and status=\textquotesingle{}PENDING\textquotesingle{}
\item Creates mwl\+\_\+attributes for all patient demographics
\item Resolves DICOM tag IDs via Dicom\+Tag\+Repository
\item Executes all operations in a single database transaction (atomic)
\end{DoxyItemize}

DICOM Hierarchy (for default settings:\+ 1 Study, 1 Series, N Images):\+ Patient → Study (one per body part) → Series (one per study) → Images (multiple)

Register a new patient into the local MWL system. 

Creates MWL entry with attributes for patient demographics. Each selected body part will result in a separate MWL entry (future:\+ separate studies).

Transaction flow:\+
\begin{DoxyEnumerate}

\item COMMIT (or ROLLBACK on error)
