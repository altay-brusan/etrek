\doxysubsection{Detailed Description}
a helper class used by \doxylink{classvtk_x_m_l_writer2}{vtk\+XMLWriter2} subclasses that write composite datasets. 

\doxylink{classvtk_x_m_l_composite_data_set_writer_helper}{vtk\+XMLComposite\+Data\+Set\+Writer\+Helper} is a helper class intended to be used by subclasses of \doxylink{classvtk_x_m_l_writer2}{vtk\+XMLWriter2} that want to write composite datasets. It consolidates the logic to write individual datasets for leaf nodes into separate files.

Write a specific dataset to a file. \doxylink{requirements_The}{The} dataset cannot be a composite dataset. \doxylink{requirements_The}{The} implementation uses {\ttfamily \doxylink{classvtk_x_m_l_data_object_writer}{vtk\+XMLData\+Object\+Writer}} to find a writer to use. Internally, writers are cached and will be reused when same type of data is being written out multiple times.

\doxylink{requirements_The}{The} filename is created using the {\ttfamily path} and {\ttfamily prefix}. \doxylink{requirements_The}{The} prefix is extended with a {\ttfamily .\texorpdfstring{$<$}{<}ext\texorpdfstring{$>$}{>}} where the {\ttfamily \texorpdfstring{$<$}{<}ext\texorpdfstring{$>$}{>}} is dictated by the writer used. {\ttfamily \doxylink{classvtk_x_m_l_writer_base_ac33fc1ea19199e3de8feb2210daa373b}{vtk\+XMLWriter\+Base::\+\+Get\+Default\+File\+Extension}} is used to obtain the extension to use for the file written out.

On success, returns {\ttfamily \texorpdfstring{$<$}{<}prefix\texorpdfstring{$>$}{>}.\texorpdfstring{$<$}{<}ext\texorpdfstring{$>$}{>}}, otherwise an empty string is returned.
