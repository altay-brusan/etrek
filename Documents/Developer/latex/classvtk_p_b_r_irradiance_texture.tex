\doxysubsection{Detailed Description}
precompute irradiance texture used in physically based rendering 

Irradiance texture is a cubemap which average light of a hemisphere of the input texture. \doxylink{requirements_The}{The} input texture can be a cubemap or an equirectangular projection. It is used in Image Base Lighting to compute the diffuse part.
