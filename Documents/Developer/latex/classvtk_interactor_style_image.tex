\doxysubsection{Detailed Description}
interactive manipulation of the camera specialized for images 

\doxylink{classvtk_interactor_style_image}{vtk\+Interactor\+Style\+Image} allows the user to interactively manipulate (rotate, pan, zoom etc.) the camera. \doxylink{classvtk_interactor_style_image}{vtk\+Interactor\+Style\+Image} is specially designed to work with images that are being rendered with \doxylink{classvtk_image_actor}{vtk\+Image\+Actor}. Several events are overloaded from its superclass \doxylink{classvtk_interactor_style}{vtk\+Interactor\+Style}, hence the mouse bindings are different. (\doxylink{requirements_The}{The} bindings keep the camera\textquotesingle{}s view plane normal perpendicular to the x-\/y plane.) In summary the mouse events for 2D image interaction are as follows:\+
\begin{DoxyItemize}
\item Left Mouse button triggers window level events
\item CTRL Left Mouse spins the camera around its view plane normal
\item SHIFT Left Mouse pans the camera
\item CTRL SHIFT Left Mouse dollys (a positional zoom) the camera
\item Middle mouse button pans the camera
\item Right mouse button dollys the camera.
\item SHIFT Right Mouse triggers pick events
\end{DoxyItemize}

If Set\+Interaction\+Mode\+To\+Image\+Slicing() is called, then some of the mouse events are changed as follows:\+
\begin{DoxyItemize}
\item CTRL Left Mouse slices through the image
\item SHIFT Middle Mouse slices through the image
\item CTRL Right Mouse spins the camera
\end{DoxyItemize}

If Set\+Interaction\+Mode\+To\+Image3\+D() is called, then some of the mouse events are changed as follows:\+
\begin{DoxyItemize}
\item SHIFT Left Mouse rotates the camera for oblique slicing
\item SHIFT Middle Mouse slices through the image
\item CTRL Right Mouse also slices through the image
\end{DoxyItemize}

In all modes, the following key bindings are in effect:\+
\begin{DoxyItemize}
\item R Reset the Window/\+\+Level
\item X Reset to a sagittal view
\item Y Reset to a coronal view
\item Z Reset to an axial view
\end{DoxyItemize}

Note that the renderer\textquotesingle{}s actors are not moved; instead the camera is moved.
