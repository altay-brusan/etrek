\doxysubsection{Detailed Description}
perform Discrete Fourier Transforms 

\doxylink{classvtk_f_f_t}{vtk\+FFT} provides methods to perform Discrete Fourier Transforms (DFT). These include providing forward and reverse Fourier transforms. \doxylink{requirements_The}{The} current implementation uses the third-\/party library kissfft.

\doxylink{requirements_The}{The} terminology tries to follow the Numpy terminology, that is :\+
\begin{DoxyItemize}
\item Fft means the Fast Fourier Transform algorithm
\item Prefix {\ttfamily R} stands for Real (meaning optimized function for real inputs)
\item Prefix {\ttfamily I} stands for Inverse
\end{DoxyItemize}

Some functions provides pointer-\/based version of themself in order to prevent copying memory when possible.

Useful type definitions and utilities.

\doxylink{classvtk_f_f_t_a1cbfbb961b91211116bc1d71de240f56}{Scalar\+Number} is defined as a floating point number.

Complex\+Number is defined as a struct that contains two \doxylink{classvtk_f_f_t_a1cbfbb961b91211116bc1d71de240f56}{Scalar\+Number}. These 2 numbers should be contiguous in memory. First one should be named r and represent the real part, while second one should be named i and represent the imaginary part. This specification is important for the implementation of functions accepting and returning values from vtk\+Data\+Arrays as it allows to do some zero-\/copy operations.

A vtk\+Scalar\+Number\+Array is a data array with a layout memory compatible with the underlying library for zero copy operations.

\doxylink{structvtk_f_f_t_1_1is_fft_type}{is\+Fft\+Type} is a trait to tell templates if Type is either \doxylink{classvtk_f_f_t_a1cbfbb961b91211116bc1d71de240f56}{Scalar\+Number} or Complex\+Number.
