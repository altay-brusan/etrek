\doxysubsection{Detailed Description}
Extends the \doxylink{classvtk_widget_representation}{vtk\+Widget\+Representation} to help positioning widget in space and how it should be displayed regarding to input bounds. 

This adds an Outline feature for the widget:\+ an interactive box can be displayed, representing the bounding box of the widget. This is usually initialized with some input data bounding box (for instance when using widget to create a slice).

Then, different flags control the behavior of the widget origin interactions:\+
\begin{DoxyItemize}
\item Outside\+Bounds:\+ when on (default), the origin of the widget can move outside the Initial\+Bounds (see \doxylink{classvtk_widget_representation_ace46ae42c9beea7b5ab1f74b62cddf28}{vtk\+Widget\+Representation::\+\+Place\+Widget})
\item Constrain\+To\+Widget\+Bounds:\+ when on (default), the origin of the Widget cannot move outside the Widget\+Bounds. When off, the Outline is extended as needed to contains the origin. 
\end{DoxyItemize}
