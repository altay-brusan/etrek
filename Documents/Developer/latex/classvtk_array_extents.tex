\doxysubsection{Detailed Description}
Stores the number of dimensions and valid coordinate ranges along each dimension for \doxylink{classvtk_array}{vtk\+Array}. 

\doxylink{classvtk_array_extents}{vtk\+Array\+Extents} describes the number of dimensions and coordinate ranges along each dimension of an N-\/way collection of values. It is used to retrieve and update the extents of a \doxylink{classvtk_array}{vtk\+Array} object.

Conceptually, \doxylink{classvtk_array_extents}{vtk\+Array\+Extents} is a collection of \doxylink{classvtk_array_range}{vtk\+Array\+Range} objects, one per dimension, that store the half-\/open range of valid coordinates (the "{}extent"{}) for that dimension. Because each extent is stored as a range rather than a size, you can:\+ create arrays that use one-\/based coordinates for consistency with mathematics and tools such as MATLAB; easily represent arbitrary subsets of an array; and easily store and manipulate distributed arrays using "{}global"{} coordinates.

Convenience constructors are provided for creating extents along one, two, and three dimensions. For higher dimensions, you can:\+

Use the static \doxylink{classvtk_array_extents_a020eeea36de725a36826b03fc3bc9ee7}{Uniform()} factory method to create extents that have the same size along an arbitrary number of dimensions.

Use the default constructor and the \doxylink{classvtk_array_extents_aa32a1b8fae197e217124aae04766e62e}{Append()} method to "{}grow"{} your extents to the correct number of dimensions.

Use the default constructuor, \doxylink{classvtk_array_extents_a8f36272baca5d7265a1762e621800bcd}{Set\+Dimensions()} and operator\+[]\+ to assign a size along each dimension.

Returns true iff every range in the current extents is zero-\/based. This is useful as a precondition test for legacy filters/\+operations that predate the switch to range-\/based extents and assume that all extents are zero-\/based. In general, new code should be written to work with arbitrary range extents, so won\textquotesingle{}t need to perform this check.
