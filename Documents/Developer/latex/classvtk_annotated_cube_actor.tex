\doxysubsection{Detailed Description}
a 3D cube with face labels 

\doxylink{classvtk_annotated_cube_actor}{vtk\+Annotated\+Cube\+Actor} is a hybrid 3D actor used to represent an anatomical orientation marker in a scene. \doxylink{requirements_The}{The} class consists of a 3D unit cube centered on the origin with each face labelled in correspondence to a particular coordinate direction. For example, with Cartesian directions, the user defined text labels could be:\+ +X, -\/X, +Y, -\/Y, +Z, -\/Z, while for anatomical directions:\+ A, P, L, R, S, I. Text is automatically centered on each cube face and is not restriceted to single characters. In addition to or in replace of a solid text label representation, the outline edges of the labels can be displayed. \doxylink{requirements_The}{The} individual properties of the cube, face labels and text outlines can be manipulated as can their visibility.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_annotated_cube_actor}{vtk\+Annotated\+Cube\+Actor} is primarily intended for use with \doxylink{classvtk_orientation_marker_widget}{vtk\+Orientation\+Marker\+Widget}. \doxylink{requirements_The}{The} cube face text is generated by \doxylink{classvtk_vector_text}{vtk\+Vector\+Text} and therefore the font attributes are restricted.
\end{DoxyWarning}
