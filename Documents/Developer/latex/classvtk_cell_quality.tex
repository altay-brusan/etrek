\doxysubsection{Detailed Description}
Calculate functions of quality of the elements of a mesh. 

\doxylink{classvtk_cell_quality}{vtk\+Cell\+Quality} computes one or more functions of (geometric) quality for each cell of a mesh. \doxylink{requirements_The}{The} per-\/cell quality is added to the mesh\textquotesingle{}s cell data, in an array named "{}\+Cell\+Quality."{} Cell types not supported by this filter or undefined quality of supported cell types will have an entry of -\/1.

\begin{DoxyWarning}{Warning}
Most quadrilateral quality functions are intended for planar quadrilaterals only. \doxylink{requirements_The}{The} minimal angle is not, strictly speaking, a quality function, but it is provided because of its usage by many authors.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly. 
\end{DoxyWarning}
