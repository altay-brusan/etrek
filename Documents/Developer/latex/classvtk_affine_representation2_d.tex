\doxysubsection{Detailed Description}
represent 2D affine transformations 

This class is used to represent a \doxylink{classvtk_affine_widget}{vtk\+Affine\+Widget}. This representation consists of three parts:\+ a box, a circle, and a cross. \doxylink{requirements_The}{The} box is used for scaling and shearing, the circle for rotation, and the cross for translation. These parts are drawn in the overlay plane and maintain a constant size (width and height) specified in terms of normalized viewport coordinates.

\doxylink{requirements_The}{The} representation maintains an internal transformation matrix (see superclass\textquotesingle{} \doxylink{classvtk_affine_representation2_d_a0f12e2a7a41388cf722de1a90e530409}{Get\+Transform()} method). \doxylink{requirements_The}{The} transformations generated by this widget assume that the representation lies in the x-\/y plane. If this is not the case, the user is responsible for transforming this representation\textquotesingle{}s matrix into the correct coordinate space (by judicious matrix multiplication). Note that the transformation matrix returned by \doxylink{classvtk_affine_representation2_d_a0f12e2a7a41388cf722de1a90e530409}{Get\+Transform()} is relative to the last \doxylink{classvtk_affine_representation2_d_a13df483343d94ffd4e777e27f26a8acd}{Place\+Widget()} invocation. (\doxylink{requirements_The}{The} \doxylink{classvtk_affine_representation2_d_a13df483343d94ffd4e777e27f26a8acd}{Place\+Widget()} sets the origin around which rotation and scaling occurs; the origin is the center point of the bounding box provided.)
