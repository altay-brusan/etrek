\doxysubsection{Detailed Description}
Store the finite/\+entire range for a single component of a cell-\/attribute.

Each \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid} instance holds a map of these structures to accelerate range lookups and passes in the address of this map to us before running the query. This way the object holding the cell-\/attributes holds their cached ranges.

\doxylink{requirements_The}{The} \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute} itself cannot hold its cached component-\/ranges because it may be referenced by multiple \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid} instances.
