Detailed Description

An iterator for iterating over all the files (and folders) contained in a given filesystem location. OFdirectory_iterator implements a subset of the functionality described as std::filesystem::directory_iterator, see http://en.cppreference.com/w/cpp/filesystem/directory_iterator for more information.
