\doxylink{classvtk_o_b_j_exporter}{vtk\+OBJExporter} is a concrete subclass of \doxylink{classvtk_exporter}{vtk\+Exporter} that writes wavefront .OBJ files in ASCII form. It also writes out a mtl file that contains the material properties. \doxylink{requirements_The}{The} filenames are derived by appending the .obj and .mtl suffix onto the user specified File\+Prefix.
