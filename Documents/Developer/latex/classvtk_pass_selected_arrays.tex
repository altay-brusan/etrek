pass through chosen arrays 

\doxylink{classvtk_pass_selected_arrays}{vtk\+Pass\+Selected\+Arrays} can be used to pass through chosen arrays. It is intended as a replacement for \doxylink{classvtk_pass_arrays}{vtk\+Pass\+Arrays} filter with a more standard API that uses {\ttfamily \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection}} to choose arrays to pass through.

To enable/\+disable arrays to pass, get the appropriate {\ttfamily \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection}} instance using {\ttfamily Get\+Array\+Selection} or the association specific get methods such as {\ttfamily Get\+Point\+Data\+Array\+Selection}, {\ttfamily Get\+Cell\+Data\+Array\+Selection} etc. and then enable/\+disable arrays using {\ttfamily \doxylink{classvtk_data_array_selection}{vtk\+Data\+Array\+Selection}} API. Using vtk\+Data\+Array\+Selection::\+\+Set\+Unknown\+Array\+Setting\`{} one also dictate how arrays not explicitly listed are to be handled.
