\doxysubsection{Detailed Description}
A class to handle a series cache (list of items). This is the middle level in the hierarchical cache structure. This class is used by \doxylink{class_d_v_study_cache}{DVStudy\+Cache}. \doxylink{requirements_The}{The} internal structure is a list of \doxylink{class_d_v_instance_cache}{DVInstance\+Cache}.
