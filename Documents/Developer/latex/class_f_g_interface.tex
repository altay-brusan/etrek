Checking might be time consuming on functional groups with many frames, though disabling might result in invalid functional group structures. Disabling should only be done if the user knows that the functional groups are valid, wants to to adapt the functional groups manually after calling \doxylink{class_f_g_interface_a68659c652400f5787eda2b5e84cdfaf5}{write()} or knows what he\textquotesingle{}s doing otherwise.~\newline
