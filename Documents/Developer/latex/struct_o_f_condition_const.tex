\doxysubsection{Detailed Description}
A constant data structure which can be used for an \doxylink{class_o_f_condition}{OFCondition}. \doxylink{requirements_The}{The} reason this exists is because we need a trivially constructible class (= needs no constructor to be run before being usable) that can hold static condition codes.
