\doxysubsection{Detailed Description}
\doxylink{classvtk_widget_representation}{vtk\+Widget\+Representation} for a poly line. 

\doxylink{classvtk_poly_line_representation}{vtk\+Poly\+Line\+Representation} is a \doxylink{classvtk_curve_representation}{vtk\+Curve\+Representation} for a poly line. This 3D widget defines a poly line that can be interactively placed in a scene. \doxylink{requirements_The}{The} poly line has handles, the number of which can be changed, plus the widget can be picked on the poly line itself to translate or rotate it in the scene.
