\doxysubsection{Detailed Description}
Abstract base class for VTK-\/\+XML writers. 

\doxylink{classvtk_x_m_l_writer_base}{vtk\+XMLWriter\+Base} class was created to help refactor XML writers (\doxylink{classvtk_x_m_l_writer}{vtk\+XMLWriter} and subclasses). Get/\+\+Set API on \doxylink{classvtk_x_m_l_writer}{vtk\+XMLWriter} is moved here while all the gory implementation details are left in \doxylink{classvtk_x_m_l_writer}{vtk\+XMLWriter}. This enables use to create a sibling hierarchy to \doxylink{classvtk_x_m_l_writer}{vtk\+XMLWriter} that uses a cleaner design to implement the IO capabilities. Eventually, we \doxylink{classvtk_x_m_l_writer}{vtk\+XMLWriter} and its children will be substituted by a parallel hierarchy at which point this class may merge with it\textquotesingle{}s new subclass.
