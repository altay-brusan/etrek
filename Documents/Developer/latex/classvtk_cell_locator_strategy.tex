\doxysubsection{Detailed Description}
implement a specific \doxylink{classvtk_point_set_a986526d35be66c4553b9521522935941}{vtk\+Point\+Set::\+\+Find\+Cell()} strategy based on using a cell locator 

\doxylink{classvtk_cell_locator_strategy}{vtk\+Cell\+Locator\+Strategy} is implements a \doxylink{classvtk_cell_locator_strategy_adf61f35f5d2e002e5cc258f4116eaa04}{Find\+Cell()} strategy based on using the \doxylink{classvtk_cell_locator_strategy_adf61f35f5d2e002e5cc258f4116eaa04}{Find\+Cell()} method in a cell locator. This is often the slowest strategy, but the most robust.
