Global timeout in seconds for sending data on a socket to a remote host. \doxylink{requirements_The}{The} default value is 60, which is useful in cases where the sender (e.\+g. storescu) looses the connection to the receiver because the network cable is pulled (e.\+g. for a mobile device). A value of 0 means that the send() will never timeout, and a value of -\/1 disables the call of the corresponding setsockopt() function, so that the system\textquotesingle{}s default behavior remains unchanged.
