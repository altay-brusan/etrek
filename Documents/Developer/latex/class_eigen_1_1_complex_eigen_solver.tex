\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen::\+\+Complex\+Eigen\+Solver$<$ \+\_\+\+Matrix\+Type $>$}
Computes eigenvalues and eigenvectors of general complex matrices. 

\textbackslash{}eigenvalues\+\_\+module


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the matrix of which we are computing the eigendecomposition; this is expected to be an instantiation of the \doxylink{class_eigen_1_1_matrix}{Matrix} class template.\\
\hline
\end{DoxyTemplParams}
\doxylink{requirements_The}{The} eigenvalues and eigenvectors of a matrix $ A $ are scalars $ \lambda $ and vectors $ v $ such that  $ Av = \lambda v
$. If $ D $ is a diagonal matrix with the eigenvalues on the diagonal, and $ V $ is a matrix with the eigenvectors as its columns, then $ A V = V D $. \doxylink{requirements_The}{The} matrix $ V $ is almost always invertible, in which case we have  $ A = V D V^{-1}
$. This is called the eigendecomposition.

\doxylink{requirements_The}{The} main function in this class is \doxylink{class_eigen_1_1_complex_eigen_solver_af5acd2af1ffbc97c798c06902b26b6c4}{compute()}, which computes the eigenvalues and eigenvectors of a given function. \doxylink{requirements_The}{The} documentation for that function contains an example showing the main features of the class.

This function computes the eigenvalues of the complex matrix {\ttfamily matrix}. \doxylink{requirements_The}{The} \doxylink{class_eigen_1_1_complex_eigen_solver_a021de3dc1f37d4426a639eea39f9caae}{eigenvalues()} function can be used to retrieve them. If {\ttfamily compute\+Eigenvectors} is true, then the eigenvectors are also computed and can be retrieved by calling \doxylink{class_eigen_1_1_complex_eigen_solver_a3f455e33d41cde76f622f9b21f536be3}{eigenvectors()}.

\doxylink{requirements_The}{The} matrix is first reduced to Schur form using the \doxylink{class_eigen_1_1_complex_schur}{Complex\+Schur} class. \doxylink{requirements_The}{The} Schur decomposition is then used to compute the eigenvalues and eigenvectors.

\doxylink{requirements_The}{The} cost of the computation is dominated by the cost of the Schur decomposition, which is $ O(n^3) $ where $ n $ is the size of the matrix.
