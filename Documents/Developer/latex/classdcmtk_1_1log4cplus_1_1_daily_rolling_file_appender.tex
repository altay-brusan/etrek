\doxysubsection{Detailed Description}
\doxylink{classdcmtk_1_1log4cplus_1_1_daily_rolling_file_appender}{Daily\+Rolling\+File\+Appender} extends {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_file_appender}{File\+Appender}} so that the underlying file is rolled over at a user chosen frequency.

\doxysubsubsubsection*{Properties}

Properties additional to {\ttfamily \doxylink{classdcmtk_1_1log4cplus_1_1_file_appender}{File\+Appender}}\textquotesingle{}s properties:\+


\begin{DoxyDescription}
\item[{\parbox[t]{\linewidth}{{\ttfamily Schedule} }}]\hfill \\
This property specifies rollover schedule. \doxylink{requirements_The}{The} possible values are {\ttfamily MONTHLY}, {\ttfamily WEEKLY}, {\ttfamily DAILY}, {\ttfamily TWICE\+\_\+\+DAILY}, {\ttfamily HOURLY} and {\ttfamily MINUTELY}.


\item[{\parbox[t]{\linewidth}{{\ttfamily Max\+Backup\+Index} }}]\hfill \\
This property limits how many backup files are kept per single logging period; e.\+g. how many {\ttfamily log.\+2009-\/11-\/07.\+1}, {\ttfamily log.\+2009-\/11-\/07.\+2} etc. files are kept.


\end{DoxyDescription}
