\doxysubsection{Detailed Description}
Key for \doxylink{classvtk_object_base}{vtk\+Object\+Base} vector values. 

\doxylink{classvtk_information_object_base_vector_key}{vtk\+Information\+Object\+Base\+Vector\+Key} is used to represent keys for double vector values in \doxylink{vtk_information_8h_source}{vtk\+Information.\+h}. NOTE the interface in this key differs from that in other similar keys because of our internal use of smart pointers.
