\doxysubsection{Detailed Description}
Generic algorithm superclass for image algs. 

\doxylink{classvtk_image_algorithm}{vtk\+Image\+Algorithm} is a filter superclass that hides much of the pipeline complexity. It handles breaking the pipeline execution into smaller extents so that the \doxylink{classvtk_image_data}{vtk\+Image\+Data} limits are observed. It also provides support for multithreading. If you don\textquotesingle{}t need any of this functionality, consider using \doxylink{classvtk_simple_image_to_image_filter}{vtk\+Simple\+Image\+To\+Image\+Filter} instead. \begin{DoxySeeAlso}{See also}
\doxylink{classvtk_simple_image_to_image_filter}{vtk\+Simple\+Image\+To\+Image\+Filter} 
\end{DoxySeeAlso}
