class vtk\+Mapped\+Unstructured\+Grid\+Cell\+Iterator$<$ Implementation $>$}
Default cell iterator for \doxylink{classvtk_mapped_unstructured_grid}{vtk\+Mapped\+Unstructured\+Grid}. 

This class is used by default for vtk\+Mapped\+Unstructed\+Grid instances. It uses random access for data lookups. Custom \doxylink{classvtk_cell_iterator}{vtk\+Cell\+Iterator} implementations should be used instead when random-\/access is inefficient.
