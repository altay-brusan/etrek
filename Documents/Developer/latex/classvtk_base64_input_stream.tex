Reads base64-\/encoded input from a stream. 

\doxylink{classvtk_base64_input_stream}{vtk\+Base64\+Input\+Stream} implements base64 decoding with the \doxylink{classvtk_input_stream}{vtk\+Input\+Stream} interface.
