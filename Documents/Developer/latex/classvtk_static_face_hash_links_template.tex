\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename TInput\+Id\+Type, typename TFace\+Id\+Type$>$\newline
class vtk\+Static\+Face\+Hash\+Links\+Template$<$ TInput\+Id\+Type, TFace\+Id\+Type $>$}
templated hash\+Links for extracting faces from a \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} 

Templated on types of ids defining an edge.

\doxylink{classvtk_static_face_hash_links_template}{vtk\+Static\+Face\+Hash\+Links\+Template} is a templated class for grouping faces of an unstructured grid. \doxylink{requirements_The}{The} faces are grouped by their hash value. Their hash value is the minimum of the ids of the points defining the face of a 3D cells, or the the number of points of the unstructured grid if the cell is a 1D-\/2D.

To use this class first you need to call \doxylink{classvtk_static_face_hash_links_template_a1b6c7dbb72cce27be9def44322c05e2b}{Build\+Hash\+Links()} with the \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} as argument. Then you can use the methods 1) \doxylink{classvtk_static_face_hash_links_template_afc09a9354b7d273a688a0cd417ab3072}{Get\+Number\+Of\+Faces()} to get the number of faces in the grid 2) \doxylink{classvtk_static_face_hash_links_template_a6fff9969d4affcd3d6a03e59acf106ee}{Get\+Number\+Of\+Hashes()} to get the number of hashes 4) \doxylink{classvtk_static_face_hash_links_template_ab71a1faaaee128d1228ca71bf801efe0}{Get\+Number\+Of\+Faces\+In\+Hash()} to get the number of faces in a particular hash 5) \doxylink{classvtk_static_face_hash_links_template_a40aa50b5edb8ca4d82918061ad88e1dd}{Get\+Cell\+Id\+Of\+Faces\+In\+Hash()} to get the cell id of the faces in a particular hash 6) \doxylink{classvtk_static_face_hash_links_template_aa1543fe59a4ee83db720d90873986eda}{Get\+Face\+Id\+Of\+Faces\+In\+Hash()} to get the face id of the faces in a particular hash

In general, this class tries to minimize the memory usage as much as possible. For that reason while to get a face you need to cell id and the face id, so they could be a struct, it\textquotesingle{}s more efficient to store them in two different arrays to minimize the memory usage.

Template parameters:\+ 1) TInput\+Id\+Type:\+ the type of the id of the cells and points of the input grid. If Number of points and number of cells Cells \texorpdfstring{$<$}{<} 2\texorpdfstring{$^\wedge$}{\string^}31 then use vtk\+Type\+Int32. Otherwise, use vtk\+Type\+Int64. 2) TFace\+Id\+Type:\+ the type of the id of the faces of the input grid. Most of the times a cell can have less than 2\texorpdfstring{$^\wedge$}{\string^}7 faces, so use vtk\+Type\+Int8. Otherwise, use vtk\+Type\+Int32 when the input grid has polyhedron cells.

\begin{DoxyWarning}{Warning}
This class handles only linear cells.

This class has been threaded with \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}. Using TBB or other non-\/sequential type (set in the CMake variable VTK\+\_\+\+SMP\+\_\+\+IMPLEMENTATION\+\_\+\+TYPE) may improve performance significantly.
\end{DoxyWarning}
