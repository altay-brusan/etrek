OFConditionConst
Definition ofcond.h:63

use this macro for creating static OFCondition instances. Instead of an OFCondition instance which needs a constructor, an instance of OFConditionConst is created. This avoids the problem of static initializers (and deinitializers) being executed in undefined order (some other static initializer might want to use this OFCondition / OFConditionConst instance).
