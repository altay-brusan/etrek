\doxysubsection{Detailed Description}
Read unstructured Net\+CDF UGRID files. 

This reader read a single 2D mesh for a Net\+CDF UGRID. It will extract points and cells but not edges. Temporal datasets are supported as long as the "{}time"{} variable exists in the file. Supported point types are float and double. Supported cell types are triangle and quad. Supported data array types are \+[u]\+int\+[8/\+16/\+32/\+64]\+, float and double.
