\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
struct OFrvalue$<$ T $>$}
A helper class to \textquotesingle{}tag\textquotesingle{} objects as {\itshape rvalues} to help DCMTK\textquotesingle{}s move emulation employed on pre C++11 compilers. 
\begin{DoxyTemplParams}{Template Parameters}
{\em T} & the base type an rvalue should be create of.\\
\hline
\end{DoxyTemplParams}
\doxylink{struct_o_frvalue}{OFrvalue} wraps the type T inside a zero-\/overhead object employing T\textquotesingle{}s move constructor when possible. \begin{DoxyNote}{Note}
When C++11 support is available, \doxylink{struct_o_frvalue}{OFrvalue$<$\+T$>$} will simply be a type alias for {\itshape T}, since a C++11 compiler handles rvalue reference conversions natively.
\end{DoxyNote}
