\doxysubsection{Detailed Description}
A 2D graphics item for rendering a tree as a dendrogram. 

Draw a tree as a dendrogram \doxylink{requirements_The}{The} input tree\textquotesingle{}s vertex data must contain at least two arrays. \doxylink{requirements_The}{The} first required array is a \doxylink{classvtk_string_array}{vtk\+String\+Array} called "{}node name"{}. This array is used to label the leaf nodes of the tree. \doxylink{requirements_The}{The} second required array is a scalar array called "{}node weight"{}. This array is used by \doxylink{classvtk_tree_layout_strategy}{vtk\+Tree\+Layout\+Strategy} to set any particular node\textquotesingle{}s distance from the root of the tree.

\doxylink{requirements_The}{The} \doxylink{classvtk_newick_tree_reader}{vtk\+Newick\+Tree\+Reader} automatically initializes both of these required arrays in its output tree.
