\doxysubsection{Detailed Description}
draw an image in a rendered 3D scene 

\doxylink{classvtk_image_actor}{vtk\+Image\+Actor} is used to render an image in a 3D scene. \doxylink{requirements_The}{The} image is placed at the origin of the image, and its size is controlled by the image dimensions and image spacing. \doxylink{requirements_The}{The} orientation of the image is orthogonal to one of the x-\/y-\/z axes depending on which plane the image is defined in. This class has been mostly superseded by the \doxylink{classvtk_image_slice}{vtk\+Image\+Slice} class, which provides more functionality than \doxylink{classvtk_image_actor}{vtk\+Image\+Actor}.
