\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_contour_widget}{vtk\+Contour\+Widget} 

\doxylink{requirements_The}{The} \doxylink{classvtk_contour_representation}{vtk\+Contour\+Representation} is a superclass for various types of representations for \doxylink{classvtk_contour_widget}{vtk\+Contour\+Widget}.

\begin{DoxyParagraph}{Managing contour points:\+}
\doxylink{requirements_The}{The} classes \doxylink{classvtk_contour_representation_node}{vtk\+Contour\+Representation\+Node}, \doxylink{classvtk_contour_representation_internals}{vtk\+Contour\+Representation\+Internals}, and \doxylink{classvtk_contour_representation_point}{vtk\+Contour\+Representation\+Point} manage the data structure used to represent nodes and points on a contour. A contour may contain several nodes and several additional points. Nodes are usually the result of user-\/clicked points on the contour. Additional points are created between nodes to generate a smooth curve using some Interpolator -- see the method {\ttfamily Set\+Line\+Interpolator}.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Managing contour points:\+}

\end{DoxyParagraph}
\begin{DoxyParagraph}{}
\doxylink{requirements_The}{The} data structure stores both the world and display positions for every point. (This may seem like a duplication.) \doxylink{requirements_The}{The} default behaviour of this class is to use the World\+Position to do all the math. Typically a point is added at a given display position. Its corresponding world position is computed using the point placer, and stored. Any query of the display position of a stored point is done via the Renderer, which computes the display position given a world position.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Managing contour points:\+}

\end{DoxyParagraph}
\begin{DoxyParagraph}{}
So why maintain the display position? Consider drawing a contour on a volume widget. You might want the contour to be located at a certain world position in the volume or you might want to be overlaid over the window like an Actor2D. \doxylink{requirements_The}{The} default behaviour of this class is to provide the former behaviour.
\end{DoxyParagraph}
\begin{DoxyParagraph}{Managing contour points:\+}

\end{DoxyParagraph}
\begin{DoxyParagraph}{}
To achieve the latter behaviour, override the methods that return the display position (to return the set display position instead of computing it from the world positions) and the method {\ttfamily Build\+Lines()} to interpolate lines using their display positions instead of world positions.
\end{DoxyParagraph}
