\doxysubsection{Detailed Description}
Service for loading medical images from various sources and formats. 

Supported formats:\+
\begin{DoxyItemize}
\item DICOM (.dcm, .dicom, or files without extension)
\item PNG
\item JPEG
\item JPEG2000 (via DCMTK if available)
\item BMP
\item TIFF
\end{DoxyItemize}

Features:\+
\begin{DoxyItemize}
\item Auto-\/detect file format
\item Auto-\/detect bit depth
\item Convert to \doxylink{classvtk_image_data}{vtk\+Image\+Data} for VTK rendering
\item Load from file path or memory (QByte\+Array) 
\end{DoxyItemize}
