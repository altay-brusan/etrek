\doxysubsection{Detailed Description}
Interface class to DICOM data management (dcmdata). NB:\+ This is an internal class of module dcmimgle/\+dcmimage. Please do not use it for accessing DICOM data structures. Instead use the classes and functions provided by dcmdata (e.\+g. class \doxylink{class_dcm_file_format}{Dcm\+File\+Format}, \doxylink{class_dcm_item}{Dcm\+Item}).
