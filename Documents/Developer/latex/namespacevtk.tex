\doxysubsection{Detailed Description}
Specialization of tuple ranges and iterators for \doxylink{classvtk_a_o_s_data_array_template}{vtk\+AOSData\+Array\+Template}.

Generic implementation of tuple ranges and iterators, suitable for \doxylink{classvtk_data_array}{vtk\+Data\+Array} and all subclasses.

Specialization of value ranges and iterators for \doxylink{classvtk_a_o_s_data_array_template}{vtk\+AOSData\+Array\+Template}.

Generic implementation of value ranges and iterators, suitable for \doxylink{classvtk_data_array}{vtk\+Data\+Array} and all subclasses.

This file contains the traits for the implicit array mechanism in VTK. These traits are very much an internal to vtk\+Implicit\+Arrays and normal developers looking to develop a new \doxylink{classvtk_implicit_array}{vtk\+Implicit\+Array} should (ideally) not have to open this file.

In order to ensure that template parameters passed to the \doxylink{classvtk_implicit_array}{vtk\+Implicit\+Array} share a common interface without having to subclass all of them from the same abstract class, we have decided to use a trait mechanism to statically dispatch the functionalities of types passed as template parameters to the array.

There is 1 mandatory traits that a template type to \doxylink{classvtk_implicit_array}{vtk\+Implicit\+Array} must implement:\+
\begin{DoxyItemize}
\item has\+\_\+map\+\_\+trait \texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|} is\+\_\+closure\+\_\+trait:\+ ensures an implementation of int -\/\texorpdfstring{$>$}{>} value
\end{DoxyItemize}

Potential improvements to implicit arrays which would allow for write access would include the following 2 optional traits:\+
\begin{DoxyItemize}
\item has\+\_\+insert\+\_\+trait \texorpdfstring{$\vert$}{|}\texorpdfstring{$\vert$}{|} is\+\_\+reference\+\_\+closure\+\_\+trait:\+ provides an implementation to update the internals of the template type to add or set new values to the array
\item has\+\_\+remove\+\_\+trait:\+ provides an implementation to update the internals of the template to remove values from the array
\end{DoxyItemize}

All the traits defining the behavior of the implicit "{}function"{} or "{}backend"{} to the \doxylink{classvtk_implicit_array}{vtk\+Implicit\+Array} should be composited into the implicit\+\_\+array\+\_\+traits
