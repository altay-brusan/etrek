\doxysubsection{Detailed Description}
a modified version of the PLY 1.\+1 library 

\doxylink{classvtk_p_l_y}{vtk\+PLY} is a modified version of the PLY 1.\+1 library. \doxylink{requirements_The}{The} library has been modified by wrapping in a class (to minimize global symbols); to take advantage of functionality generally not available through the PLY library API; and to correct problems with the PLY library.

\doxylink{requirements_The}{The} original distribution was taken from the Stanford University PLY file format release 1.\+1 (see \href{http://graphics.stanford.edu/data/3Dscanrep/}{\texttt{http:\+/\+/\+graphics.\+stanford.\+edu/\+data/\+3\+Dscanrep/\+}}).
