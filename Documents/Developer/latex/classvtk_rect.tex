\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class vtk\+Rect$<$ T $>$}
templated base type for storage of 2D rectangles. 

This class is a templated data type for storing and manipulating rectangles. \doxylink{requirements_The}{The} memory layout is a contiguous array of the specified type, such that a float\+[4]\+ can be cast to a \doxylink{classvtk_rectf}{vtk\+Rectf} and manipulated. Also a float\+[12]\+ could be cast and used as a \doxylink{classvtk_rectf}{vtk\+Rectf}\+[3]\+.
