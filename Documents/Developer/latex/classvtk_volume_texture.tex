\doxysubsection{Detailed Description}
Creates and manages the volume texture rendered by \doxylink{classvtk_open_g_l_g_p_u_volume_ray_cast_mapper}{vtk\+Open\+GLGPUVolume\+Ray\+Cast\+Mapper}. 

Wraps a \doxylink{classvtk_texture_object}{vtk\+Texture\+Object} for which it selects the appropriate format (depending on the input \doxylink{classvtk_data_array}{vtk\+Data\+Array} type, number of components, etc.) and loads input data. \doxylink{requirements_The}{The} class maintains a set of members of interest to the parent mapper, such as:\+

This class supports streaming the volume data in separate blocks to make it fit in graphics memory (sometimes referred to as bricking). \doxylink{requirements_The}{The} data is split into a user-\/defined number of blocks in such a way that a single sub-\/block (brick) fits completely into GPU memory. A stride is passed to Open\+GL so that it can access the underlying \doxylink{classvtk_data_array}{vtk\+Data\+Array} adequately for each of the blocks to be streamed into GPU memory (back-\/to-\/front for correct composition).

Streaming the volume as separate texture bricks certainly imposes a performance trade-\/off but acts as a graphics memory expansion scheme for devices that would not be able to render higher resoulution volumes otherwise.

\begin{DoxyWarning}{Warning}
There are certain caveats when texture streaming is enabled, given the locality constraint that rendering a single block imposes.
\end{DoxyWarning}

\begin{DoxyItemize}
\item Quality might suffer near the block seams with Shade\+On() (gradient computation at the boundaries needs adjustment).
\item Not all of the features supported by the mapper currently work correctly. This is a list of known issues:\+
\begin{DoxyItemize}
\item Blending modes such as average and additive might compute a different value near the edges.
\end{DoxyItemize}
\item Future work will extend the API to be able to compute an ideal number of partitions and extents based on the platform capabilities.
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
This is an internal class of \doxylink{classvtk_open_g_l_g_p_u_volume_ray_cast_mapper}{vtk\+Open\+GLGPUVolume\+Ray\+Cast\+Mapper}. It assumes there is an active Open\+GL context in methods involving GL calls (Make\+Current() is expected to be called in the mapper beforehand). 
\end{DoxyWarning}
