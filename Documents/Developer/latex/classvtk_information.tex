\doxysubsection{Detailed Description}
Store \doxylink{classvtk_algorithm}{vtk\+Algorithm} input/\+output information. 

\doxylink{classvtk_information}{vtk\+Information} represents information and/\+or data for one input or one output of a \doxylink{classvtk_algorithm}{vtk\+Algorithm}. It maps from keys to values of several data types. Instances of this class are collected in \doxylink{classvtk_information_vector}{vtk\+Information\+Vector} instances and passed to \doxylink{classvtk_algorithm_a4562e3c326792eff6ddac398c170b2a5}{vtk\+Algorithm::\+\+Process\+Request} calls. \doxylink{requirements_The}{The} information and data referenced by the instance on a particular input or output define the request made to the \doxylink{classvtk_algorithm}{vtk\+Algorithm} instance.
