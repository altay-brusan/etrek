\doxysubsection{Detailed Description}
abstract base class for most VTK objects 

\doxylink{classvtk_object}{vtk\+Object} is the base class for most objects in the visualization toolkit. \doxylink{classvtk_object}{vtk\+Object} provides methods for tracking modification time, debugging, printing, and event callbacks. Most objects created within the VTK framework should be a subclass of \doxylink{classvtk_object}{vtk\+Object} or one of its children. \doxylink{requirements_The}{The} few exceptions tend to be very small helper classes that usually never get instantiated or situations where multiple inheritance gets in the way. \doxylink{classvtk_object}{vtk\+Object} also performs reference counting:\+ objects that are reference counted exist as long as another object uses them. Once the last reference to a reference counted object is removed, the object will spontaneously destruct.

\begin{DoxyWarning}{Warning}
Note:\+ in VTK objects should always be created with the \doxylink{classvtk_object_ab522226b135754e829b30804b4572427}{New()} method and deleted with the \doxylink{classvtk_object_base_aa32595c1d2734908fe30344b77b77b32}{Delete()} method. VTK objects cannot be allocated off the stack (i.\+e., automatic objects) because the constructor is a protected method.
\end{DoxyWarning}
