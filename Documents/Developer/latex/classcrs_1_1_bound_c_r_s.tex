\doxysubsection{Detailed Description}
A coordinate reference system with an associated transformation to a target/\+hub \doxylink{classcrs_1_1_c_r_s}{CRS}. 

\doxylink{requirements_The}{The} definition of a \doxylink{classcrs_1_1_c_r_s}{CRS} is not dependent upon any relationship to an independent \doxylink{classcrs_1_1_c_r_s}{CRS}. However in an implementation that merges datasets referenced to differing CRSs, it is sometimes useful to associate the definition of the transformation that has been used with the \doxylink{classcrs_1_1_c_r_s}{CRS} definition. This facilitates the interrelationship of \doxylink{classcrs_1_1_c_r_s}{CRS} by concatenating transformations via a common or hub \doxylink{classcrs_1_1_c_r_s}{CRS}. This is sometimes referred to as "{}early-\/binding"{}. WKT2 permits the association of an abridged coordinate transformation description with a coordinate reference system description in a single text string. In a \doxylink{classcrs_1_1_bound_c_r_s}{Bound\+CRS}, the abridged coordinate transformation is applied to the source \doxylink{classcrs_1_1_c_r_s}{CRS} with the target \doxylink{classcrs_1_1_c_r_s}{CRS} being the common or hub system.

Coordinates referring to a \doxylink{classcrs_1_1_bound_c_r_s}{Bound\+CRS} are expressed into its source/\+base \doxylink{classcrs_1_1_c_r_s}{CRS}.

This abstraction can for example model the concept of TOWGS84 datum shift present in WKT1.
