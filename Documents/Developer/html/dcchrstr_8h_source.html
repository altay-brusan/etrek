28//
29// This implementation does not support 16 bit character sets. Since 8 bit
30// character sets are supported by the class DcmByteString the class
31// DcmCharString is derived from DcmByteString without any extensions.
32//
33// If the extension for 16 bit character sets will be implemented, this class
34// must be derived directly from DcmElement. This class is designed to support
35// the value representations (LO, LT, PN, SH, ST, UC and UT). They are a problem
36// because their value width (1, 2, ... bytes) is specified by the element
37// SpecificCharacterSet (0008,0005) and an implementation must support
38// different value widths that cannot be derived from the value representation.
39//
40
