\doxysubsection{Detailed Description}
A namespace for the exodus database format. 

A namespace for the file-\/per-\/process version of the parallel exodus database format.

A namespace for the exodus change set type.

This set of classes provides a thin wrapper around the exodus\+II internals. It supplants several of the exodus\+II API calls in order to avoid ncredef calls which totally rewrite the existing database and can be very expensive. These routines provide all required variable, dimension, and attribute definitions to the underlying netcdf file with only a single ncredef call.

To use the application must create an \doxylink{class_ioex_1_1_internals}{Internals} instance and call the Internals::\+write\+\_\+meta\+\_\+data() function. This function requires several classes as arguments including:\+ 
\begin{DoxyItemize}
\item \doxylink{class_ioex_1_1_mesh}{Mesh} -- defines mesh global metadata 
\item Block -- defines metadata for each block 
\item \doxylink{struct_ioex_1_1_node_set}{Node\+Set} -- defines metadata for each nodeset 
\item \doxylink{struct_ioex_1_1_side_set}{Side\+Set} -- defines metadata for each sideset 
\item \doxylink{struct_ioex_1_1_communication_meta_data}{Communication\+Meta\+Data} -- global metadata relating to parallel info. 
\end{DoxyItemize}

Calling Internals::\+write\+\_\+meta\+\_\+data(), replaces the following exodus\+II and nemesis API calls:\+ 
\begin{DoxyItemize}
\item ex\+\_\+put\+\_\+init(), 
\item ex\+\_\+put\+\_\+elem\+\_\+block(), 
\item ex\+\_\+put\+\_\+node\+\_\+set\+\_\+param(), 
\item ex\+\_\+put\+\_\+side\+\_\+set\+\_\+param(), 
\item ne\+\_\+put\+\_\+init\+\_\+info(), 
\item ne\+\_\+put\+\_\+loadbal\+\_\+param(), 
\item ne\+\_\+put\+\_\+cmap\+\_\+params(), 
\end{DoxyItemize}
