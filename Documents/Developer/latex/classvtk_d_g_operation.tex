Prepare this instance of \doxylink{classvtk_d_g_operation}{vtk\+DGOperation} to evaluate {\itshape operation\+Name} on the given {\itshape cell\+Type} and {\itshape cell\+Attribute}.

This populates the Evaluators ivar with functors valid for a range of cells corresponding to non-\/blanked \doxylink{structvtk_d_g_cell_1_1_source}{vtk\+DGCell::\+\+Source} instances.

This method returns true upon success and false otherwise. This method returns false if {\itshape operation\+Name} does not name an operator; other inputs are null pointers; or the cell attribute does not provide information on how the attribute should be evaluated on the given cell type.

You should not call the parenthesis operator () if \doxylink{classvtk_d_g_operation_a32e80e3a37687455a9502414d92830b5}{Prepare()} returns false.

If {\itshape include\+Shape} is true (the default), then any transformation of {\itshape cell\+Attribute} by the grid\textquotesingle{}s shape-\/attribute that is needed will be factored into the evaluators. This avoids a double-\/lookup expense (i.\+e., once for {\itshape cell\+Attribute} and again for the shape attribute) when determining which entry in this-\/\texorpdfstring{$>$}{>}Evaluators to invoke for each ID.

For HGrad function spaces, {\itshape include\+Shape} has no effect. For HDiv and HCurl function spaces, this will transform vector values from reference coordinates into world coordinates.
