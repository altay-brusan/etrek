\doxysubsection{Detailed Description}
octree-\/based spatial search object to quickly locate cells 

\doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} is a spatial search object to quickly locate cells in 3D. \doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} uses a uniform-\/level octree subdivision, where each octant (an octant is also referred to as a bucket) carries an indication of whether it is empty or not, and each leaf octant carries a list of the cells inside of it. (An octant is not empty if it has one or more cells inside of it.) Typical operations are intersection with a line to return candidate cells, or intersection with another \doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} to return candidate cells.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} utilizes the following parent class parameters:\+
\begin{DoxyItemize}
\item Automatic (default true)
\item Level (default 8)
\item Max\+Level (default 8)
\item Number\+Of\+Cells\+Per\+Node (default 25)
\item Cache\+Cell\+Bounds (default true)
\item Use\+Existing\+Search\+Structure (default false)
\end{DoxyItemize}
\end{DoxyWarning}
\doxylink{classvtk_cell_locator}{vtk\+Cell\+Locator} does NOT utilize the following parameters:\+
\begin{DoxyItemize}
\item Tolerance
\item Retain\+Cell\+Lists
\end{DoxyItemize}
