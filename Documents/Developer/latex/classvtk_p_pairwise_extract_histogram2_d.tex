\doxysubsection{Detailed Description}
compute a 2D histogram between all adjacent columns of an input \doxylink{classvtk_table}{vtk\+Table} in parallel. 

This class does exactly the same this as \doxylink{classvtk_pairwise_extract_histogram2_d}{vtk\+Pairwise\+Extract\+Histogram2D}, but does it in a multi-\/process environment. After each node computes their own local histograms, this class does an All\+Reduce that distributes the sum of all local histograms onto each node.

Because \doxylink{classvtk_pairwise_extract_histogram2_d}{vtk\+Pairwise\+Extract\+Histogram2D} is a light wrapper around a series of \doxylink{classvtk_extract_histogram2_d}{vtk\+Extract\+Histogram2D} classes, this class just overrides the function that instantiates new histogram filters and returns the parallel version (\doxylink{classvtk_p_extract_histogram2_d}{vtk\+PExtract\+Histogram2D}).
