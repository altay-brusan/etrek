\doxysubsection{Detailed Description}
Persistable entity describing a standardized body part. 

Stores display attributes and internal coding values for a body part used across scan protocols, validation, and UI. Associated with an \doxylink{class_etrek_1_1_scan_protocol_1_1_data_1_1_entity_1_1_anatomic_region}{Anatomic\+Region} to support hierarchical organization in the application. Equality compares only the surrogate key (\doxylink{class_etrek_1_1_scan_protocol_1_1_data_1_1_entity_1_1_body_part_a9488fa7b1c1eb31a6058142f07146ceb}{Id}).
