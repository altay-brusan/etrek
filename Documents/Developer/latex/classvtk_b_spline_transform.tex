\doxysubsection{Detailed Description}
a cubic b-\/spline deformation transformation 

\doxylink{classvtk_b_spline_transform}{vtk\+BSpline\+Transform} computes a cubic b-\/spline transformation from a grid of b-\/spline coefficients. \begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} inverse grid transform is calculated using an iterative method, and is several times more expensive than the forward transform. 
\end{DoxyWarning}
