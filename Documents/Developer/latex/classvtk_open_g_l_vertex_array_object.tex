\doxysubsection{Detailed Description}
\doxylink{requirements_The}{The} Vertex\+Array\+Object class uses, or emulates, vertex array objects. These are extremely useful for setup/\+tear down of vertex attributes, and can offer significant performance benefits when the hardware supports them. 

It should be noted that this object is very lightweight, and it assumes the objects being used are correctly set up. Even without support for VAOs this class caches the array locations, types, etc and avoids repeated look ups. It it bound to a single Shader\+Program object.
