enum DcmStorageMode

Storage mode used for DICOM objects received via C-STORE

Enumerator
DCMSCU_STORAGE_IGNORE 

Ignore any objects received via C-STORE.

DCMSCU_STORAGE_DISK 

Try to store the objects to disk.

DCMSCU_STORAGE_BIT_PRESERVING 

Try to store to disk in bit-preserving mode. This is especially useful for huge files that cannot fully be received in memory since the data is directly streamed to disk. Originally, this was introduced for DICOM signatures which can be kept valid this way.
