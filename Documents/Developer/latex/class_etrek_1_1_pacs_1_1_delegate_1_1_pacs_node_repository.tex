\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_pacs_1_1_repository}{Repository} for PACS server node configuration. 

Implements the \doxylink{namespace_etrek_1_1_pacs_1_1_repository}{Repository} pattern for PACS node data access. Provides CRUD operations for PACS server configurations.

Supported entity types:\+
\begin{DoxyItemize}
\item Archive:\+ DICOM storage/\+query servers
\item MPPS:\+ Modality Performed Procedure Step servers
\end{DoxyItemize}

Each PACS node includes:\+
\begin{DoxyItemize}
\item AE Title (Application Entity Title)
\item Hostname/\+\+IP address
\item Port number
\item Entity type
\item Connection settings
\end{DoxyItemize}
