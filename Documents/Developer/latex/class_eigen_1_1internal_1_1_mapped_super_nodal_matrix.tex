a class to manipulate the L supernodal factor from the \doxylink{class_eigen_1_1_sparse_l_u}{Sparse\+LU} factorization 

This class contain the data to easily store and manipulate the supernodes during the factorization and solution phase of \doxylink{struct_eigen_1_1_sparse}{Sparse} LU. Only the lower triangular matrix has supernodes.

NOTE :\+ This class corresponds to the SCformat structure in \doxylink{class_eigen_1_1_super_l_u}{Super\+LU}
