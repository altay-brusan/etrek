\doxysubsection{Detailed Description}
Non-\/templated superclass for \doxylink{classvtk_weak_pointer}{vtk\+Weak\+Pointer}. 

\doxylink{classvtk_weak_pointer_base}{vtk\+Weak\+Pointer\+Base} holds a pointer to a \doxylink{classvtk_object_base}{vtk\+Object\+Base} or subclass instance, but it never affects the reference count of the \doxylink{classvtk_object_base}{vtk\+Object\+Base}. However, when the \doxylink{classvtk_object_base}{vtk\+Object\+Base} referred to is destroyed, the pointer gets initialized to nullptr, thus avoid dangling references.
