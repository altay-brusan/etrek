\doxysubsection{Detailed Description}
Helper class to perform formatted input from \doxylink{classvtk_resource_stream}{vtk\+Resource\+Stream}. 

\doxylink{classvtk_resource_parser}{vtk\+Resource\+Parser} is a helper class that format input from an associated vtk\+Resource\+Resource. This class defines function to read integers, floats, booleans and strings. Other utility functions such as Read\+Until or Discard\+Until are also available.

Quick how to:\+
\begin{DoxyItemize}
\item Assign a stream to the parser using {\ttfamily \doxylink{classvtk_resource_parser_a488c7bf5a18d0599cb60695521047647}{Set\+Stream}}
\item Perform input using one of the {\ttfamily \doxylink{classvtk_resource_parser_a18efec643bdf279418c14b1bded7c71a}{Parse}} overload
\item Perform low level read using {\ttfamily Parse(char\texorpdfstring{$\ast$}{*}, size)} overload
\item Read data until a predicate is met using {\ttfamily \doxylink{classvtk_resource_parser_a97ad6a7a04acefcc6b985ae8642fa490}{Read\+Until}}
\item Discard data until a predicate is met using {\ttfamily \doxylink{classvtk_resource_parser_addd598447f023b7caf13332ef068bbf6}{Discard\+Until}}
\item Use {\ttfamily \doxylink{classvtk_resource_parser_acba6766d49db5aada030ad0f3b0ffd7a}{Seek}} and {\ttfamily \doxylink{classvtk_resource_parser_aebedcaf2e496d4ece9a09c0cd6f91b9e}{Tell}} functions to modify/\+get cursor position including parser context
\item Use {\ttfamily \doxylink{classvtk_resource_parser_a3f316ccbeabbbf718d87055fd1455933}{Reset}} when the stream has been modified externally 
\end{DoxyItemize}

Main parsing function. 

{\bfseries{{\bfseries{Parsing operation:\+}}}}

\doxylink{requirements_The}{The} parsing operation is divided in 2 {\ttfamily Steps}:\+


\begin{DoxyEnumerate}
\item Leading {\itshape discarded characters} are discarded:\+
\begin{DoxyItemize}
\item A character is a {\itshape discarded characters} if {\ttfamily discard\+Pred} returns {\ttfamily true}.
\item If no {\ttfamily discard\+Pred} is specified, the default predicate is {\ttfamily Discard\+Whitespace}
\item If Stop\+On\+New\+Line is true, this function will return {\ttfamily vtk\+Parse\+Result::\+\+End\+Of\+Line} if it encounters a new line regardless of what {\ttfamily discard\+Pred} returns for {\ttfamily \textbackslash{}n} and {\ttfamily \textbackslash{}r}.
\item If end of stream is reached, returns {\ttfamily vtk\+Parse\+Result::\+\+End\+Of\+Stream}.
\end{DoxyItemize}
\item \doxylink{requirements_The}{The} value is parsed using different algorithms, depending on its type, see below.
\end{DoxyEnumerate}

{\ttfamily vtk\+Parse\+Result::\+\+End\+Of\+Stream} will only be signaled if it is reached during step {\ttfamily 1}. If it is reached during step {\ttfamily 2}, it will return the result of the decoding operation, and return {\ttfamily vtk\+Parse\+Result::\+\+End\+Of\+Stream} during the next Parse step {\ttfamily 1}.

\DoxyHorRuler{0}


{\bfseries{{\bfseries{Supported types:\+}}}} Supported types are {\ttfamily char}, {\ttfamily signed char}, {\ttfamily unsigned char}, {\ttfamily short}, {\ttfamily unsigned short}, {\ttfamily int}, {\ttfamily unsigned int}, {\ttfamily long}, {\ttfamily unsigned long}, {\ttfamily long long}, {\ttfamily unsigned long long}, {\ttfamily float}, {\ttfamily double}, {\ttfamily bool} and {\ttfamily std::\+string}.

{\ttfamily char} parsing will read a byte and will return the value as-\/is.

{\ttfamily std::\+string} parsing reads characters until discard\+Pred returns true. This last character is not appended to the string nor discarded from input.

Other types are parsed using ::\+vtk\+Value\+From\+String.
