\doxysubsection{Detailed Description}
\doxylink{classvtk_c_g_n_s_reader}{vtk\+CGNSReader} creates a multi-\/block dataset and reads unstructured grids and structured meshes from binary files stored in CGNS file format, with data stored at the nodes, cells or faces.

\doxylink{classvtk_c_g_n_s_reader}{vtk\+CGNSReader} is inspired by the Vis\+It CGNS reader originally written by B. Whitlock. \doxylink{classvtk_c_g_n_s_reader}{vtk\+CGNSReader} relies on the low level CGNS API to load data sets and reduce memory footprint.
