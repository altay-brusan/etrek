\doxysubsection{Detailed Description}
Objects for traversal a Hyper\+Tree\+Grid. 

Objects that can perform depth traversal of a hyper tree grid, take into account more parameters (related to the grid structure) than the compact hyper tree cursor implemented in \doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree} can. This is an abstract class. Cursors are created by the Hyper\+Tree\+Grid implementation.

\doxylink{classvtk_hyper_tree}{vtk\+Hyper\+Tree} \doxylink{classvtk_hyper_tree_grid}{vtk\+Hyper\+Tree\+Grid}
\end{DoxySeeAlso}
This supercursor allows to traverse neighbors attached to coface of the current position.
