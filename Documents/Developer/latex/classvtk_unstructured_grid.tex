\doxysubsection{Detailed Description}
dataset represents arbitrary combinations of all possible cell types 

\doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} is a data object that is a concrete implementation of \doxylink{classvtk_data_set}{vtk\+Data\+Set}. \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} represents any combinations of any cell types. This includes 0D (e.\+g., points), 1D (e.\+g., lines, polylines), 2D (e.\+g., triangles, polygons), and 3D (e.\+g., hexahedron, tetrahedron, polyhedron, etc.). \doxylink{classvtk_unstructured_grid}{vtk\+Unstructured\+Grid} provides random access to cells, as well as topological information (such as lists of cells using each point).
