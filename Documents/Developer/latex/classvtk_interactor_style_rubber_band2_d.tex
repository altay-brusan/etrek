\doxysubsection{Detailed Description}
A rubber band interactor for a 2D view. 

\doxylink{classvtk_interactor_style_rubber_band2_d}{vtk\+Interactor\+Style\+Rubber\+Band2D} manages interaction in a 2D view. Camera rotation is not allowed with this interactor style. Zooming affects the camera\textquotesingle{}s parallel scale only, and assumes that the camera is in parallel projection mode. \doxylink{requirements_The}{The} style also allows draws a rubber band using the left button. All camera changes invoke Start\+Interaction\+Event when the button is pressed, Interaction\+Event when the mouse (or wheel) is moved, and End\+Interaction\+Event when the button is released. \doxylink{requirements_The}{The} bindings are as follows:\+ Left mouse -\/ Select (invokes a Selection\+Changed\+Event). Right mouse -\/ Zoom. Middle mouse -\/ Pan. Scroll wheel -\/ Zoom.
