\doxysubsection{Detailed Description}
Generate Kuens\textquotesingle{} surface. 

\doxylink{classvtk_parametric_kuen}{vtk\+Parametric\+Kuen} generates Kuens\textquotesingle{} surface. This surface has a constant negative gaussian curvature. For more information about this surface, see Dr. O\textquotesingle{}Niell\textquotesingle{}s page at the \href{http://www.math.ucla.edu/~bon/kuen.html}{\texttt{UCLA Mathematics Department}}. \begin{DoxyParagraph}{Thanks:\+}
Tim Meehan

Kuen\textquotesingle{}s surface.

This function performs the mapping $f(u,v) \rightarrow (x,y,x)$, returning it as Pt. It also returns the partial derivatives Du and Dv. $Pt = (x, y, z), D_u\vec{f} = (dx/du, dy/du, dz/du), D_v\vec{f} = (dx/dv, dy/dv, dz/dv)$ . Then the normal is $N = D_u\vec{f} \times D_v\vec{f}$ .
