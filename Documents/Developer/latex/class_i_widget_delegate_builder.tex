\subsubsection*{template$<$typename Widget\+Type, typename Delegate\+Type$>$\newline
class IWidget\+Delegate\+Builder$<$ Widget\+Type, Delegate\+Type $>$}
Template interface for building a widget and its corresponding delegate. 

In the project, each UI element (widget) has an associated delegate which acts as the controller (MVC-\/like separation). This interface standardizes the construction of these widget-\/delegate pairs.


\begin{DoxyTemplParams}{Template Parameters}
{\em Widget\+Type} & \doxylink{requirements_The}{The} QWidget-\/derived class type. \\
\hline
{\em Delegate\+Type} & \doxylink{requirements_The}{The} delegate class type implementing \doxylink{class_i_delegate}{IDelegate} or similar interface.\\
\hline
\end{DoxyTemplParams}
Builders are responsible for:\+
\begin{DoxyItemize}
\item Creating the widget and delegate.
\item Wiring signals and slots between the widget and delegate.
\item Configuring the delegate based on provided parameters.
\end{DoxyItemize}

Note:\+
\begin{DoxyItemize}
\item Raw pointers are returned so that Qt\textquotesingle{}s parent-\/child mechanism can manage object lifetimes automatically.
\item \doxylink{requirements_The}{The} builder receives:\+
\begin{DoxyItemize}
\item {\ttfamily parent\+Widget} to set as the QWidget parent.
\item {\ttfamily parent\+Delegate} to set as the delegate parent (QObject-\/based).
\item {\ttfamily \doxylink{struct_delegate_parameter}{Delegate\+Parameter}} containing settings or configuration read from settings files or runtime context. 
\end{DoxyItemize}
\end{DoxyItemize}
