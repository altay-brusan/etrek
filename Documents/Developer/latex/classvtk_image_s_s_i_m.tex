\doxysubsection{Detailed Description}
This filter implements an algorithm based on SSIM for image comparison. 

\doxylink{requirements_The}{The} SSIM (Structural Similarity Index Measure) is a method for measuring the similarity between two images. \doxylink{requirements_The}{The} SSIM index was originally proposed in:\+ "{}\+Zhou Wang, Alan C. Bovik, Hamid R. Sheikh, Eero P. Simoncelli, \textquotesingle{}\+Image Quality \+Assessment:\+ From Error Visibility to Structural Similarity\textquotesingle{}, IEEE Transactions on Image Processing, 13(4), 600-\/612, April 2004."{}

This filter takes 2 images as inputs. It will compare the arrays returned by {\ttfamily Get\+Scalars} in the input point data. \doxylink{requirements_The}{The} 2 arrays need te have the same underlying type, and have the same number of components. It outputs a heatmap of SSIM values between -\/1 and 1, measuring the structural similarity between 2 corresponding tiles in the images. Input values are weighted by a Gaussian kernel whose standard deviation is defined as {\ttfamily Patch\+Radius /\+ 3}.

\doxylink{requirements_The}{The} range of the input arrays is important to know for regularizations purposes. 2 constants {\ttfamily c1} and {\ttfamily c2} are set by the filter to avoid divisions by zero without distorting the SSIM computation too much. If {\ttfamily L} is the range of an input channel, then {\ttfamily c1 = 0.\+0001 \texorpdfstring{$\ast$}{*} L \texorpdfstring{$\ast$}{*} L}, and {\ttfamily c2 = 0.\+0009 \texorpdfstring{$\ast$}{*} L \texorpdfstring{$\ast$}{*} L}, as advised by the original paper. \doxylink{requirements_The}{The} range can be automatically computed, or set by the user sungi {\ttfamily \doxylink{classvtk_image_s_s_i_m_add0ead2069df873e4b7fbd179afa6b6d}{Set\+Input\+To\+Lab}}, {\ttfamily \doxylink{classvtk_image_s_s_i_m_a541e7af6a123016400e4c9ee53be0331}{Set\+Input\+To\+RGB}}, {\ttfamily \doxylink{classvtk_image_s_s_i_m_a8c04ca989164f1bdd72b3dde31e8634c}{Set\+Input\+To\+Grayscale}} or {\ttfamily \doxylink{classvtk_image_s_s_i_m_ab4d8fa628ba47774ef75f40e48f6bc02}{Set\+Input\+Range}}.
