\doxysubsection{Detailed Description}
a class defining the representation for a \doxylink{classvtk_q_widget_widget}{vtk\+QWidget\+Widget} 

This class renders a QWidget as a simple \doxylink{classvtk_plane_source}{vtk\+Plane\+Source} with a \doxylink{classvtk_texture}{vtk\+Texture} that contains a \doxylink{classvtk_q_widget_texture}{vtk\+QWidget\+Texture} which imports the Open\+GL texture handle from Qt into the vtk scene. Qt and VTK may need to be using the same graphics context.
