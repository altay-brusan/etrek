\doxysubsection{Detailed Description}
\doxylink{class_o_ferror__category}{OFerror\+\_\+category} serves as the base class for specific error category types, such as OFsystem\+\_\+category. It is possible to make your own error\+\_\+category class. \doxylink{requirements_The}{The} objects of error category classes are treated as singletons, passed by reference. \begin{DoxyNote}{Note}
this implementation is meant to be a subset of the C++11\textquotesingle{}s std::\+error\+\_\+category that lacks the following features:\+ error condition support, iostream category, future category. See:\+ \href{http://en.cppreference.com/w/cpp/error/error_category}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+error/\+error\+\_\+category}} to compare \doxylink{class_o_ferror__category}{OFerror\+\_\+category} against std::\+error\+\_\+category.
\end{DoxyNote}
