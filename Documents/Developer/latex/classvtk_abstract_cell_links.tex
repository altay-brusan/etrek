\doxysubsection{Detailed Description}
an abstract base class for classes that build topological links from points to cells 

\doxylink{classvtk_abstract_cell_links}{vtk\+Abstract\+Cell\+Links} is a family of supplemental objects to \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} and \doxylink{classvtk_cell_types}{vtk\+Cell\+Types}, enabling fast access from points to the cells using the points. \doxylink{classvtk_abstract_cell_links}{vtk\+Abstract\+Cell\+Links} is an array of links, each link representing a list of cell ids using a particular point. \doxylink{requirements_The}{The} information provided by this object can be used to determine neighbors and construct other local topological information.
