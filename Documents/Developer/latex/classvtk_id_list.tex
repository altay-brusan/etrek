\doxysubsection{Detailed Description}
list of point or cell ids 

\doxylink{classvtk_id_list}{vtk\+Id\+List} is used to represent and pass data id\textquotesingle{}s between objects. \doxylink{classvtk_id_list}{vtk\+Id\+List} may represent any type of integer id, but usually represents point and cell ids.
