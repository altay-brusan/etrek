Detailed Description

Provides file-based logging services for the application.

LoggerProvider is currently limited to managing file loggers using spdlog's rotating file sink. It is responsible for initializing log file settings, creating and retrieving loggers for services, and ensuring thread-safe access to logger resources.

Future extensions may introduce support for other logging backends (e.g., XML, in-memory, network). In such cases, an abstract base class (interface) should be introduced to allow polymorphic use of different logger providers, each with their own initialization and configuration requirements.
