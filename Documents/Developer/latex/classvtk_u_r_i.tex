\doxysubsection{Detailed Description}
URI representation. 

This class is final and immutable.
\begin{DoxyItemize}
\item Use {\ttfamily \doxylink{classvtk_u_r_i_afa8affe6568269b70a11727e0035d99b}{vtk\+URI::\+\+Parse}} to create an URI from its string representation.

\item Use {\ttfamily \doxylink{classvtk_u_r_i_a56839a3d41d3a799de37ef8ffa0ae8cd}{vtk\+URI::\+\+Make}} to create an URI from components directly.
\item Use {\ttfamily \doxylink{classvtk_u_r_i_ac8f3aef68e892adefc93ae2654a848bd}{vtk\+URI::\+\+Resolve}} to merge two URIs.
\item Use {\ttfamily \doxylink{classvtk_u_r_i_a8343d0f857a02fa6e8a0759a503f389e}{vtk\+URI::\+\+Clone}} or member {\ttfamily \doxylink{classvtk_u_r_i_a8343d0f857a02fa6e8a0759a503f389e}{Clone}} if you need to copy an URI.

URI types determination. 

URI can be either:\+
\begin{DoxyItemize}
\item A full \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-3}{\texttt{URI}}:\+ It has a scheme.
\item an \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-4.1}{\texttt{URI reference}}:\+ an URI that is either a relative reference or a full URI.
\item a \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-4.2}{\texttt{relative reference}}, an URI that refers to data that has to be resolved from a base URI prior to loading. It does not define a scheme but defines at least one other component.
\item an \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-4.3}{\texttt{absolute URI}}, an URI that can be used as a base URI. It defines a scheme and no fragment. It may define other components.
\item a \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-4.4}{\texttt{same-\/document reference}}:\+ an URI that defines only a fragment.
\item An empty URI

Create a new \doxylink{classvtk_u_r_i}{vtk\+URI} with specified components. 

Syntax of components is checked in order to ensure that they respect \href{https://datatracker.ietf.org/doc/html/rfc3986\#section-3}{\texttt{RFC3986}}.

If scheme is "{}data"{} (case-\/insensitive), the path is only checked until the beginning of the data. This is done to prevent massive overhead when constructing a big data URI. Data validation has to be performed by the decoding algorithm. \doxylink{classvtk_u_r_i_a076aeb00f1d3a6f9af0a052dca627f72}{vtk\+URI::\+\+Percent\+Decode} does the required checks for raw data URIs.

Percent-\/encoded character are not decoded. Use {\ttfamily \doxylink{classvtk_u_r_i_ab6980965a06766d19ac282ee725b1244}{vtk\+URI::\+\+Percent\+Encode}} if necessary.

Tip:\+ Parameters may be moved-\/in to prevent copy of big strings. This function is not wrapped. If you need to construct an URI from a wrapper, use {\ttfamily Parse(str)}.
