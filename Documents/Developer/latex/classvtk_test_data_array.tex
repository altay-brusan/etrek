\subsubsection*{template$<$class ArrayT$>$\newline
class vtk\+Test\+Data\+Array$<$ Array\+T $>$}
An implementation of \doxylink{classvtk_generic_data_array}{vtk\+Generic\+Data\+Array} for testing fallback algorithms. 

\doxylink{classvtk_test_data_array}{vtk\+Test\+Data\+Array} is derived from \doxylink{classvtk_generic_data_array}{vtk\+Generic\+Data\+Array}, and is deliberately omitted from VTK\textquotesingle{}s whitelist of dispatchable data arrays. It is used to test the fallback mechanisms of algorithms in the case that array dispatch fails.
