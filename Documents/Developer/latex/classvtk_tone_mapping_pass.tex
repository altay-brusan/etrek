\doxysubsection{Detailed Description}
Implement a post-\/processing Tone Mapping. 

Tone mapping is the process of mapping HDR colors to \+[0;1]\+ range. This render pass supports four different modes:\+
\begin{DoxyItemize}
\item Clamp:\+ clamps the color to \+[0;1]\+ range
\item Reinhard:\+ maps the color using formula:\+ x/\+(x+1)
\item Exponential:\+ maps the colors using a coefficient and the formula:\+ 1-\/exp(-\/a\texorpdfstring{$\ast$}{*}x)
\item Generic\+Filmic:\+ maps the color using five parameters that allow to shape the tonemapping curve :\+ Contrast adjust the toe (left part) of the curve; Shoulder adjusts the right part; Mid\+In and Mid\+Out adjusts the middle gray level in percent of the curve for input and output (ie. the halfway point between white and black); and Hdr\+Max is the maximum HDR input that is not clipped. A boolean Use\+ACES allows to use the Academy Color Encoding System.
\end{DoxyItemize}

Advanced tone mapping like Generic\+Filmic, Reinhard or Exponential can be useful when several lights are added to the renderer.
