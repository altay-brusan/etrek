\doxysubsection{Detailed Description}
this class provides a simple C++ encapsulation layer for stdio FILE pointers. All stdio functions on files are directly mapped into member functions. \doxylink{requirements_The}{The} handling of large files (64 bit file systems) is transparent. Instead of type off\+\_\+t, \doxylink{class_o_f_file_a8490f9cb1a5e7bcb6a48e12fa47b223d}{fseek()} and \doxylink{class_o_f_file_a815432fffe399103ac661e57a202a02d}{ftell()} use offile\+\_\+off\+\_\+t which is a 64 bit type if available on the underlying platform. Similarly, getpos() and setpos() use type offile\+\_\+fpos\+\_\+t, which is defined appropriately. This class provides both \doxylink{class_o_f_file_ae79262a03b727f2d513439901aa1a42b}{fclose()} and \doxylink{class_o_f_file_ac980a9c66c2342829281dc2ecebd3746}{pclose()}, but these are equivalent -\/ the code always closes pipes with \doxylink{class_o_f_file_ac980a9c66c2342829281dc2ecebd3746}{pclose()} and files with \doxylink{class_o_f_file_ae79262a03b727f2d513439901aa1a42b}{fclose()}. Finally, an abstraction for errno is provided. Error codes should always be retrieves using methods \doxylink{class_o_f_file_a6629332d9b54b70d47903de082c81dcc}{get\+Last\+Error()} and \doxylink{class_o_f_file_a6d22e3cab9f88a8d553b3f6a3cee3767}{get\+Last\+Error\+String()} which on Unix platforms are based on errno and strerror/\+strerror\+\_\+r, but may be based on other mechanisms on platforms where errno does not exist.
