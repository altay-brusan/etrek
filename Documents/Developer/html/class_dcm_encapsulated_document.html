◆ setOverrideKeys()

void DcmEncapsulatedDocument::setOverrideKeys ( const OFList< OFString > & ovkeys)

Specifies some attributes that should be inserted after encapsulation They will override any identical attributes already existing in the resulting encapsulated DICOM object. The override keys are applied at the very end of the conversion and do not undergo any validity checking.

Parameters
ovkeysoverride keys that can be tags, dictionary names and paths (see DcmPath for syntax). Also it is permitted to set a value if appropriate, e. g. "PatientName=Doe^John" would be a valid overridekey.
Returns
none.
