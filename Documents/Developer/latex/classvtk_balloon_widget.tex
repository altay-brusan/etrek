\doxysubsection{Detailed Description}
popup text balloons above instance of \doxylink{classvtk_prop}{vtk\+Prop} when hovering occurs 

\doxylink{requirements_The}{The} \doxylink{classvtk_balloon_widget}{vtk\+Balloon\+Widget} is used to popup text and/\+or an image when the mouse hovers over an instance of \doxylink{classvtk_prop}{vtk\+Prop}. \doxylink{requirements_The}{The} widget keeps track of (\doxylink{classvtk_prop}{vtk\+Prop},vtk\+Balloon) pairs (where the internal vtk\+Balloon class is defined by a pair of \doxylink{classvtk_std_string}{vtk\+Std\+String} and \doxylink{classvtk_image_data}{vtk\+Image\+Data}), and when the mouse stops moving for a user-\/specified period of time over the \doxylink{classvtk_prop}{vtk\+Prop}, then the vtk\+Balloon is drawn nearby the \doxylink{classvtk_prop}{vtk\+Prop}. Note that an instance of \doxylink{classvtk_balloon_representation}{vtk\+Balloon\+Representation} is used to draw the balloon.

To use this widget, specify an instance of \doxylink{classvtk_balloon_widget}{vtk\+Balloon\+Widget} and a representation (e.\+g., \doxylink{classvtk_balloon_representation}{vtk\+Balloon\+Representation}). Then list all instances of \doxylink{classvtk_prop}{vtk\+Prop}, a text string, and/\+or an instance of \doxylink{classvtk_image_data}{vtk\+Image\+Data} to be associated with each \doxylink{classvtk_prop}{vtk\+Prop}. (Note that you can specify both text and an image, or just one or the other.) You may also wish to specify the hover delay (i.\+e., set in the superclass \doxylink{classvtk_hover_widget}{vtk\+Hover\+Widget}).

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget observes the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
  MouseMoveEvent -\/ occurs when mouse is moved in render window.
  TimerEvent -\/ occurs when the time between events (e.g., mouse move)
               is greater than TimerDuration.
  KeyPressEvent -\/ when the "{}Enter"{} key is pressed after the balloon appears,
                  a callback is activated (e.g., WidgetActivateEvent).
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_balloon_widget}{vtk\+Balloon\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::Move -\/-\/ start the timer
  vtkWidgetEvent::TimedOut -\/-\/ when hovering occurs,
  vtkWidgetEvent::SelectAction -\/-\/ activate any callbacks associated
                                  with the balloon.
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
This widget invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::TimerEvent (when hovering is determined to occur)
  vtkCommand::EndInteractionEvent (after a hover has occurred and the
                                   mouse begins moving again).
  vtkCommand::WidgetActivateEvent (when the balloon is selected with a
                                   keypress).
\end{DoxyPre}

\end{DoxyParagraph}
