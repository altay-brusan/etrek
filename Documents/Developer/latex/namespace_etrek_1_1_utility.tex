\doxysubsection{Detailed Description}
Provides utility functions for converting and handling QDate\+Time objects in UTC and local time formats. 

Provides utility functions for converting between DCMTK and Qt types.

This namespace contains helper functions for type conversion and adaptation between DCMTK (DICOM Toolkit) types and Qt types, such as QString and \doxylink{class_o_f_string}{OFString}.
