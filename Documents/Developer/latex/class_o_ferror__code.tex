\doxysubsection{Detailed Description}
\doxylink{class_o_ferror__code}{OFerror\+\_\+code} is a platform abstracting wrapper for platform specific error codes. Each \doxylink{class_o_ferror__code}{OFerror\+\_\+code} object holds an error code originating from the operating system or some low-\/level interface and a pointer to an object of type \doxylink{class_o_ferror__category}{OFerror\+\_\+category}, which corresponds to the said interface. \doxylink{requirements_The}{The} error code values may be not unique across different error categories. \begin{DoxyNote}{Note}
This implementation is meant to be a subset of the C++11\textquotesingle{}s std::\+error\+\_\+code that lacks the following features:\+ error condition support, iostream category, future category. See:\+ \href{http://en.cppreference.com/w/cpp/error/error_code}{\texttt{http:\+/\+/\+en.\+cppreference.\+com/\+w/\+cpp/\+error/\+error\+\_\+code}} to compare \doxylink{class_o_ferror__code}{OFerror\+\_\+code} against std::\+error\+\_\+code.
\end{DoxyNote}
