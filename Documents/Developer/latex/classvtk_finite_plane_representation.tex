\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_finite_plane_widget}{vtk\+Finite\+Plane\+Widget}. 

This class is a concrete representation for the \doxylink{classvtk_finite_plane_widget}{vtk\+Finite\+Plane\+Widget}. It represents a plane with three handles:\+ one on two faces, plus a center handle. Through interaction with the widget, the plane representation can be arbitrarily positioned and modified in the 3D space.

To use this representation, you normally use the \doxylink{classvtk_finite_plane_representation_ac2c6b170cc3b6f286538b960a64cb52d}{Place\+Widget()} method to position the widget at a specified region in space.
