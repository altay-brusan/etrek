\doxysubsection{Detailed Description}
Stores coordinate into an N-\/way array. 

\doxylink{classvtk_array_coordinates}{vtk\+Array\+Coordinates} stores a collection of coordinates that can be used to access values in a \doxylink{classvtk_array}{vtk\+Array} containing an arbitrary number of dimensions.

Convenience constructors are provided for working with one, two, and three dimensions. For higher dimensions, use the default constructor, \doxylink{classvtk_array_coordinates_a1c111b2577308244a3794a2834b8a686}{Set\+Dimensions()} and operator\+[]\+ to assign a coordinate value along each dimension.
