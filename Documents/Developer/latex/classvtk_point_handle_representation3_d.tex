\doxysubsection{Detailed Description}
represent the position of a point in 3D space 

This class is used to represent a \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget}. It represents a position in 3D world coordinates using a x-\/y-\/z cursor. \doxylink{requirements_The}{The} cursor can be configured to show a bounding box and/\+or shadows.
