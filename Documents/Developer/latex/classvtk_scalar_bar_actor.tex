\doxysubsection{Detailed Description}
Create a scalar bar with labels. 

\doxylink{classvtk_scalar_bar_actor}{vtk\+Scalar\+Bar\+Actor} creates a scalar bar with tick marks. A scalar bar is a legend that indicates to the viewer the correspondence between color value and data value. \doxylink{requirements_The}{The} legend consists of a rectangular bar made of rectangular pieces each colored a constant value. Since \doxylink{classvtk_scalar_bar_actor}{vtk\+Scalar\+Bar\+Actor} is a subclass of \doxylink{classvtk_actor2_d}{vtk\+Actor2D}, it is drawn in the image plane (i.\+e., in the renderer\textquotesingle{}s viewport) on top of the 3D graphics window.

To use \doxylink{classvtk_scalar_bar_actor}{vtk\+Scalar\+Bar\+Actor} you must associate a \doxylink{classvtk_scalars_to_colors}{vtk\+Scalars\+To\+Colors} (or subclass) with it. \doxylink{requirements_The}{The} lookup table defines the colors and the range of scalar values used to map scalar data. Typically, the number of colors shown in the scalar bar is not equal to the number of colors in the lookup table, in which case sampling of the lookup table is performed.

Other optional capabilities include specifying the fraction of the viewport size (both x and y directions) which will control the size of the scalar bar and the number of tick labels. \doxylink{requirements_The}{The} actual position of the scalar bar on the screen is controlled by using the vtk\+Actor2\+D::\+\+Set\+Position() method (by default the scalar bar is centered in the viewport). Other features include the ability to orient the scalar bar horizontally of vertically and controlling the format (printf style) with which to print the labels on the scalar bar. Also, the \doxylink{classvtk_scalar_bar_actor}{vtk\+Scalar\+Bar\+Actor}\textquotesingle{}s property is applied to the scalar bar and annotations (including layer, and compositing operator).

Set the text property/\+attributes of the title and the labels through the \doxylink{classvtk_text_property}{vtk\+Text\+Property} objects associated to this actor.

\begin{DoxyWarning}{Warning}
If a \doxylink{classvtk_log_lookup_table}{vtk\+Log\+Lookup\+Table} is specified as the lookup table to use, then the labels are created using a logarithmic scale.
\end{DoxyWarning}
