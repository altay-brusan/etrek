\doxysubsection{Detailed Description}
dynamic, self-\/adjusting array of bits 

\doxylink{classvtk_bit_array}{vtk\+Bit\+Array} is an array of bits (0/\+1 data value). \doxylink{requirements_The}{The} array is packed so that each byte stores eight bits. \doxylink{classvtk_bit_array}{vtk\+Bit\+Array} provides methods for insertion and retrieval of bits, and will automatically resize itself to hold new data.

\begin{quote}
WARNING This class is not thread-\/safe during write access \end{quote}
