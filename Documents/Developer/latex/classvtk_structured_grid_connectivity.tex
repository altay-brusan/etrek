\doxysubsection{Detailed Description}
\doxylink{classvtk_structured_grid_connectivity}{vtk\+Structured\+Grid\+Connectivity} is a concrete instance of \doxylink{classvtk_object}{vtk\+Object} that implements functionality for computing the neighboring topology within a single partitioned structured grid dataset. This class implementation does not have any support for distributed data. For the parallel implementation see vtk\+PStructured\+Grid\+Connectivity.
