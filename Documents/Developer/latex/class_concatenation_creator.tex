\doxysubsection{Detailed Description}
Class for creating Concatenations from existing SOP Instances. As input, a user can either provide a full SOP Instance with Pixel Data attribute, or a SOP Instance plus separate pixel data as a vector of frame data. \doxylink{requirements_The}{The} input file is uncompressed if necessary and possible, and the resulting concatenation instances will also contain uncompressed pixel data. During conversion, the original source pixel data is held into memory and additionally one of the concatenation instances the moment it is being produced when calling \doxylink{class_concatenation_creator_a46bd33ad1caf8dd1c56c3991c8c10c5e}{write\+Next\+Instance()} (see below). \doxylink{requirements_The}{The} following workflow must be used to create a Concatenation:\+ 
\begin{DoxyItemize}
\item Call to one of the \doxylink{class_concatenation_creator_a7bdf4e0ffe8bd782f5a496772f201b05}{set\+Cfg\+Input()} methods in order to set the concatenation source data, i.\+e. the SOP Instance that should be split into a number of concatenation instances. 
\item Call to other set\+Cfg...() calls in order to set conversion options. For example the number of frames per concatenation instance produced can be configured by calling \doxylink{class_concatenation_creator_aa930812849d588f6bc3b4c0ed31e91a2}{set\+Cfg\+Frames\+Per\+Instance()}. Per default, 25 frames per instance are being used. 
\item Call to one of the \doxylink{class_concatenation_creator_a46bd33ad1caf8dd1c56c3991c8c10c5e}{write\+Next\+Instance()} methods in order to write the next concatenation instance. 
\item Call to the load() method in order to load of the the Concatenations found during scan(). Selection is done via the Concatenations Concatenation UID. \doxylink{requirements_The}{The} result is made available as a single, merged dataset without Pixel Data attribute and a vector containing all frames of the merged instance. 
\end{DoxyItemize}
