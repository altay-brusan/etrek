\doxysubsection{Detailed Description}
compute dot-\/product similarity metrics. 

Treats matrices as collections of vectors and computes dot-\/product similarity metrics between vectors.

\doxylink{requirements_The}{The} results are returned as an edge-\/table that lists the index of each vector and their computed similarity. \doxylink{requirements_The}{The} output edge-\/table is typically used with \doxylink{classvtk_table_to_graph}{vtk\+Table\+To\+Graph} to create a similarity graph.

This filter can be used with one or two input matrices. If you provide a single matrix as input, every vector in the matrix is compared with every other vector. If you provide two matrices, every vector in the first matrix is compared with every vector in the second matrix.

Note that this filter {\itshape only} computes the dot-\/product between each pair of vectors; if you want to compute the cosine of the angles between vectors, you will need to normalize the inputs yourself.

Inputs:\+ Input port 0:\+ (required) A \doxylink{classvtk_dense_array}{vtk\+Dense\+Array$<$double$>$} with two dimensions (a matrix). Input port 1:\+ (optional) A \doxylink{classvtk_dense_array}{vtk\+Dense\+Array$<$double$>$} with two dimensions (a matrix).

Outputs:\+ Output port 0:\+ A \doxylink{classvtk_table}{vtk\+Table} containing "{}source"{}, "{}target"{}, and "{}similarity"{} columns.

\begin{DoxyWarning}{Warning}
Note that the complexity of this filter is quadratic! It also requires dense arrays as input, in the future it should be generalized to accept sparse arrays.
\end{DoxyWarning}
