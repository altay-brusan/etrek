\doxysubsection{Detailed Description}
Class designed to help with merging of points in parallel. 

\doxylink{classvtk_s_m_p_merge_points}{vtk\+SMPMerge\+Points} is a subclass of \doxylink{classvtk_merge_points}{vtk\+Merge\+Points} designed to help with merging of points generated by using multiple locators in parallel. Its main functionality is provided by the Merge function. It also has a few additional convenience functions. Merge is thread safe as long as no two threads are merging the same bin. \doxylink{requirements_The}{The} common way of using \doxylink{classvtk_s_m_p_merge_points}{vtk\+SMPMerge\+Points} is:\+
\begin{DoxyItemize}
\item Initialize with out\+Locator-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_s_m_p_merge_points_a8d617c580ec1452ef9c07b367d383cd9}{Initialize\+Merge()}
\item Allocate points with out\+Locator-\/\texorpdfstring{$>$}{>}Get\+Points()-\/\texorpdfstring{$>$}{>}Resize(num\+Pts) (num\+Pts should be \texorpdfstring{$>$}{>}= total number of points)
\item Do bunch of merging with out\+Locator-\/\texorpdfstring{$>$}{>}Merge(in\+Locator\+[i]\+, ...) (this can be done in parallel as long as no two bins are done at the same time)
\item Fix the size of points with out\+Locator-\/\texorpdfstring{$>$}{>}\doxylink{classvtk_s_m_p_merge_points_a2f34ed900d5d222c1007b18c53288189}{Fix\+Size\+Of\+Point\+Array()}
