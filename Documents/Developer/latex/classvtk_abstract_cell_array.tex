\doxysubsection{Detailed Description}
abstract object to represent cell connectivity 

\doxylink{classvtk_abstract_cell_array}{vtk\+Abstract\+Cell\+Array} is an abstract base class for storing a connectivity table listing the point ids that make up each cell.
