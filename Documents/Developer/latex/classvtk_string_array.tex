\doxysubsection{Detailed Description}
a \doxylink{classvtk_abstract_array}{vtk\+Abstract\+Array} subclass for strings 

Points and cells may sometimes have associated data that are stored as strings, e.\+g. labels for information visualization projects. This class provides a clean way to store and access those strings. \begin{DoxyParagraph}{Thanks:\+}
Andy Wilson (\href{mailto:atwilso@sandia.gov}{\texttt{atwilso@sandia.\+gov}}) wrote this class. 
\end{DoxyParagraph}
