\doxysubsection{Detailed Description}
a simple 2D graph layout 

This class is an implementation of the work presented in:\+ Fruchterman \& Reingold "{}\+Graph Drawing by Force-\/directed Placement"{} Software-\/\+Practice and Experience 21(11) 1991). \doxylink{requirements_The}{The} class includes some optimizations but nothing too fancy.
