\doxysubsection{Detailed Description}
Place points on the surface of polygonal data. 

\doxylink{classvtk_polygonal_surface_point_placer}{vtk\+Polygonal\+Surface\+Point\+Placer} places points on polygonal data and is meant to be used in conjunction with \doxylink{classvtk_polygonal_surface_contour_line_interpolator}{vtk\+Polygonal\+Surface\+Contour\+Line\+Interpolator}.

\begin{DoxyWarning}{Warning}
You should have computed cell normals for the input polydata if you are specifying a distance offset.
