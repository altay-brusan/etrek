\doxysubsection{Detailed Description}
General purpose class hiding global functions, constants and types from the global namespace. Some of them might be moved to \textquotesingle{}ofstd\textquotesingle{} or \textquotesingle{}dcmdata\textquotesingle{} later on. All functions and constants are static and can, therefore, be accessed without creating an instance of this class.
