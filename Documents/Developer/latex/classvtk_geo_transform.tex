\doxysubsection{Detailed Description}
A transformation between two geographic coordinate systems. 

Describe a geographic transform.

This class takes two geographic projections and transforms point coordinates between them.

Describe a geographic transform either using PROJ strings or using \doxylink{classvtk_geo_projection}{vtk\+Geo\+Projection} classes.

WARNING:\+ Normal vectors have to be removed before a transform using this class otherwise the transform will be a no-\/operation. See \doxylink{classvtk_geo_transform_a842d0d35e5c77de9245c2ff743822014}{vtk\+Geo\+Transform::\+\+Internal\+Transform\+Derivative}.
