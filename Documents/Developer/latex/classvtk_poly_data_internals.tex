\doxysubsection{Detailed Description}
Store mapping from \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} cell ids to internal cell array ids. 

Optimized data structure for storing internal cell ids and type information for \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} datasets.

Since \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} only supports a handful of types, the type information is compressed to four bits -- the first two indicate which internal \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} object a cell is stored in (verts, lines, polys, strips), and the second two bits indicate which type of cell (e.\+g. lines vs polylines, triangles vs quads vs polygons, etc), as well as whether or not the cell has been deleted from the \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}.

These four bits are stored at the top of a 64 bit index, and the remaining 60 bits store the cell id. This implies that the internal cell arrays cannot store more than 2\texorpdfstring{$^\wedge$}{\string^}60 cells each, a reasonable limit for modern hardware.
