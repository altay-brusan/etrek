\doxysubsection{Detailed Description}
represent and manipulate 4x4 transformation matrices 

\doxylink{classvtk_matrix4x4}{vtk\+Matrix4x4} is a class to represent and manipulate 4x4 matrices. Specifically, it is designed to work on 4x4 transformation matrices found in 3D rendering using homogeneous coordinates \+[x y z w]\+. Many of the methods take an array of 16 doubles in row-\/major format. Note that Open\+GL stores matrices in column-\/major format, so the matrix contents must be transposed when they are moved between Open\+GL and VTK. \begin{DoxySeeAlso}{See also}
