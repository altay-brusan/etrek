\doxysubsection{Detailed Description}
Class representing a path of DICOM objects. A path is a "{}way"{} through a DICOM dataset, i.\+e. it starts e.\+g. with an item, followed by a sequence originally contained in this item. \doxylink{requirements_The}{The} sequence then could be followed by another item which is part of the sequence and so on. Thus the path should be well-\/formed, but if it is created manually (e.\+g. using \doxylink{class_dcm_path_a4d1b8f10ea3e3b6854137402086dc5df}{append()}) there is no corresponding checking.
