\doxysubsection{Detailed Description}
a list of 2D actors 

\doxylink{classvtk_actor2_d_collection}{vtk\+Actor2\+DCollection} is a subclass of \doxylink{classvtk_collection}{vtk\+Collection}. \doxylink{classvtk_actor2_d_collection}{vtk\+Actor2\+DCollection} maintains a collection of \doxylink{classvtk_actor2_d}{vtk\+Actor2D} objects that is sorted by layer number, with lower layer numbers at the start of the list. This allows the \doxylink{classvtk_actor2_d}{vtk\+Actor2D} objects to be rendered in the correct order.
