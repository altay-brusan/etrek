 GetShaderMTime returns the last time a modification was made that affected the code of the shader (either code replacement was changed or one or more uniform variables were added or removed. Detailed Description

represent GPU shader properties

vtkOpenGLShaderProperty is used to hold user-defined modifications of a GPU shader program used in a mapper.

See also
vtkShaderProperty vtkUniforms vtkOpenGLUniform
