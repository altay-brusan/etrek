\doxysubsection{Detailed Description}
maintain a connection to an SQLite database 

SQLite (\href{http://www.sqlite.org}{\texttt{http:\+/\+/\+www.\+sqlite.\+org}}) is a public-\/domain SQL database written in C++. It\textquotesingle{}s small, fast, and can be easily embedded inside other applications. Its databases are stored in files.

This class provides a VTK interface to SQLite. You do not need to download any external libraries:\+ we include a copy of SQLite 3.\+3.\+16 in VTK/\+\+Utilities/\+vtksqlite.

If you want to open a database that stays in memory and never gets written to disk, pass in the URL {\ttfamily sqlite:\+/\+/\+:\+memory:\+}; otherwise, specify the file path by passing the URL {\ttfamily sqlite:\+/\+/\+\texorpdfstring{$<$}{<}file\+\_\+path\texorpdfstring{$>$}{>}}.
