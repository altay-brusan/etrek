Main interface to serialization, meant to be specialized for the types that require special handling. {\ttfamily diy::\+save()} and {\ttfamily diy::\+load()} call the static member functions of this class. 

\doxylink{requirements_The}{The} default (unspecialized) version copies {\ttfamily sizeof(\+T)} bytes from {\ttfamily \&x} to or from {\ttfamily bb} via its {\ttfamily diy::\+\+Binary\+Buffer::\+save\+\_\+binary()} and {\ttfamily diy::\+\+Binary\+Buffer::\+load\+\_\+binary()} functions. This works out perfectly for plain old data (e.\+g., simple structs).
