\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class vtk\+Label\+Map\+Lookup$<$ T $>$}
provide an efficient numeric label lookup 

\doxylink{structvtk_label_map_lookup}{vtk\+Label\+Map\+Lookup} is a light weight helper object that enables faster lookup of a segmentation label from a set of labels. It uses caching, and different strategies depending on the size of the set of labels.

Note that, due to speed concerns, \doxylink{structvtk_label_map_lookup}{vtk\+Label\+Map\+Lookup} does not inherit from \doxylink{classvtk_object}{vtk\+Object} hence does not support the usual VTK reference counting.
