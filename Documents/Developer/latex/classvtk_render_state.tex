\doxysubsection{Detailed Description}
Context in which a \doxylink{classvtk_render_pass}{vtk\+Render\+Pass} will render. 

\doxylink{classvtk_render_state}{vtk\+Render\+State} is a lightweight effective class which gather information used by a \doxylink{classvtk_render_pass}{vtk\+Render\+Pass} to perform its execution. \begin{DoxyAttention}{Attention}
Get methods are const to enforce that a renderpass cannot modify the Render\+Pass object. It works in conjunction with \doxylink{classvtk_render_pass_ae294a805df37151e743034fd59c2f377}{vtk\+Render\+Pass::\+\+Render} where the argument \doxylink{classvtk_render_state}{vtk\+Render\+State} is const. 
\end{DoxyAttention}
