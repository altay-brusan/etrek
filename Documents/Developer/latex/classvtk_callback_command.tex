\doxysubsection{Detailed Description}
supports function callbacks 

Use \doxylink{classvtk_callback_command}{vtk\+Callback\+Command} for generic function callbacks. That is, this class can be used when you wish to execute a function (of the signature described below) using the Command/\+\+Observer design pattern in VTK. \doxylink{requirements_The}{The} callback function should have the form 
\begin{DoxyPre}
void func(vtkObject*, unsigned long eid, void* clientdata, void *calldata)
\end{DoxyPre}
 where the parameter vtk\+Object\texorpdfstring{$\ast$}{*} is the object invoking the event; eid is the event id (see \doxylink{vtk_command_8h_source}{vtk\+Command.\+h}); clientdata is special data that should is associated with this instance of \doxylink{classvtk_callback_command}{vtk\+Callback\+Command}; and calldata is data that the \doxylink{classvtk_object_a8c10fc51d6ce89760e02d4d81f4f54c3}{vtk\+Object::\+\+Invoke\+Event()} may send with the callback. For example, the invocation of the Progress\+Event sends along the progress value as calldata.
