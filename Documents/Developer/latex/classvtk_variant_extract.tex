\doxysubsection{Detailed Description}
Performs an explicit conversion from a \doxylink{classvtk_variant}{vtk\+Variant} to the type that it contains. Implicit conversions are {\itshape not} performed, so casting a \doxylink{classvtk_variant}{vtk\+Variant} containing one type (e.\+g. double) to a different type (e.\+g. string) will not convert between types.

Callers should use the \textquotesingle{}valid\textquotesingle{} flag to verify whether the extraction succeeded.
