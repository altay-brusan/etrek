Linear Integration Strategy. 

This class inherits from {\ttfamily \doxylink{classvtk_integration_strategy}{vtk\+Integration\+Strategy}} and its integration strategy assumes each cell to be linear. If a cell is not a simplex, it divides the shape into simplices.
