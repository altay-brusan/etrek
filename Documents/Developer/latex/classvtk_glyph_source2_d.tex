\doxylink{classvtk_glyph_source2_d}{vtk\+Glyph\+Source2D} can generate a family of 2D glyphs each of which lies in the x-\/y plane (i.\+e., the z-\/coordinate is zero). \doxylink{requirements_The}{The} class is a helper class to be used with \doxylink{classvtk_glyph2_d}{vtk\+Glyph2D} and \doxylink{classvtk_x_y_plot_actor}{vtk\+XYPlot\+Actor}.

To use this class, specify the glyph type to use and its attributes. Attributes include its position (i.\+e., center point), scale, color, and whether the symbol is filled or not (a polygon or closed line sequence). You can also put a short line through the glyph running from -\/x to +x (the glyph looks like it\textquotesingle{}s on a line), or a cross.

\doxylink{requirements_The}{The} simple arrow can also be double pointed and point inwards.
