\doxysubsection{Detailed Description}
Generate a surface covered with randomly placed hills. 

\doxylink{classvtk_parametric_random_hills}{vtk\+Parametric\+Random\+Hills} generates a surface covered with randomly placed hills. Hills will vary in shape and height since the presence of nearby hills will contribute to the shape and height of a given hill. An option is provided for placing hills on a regular grid on the surface. In this case the hills will all have the same shape and height.

For further information about this surface, please consult the technical description "{}\+Parametric surfaces"{} in \href{http://www.vtk.org/publications}{\texttt{http:\+/\+/\+www.\+vtk.\+org/\+publications}} in the "{}\+VTK Technical Documents"{} section in the VTk.\+org web pages.
