\doxysubsection{Detailed Description}
efficient description of an image stencil 

\doxylink{classvtk_image_stencil_data}{vtk\+Image\+Stencil\+Data} describes an image stencil in a manner which is efficient both in terms of speed and storage space. \doxylink{requirements_The}{The} stencil extents are stored for each x-\/row across the image (multiple extents per row if necessary) and can be retrieved via the \doxylink{classvtk_image_stencil_data_a3cdc3f9b6aa556013b06f61bccdd23b6}{Get\+Next\+Extent()} method. \begin{DoxySeeAlso}{See also}
