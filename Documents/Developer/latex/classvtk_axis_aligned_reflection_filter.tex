\doxysubsection{Detailed Description}
Reflects the input over an axis-\/aligned plane. 

\doxylink{requirements_The}{The} Axis Aligned Reflection filter reflects the input dataset across the specified plane. This filter operates on any type of data set or hyper tree grid and produces a Partitioned Data\+Set Collection containing partitions of the same type as the input (the reflection and the input if Copy\+Input is enabled). Data arrays are also reflected (if Reflect\+All\+Input\+Arrays is false, only Vectors, Normals and Tensors will be reflected, otherwise, all 3, 6 and 9-\/component data arrays are reflected).

\begin{DoxySeeAlso}{See also}
\doxylink{classvtk_reflection_filter}{vtk\+Reflection\+Filter} \doxylink{classvtk_hyper_tree_grid_axis_reflection}{vtk\+Hyper\+Tree\+Grid\+Axis\+Reflection} \doxylink{requirements_The}{The} main difference between \doxylink{classvtk_reflection_filter}{vtk\+Reflection\+Filter} and \doxylink{classvtk_axis_aligned_reflection_filter}{vtk\+Axis\+Aligned\+Reflection\+Filter} is the output \doxylink{struct_o_fremove__volatile}{type} (\doxylink{classvtk_reflection_filter}{vtk\+Reflection\+Filter} produces an Unstructured Grid no matter the input \doxylink{struct_o_fremove__volatile}{type}). Also, \doxylink{classvtk_axis_aligned_reflection_filter}{vtk\+Axis\+Aligned\+Reflection\+Filter} supports Hyper Tree Grids (\doxylink{classvtk_reflection_filter}{vtk\+Reflection\+Filter} does not).
