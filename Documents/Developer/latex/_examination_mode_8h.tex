Defines the operational mode for an examination workflow. 

Different modes affect how acquisitions are handled:\+
\begin{DoxyItemize}
\item CLINICAL:\+ Normal patient examination, creates DICOM objects
\item DEMO:\+ Exhibition mode, loads sample images for demonstration
\item CALIBRATION:\+ Detector/\+generator calibration, no patient data
\item TEST:\+ Device verification, internal testing only 
\end{DoxyItemize}
