\doxysubsection{Detailed Description}
Helper class to create XML files using "{}printf"{}, "{}fprintf"{}, "{}cout"{},... functions. 

\doxylink{requirements_The}{The} \doxylink{struct_to_x_m_l_string_tool}{To\+XMLString\+Tool} class helps you creating XML files using "{}printf"{}, "{}fprintf"{}, "{}cout"{},... functions. \doxylink{requirements_The}{The} "{}\+To\+XMLString\+Tool"{} class is processing strings so that all the characters \&,"{},\textquotesingle{},$<$,$>$ are replaced by their XML equivalent:\+ @verbatim \&, "{}, \textquotesingle{}, <, > \textbackslash{}endverbatim \+Using the "{}\doxylink{struct_to_x_m_l_string_tool}{To\+XMLString\+Tool} class"{} and the "{}fprintf function"{} is THE most efficient way to produce VERY large XML documents VERY fast. \textbackslash{}note If you are creating from scratch an XML file using the provided XMLNode class you must not use the "{}\doxylink{struct_to_x_m_l_string_tool}{To\+XMLString\+Tool}"{} class (because the "{}\doxylink{struct_x_m_l_node}{XMLNode}"{} class does the processing job for you during rendering).
