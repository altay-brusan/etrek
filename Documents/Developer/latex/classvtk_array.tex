\doxysubsection{Detailed Description}
Abstract interface for N-\/dimensional arrays. 

\doxylink{classvtk_array}{vtk\+Array} is the root of a hierarchy of arrays that can be used to store data with any number of dimensions. It provides an abstract interface for retrieving and setting array attributes that are independent of the type of values stored in the array -\/ such as the number of dimensions, extents along each dimension, and number of values stored in the array.

To get and set array values, the \doxylink{classvtk_typed_array}{vtk\+Typed\+Array} template class derives from \doxylink{classvtk_array}{vtk\+Array} and provides type-\/specific methods for retrieval and update.

Two concrete derivatives of \doxylink{classvtk_typed_array}{vtk\+Typed\+Array} are provided at the moment:\+ \doxylink{classvtk_dense_array}{vtk\+Dense\+Array} and \doxylink{classvtk_sparse_array}{vtk\+Sparse\+Array}, which provide dense and sparse storage for arbitrary-\/dimension data, respectively. Toolkit users can create their own concrete derivatives that implement alternative storage strategies, such as compressed-\/sparse-\/row, etc. You could also create an array that provided read-\/only access to \textquotesingle{}virtual\textquotesingle{} data, such as an array that returned a Fibonacci sequence, etc.
