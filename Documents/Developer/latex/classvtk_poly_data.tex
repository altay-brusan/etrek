\doxysubsection{Detailed Description}
concrete dataset represents vertices, lines, polygons, and triangle strips 

\doxylink{classvtk_poly_data}{vtk\+Poly\+Data} is a data object that is a concrete implementation of \doxylink{classvtk_data_set}{vtk\+Data\+Set}. \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} represents a geometric structure consisting of vertices, lines, polygons, and/\+or triangle strips. Point and cell attribute values (e.\+g., scalars, vectors, etc.) also are represented.

\doxylink{requirements_The}{The} actual cell types (\doxylink{vtk_cell_type_8h_source}{vtk\+Cell\+Type.\+h}) supported by \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} are:\+ \doxylink{classvtk_vertex}{vtk\+Vertex}, \doxylink{classvtk_poly_vertex}{vtk\+Poly\+Vertex}, \doxylink{classvtk_line}{vtk\+Line}, \doxylink{classvtk_poly_line}{vtk\+Poly\+Line}, \doxylink{classvtk_triangle}{vtk\+Triangle}, \doxylink{classvtk_quad}{vtk\+Quad}, \doxylink{classvtk_polygon}{vtk\+Polygon}, and \doxylink{classvtk_triangle_strip}{vtk\+Triangle\+Strip}.

One important feature of \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} objects is that special traversal and data manipulation methods are available to process data. These methods are generally more efficient than \doxylink{classvtk_data_set}{vtk\+Data\+Set} methods and should be used whenever possible. For example, traversing the cells in a dataset we would use \doxylink{classvtk_poly_data_a1c60c918eb146402212ca26658cde798}{Get\+Cell()}. To traverse cells with \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} we would retrieve the cell array object representing polygons (for example using \doxylink{classvtk_poly_data_aba1510fe959e16fa27ec448b62bbe285}{Get\+Polys()}) and then use \doxylink{classvtk_cell_array}{vtk\+Cell\+Array}\textquotesingle{}s Init\+Traversal() and Get\+Next\+Cell() methods.

\begin{DoxyWarning}{Warning}
Because \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} is implemented with four separate instances of \doxylink{classvtk_cell_array}{vtk\+Cell\+Array} to represent 0D vertices, 1D lines, 2D polygons, and 2D triangle strips, it is possible to create \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} instances that consist of a mixture of cell types. Because of the design of the class, there are certain limitations on how mixed cell types are inserted into the \doxylink{classvtk_poly_data}{vtk\+Poly\+Data}, and in turn the order in which they are processed and rendered. To preserve the consistency of cell ids, and to ensure that cells with cell data are rendered properly, users must insert mixed cells in the order of vertices (\doxylink{classvtk_vertex}{vtk\+Vertex} and \doxylink{classvtk_poly_vertex}{vtk\+Poly\+Vertex}), lines (\doxylink{classvtk_line}{vtk\+Line} and \doxylink{classvtk_poly_line}{vtk\+Poly\+Line}), polygons (\doxylink{classvtk_triangle}{vtk\+Triangle}, \doxylink{classvtk_quad}{vtk\+Quad}, \doxylink{classvtk_polygon}{vtk\+Polygon}), and triangle strips (\doxylink{classvtk_triangle_strip}{vtk\+Triangle\+Strip}).

Some filters when processing \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} with mixed cell types may process the cells in differing ways. Some will convert one type into another (e.\+g., \doxylink{classvtk_triangle_strip}{vtk\+Triangle\+Strip} into vtk\+Triangles) or expect a certain type (\doxylink{classvtk_decimate_pro}{vtk\+Decimate\+Pro} expects triangles or triangle strips; \doxylink{classvtk_tube_filter}{vtk\+Tube\+Filter} expects lines). Read the documentation for each filter carefully to understand how each part of \doxylink{classvtk_poly_data}{vtk\+Poly\+Data} is processed.

Some of the methods specified here function properly only when the dataset has been specified as "{}\+Editable"{}. They are documented as such. 
\end{DoxyWarning}
