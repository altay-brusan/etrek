\doxysubsection{Detailed Description}
Custom proxy model for filtering and searching worklist data. 

Filters and search are applied in-\/memory on the already-\/loaded table data.
\begin{DoxyItemize}
\item Date filtering uses the "{}\+Created At"{} column (column 9)
\item Source filtering uses the "{}\+Source"{} column (column 8)
\item Search operates on:\+ Name (0), Patient ID (1), Study Name (2), Birth Date (4), Accession No (5)
\end{DoxyItemize}

Search is applied ON TOP of filters -\/ rows must match both filters AND search criteria.
