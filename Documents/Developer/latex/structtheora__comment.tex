\doxysubsection{Detailed Description}
Comment header metadata.

This structure holds the in-\/stream metadata corresponding to the \textquotesingle{}comment\textquotesingle{} header packet.

Meta data is stored as a series of (tag, value) pairs, in length-\/encoded string vectors. \doxylink{requirements_The}{The} first occurence of the \textquotesingle{}=\textquotesingle{} character delimits the tag and value. A particular tag may occur more than once. \doxylink{requirements_The}{The} character set encoding for the strings is always UTF-\/8, but the tag names are limited to case-\/insensitive ASCII. See the spec for details.

In filling in this structure, theora\+\_\+decode\+\_\+header() will null-\/terminate the user\+\_\+comment strings for safety. However, the bitstream format itself treats them as 8-\/bit clean, and so the length array should be treated as authoritative for their length.
