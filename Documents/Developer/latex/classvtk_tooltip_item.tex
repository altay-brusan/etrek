\doxysubsection{Detailed Description}
takes care of drawing 2D axes 

\doxylink{requirements_The}{The} \doxylink{classvtk_tooltip_item}{vtk\+Tooltip\+Item} is drawn in screen coordinates. It is used to display a tooltip on a scene, giving additional information about an element on the scene, such as in \doxylink{classvtk_chart_x_y}{vtk\+Chart\+XY}. It takes care of ensuring that it draws itself within the bounds of the screen.
