\doxysubsection{Detailed Description}
provides a view of the \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}. 

This class is derived from \doxylink{classvtk_render_view_base}{vtk\+Render\+View\+Base} and provides a view of a \doxylink{classvtk_context_scene}{vtk\+Context\+Scene}, with a default interactor style, renderer etc. It is the simplest way to create a \doxylink{classvtk_render_window}{vtk\+Render\+Window} and display a 2D scene inside of it.

By default the scene has a white background.
