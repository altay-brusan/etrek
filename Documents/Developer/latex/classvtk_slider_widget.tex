\doxysubsection{Detailed Description}
set a value by manipulating a slider 

\doxylink{requirements_The}{The} \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} is used to set a scalar value in an application. This class assumes that a slider is moved along a 1D parameter space (e.\+g., a spherical bead that can be moved along a tube). Moving the slider modifies the value of the widget, which can be used to set parameters on other objects. Note that the actual appearance of the widget depends on the specific representation for the widget.

To use this widget, set the widget representation. \doxylink{requirements_The}{The} representation is assumed to consist of a tube, two end caps, and a slider (the details may vary depending on the particulars of the representation). Then in the representation you will typically set minimum and maximum value, as well as the current value. \doxylink{requirements_The}{The} position of the slider must also be set, as well as various properties.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
If the slider bead is selected:
  LeftButtonPressEvent -\/ select slider (if on slider)
  LeftButtonReleaseEvent -\/ release slider (if selected)
  MouseMoveEvent -\/ move slider
If the end caps or slider tube are selected:
  LeftButtonPressEvent -\/ move (or animate) to cap or point on tube;
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::Select -\/-\/ some part of the widget has been selected
  vtkWidgetEvent::EndSelect -\/-\/ the selection process has completed
  vtkWidgetEvent::Move -\/-\/ a request for slider motion has been invoked
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
In turn, when these widget events are processed, the \doxylink{classvtk_slider_widget}{vtk\+Slider\+Widget} invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (on vtkWidgetEvent::Select)
  vtkCommand::EndInteractionEvent (on vtkWidgetEvent::EndSelect)
  vtkCommand::InteractionEvent (on vtkWidgetEvent::Move)
\end{DoxyPre}
 
\end{DoxyParagraph}
