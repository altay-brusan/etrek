a class that renders hierarchical cell-\/grid data 

This class uses a \doxylink{classvtk_cell_grid_mapper}{vtk\+Cell\+Grid\+Mapper} to render input data which may be hierarchical. \doxylink{requirements_The}{The} input to this mapper may be either \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid} or a \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} built from cell-\/grids. If something other than \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid} is encountered, an error message will be produced. \begin{DoxySeeAlso}{See also}
