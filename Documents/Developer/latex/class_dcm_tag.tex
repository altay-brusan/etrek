\doxysubsection{Detailed Description}
this class encapsulates an attribute tag (group, element) and a VR. It maintains a private creator identifier for private tags and caches the attribute name, once it is looked up in the data dictionary. This class maintains the interface to the DICOM data dictionary, i.\+e. performs look-\/ups of attribute VR and name in the background. Therefore, creation of \doxylink{class_dcm_tag}{Dcm\+Tag} element is significantly more expensive than creation of simple \doxylink{class_dcm_tag_key}{Dcm\+Tag\+Key} objects unless the VR is passed in the constructor.
