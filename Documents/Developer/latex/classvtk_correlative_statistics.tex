\doxysubsection{Detailed Description}
A class for bivariate linear correlation. 

Given a selection of pairs of columns of interest, this class provides the following functionalities, depending on the chosen execution options:\+
\begin{DoxyItemize}
\item Learn:\+ calculate sample mean and M2 aggregates for each pair of variables (cf. P. Pebay, Formulas for robust, one-\/pass parallel computation of covariances and Arbitrary-\/\+Order Statistical Moments, Sandia Report SAND2008-\/6212, Sep 2008, \href{http://infoserve.sandia.gov/sand_doc/2008/086212.pdf}{\texttt{http:\+/\+/\+infoserve.\+sandia.\+gov/\+sand\+\_\+doc/\+2008/\+086212.\+pdf}} for details)
\item Derive:\+ calculate unbiased covariance matrix estimators and its determinant, linear regressions, and Pearson correlation coefficient.
\item Assess:\+ given an input data set, two means and a 2x2 covariance matrix, mark each datum with corresponding relative deviation (2-\/dimensional Mahlanobis distance).
\item Test:\+ Perform Jarque-\/\+Bera-\/\+Srivastava test of 2-\/d normality
\end{DoxyItemize}
