\doxysubsection{Detailed Description}
Class representing the Multi-\/\+Frame Dimension Module:\+

Dimension Organization Sequence:\+ (SQ, VM 1-\/n, Type 1) \begin{quote}
Dimension Organization UID:\+ (UI, 1, 1) Dimension Organization Type:\+ (CS, 1, 1) Dimension Index Sequence:\+ (SQ, 1-\/n, 1) Dimension Index Pointer (AT, 1, 1) Dimension Index Private Creator (LO, 1, 1C) Functional Group Pointer (AT, 1, 1C) Functional Group Private Creator (LO, 1, 1C) Dimension Organization UID (UI, 1, 1C) Dimension Description Label (LO, 1, 3) \end{quote}


\doxylink{requirements_The}{The} Dimension Organization UIDs within the Dimension Organization Sequence cannot be set explicitly. Instead the sequence is populated from the data found within the Dimension Index Sequence.
