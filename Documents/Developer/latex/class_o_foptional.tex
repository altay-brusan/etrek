\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class OFoptional$<$ T $>$}
\doxylink{requirements_The}{The} class template \doxylink{class_o_foptional}{OFoptional} manages an optional contained value, i.\+e. a value tagged with a state that reports its validity. A common use case for \doxylink{class_o_foptional}{OFoptional} is the return value of a function that may fail. \doxylink{class_o_foptional}{OFoptional} handles expensive to construct objects well and is more readable, as the intent is expressed explicitly. An \doxylink{class_o_foptional}{OFoptional} object which actually contains a value is called \textquotesingle{}engaged\textquotesingle{}, whereas an \doxylink{class_o_foptional}{OFoptional} object not containing a valid value is called \textquotesingle{}disengaged\textquotesingle{}. \doxylink{requirements_The}{The} global constant \textquotesingle{}OFnullopt\textquotesingle{} of type \textquotesingle{}\doxylink{struct_o_fnullopt__t}{OFnullopt\+\_\+t}\textquotesingle{} may be used to explicitly mark an optional object as disengaged, for example to return a disengaged object from a function if an error occurred. 
\begin{DoxyTemplParams}{Template Parameters}
{\em T} & the type of the value to manage initialization state for. \doxylink{requirements_The}{The} type\textquotesingle{}s destructor must be accessible by \doxylink{class_o_foptional}{OFoptional$<$\+T$>$}. \\
\hline
\end{DoxyTemplParams}
\begin{DoxyNote}{Note}
There exists a sufficient specialization for reference types (T\&) that behaves exactly like a pointer (T\texorpdfstring{$\ast$}{*}) but allows \doxylink{class_o_foptional}{OFoptional} to be used in a generic context (when it\textquotesingle{}s unknown if T is a reference or not). 
\end{DoxyNote}
