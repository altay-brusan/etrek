\doxysubsection{Detailed Description}
Asynchronously measures GPU execution times for a series of events. 

This class measures the time it takes for events to occur on the GPU by posting timing events into the rendering command stream. This can be used to compute the time spent doing work on the GPU without stalling the CPU.

To aid asynchronous usage, this class uses the concepts "{}\+Event"{} and "{}\+Frame"{}, where a \doxylink{structvtk_render_timer_log_1_1_frame}{Frame} is a logical collection of Events. \doxylink{requirements_The}{The} timer log can manage multiple Frames at a time:\+
\begin{DoxyItemize}
\item \doxylink{requirements_The}{The} current \doxylink{structvtk_render_timer_log_1_1_frame}{Frame}, where new Events are created.
\item Pending Frames, for which all Events have been marked, but the results are not available (the timer requests are still waiting to be processed by the graphics device).
\item Ready Frames, which have been completed by the graphics device and may be retrieved.
\end{DoxyItemize}

Call \doxylink{classvtk_render_timer_log_a5bf7a3f54d54f2e7ac0faa6d19d12e1f}{Mark\+Frame()} to begin a new \doxylink{structvtk_render_timer_log_1_1_frame}{Frame}. This pushes the current \doxylink{structvtk_render_timer_log_1_1_frame}{Frame} to the collection of pending Frames, and creates a new one to store future Events.

Call \doxylink{classvtk_render_timer_log_a19ac58ab2141d8ed43005a95a01c05ae}{Mark\+Start\+Event()} and Mark\+End\+Event() to mark the beginning and end of an \doxylink{structvtk_render_timer_log_1_1_event}{Event}. These Events may be nested, but all child Events must have their end marked before the parent \doxylink{structvtk_render_timer_log_1_1_event}{Event} ends.

Use \doxylink{classvtk_render_timer_log_afe83ee5a1e94643446c2412cd1ab76de}{Frame\+Ready()} and \doxylink{classvtk_render_timer_log_ae9df685b1e569525b95cf475b3794a70}{Pop\+First\+Ready\+Frame()} to check for completed Frames and retrieve results.

This is currently only implemented for the Open\+GL2 backend. \doxylink{requirements_The}{The} \doxylink{classvtk_render_timer_log_acee88a94614382bc5c90fecd743d9a44}{Is\+Supported()} method can be used to detect if there is a valid implementation available.
