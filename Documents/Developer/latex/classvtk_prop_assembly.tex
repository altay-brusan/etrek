\doxysubsection{Detailed Description}
create hierarchies of props 

\doxylink{classvtk_prop_assembly}{vtk\+Prop\+Assembly} is an object that groups props and other prop assemblies into a tree-\/like hierarchy. \doxylink{requirements_The}{The} props can then be treated as a group (e.\+g., turning visibility on and off).

A \doxylink{classvtk_prop_assembly}{vtk\+Prop\+Assembly} object can be used in place of an \doxylink{classvtk_prop}{vtk\+Prop} since it is a subclass of \doxylink{classvtk_prop}{vtk\+Prop}. \doxylink{requirements_The}{The} difference is that \doxylink{classvtk_prop_assembly}{vtk\+Prop\+Assembly} maintains a list of other prop and prop assembly instances (its "{}parts"{}) that form the assembly. Note that this process is recursive:\+ you can create groups consisting of prop assemblies to arbitrary depth.

\doxylink{classvtk_prop_assembly}{vtk\+Prop\+Assembly}\textquotesingle{}s and \doxylink{classvtk_prop}{vtk\+Prop}\textquotesingle{}s that compose a prop assembly need not be added to a renderer\textquotesingle{}s list of props, as long as the parent assembly is in the prop list. This is because they are automatically rendered during the hierarchical traversal process.

\begin{DoxyWarning}{Warning}
vtk\+Prop\+Assemblies can consist of hierarchies of assemblies, where one actor or assembly used in one hierarchy is also used in other hierarchies. However, make that there are no cycles (e.\+g., parent-\/\texorpdfstring{$>$}{>}child-\/\texorpdfstring{$>$}{>}parent), this will cause program failure.
\end{DoxyWarning}
