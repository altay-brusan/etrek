\doxysubsection{Detailed Description}
direct /\+ check-\/free point insertion. 

As a special sub-\/class of \doxylink{classvtk_point_locator}{vtk\+Point\+Locator}, \doxylink{classvtk_non_merging_point_locator}{vtk\+Non\+Merging\+Point\+Locator} is intended for direct /\+ check-\/free insertion of points into a \doxylink{classvtk_points}{vtk\+Points} object. In other words, any given point is always directly inserted. \doxylink{requirements_The}{The} name emphasizes the difference between this class and its sibling class \doxylink{classvtk_merge_points}{vtk\+Merge\+Points} in that the latter class performs check-\/based zero tolerance point insertion (or to \textquotesingle{}merge\textquotesingle{} exactly duplicate /\+ coincident points) by exploiting the uniform bin mechanism employed by the parent class \doxylink{classvtk_point_locator}{vtk\+Point\+Locator}. \doxylink{classvtk_point_locator}{vtk\+Point\+Locator} allows for generic (zero and non-\/ zero) tolerance point insertion as well as point location.
