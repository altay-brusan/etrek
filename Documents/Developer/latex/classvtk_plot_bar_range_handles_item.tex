\doxysubsection{Detailed Description}
show and control the range of a \doxylink{classvtk_axis}{vtk\+Axis} used with a \doxylink{classvtk_plot_bar}{vtk\+Plot\+Bar} 

This class is a \doxylink{classvtk_plot_range_handles_item}{vtk\+Plot\+Range\+Handles\+Item} specialization working in coordination with a \doxylink{classvtk_plot_bar}{vtk\+Plot\+Bar}. It ensures that handles are sticking to the plot bars when being dragged. Vertical and horizontal bars are both supported but the handles orientation must match the \doxylink{classvtk_plot_bar}{vtk\+Plot\+Bar} orientation.
