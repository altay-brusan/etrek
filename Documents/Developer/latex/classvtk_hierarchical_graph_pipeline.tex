\doxysubsection{Detailed Description}
helper class for rendering graphs superimposed on a tree. 

\doxylink{classvtk_hierarchical_graph_pipeline}{vtk\+Hierarchical\+Graph\+Pipeline} renders bundled edges that are meant to be viewed as an overlay on a tree. This class is not for general use, but is used in the internals of \doxylink{classvtk_rendered_hierarchy_representation}{vtk\+Rendered\+Hierarchy\+Representation} and \doxylink{classvtk_rendered_tree_area_representation}{vtk\+Rendered\+Tree\+Area\+Representation}.
