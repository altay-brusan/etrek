\doxysubsection{Detailed Description}
A class for managing and converting between different DICOM character sets. \doxylink{requirements_The}{The} conversion relies on the \doxylink{class_o_f_character_encoding}{OFCharacter\+Encoding} class, which again relies on an underlying character encoding library (e.\+g. libiconv or ICU). \begin{DoxyNote}{Note}
Please note that a current limitation is that only a single value is allowed for the destination character set (i.\+e. no code extensions). Of course, for the source character set, also multiple values are supported. 
\end{DoxyNote}
