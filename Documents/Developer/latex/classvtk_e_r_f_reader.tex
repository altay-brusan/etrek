\doxysubsection{Detailed Description}
Read ERF-\/\+HDF5 files. 

Based on HDF5, ERF format will contain multiple stages and a special group named \textquotesingle{}post\textquotesingle{} which indicates the default stage.

A stage is a group with multiple subgroups which could be mandatory or not:\+
\begin{DoxyItemize}
\item erfheader (mandatory):\+ defines the version of the format /\+ simulation.
\item constant (mandatory):\+ defines all data which is not varying.
\item singlestate (opt) :\+ defines multiple states with varying data.
\item multistate (opt) :\+ defines data which can depend on multiple varying parameters like time series and load cases.
\end{DoxyItemize}

Here is an example of a valid ERF HDF5 file hierarchy:\+ /\+ CSMEXPL/\+ constant/\+ connectivities/\+ SHELL/\+ erfblock/\+ cell indices connecitvity indices offsets entityresults/\+ NODE/\+ erfblock/\+ indices points offsets systems/\+ erfblock/\+ erfheader/\+ multistate/\+ (currently not supported yet) singlestate/\+ state00001/\+ ... state00004/\+ ... post/\+

Each subgroup of stage, like \textquotesingle{}constant\textquotesingle{}, will also contains multiple groups (e.\+g. \textquotesingle{}connectivities\textquotesingle{}) and so on. \doxylink{requirements_The}{The} deeper subgroup, for each possible path, named {\ttfamily erfblock} has several handy attributes to generate the data in VTK like:\+ dimension, cell type, associated groups, ... Also \textquotesingle{}erfblock\textquotesingle{} contains several datasets (which is a file in HDF5) which will be the raw data like points, indices, ...

This reader will output a \doxylink{classvtk_partitioned_data_set_collection}{vtk\+Partitioned\+Data\+Set\+Collection} as it should be read in distributed fashion later and it represents a collection of data\+Set which can vary depending on the time (singlestate, multistate) or not (constant).

\begin{DoxyWarning}{Warning}
Multistate isn\textquotesingle{}t supported for now.
\end{DoxyWarning}
