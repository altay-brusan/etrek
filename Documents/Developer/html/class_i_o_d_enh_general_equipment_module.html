Detailed Description

Class representing the Enhanced Equipment Module:

Manufacturer: (LO, 1, 1) Manufacturer's Model Name: (LO, 1, 1) Device Serial Number: (LO, 1, 1) Software Version(s): (LO, 1-n, 1)
