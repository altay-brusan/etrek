\doxysubsection{Detailed Description}
Superclass for QAbstract\+Item\+View-\/based views. 

This superclass provides all the plumbing to integrate a QAbstract\+Item\+View into the VTK view framework, including reporting selection changes and detecting selection changes from linked views.
