\doxysubsection{Detailed Description}
abstract codec class for JPEG encoders. This abstract class contains most of the application logic needed for a dcmdata codec object that implements a JPEG encoder using the \doxylink{class_d_j_encoder}{DJEncoder} interface to the underlying JPEG implementation. This class only supports compression, it neither implements decoding nor transcoding.
