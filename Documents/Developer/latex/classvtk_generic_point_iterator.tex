\doxysubsection{Detailed Description}
iterator used to traverse points 

This class (and subclasses) are used to iterate over points. Use it only in conjunction with \doxylink{classvtk_generic_data_set}{vtk\+Generic\+Data\+Set} (i.\+e., the adaptor framework).

Typical use is:\+

\doxylink{classvtk_generic_data_set}{vtkGenericDataSet} *dataset;
\doxylink{classvtk_generic_point_iterator}{vtkGenericPointIterator} *it = dataset-\/>NewPointIterator();

  \{
  x=it-\/>\doxylink{classvtk_generic_point_iterator_a90c2155dc92afc1c929f327b29da36f0}{GetPosition()};
  \}
\end{DoxyPre}
