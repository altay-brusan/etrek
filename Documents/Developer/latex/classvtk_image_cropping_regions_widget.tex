\doxysubsection{Detailed Description}
widget for cropping an image 

This widget displays a set of axis aligned lines that can be interactively manipulated to crop a volume. \doxylink{requirements_The}{The} region to be cropped away is displayed in a different highlight. Much like the \doxylink{classvtk_volume_mapper}{vtk\+Volume\+Mapper}, this widget supports 27 possible configurations of cropping planes. (See Cropping\+Region\+Flags). If a volume mapper is set, the cropping planes are directly propagated to the volume mapper. \doxylink{requirements_The}{The} widget invokes a Cropping\+Planes\+Position\+Changed\+Event when the position of any of the cropping planes is changed. \doxylink{requirements_The}{The} widget also invokes an Interaction\+Event in response to user interaction.
