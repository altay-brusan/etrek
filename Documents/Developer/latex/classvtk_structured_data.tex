\doxysubsection{Detailed Description}
Singleton class for topologically regular data. 

\doxylink{classvtk_structured_data}{vtk\+Structured\+Data} is a singleton class that provides an interface for topologically regular data. Regular data is data that can be accessed in rectangular fashion using an i-\/j-\/k index. A finite difference grid, a volume, or a pixmap are all considered regular.
