Invoke a functor on the named type and each of its parent types.

\doxylink{requirements_The}{The} {\itshape VTKObject\+Type} template-\/parameter should be a subclass of \doxylink{classvtk_object_base}{vtk\+Object\+Base} that uses the {\ttfamily vtk\+Type\+Macro()} to define a {\ttfamily Superclass} type-\/alias, as this is how the inheritance hierarchy is traversed.

Call the static {\ttfamily enumerate()} method of \doxylink{structvtk_1_1_parent_classes}{Parent\+Classes} with a functor that accepts no arguments and a single template parameter. If the return value of your functor is void, then {\ttfamily enumerate()} will invoke your functor once on every type in your object\textquotesingle{}s hierarchy. If the return value of your functor is a boolean, then {\ttfamily enumerate()} will invoke your functor on every type in your object\textquotesingle{}s hierarchy until the functor returns false (indicating early termination is requested). See detail::\+\+Add\+Names() above for an example of the latter.
