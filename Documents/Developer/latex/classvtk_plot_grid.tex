\doxysubsection{Detailed Description}
takes care of drawing the plot grid 

\doxylink{requirements_The}{The} \doxylink{classvtk_plot_grid}{vtk\+Plot\+Grid} is drawn in screen coordinates. It is usually one of the first elements of a chart to be drawn, and will generally be obscured by all other elements of the chart. It builds up its own plot locations from the parameters of the x and y axis of the plot.
