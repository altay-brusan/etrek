\doxysubsubsection{Detailed Description}
\doxylink{requirements_The}{The} functions in this group allows you to create from scratch (or update) a \doxylink{struct_x_m_l_node}{XMLNode} structure. Start by creating your top node with the "{}create\+XMLTop\+Node"{} function and then add new nodes with the "{}add\+Child"{} function. \doxylink{requirements_The}{The} parameter \textquotesingle{}pos\textquotesingle{} gives the position where the child\+Node, the text or the XMLClear\+Tag will be inserted. \doxylink{requirements_The}{The} default value (pos=-\/1) inserts at the end. \doxylink{requirements_The}{The} value (pos=0) insert at the beginning (Insertion at the beginning is slower than at the end). ~\newline
