\doxysubsection{Detailed Description}
abstract superclass for composite (multi-\/block or AMR) datasets 

\doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} is an abstract class that represents a collection of datasets (including other composite datasets). It provides an interface to access the datasets through iterators. \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} provides methods that are used by subclasses to store the datasets. \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set} provides the datastructure for a full tree representation. Subclasses provide the semantics for it and control how this tree is built.
