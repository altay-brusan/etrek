\doxysubsection{Detailed Description}
Parse XML to handle element tags and attributes. 

\doxylink{classvtk_x_m_l_parser}{vtk\+XMLParser} reads a stream and parses XML element tags and corresponding attributes. Each element begin tag and its attributes are sent to the Start\+Element method. Each element end tag is sent to the End\+Element method. Subclasses should replace these methods to actually use the tags.
