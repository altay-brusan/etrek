\doxysubsection{Detailed Description}
\doxylink{classvtk_p_directory}{vtk\+PDirectory} provides a portable way of finding the names of the files in a system directory where process 0 finds the information and broadcasts it to other processes. It tries to replicate the API for both Directory and \doxylink{classvtk_directory}{vtk\+Directory} though there are slight mismatches between the two. This is a blocking collective operation.
