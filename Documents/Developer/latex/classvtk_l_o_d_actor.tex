\doxysubsection{Detailed Description}
an actor that supports multiple levels of detail 

\doxylink{classvtk_l_o_d_actor}{vtk\+LODActor} is an actor that stores multiple levels of detail (LOD) and can automatically switch between them. It selects which level of detail to use based on how much time it has been allocated to render. Currently a very simple method of Total\+Time/\+\+Number\+Of\+Actors is used. (In the future this should be modified to dynamically allocate the rendering time between different actors based on their needs.)

There are three levels of detail by default. \doxylink{requirements_The}{The} top level is just the normal data. \doxylink{requirements_The}{The} lowest level of detail is a simple bounding box outline of the actor. \doxylink{requirements_The}{The} middle level of detail is a point cloud of a fixed number of points that have been randomly sampled from the mapper\textquotesingle{}s input data. Point attributes are copied over to the point cloud. These two lower levels of detail are accomplished by creating instances of a \doxylink{classvtk_outline_filter}{vtk\+Outline\+Filter} (low-\/res) and \doxylink{classvtk_mask_points}{vtk\+Mask\+Points} (medium-\/res). Additional levels of detail can be add using the \doxylink{classvtk_l_o_d_actor_a8cecc005d8e3e8deaa8859905d3f064f}{Add\+LODMapper()} method.

To control the frame rate, you typically set the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} Desired\+Update\+Rate and Still\+Update\+Rate. This then will cause \doxylink{classvtk_l_o_d_actor}{vtk\+LODActor} to adjust its LOD to fulfill the requested update rate.

For greater control on levels of detail, see also \doxylink{classvtk_l_o_d_prop3_d}{vtk\+LODProp3D}. That class allows arbitrary definition of each LOD.

\begin{DoxyWarning}{Warning}
If you provide your own mappers, you are responsible for setting its ivars correctly, such as Scalar\+Range, Lookup\+Table, and so on.

On some systems the point cloud rendering (the default, medium level of detail) can result in points so small that they can hardly be seen. In this case, use the Get\+Property()-\/\texorpdfstring{$>$}{>}Set\+Point\+Size() method to increase the rendered size of the points.
\end{DoxyWarning}
