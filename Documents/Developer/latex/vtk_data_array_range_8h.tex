\doxysubsection{Detailed Description}
STL-\/compatible iterable ranges that provide access to \doxylink{classvtk_data_array}{vtk\+Data\+Array} elements.

\begin{DoxyNote}{Note}
Since the term \textquotesingle{}range\textquotesingle{} is overloaded, it\textquotesingle{}s worth pointing out that to determine the value-\/range of an array\textquotesingle{}s elements (an unrelated concept to the Range objects defined here), see the vtk\+Data\+Array::\+\+Get\+Range and \doxylink{classvtk_generic_data_array_a6d989e0cf1eac6af3e3f1166bdef7b09}{vtk\+Generic\+Data\+Array::\+\+Get\+Value\+Range} methods.
\end{DoxyNote}
\doxylink{requirements_The}{The} \doxylink{vtk_data_array_range_8h}{vtk\+Data\+Array\+Range.\+h} header provides utilities to convert vtk\+Data\+Arrays into "{}range"{} objects that behave like STL ranges. There are two types of ranges:\+ Tuple\+Range and Value\+Range.

See Testing/\+\+Cxx/\+\+Example\+Data\+Array\+Range\+API.\+cxx for an illustrative example of how these ranges and their associated iterators and references are used.

These ranges unify the different memory layouts supported by VTK and provide a consistent interface to processing them with high efficiency. Whether a range is constructed from a \doxylink{classvtk_data_array}{vtk\+Data\+Array}, \doxylink{classvtk_float_array}{vtk\+Float\+Array}, or even vtk\+Scaled\+SOAData\+Array\+Template, the same range-\/based algorithm implementation can be used to provide the best performance possible using the input array\textquotesingle{}s API.

Constructing a range using a derived subclass of \doxylink{classvtk_data_array}{vtk\+Data\+Array} (such as \doxylink{classvtk_float_array}{vtk\+Float\+Array}) will always give better performance than a range constructed from a \doxylink{classvtk_data_array}{vtk\+Data\+Array} pointer, since the \doxylink{classvtk_data_array}{vtk\+Data\+Array} API requires virtual calls and type conversion. Using a more derived type generally allows the compiler to optimize out any function calls and emit assembly that directly operates on the array\textquotesingle{}s raw memory buffer(s). See \doxylink{classvtk_array_dispatch}{vtk\+Array\+Dispatch} for utilities to convert an unknown \doxylink{classvtk_data_array}{vtk\+Data\+Array} into a more derived type.
