\doxysubsection{Detailed Description}
A function defined over the physical domain of a \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid}. 

This is a base class for attributes (functions) defined on the space discretized by a \doxylink{classvtk_cell_grid}{vtk\+Cell\+Grid}. A \doxylink{classvtk_cell_attribute}{vtk\+Cell\+Attribute} class must handle cells of all types present in the grid.

Return a token identifying the space containing all field values.

Currently, this is just a free-\/form string but in the future we may adopt a more rigorous standard.

Some suggested values
\begin{DoxyItemize}
\item "{}ℝ¹"{} – single (scalar) values over the real numbers.
\item "{}ℝ¹+"{} – single (scalar) values over the non-\/negative real numbers.
\item "{}ℝ²"{} – 2-\/d vector values over the real numbers.
\item "{}ℝ³"{} – 3-\/d vector values over the real numbers.
\item "{}𝕊³"{} – points inside a unit 3-\/dimensional ball.
\item "{}\+S²"{} – points on the surface of a unit 3-\/dimensional sphere.
\item "{}\+SO(3)"{} – rotation matrices.
\item "{}\+SU(2)"{} – special unitary group (homeomorphic to SO(3)).
\end{DoxyItemize}

Note that the space might imply the number of components but it also specifies how users should interpret operations such as addition and/\+or multipliciation, especially in the case of transforms applied to the domain.
