\doxysubsection{Detailed Description}
convert an arbitrary dataset to a voxel representation 

\doxylink{classvtk_voxel_modeller}{vtk\+Voxel\+Modeller} is a filter that converts an arbitrary data set to a structured point (i.\+e., voxel) representation. It is very similar to \doxylink{classvtk_implicit_modeller}{vtk\+Implicit\+Modeller}, except that it doesn\textquotesingle{}t record distance; instead it records occupancy. By default it supports a compact output of 0/\+1 VTK\+\_\+\+BIT. Other vtk scalar types can be specified. \doxylink{requirements_The}{The} Foreground and Background values of the output can also be specified. NOTE:\+ Not all vtk filters/\+readers/\+writers support the VTK\+\_\+\+BIT scalar type. You may want to use VTK\+\_\+\+CHAR as an alternative. \begin{DoxySeeAlso}{See also}
