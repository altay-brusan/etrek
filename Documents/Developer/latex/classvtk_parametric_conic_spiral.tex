\doxysubsection{Detailed Description}
Generate conic spiral surfaces that resemble sea-\/shells. 

\doxylink{classvtk_parametric_conic_spiral}{vtk\+Parametric\+Conic\+Spiral} generates conic spiral surfaces. These can resemble sea shells, or may look like a torus "{}eating"{} its own tail.

For further information about this surface, please consult the technical description "{}\+Parametric surfaces"{} in \href{http://www.vtk.org/publications}{\texttt{http:\+/\+/\+www.\+vtk.\+org/\+publications}} in the "{}\+VTK Technical Documents"{} section in the VTk.\+org web pages.

A conic spiral surface.

This function performs the mapping $f(u,v) \rightarrow (x,y,x)$, returning it as Pt. It also returns the partial derivatives Du and Dv. $Pt = (x, y, z), Du = (dx/du, dy/du, dz/du), Dv = (dx/dv, dy/dv, dz/dv)$ . Then the normal is $N = Du X Dv$ .
