\doxysubsection{Detailed Description}
measure the distance between two points 

\doxylink{requirements_The}{The} \doxylink{classvtk_distance_widget}{vtk\+Distance\+Widget} is used to measure the distance between two points. \doxylink{requirements_The}{The} two end points can be positioned independently, and when they are released, a special Place\+Point\+Event is invoked so that special operations may be take to reposition the point (snap to grid, etc.) \doxylink{requirements_The}{The} widget has two different modes of interaction:\+ when initially defined (i.\+e., placing the two points) and then a manipulate mode (adjusting the position of the two points).

To use this widget, specify an instance of \doxylink{classvtk_distance_widget}{vtk\+Distance\+Widget} and a representation (a subclass of \doxylink{classvtk_distance_representation}{vtk\+Distance\+Representation}). \doxylink{requirements_The}{The} widget is implemented using two instances of \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget} which are used to position the end points of the line. \doxylink{requirements_The}{The} representations for these two handle widgets are provided by the \doxylink{classvtk_distance_representation}{vtk\+Distance\+Representation}.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
  LeftButtonPressEvent -\/ add a point or select a handle
  MouseMoveEvent -\/ position the second point or move a handle
  LeftButtonReleaseEvent -\/ release the handle
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_distance_widget}{vtk\+Distance\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::AddPoint -\/-\/ add one point; depending on the state
                              it may the first or second point added. Or,
                              if near a handle, select the handle.
  vtkWidgetEvent::Move -\/-\/ move the second point or handle depending on the state.
  vtkWidgetEvent::EndSelect -\/-\/ the handle manipulation process has completed.
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
This widget invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (beginning to interact)
  vtkCommand::EndInteractionEvent (completing interaction)
  vtkCommand::InteractionEvent (moving after selecting something)
  vtkCommand::PlacePointEvent (after point is positioned;
                               call data includes handle id (0,1))
\end{DoxyPre}

\end{DoxyParagraph}
