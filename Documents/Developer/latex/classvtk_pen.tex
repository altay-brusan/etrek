\doxysubsection{Detailed Description}
provides a pen that draws the outlines of shapes drawn by \doxylink{classvtk_context2_d}{vtk\+Context2D}. 

\doxylink{requirements_The}{The} \doxylink{classvtk_pen}{vtk\+Pen} defines the outline of shapes that are drawn by \doxylink{classvtk_context2_d}{vtk\+Context2D}. \doxylink{requirements_The}{The} color is stored as four unsigned chars (RGBA), where the opacity defaults to 255, but can be modified separately to the other components. Ideally we would use a lightweight color class to store and pass around colors.
