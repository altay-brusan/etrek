\doxysubsection{Detailed Description}
perform b-\/spline interpolation on images 

\doxylink{classvtk_image_b_spline_interpolator}{vtk\+Image\+BSpline\+Interpolator} can be used to perform b-\/spline interpolation on images that have been filtered with \doxylink{classvtk_image_b_spline_coefficients}{vtk\+Image\+BSpline\+Coefficients}. \doxylink{requirements_The}{The} b-\/spline interpolants provide the maximum possible degree of continuity for a given kernel size, but require that the image data be pre-\/filtered to generate b-\/spline coefficients before the interpolation is performed. Interpolating data that has not been pre-\/filtered will give incorrect results. \begin{DoxySeeAlso}{See also}
