211 // When ScalarMode is set to use Field Data (ScalarModeToFieldData),
212 // you must call SelectColorArray to choose the field data array to
213 // be used to color cells. In this mode, the default behavior is to
214 // treat the field data tuples as being associated with cells. If
215 // the poly data contains triangle strips, the array is expected to
216 // contain the cell data for each mini-cell formed by any triangle
217 // strips in the poly data as opposed to treating them as a single
218 // tuple that applies to the entire strip. This mode can also be
219 // used to color the entire poly data by a single color obtained by
220 // mapping the tuple at a given index in the field data array
221 // through the color map. Use SetFieldDataTupleId() to specify
222 // the tuple index.
