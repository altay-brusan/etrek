\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T, int Size$>$\newline
class vtk\+Vector$<$ T, Size $>$}
templated base type for storage of vectors. 

This class is a templated data type for storing and manipulating fixed size vectors, which can be used to represent two and three dimensional points. \doxylink{requirements_The}{The} memory layout is a contiguous array of the specified type, such that a float\+[2]\+ can be cast to a \doxylink{classvtk_vector2f}{vtk\+Vector2f} and manipulated. Also a float\+[6]\+ could be cast and used as a \doxylink{classvtk_vector2f}{vtk\+Vector2f}\+[3]\+.
