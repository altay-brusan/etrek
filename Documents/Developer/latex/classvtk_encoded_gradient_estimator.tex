\doxysubsection{Detailed Description}
Superclass for gradient estimation. 

\doxylink{classvtk_encoded_gradient_estimator}{vtk\+Encoded\+Gradient\+Estimator} is an abstract superclass for gradient estimation. It takes a scalar input of \doxylink{classvtk_image_data}{vtk\+Image\+Data}, computes a gradient value for every point, and encodes this value into a three byte value (2 for direction, 1 for magnitude) using the \doxylink{classvtk_direction_encoder}{vtk\+Direction\+Encoder}. \doxylink{requirements_The}{The} direction encoder is defaulted to a \doxylink{classvtk_recursive_sphere_direction_encoder}{vtk\+Recursive\+Sphere\+Direction\+Encoder}, but can be overridden with the Set\+Direction\+Encoder method. \doxylink{requirements_The}{The} scale and the bias values for the gradient magnitude are used to convert it into a one byte value according to v = m\texorpdfstring{$\ast$}{*}scale + bias where m is the magnitude and v is the resulting one byte value. \begin{DoxySeeAlso}{See also}
