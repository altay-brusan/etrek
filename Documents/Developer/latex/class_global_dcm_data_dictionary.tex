\doxysubsection{Detailed Description}
global singleton DICOM dictionary that is used by DCMTK in order to lookup attribute VR, tag names and so on. \doxylink{requirements_The}{The} dictionary is internally populated on first use, if the user accesses it via \doxylink{class_global_dcm_data_dictionary_aec03f15c0ca97a9f5580f8b9f23cdc03}{rdlock()} or \doxylink{class_global_dcm_data_dictionary_a5ea7fc4d063743988a2edffd5e4e3555}{wrlock()}. \doxylink{requirements_The}{The} dictionary allows safe read (shared) and write (exclusive) access from multiple threads in parallel.
