\doxysubsection{Detailed Description}
manage vertex buffer objects shared within a mapper 

This class holds onto the VBOs that a mapper is using. \doxylink{requirements_The}{The} basic operation is that during the render process the mapper may cache a number of data\+Arrays as VBOs associated with attributes. This class keep track of freeing VBOs no longer used by the mapper and uploading new data as needed.

When using Cache\+Cata\+Array the same array can be set each time and this class will not rebuild or upload unless needed.

When using the Append\+Data\+Array API no caching is done and the VBOs will be rebuilt and uploaded each time. So when appending th emapper need to handle checking if the VBO should be updated.
