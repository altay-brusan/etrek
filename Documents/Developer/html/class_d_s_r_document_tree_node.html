virtual OFCondition DSRDocumentTreeNode::getTemplateIdentification ( OFString & templateIdentifier,
OFString & mappingResource ) const
virtual

get template identifier and mapping resource. This value pair identifies the template that was used to create this content item (and its children). According to the DICOM standard, it is "required if a template was used to define the content of this Item, and the template consists of a single CONTAINER with nested content, and it is the outermost invocation of a set of nested templates that start with the same CONTAINER." The identification is valid if both values are either present (non-empty) or absent (empty).

Parameters
templateIdentifieridentifier of the template (might be empty)
mappingResourcemapping resource that defines the template (might be empty)
Returns
status, EC_Normal if successful, an error code otherwise
