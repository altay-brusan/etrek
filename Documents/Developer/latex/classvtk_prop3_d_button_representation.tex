\doxysubsection{Detailed Description}
defines a representation for a \doxylink{classvtk_button_widget}{vtk\+Button\+Widget} 

This class implements one type of \doxylink{classvtk_button_representation}{vtk\+Button\+Representation}. Each button state can be represented with a separate instance of \doxylink{classvtk_prop3_d}{vtk\+Prop3D}. Thus buttons can be represented with \doxylink{classvtk_actor}{vtk\+Actor}, \doxylink{classvtk_image_actor}{vtk\+Image\+Actor}, volumes (e.\+g., \doxylink{classvtk_volume}{vtk\+Volume}) and/\+or any other \doxylink{classvtk_prop3_d}{vtk\+Prop3D}. Also, the class invokes events when highlighting occurs (i.\+e., hovering, selecting) so that appropriate action can be taken to highlight the button (if desired).

To use this representation, always begin by specifying the number of button states. Then provide, for each state, an instance of \doxylink{classvtk_prop3_d}{vtk\+Prop3D}.

This widget representation uses the conventional placement method. \doxylink{requirements_The}{The} button is placed inside the bounding box defined by Place\+Widget by translating and scaling the \doxylink{classvtk_prop3_d}{vtk\+Prop3D} to fit (each \doxylink{classvtk_prop3_d}{vtk\+Prop3D} is transformed). Therefore, you must define the number of button states and each state (i.\+e., \doxylink{classvtk_prop3_d}{vtk\+Prop3D}) prior to calling vtk\+Place\+Widget.
