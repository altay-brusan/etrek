\doxysubsection{Detailed Description}
Class for drawing an points given two columns from a \doxylink{classvtk_table}{vtk\+Table}. 

This class draws points in a plot given two columns from a table. If you need a line as well you should use \doxylink{classvtk_plot_line}{vtk\+Plot\+Line} which derives from \doxylink{classvtk_plot_points}{vtk\+Plot\+Points} and is capable of drawing both points and a line.
