\doxysubsection{Detailed Description}
a list of nodes that form an assembly path 

\doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path} represents an ordered list of assembly nodes that represent a fully evaluated assembly path. This class is used primarily for picking. Note that the use of this class is to add one or more assembly nodes to form the path. (An assembly node consists of an instance of \doxylink{classvtk_prop}{vtk\+Prop} and \doxylink{classvtk_matrix4x4}{vtk\+Matrix4x4}, the matrix may be NULL.) As each node is added, the matrices are concatenated to create a final, evaluated matrix.
