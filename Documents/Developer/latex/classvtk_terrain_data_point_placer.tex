\doxysubsection{Detailed Description}
Place points on terrain data. 

\doxylink{classvtk_terrain_data_point_placer}{vtk\+Terrain\+Data\+Point\+Placer} dictates the placement of points on height field data. \doxylink{requirements_The}{The} class takes as input the list of props that represent the terrain in a rendered scene. A height offset can be specified to dicatate the placement of points at a certain height above the surface.
