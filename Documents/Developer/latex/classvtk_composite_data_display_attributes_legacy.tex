\doxysubsection{Detailed Description}
rendering attributes for a multi-\/block dataset. 

\doxylink{requirements_The}{The} \doxylink{classvtk_composite_data_display_attributes_legacy}{vtk\+Composite\+Data\+Display\+Attributes\+Legacy} class stores display attributes for individual blocks in a multi-\/block dataset. Attributes are mapped to blocks through their flat-\/index; This is the mechanism used in legacy Open\+GL classes.
