\doxysubsection{Detailed Description}
Helper class for resolving overloaded functions. \doxylink{class_o_f_explicit_bool}{OFExplicit\+Bool} can be used to restrict an overloaded function\textquotesingle{}s parameter to "{}real"{} OFBool values, e.\+g. pointers and numeric values can NOT be converted to \doxylink{class_o_f_explicit_bool}{OFExplicit\+Bool} implicitly. \begin{DoxyNote}{Note}
OFBool falls back to "{}int"{} on platforms that don\textquotesingle{}t support the keyword "{}bool"{}. Therefore the conversion of int values to \doxylink{class_o_f_explicit_bool}{OFExplicit\+Bool} can\textquotesingle{}t be prevented on those platforms. 
\end{DoxyNote}
