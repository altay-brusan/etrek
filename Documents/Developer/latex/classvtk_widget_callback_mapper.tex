\doxysubsection{Detailed Description}
map widget events into callbacks 

\doxylink{classvtk_widget_callback_mapper}{vtk\+Widget\+Callback\+Mapper} maps widget events (defined in \doxylink{vtk_widget_event_8h_source}{vtk\+Widget\+Event.\+h}) into static class methods, and provides facilities to invoke the methods. This class is templated and meant to be used as an internal helper class by the widget classes. \doxylink{requirements_The}{The} class works in combination with the class \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}, which translates VTK events into widget events.
