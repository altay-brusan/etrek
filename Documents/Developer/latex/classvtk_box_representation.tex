\doxysubsection{Detailed Description}
a class defining the representation for the \doxylink{classvtk_box_widget2}{vtk\+Box\+Widget2} 

This class is a concrete representation for the \doxylink{classvtk_box_widget2}{vtk\+Box\+Widget2}. It represents a box with seven handles:\+ one on each of the six faces, plus a center handle. Through interaction with the widget, the box representation can be arbitrarily positioned in the 3D space.

To use this representation, you normally use the \doxylink{classvtk_box_representation_ad50be312a8bfa25a006e0a504174cde6}{Place\+Widget()} method to position the widget at a specified region in space.

\begin{DoxyWarning}{Warning}
This class, and \doxylink{classvtk_box_widget2}{vtk\+Box\+Widget2}, are second generation VTK widgets. An earlier version of this functionality was defined in the class \doxylink{classvtk_box_widget}{vtk\+Box\+Widget}.
\end{DoxyWarning}
