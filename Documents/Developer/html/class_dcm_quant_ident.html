Detailed Description

pseudo error diffusion class implementing an identity transformation. This class implements a public API mostly identical to that of class DcmQuantFloydSteinberg. Since several methods of the error diffusion class are called for each single image pixel during conversion of a color image to palette color, we do not use virtual methods and a common abstract base class here. Instead we implement all methods inline, and use a template to select the appropriate class at compile time. With a decent optimizer this reduces the overhead for using this class to zero.
