\doxysubsection{Detailed Description}
Superclass for Qt model adapters. 

\doxylink{classvtk_qt_abstract_model_adapter}{vtk\+Qt\+Abstract\+Model\+Adapter} is the superclass for classes that adapt VTK objects to QAbstract\+Item\+Model. This class contains API for converting between QModel\+Index and VTK ids, as well as some additional specialized functionality such as setting a column of data to use as the Qt header information.
