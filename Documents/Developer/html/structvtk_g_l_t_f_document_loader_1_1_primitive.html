Detailed Description

This struct describes a glTF primitive object. primitives specify vertex attributes, as well as connectivity information for a draw call. A primitive also specifies a material and GPU primitive type (e.g: triangle set) Data is first stored as integer indices, pointing to different accessors, then extracted into vtk data structures and finally used to build a vtkPolyData object.
