\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type$>$\newline
class Eigen::\+\+Super\+LU$<$ \+\_\+\+Matrix\+Type $>$}
A sparse direct LU factorization and solver based on the \doxylink{class_eigen_1_1_super_l_u}{Super\+LU} library. 

This class allows to solve for A.\+X = B sparse linear problems via a direct LU factorization using the \doxylink{class_eigen_1_1_super_l_u}{Super\+LU} library. \doxylink{requirements_The}{The} sparse matrix A must be squared and invertible. \doxylink{requirements_The}{The} vectors or matrices X and B can be either dense or sparse.
