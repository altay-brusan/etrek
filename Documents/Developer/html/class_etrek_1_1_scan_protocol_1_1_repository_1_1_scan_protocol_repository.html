Detailed Description

Repository for scan protocol configuration.

Implements the Repository pattern for scan protocol data access. Provides CRUD operations for:

  • Anatomic regions and body parts
  • Radiographic views
  • Radiographic procedures (multi-view sequences)
  • Technique parameters (KVP, mA, time settings)
  • View-technique associations
  • Procedure-view associations

Supports soft-delete for views and procedures to maintain historical integrity while removing from active use.
