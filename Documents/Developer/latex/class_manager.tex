void Manager::\+add\+Translation (\begin{DoxyParamCaption}\item[{Hash}]{source}{, }\item[{Hash}]{target}{}\end{DoxyParamCaption})}

Add a translation table entry for use during deserialization.

If we are deserializing pre-\/hashed strings into a non-\/empty manager, it is possible that collisions will result in different numbers being assigned to strings depending on the order of insertion. This table can be used to identify translations (from the map\textquotesingle{}s keys to the values) that should be applied when IDs from the deserialized manager are referenced by tokens also being deserialized.

{\itshape source} is a serialized key value and {\itshape target} is its new value in this manager\textquotesingle{}s m\+\_\+data map.

When you are finished deserializing, you should empty this table. \Hypertarget{class_manager_a94f3fe9bfc9e538588de9154e1f145f2}\index{Manager@{Manager}!compute@{compute}}

Compute a hash from a string value (without inserting it into the manager). If the string is not already managed, this will compute the hash value that {\itshape would} be used if the string were to be immediately inserted. This method allows hash collisions to be avoided; one can compute a hash while the map is write-\/locked and insert if needed.
