\doxysubsection{Detailed Description}
a combination of \doxylink{classvtk_color_transfer_function}{vtk\+Color\+Transfer\+Function} and \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table}. 

This is a cross between a \doxylink{classvtk_color_transfer_function}{vtk\+Color\+Transfer\+Function} and a \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} selectively combining the functionality of both. This class is a \doxylink{classvtk_color_transfer_function}{vtk\+Color\+Transfer\+Function} allowing users to specify the RGB control points that control the color transfer function. At the same time, by setting {\itshape Discretize} to 1 (true), one can force the transfer function to only have {\itshape Number\+Of\+Values} discrete colors.

When {\itshape Indexed\+Lookup} is true, this class behaves differently. \doxylink{requirements_The}{The} annotated values are considered to the be only valid values for which entries in the color table should be returned. \doxylink{requirements_The}{The} colors for annotated values are those specified using {\itshape Add\+Indexed\+Colors}. Typically, there must be at least as many indexed colors specified as the annotations. For backwards compatibility, if no indexed-\/colors are specified, the colors in the lookup {\itshape Table} are assigned to annotated values by taking the modulus of their index in the list of annotations. If a scalar value is not present in {\itshape Annotated\+Values}, then {\itshape Nan\+Color} will be used.

One can set a scalar opacity function to map scalars to color types handling transparency (VTK\+\_\+\+RGBA, VTK\+\_\+\+LUMINANCE\+\_\+\+ALPHA). Opacity mapping is off by default. Call Enable\+Opacity\+Mapping\+On() to handle mapping of alpha values.

NOTE:\+ One must call \doxylink{classvtk_discretizable_color_transfer_function_afb220beb8336ab0aa0fb5ede001af0f8}{Build()} after making any changes to the points in the Color\+Transfer\+Function to ensure that the discrete and non-\/discrete versions match up.
