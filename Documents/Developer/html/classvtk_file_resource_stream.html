◆ EndOfStream()

bool vtkFileResourceStream::EndOfStream ( )
overridevirtual

Check if the stream reached an end.

The stream may be out of range (EOF) if a Seek call move before stream begin (0), or after stream end (max) Seek on an EndOfStream stream may restore it back to a valid state. Read on an invalid stream must do nothing and return 0.

Returns
Return true if the stream reached the end of input, false otherwise.

Implements vtkResourceStream.

◆ Open()

bool vtkFileResourceStream::Open ( VTK_FILEPATH const char * path)

Open a file.

Opening a file reset the stream to initial position: Tell() = 0. EndOfStream is set to true if file opening failed. If path is nullptr, the file will only be closed. This function will increase modified time.

Parameters
paththe file path
Returns
true if file was successfully opened, false otherwise. Return false if path is nullptr.
