\doxysubsection{Detailed Description}
Represents a system user for authentication and authorization. 

\doxylink{namespace_etrek_1_1_core_1_1_data_1_1_entity}{Entity} class representing a user account in the system. Users are authenticated via username and password, and authorized based on their assigned roles.

Key features:\+
\begin{DoxyItemize}
\item Password stored as hash (via Crypto\+Manager)
\item Soft-\/delete support (Is\+Deleted flag)
\item Active/\+inactive status
\item Multiple role assignments
\item Audit timestamps (Create\+Date, Update\+Date)
\end{DoxyItemize}
