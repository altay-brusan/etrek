\doxysubsection{Detailed Description}
level of detail 3D prop 

\doxylink{classvtk_l_o_d_prop3_d}{vtk\+LODProp3D} is a class to support level of detail rendering for Prop3D. Any number of mapper/\+property/\+texture items can be added to this object. Render time will be measured, and will be used to select a LOD based on the Allocated\+Render\+Time of this Prop3D. Depending on the type of the mapper/\+property, a \doxylink{classvtk_actor}{vtk\+Actor} or a \doxylink{classvtk_volume}{vtk\+Volume} will be created behind the scenes.
