\doxysubsection{Detailed Description}
Adaptive volume mapper. 

\doxylink{classvtk_smart_volume_mapper}{vtk\+Smart\+Volume\+Mapper} is a volume mapper that will delegate to a specific volume mapper based on rendering parameters and available hardware. Use the \doxylink{classvtk_smart_volume_mapper_a84b57fd648da255337526487e580c1e3}{Set\+Requested\+Render\+Mode()} method to control the behavior of the selection. \doxylink{requirements_The}{The} following options are available:\+

\begin{DoxyParagraph}{vtk\+Smart\+Volume\+Mapper::\+Default\+Render\+Mode:\+}
Allow the \doxylink{classvtk_smart_volume_mapper}{vtk\+Smart\+Volume\+Mapper} to select the best mapper based on rendering parameters and hardware support. If GPU ray casting is supported, the \doxylink{classvtk_g_p_u_volume_ray_cast_mapper}{vtk\+GPUVolume\+Ray\+Cast\+Mapper} mapper will be used for all rendering. If not, then the \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper} will be used exclusively. This is the default requested render mode, and is generally the best option. When you use this option, your volume will always be rendered, but the method used to render it may vary based on parameters and platform.
\end{DoxyParagraph}
\begin{DoxyParagraph}{vtk\+Smart\+Volume\+Mapper::\+Ray\+Cast\+Render\+Mode:\+}
Use the \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper} for both interactive and still rendering. When you use this option your volume will always be rendered with the \doxylink{classvtk_fixed_point_volume_ray_cast_mapper}{vtk\+Fixed\+Point\+Volume\+Ray\+Cast\+Mapper}.
\end{DoxyParagraph}
\begin{DoxyParagraph}{vtk\+Smart\+Volume\+Mapper::\+GPURender\+Mode:\+}
Use the \doxylink{classvtk_g_p_u_volume_ray_cast_mapper}{vtk\+GPUVolume\+Ray\+Cast\+Mapper}, if supported, for both interactive and still rendering. If the GPU ray caster is not supported (due to hardware limitations or rendering parameters) then no image will be rendered. Use this option only if you have already checked for supported based on the current hardware, number of scalar components, and rendering parameters in the \doxylink{classvtk_volume_property}{vtk\+Volume\+Property}.
\end{DoxyParagraph}
\begin{DoxyParagraph}{vtk\+Smart\+Volume\+Mapper::\+GPURender\+Mode:\+}
You can adjust the contrast and brightness in the rendered image using the Final\+Color\+Window and Final\+Color\+Level ivars. By default the Final\+Color\+Window is set to 1.\+0, and the Final\+Color\+Level is set to 0.\+5, which applies no correction to the computed image. To apply the window /\+ level operation to the computer image color, first a Scale and Bias value are computed:\+ 
\begin{DoxyPre}
 scale = 1.0 / this-\/>FinalColorWindow
 bias  = 0.5 -\/ this-\/>FinalColorLevel / this-\/>FinalColorWindow
 \end{DoxyPre}
 To compute a new color (R\textquotesingle{}, G\textquotesingle{}, B\textquotesingle{}, A\textquotesingle{}) from an existing color (R,G,B,A) for a pixel, the following equation is used:\+ 
\begin{DoxyPre}
 R' = R*scale + bias*A
 G' = G*scale + bias*A
 B' = B*scale + bias*A
 A' = A
 \end{DoxyPre}
 Note that bias is multiplied by the alpha component before adding because the red, green, and blue component of the color are already pre-\/multiplied by alpha. Also note that the window /\+ level operation leaves the alpha component unchanged -\/ it only adjusts the RGB values. 
\end{DoxyParagraph}
