class Eigen::\+\+Map\+Base$<$ Derived, Write\+Accessors $>$}
\doxylink{class_eigen_1_1_cwise_binary_op_impl}{Base} class for non-\/const dense \doxylink{class_eigen_1_1_map}{Map} and \doxylink{class_eigen_1_1_block}{Block} expression with direct access. 

This base class provides the non-\/const low-\/level accessors (e.\+g. coeff and coeff\+Ref) of dense \doxylink{class_eigen_1_1_map}{Map} and \doxylink{class_eigen_1_1_block}{Block} objects with direct access. It inherits \doxylink{class_eigen_1_1_map_base_3_01_derived_00_01_read_only_accessors_01_4}{Map\+Base$<$\+Derived, Read\+Only\+Accessors$>$} which defines the const variant for reading specific entries.
