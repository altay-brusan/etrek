\doxysubsection{Detailed Description}
Use this class to quickly configure the package. For file based configuration see \doxylink{classdcmtk_1_1log4cplus_1_1_property_configurator}{Property\+Configurator}. \doxylink{classdcmtk_1_1log4cplus_1_1_basic_configurator}{Basic\+Configurator} automatically attaches \doxylink{classdcmtk_1_1log4cplus_1_1_console_appender}{Console\+Appender} to {\ttfamily root\+Logger}, with output going to standard output, using DEBUG \doxylink{_third_party_libraries_2dcmtk_2include_2dcmtk_2oflog_2_log_level_8h_a0b1dd55c81b77bb59e5adcd343f393d7}{Log\+Level} value. \doxylink{requirements_The}{The} additional parameter log\+To\+Std\+Err may redirect the output to standard error.
