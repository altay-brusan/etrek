\doxysubsection{Detailed Description}
record modification and/\+or execution time 

\doxylink{classvtk_time_stamp}{vtk\+Time\+Stamp} records a unique time when the method \doxylink{classvtk_time_stamp_a64a3db0969544b0ff03adc4521cf5068}{Modified()} is executed. This time is guaranteed to be monotonically increasing. Classes use this object to record modified and/\+or execution time. There is built in support for the binary \texorpdfstring{$<$}{<} and \texorpdfstring{$>$}{>} comparison operators between two \doxylink{classvtk_time_stamp}{vtk\+Time\+Stamp} objects.
