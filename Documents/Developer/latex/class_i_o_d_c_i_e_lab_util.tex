\doxysubsection{Detailed Description}
Class supporting color space conversions from and to CIELab. In some IODs DICOM stores CIELab color values which must often be converted to RGB for display or other purposes. This is supported by the functions \doxylink{class_i_o_d_c_i_e_lab_util_aaf7da7926e6e0736ba3027cf1af24489}{dicom\+Lab2\+RGB()} and \doxylink{class_i_o_d_c_i_e_lab_util_a8052d2261d22d4e2defada8ad7f91c07}{rgb2\+Dicom\+Lab()}. \doxylink{requirements_The}{The} CIELab value range in DICOM is \+[0,65535]\+ for all three values. \doxylink{requirements_The}{The} RGB value range in this class is \+[0;1]\+. Further functions are available in order to convert between RGB, "{}normal"{} CIELab value range as well as CIEXYZ. \doxylink{requirements_The}{The} class uses double floating point precision for calculations.
