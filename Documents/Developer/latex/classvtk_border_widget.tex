\doxysubsection{Detailed Description}
place a border around a 2D rectangular region 

This class is a superclass for 2D widgets that may require a rectangular border. Besides drawing a border, the widget provides methods for resizing and moving the rectangular region (and associated border). \doxylink{requirements_The}{The} widget provides methods and internal data members so that subclasses can take advantage of this widgets capabilities, requiring only that the subclass defines a "{}representation"{}, i.\+e., some combination of props or actors that can be managed in the 2D rectangular region.

\doxylink{requirements_The}{The} class defines basic positioning functionality, including the ability to size the widget with locked x/\+y proportions. \doxylink{requirements_The}{The} area within the border may be made "{}selectable"{} as well, meaning that a selection event interior to the widget invokes a virtual \doxylink{classvtk_border_widget_a54d6d4e05276100153998737fc5edf37}{Select\+Region()} method, which can be used to pick objects or otherwise manipulate data interior to the widget.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
On the boundary of the widget:
  LeftButtonPressEvent -\/ select boundary
  LeftButtonReleaseEvent -\/ deselect boundary
  MouseMoveEvent -\/ move/resize widget depending on which portion of the
                   boundary was selected.
On the interior of the widget:
  LeftButtonPressEvent -\/ invoke SelectButton() callback (if the ivar
                         Selectable is on)
Anywhere on the widget:
  MiddleButtonPressEvent -\/ move the widget
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_border_widget}{vtk\+Border\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::Select -\/-\/ some part of the widget has been selected
  vtkWidgetEvent::EndSelect -\/-\/ the selection process has completed
  vtkWidgetEvent::Translate -\/-\/ the widget is to be translated
  vtkWidgetEvent::Move -\/-\/ a request for slider motion has been invoked
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
In turn, when these widget events are processed, this widget invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (on vtkWidgetEvent::Select)
  vtkCommand::EndInteractionEvent (on vtkWidgetEvent::EndSelect)
  vtkCommand::InteractionEvent (on vtkWidgetEvent::Move)
\end{DoxyPre}

\end{DoxyParagraph}
