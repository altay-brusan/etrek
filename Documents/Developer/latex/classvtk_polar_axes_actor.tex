\doxysubsection{Detailed Description}
create an actor of a polar axes -\/ 

\doxylink{classvtk_polar_axes_actor}{vtk\+Polar\+Axes\+Actor} is a composite actor that draws polar axes in a specified plane for a give pole. Currently the plane has to be the xy plane.
