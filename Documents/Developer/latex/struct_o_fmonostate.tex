\doxysubsection{Detailed Description}
A helper type for making \doxylink{class_o_fvariant}{OFvariant} default constructible.

Use \doxylink{struct_o_fmonostate}{OFmonostate} as the first alternative of an \doxylink{class_o_fvariant}{OFvariant} otherwise holding a non default constructible type as the first alternative for making the variant itself default constructible. \begin{DoxyNote}{Note}
Be aware that any visitor applied to such an \doxylink{class_o_fvariant}{OFvariant} object must also accept \doxylink{struct_o_fmonostate}{OFmonostate} as an argument.
\end{DoxyNote}
