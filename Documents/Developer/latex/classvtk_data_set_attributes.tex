\doxysubsection{Detailed Description}
represent and manipulate attribute data in a dataset 

\doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} is a class that is used to represent and manipulate attribute data (e.\+g., scalars, vectors, normals, texture coordinates, tensors, global ids, pedigree ids, and field data).

This adds to \doxylink{classvtk_field_data}{vtk\+Field\+Data} the ability to pick one of the arrays from the field as the currently active array for each attribute type. In other words, you pick one array to be called "{}\+THE"{} Scalars, and then filters down the pipeline will treat that array specially. For example \doxylink{classvtk_contour_filter}{vtk\+Contour\+Filter} will contour "{}\+THE"{} Scalar array unless a different array is asked for.

Additionally \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} provides methods that filters call to pass data through, copy data into, and interpolate from Fields. Pass\+Data passes entire arrays from the source to the destination. Copy passes through some subset of the tuples from the source to the destination. Interpolate interpolates from the chosen tuple(s) in the source data, using the provided weights, to produce new tuples in the destination. Each attribute type has pass, copy and interpolate "{}copy"{} flags that can be set in the destination to choose which attribute arrays will be transferred from the source to the destination.

Finally this class provides a mechanism to determine which attributes a group of sources have in common, and to copy tuples from a source into the destination, for only those attributes that are held by all.

\begin{DoxyWarning}{Warning}
\doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} is not in general thread safe due to the use of its \doxylink{classvtk_field_data_1_1_basic_iterator}{vtk\+Field\+Data::\+\+Basic\+Iterator} Required\+Arrays data member. \doxylink{requirements_The}{The} class \doxylink{classvtk_array_list_template}{vtk\+Array\+List\+Template} augments \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} for thread safety.
\end{DoxyWarning}
