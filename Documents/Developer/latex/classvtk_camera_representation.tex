\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_camera_widget}{vtk\+Camera\+Widget} 

This class provides support for interactively saving a series of camera views into an interpolated path (using \doxylink{classvtk_camera_interpolator}{vtk\+Camera\+Interpolator}). \doxylink{requirements_The}{The} class typically works in conjunction with \doxylink{classvtk_camera_widget}{vtk\+Camera\+Widget}. To use this class simply specify the camera to interpolate and use the methods \doxylink{classvtk_camera_representation_affb0f2ca31e7ebc8c1411bd9aa329975}{Add\+Camera\+To\+Path()}, Animate\+Path(), and Initialize\+Path() to add a new camera view, animate the current views, and initialize the interpolation.
