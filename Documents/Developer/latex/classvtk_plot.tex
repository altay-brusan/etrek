Provide un-\/log-\/scaled bounds for the plot inputs.

This function is analogous to \doxylink{classvtk_plot_a8b073314160beb27d76ce7bd70fc1052}{Get\+Bounds()} with 2 exceptions:\+
\begin{DoxyEnumerate}
\item It will never return log-\/scaled bounds even when the x-\/ and/\+or y-\/axes are log-\/scaled.
\item It will always return the bounds along the {\itshape input} axes rather than the output chart coordinates. Thus Get\+XAxis() returns the axis associated with the first 2 bounds entries and Get\+YAxis() returns the axis associated with the next 2 bounds entries.
\end{DoxyEnumerate}

For example, \doxylink{classvtk_plot_bar}{vtk\+Plot\+Bar}\textquotesingle{}s \doxylink{classvtk_plot_a8b073314160beb27d76ce7bd70fc1052}{Get\+Bounds()} method will swap axis bounds when its orientation is vertical while its \doxylink{classvtk_plot_a7a1f47fccee9076d77ad276de4b32f26}{Get\+Unscaled\+Input\+Bounds()} will not swap axis bounds.

This method is provided so user interfaces can determine whether or not to allow log-\/scaling of a particular \doxylink{classvtk_axis}{vtk\+Axis}.

Subclasses of \doxylink{classvtk_plot}{vtk\+Plot} are responsible for implementing this function to transform input plot data.

\doxylink{requirements_The}{The} returned {\itshape bounds} are stored as (Xmin, Xmax, Ymin, Ymax).
