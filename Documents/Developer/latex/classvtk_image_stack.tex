\doxysubsection{Detailed Description}
manages a stack of composited images 

\doxylink{classvtk_image_stack}{vtk\+Image\+Stack} manages the compositing of a set of images. Each image is assigned a layer number through its property object, and it is this layer number that determines the compositing order:\+ images with a higher layer number are drawn over top of images with a lower layer number. \doxylink{requirements_The}{The} image stack has a Set\+Active\+Layer method for controlling which layer to use for interaction and picking. \begin{DoxyParagraph}{Thanks:\+}
Thanks to David Gobbi at the Seaman Family MR Centre and Dept. of Clinical Neurosciences, Foothills Medical Centre, Calgary, for providing this class.
