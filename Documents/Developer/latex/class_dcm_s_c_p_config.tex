\doxysubsection{Detailed Description}
Class that encapsulates an SCP configuration that is needed in order to configure the service negotiation behavior (presentation contexts, AE title, listening port, etc) as well as some runtime configuration like the DIMSE timeout. \doxylink{requirements_The}{The} configuration, however, is not updated to reflect any runtime connection information, e.\+g. information about the current SCU connected or the like. \doxylink{requirements_The}{The} presentation context configuration is held in profiles. Per default, the name of the active association configuration is DEFAULT.
