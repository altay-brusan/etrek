\doxysubsection{Detailed Description}
Convert a selection from one type to another. 

\doxylink{classvtk_convert_selection}{vtk\+Convert\+Selection} converts an input selection from one type to another in the context of a data object being selected. \doxylink{requirements_The}{The} first input is the selection, while the second input is the data object that the selection relates to.
