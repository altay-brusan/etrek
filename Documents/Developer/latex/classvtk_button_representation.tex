\doxysubsection{Detailed Description}
abstract class defines the representation for a \doxylink{classvtk_button_widget}{vtk\+Button\+Widget} 

This abstract class is used to specify how the \doxylink{classvtk_button_widget}{vtk\+Button\+Widget} should interact with representations of the \doxylink{classvtk_button_widget}{vtk\+Button\+Widget}. This class may be subclassed so that alternative representations can be created. \doxylink{requirements_The}{The} class defines an API, and a default implementation, that the \doxylink{classvtk_button_widget}{vtk\+Button\+Widget} interacts with to render itself in the scene.

\doxylink{requirements_The}{The} \doxylink{classvtk_button_widget}{vtk\+Button\+Widget} assumes an n-\/state button so that traversal methods are available for changing, querying and manipulating state. Derived classed determine the actual appearance. \doxylink{requirements_The}{The} state is represented by an integral value 0\texorpdfstring{$<$}{<}=state\texorpdfstring{$<$}{<}num\+States.

To use this representation, always begin by specifying the number of states. Then follow with the necessary information to represent each state (done through a subclass API).
