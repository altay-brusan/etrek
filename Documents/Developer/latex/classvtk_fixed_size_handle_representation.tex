\doxysubsection{Detailed Description}
A marker that has the same size in pixels. 

This class is a concrete implementation of \doxylink{classvtk_handle_representation}{vtk\+Handle\+Representation}. It is meant to be used as a representation for \doxylink{classvtk_handle_widget}{vtk\+Handle\+Widget}. Unlike the other representations, this can maintain a constant size in pixels, regardless of the camera zoom parameters. \doxylink{requirements_The}{The} size in pixels may be set via Set\+Handle\+Size\+In\+Pixels. This representation renders the markers as spherical blobs in 3D space with the width as specified above, defaults to 10 pixels. \doxylink{requirements_The}{The} handles will have the same size in pixels, give or take a certain tolerance, as specified by Set\+Handle\+Size\+Tolerance\+In\+Pixels. \doxylink{requirements_The}{The} tolerance defaults to half a pixel. Point\+Placers may be used to specify constraints on the placement of markers. For instance a \doxylink{classvtk_polygonal_surface_point_placer}{vtk\+Polygonal\+Surface\+Point\+Placer} will constrain placement of these spherical handles to a surface mesh.
