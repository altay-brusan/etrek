\doxysubsection{Detailed Description}
represent a node in an assembly 

\doxylink{classvtk_assembly_node}{vtk\+Assembly\+Node} represents a node in an assembly. It is used by \doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path} to create hierarchical assemblies of props. \doxylink{requirements_The}{The} props can be either 2D or 3D.

An assembly node refers to a \doxylink{classvtk_prop}{vtk\+Prop}, and possibly a \doxylink{classvtk_matrix4x4}{vtk\+Matrix4x4}. Nodes are used by \doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path} to build fully evaluated path (matrices are concatenated through the path) that is used by picking and other operations involving assemblies.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} assembly node is guaranteed to contain a reference to an instance of \doxylink{classvtk_matrix4x4}{vtk\+Matrix4x4} if the prop referred to by the node is of type \doxylink{classvtk_prop3_d}{vtk\+Prop3D} (or subclass). \doxylink{requirements_The}{The} matrix is evaluated through the assembly path, so the assembly node\textquotesingle{}s matrix is a function of its location in the \doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path}.

\doxylink{classvtk_assembly_node}{vtk\+Assembly\+Node} does not reference count its association with \doxylink{classvtk_prop}{vtk\+Prop}. Therefore, do not create an assembly node, associate a prop with it, delete the prop, and then try to dereference the prop. \doxylink{requirements_The}{The} program will break! (Reason:\+ \doxylink{classvtk_assembly_path}{vtk\+Assembly\+Path} (which uses \doxylink{classvtk_assembly_node}{vtk\+Assembly\+Node}) create self-\/referencing loops that destroy reference counting.)
\end{DoxyWarning}
