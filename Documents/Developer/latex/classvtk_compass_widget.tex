\doxysubsection{Detailed Description}
widget to set distance, tilt and heading 

\doxylink{requirements_The}{The} \doxylink{classvtk_compass_widget}{vtk\+Compass\+Widget} is used to adjust distance, tilt and heading parameters in an application. It uses \doxylink{classvtk_compass_representation}{vtk\+Compass\+Representation} as its representation.

To customize the widget override the Create\+Default\+Representation method and set the representation to your own subclass of \doxylink{classvtk_compass_representation}{vtk\+Compass\+Representation}. Ranges for distance and tilt can be set in \doxylink{classvtk_compass_representation}{vtk\+Compass\+Representation}.

\begin{DoxyParagraph}{Event Bindings:\+}
By default, the widget responds to the following VTK events (i.\+e., it watches the \doxylink{classvtk_render_window_interactor}{vtk\+Render\+Window\+Interactor} for these events):\+ 
\begin{DoxyPre}
If the slider bead is selected:
  LeftButtonPressEvent -\/ select slider
  LeftButtonReleaseEvent -\/ release slider
  MouseMoveEvent -\/ move slider
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
Note that the event bindings described above can be changed using this class\textquotesingle{}s \doxylink{classvtk_widget_event_translator}{vtk\+Widget\+Event\+Translator}. This class translates VTK events into the \doxylink{classvtk_compass_widget}{vtk\+Compass\+Widget}\textquotesingle{}s widget events:\+ 
\begin{DoxyPre}
  vtkWidgetEvent::Select -\/-\/ some part of the widget has been selected
  vtkWidgetEvent::EndSelect -\/-\/ the selection process has completed
  vtkWidgetEvent::Move -\/-\/ a request for slider motion has been invoked
\end{DoxyPre}

\end{DoxyParagraph}
\begin{DoxyParagraph}{Event Bindings:\+}
In turn, when these widget events are processed, the \doxylink{classvtk_compass_widget}{vtk\+Compass\+Widget} invokes the following VTK events on itself (which observers can listen for):\+ 
\begin{DoxyPre}
  vtkCommand::StartInteractionEvent (on vtkWidgetEvent::Select)
  vtkCommand::EndInteractionEvent (on vtkWidgetEvent::EndSelect)
  vtkCommand::InteractionEvent (on vtkWidgetEvent::Move)
  vtkCommand::WidgetValueChangedEvent (when widget values have changed)
\end{DoxyPre}
 
\end{DoxyParagraph}
