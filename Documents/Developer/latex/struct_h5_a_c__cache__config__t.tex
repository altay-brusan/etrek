\doxysubsection{Detailed Description}
\doxylink{struct_h5_a_c__cache__config__t}{H5\+AC\+\_\+cache\+\_\+config\+\_\+t} is a public structure intended for use in public APIs. At least in its initial incarnation, it is basically a copy of {\ttfamily struct} {\ttfamily H5\+C\+\_\+auto\+\_\+size\+\_\+ctl\+\_\+t}, minus the {\ttfamily report\+\_\+fcn} field, and plus the {\ttfamily dirty\+\_\+bytes\+\_\+threshold} field.

\doxylink{requirements_The}{The} {\ttfamily report\+\_\+fcn} field is omitted, as including it would require us to make {\ttfamily H5\+C\+\_\+t} structure public.

\doxylink{requirements_The}{The} {\ttfamily dirty\+\_\+bytes\+\_\+threshold} field does not appear in {\ttfamily H5\+C\+\_\+auto\+\_\+size\+\_\+ctl\+\_\+t}, as synchronization between caches on different processes is handled at the {\ttfamily H5\+AC} level, not at the level of {\ttfamily H5C}. Note however that there is considerable interaction between this value and the other fields in this structure.

Similarly, the {\ttfamily open\+\_\+trace\+\_\+file}, {\ttfamily close\+\_\+trace\+\_\+file}, and {\ttfamily trace\+\_\+file\+\_\+name} fields do not appear in {\ttfamily H5\+C\+\_\+auto\+\_\+size\+\_\+ctl\+\_\+t}, as most trace file issues are handled at the {\ttfamily H5\+AC} level. \doxylink{requirements_The}{The} one exception is storage of the pointer to the trace file, which is handled by {\ttfamily H5C}.

\doxylink{requirements_The}{The} structure is in \doxylink{_h5_a_cpublic_8h_source}{H5\+ACpublic.\+h} as we may wish to allow different configuration options for metadata and raw data caches.
