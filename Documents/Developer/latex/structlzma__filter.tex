\doxysubsection{Detailed Description}
Filter options. 

This structure is used to pass a Filter ID and a pointer to the filter\textquotesingle{}s options to liblzma. A few functions work with a single \doxylink{structlzma__filter}{lzma\+\_\+filter} structure, while most functions expect a filter chain.

A filter chain is indicated with an array of \doxylink{structlzma__filter}{lzma\+\_\+filter} structures. \doxylink{requirements_The}{The} array is terminated with .id = LZMA\+\_\+\+VLI\+\_\+\+UNKNOWN. Thus, the filter array must have LZMA\+\_\+\+FILTERS\+\_\+\+MAX + 1 elements (that is, five) to be able to hold any arbitrary filter chain. This is important when using lzma\+\_\+block\+\_\+header\+\_\+decode() from block.\+h, because a filter array that is too small would make liblzma write past the end of the array.
