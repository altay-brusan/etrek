\doxysubsection{Detailed Description}
Interface for generating images and path data from string data, using multiple backends. 

\doxylink{classvtk_text_renderer}{vtk\+Text\+Renderer} produces images, bounding boxes, and \doxylink{classvtk_path}{vtk\+Path} objects that represent text. \doxylink{requirements_The}{The} advantage of using this class is to easily integrate mathematical expressions into renderings by automatically switching between Free\+Type and Math\+Text backends. If the input string contains at least two "{}\$"{} symbols separated by text, the Math\+Text backend will be used. Alternatively, the presence of unescaped "{}\texorpdfstring{$\vert$}{|}"{} symbols defines multicolumn lines, which are processed with the Math\+Text backend.

If the string does not meet these criteria, or if no Math\+Text implementation is available, the faster Free\+Type rendering facilities are used. Literal \$ symbols can be used by escaping them with backslashes, "{}\textbackslash{}\$"{} (or "{}\textbackslash{}\textbackslash{}\$"{} if the string is set programmatically).

For example, "{}\+Acceleration (\$\textbackslash{}\textbackslash{}frac\{m\}\{s\texorpdfstring{$^\wedge$}{\string^}2\}\$)"{} will use Math\+Text, but "{}\textbackslash{}\textbackslash{}\$500, \textbackslash{}\textbackslash{}\$100"{} will use Free\+Type.

By default, the backend is set to Detect, which determines the backend based on the contents of the string. This can be changed by setting the Default\+Backend ivar.

Note that this class is abstract -- link to the vtk\+Rendering\+Freetype module to get the default implementation.
