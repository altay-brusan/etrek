\doxysubsection{Detailed Description}
Reader for amr datasets (\doxylink{classvtk_overlapping_a_m_r}{vtk\+Overlapping\+AMR} or \doxylink{classvtk_non_overlapping_a_m_r}{vtk\+Non\+Overlapping\+AMR}). 

\doxylink{classvtk_x_m_l_uniform_grid_a_m_r_reader}{vtk\+XMLUniform\+Grid\+AMRReader} reads the VTK XML data files for all types of amr datasets including \doxylink{classvtk_overlapping_a_m_r}{vtk\+Overlapping\+AMR}, \doxylink{classvtk_non_overlapping_a_m_r}{vtk\+Non\+Overlapping\+AMR} and the legacy \doxylink{classvtk_hierarchical_box_data_set}{vtk\+Hierarchical\+Box\+Data\+Set}. \doxylink{requirements_The}{The} reader uses information in the file to determine what type of dataset is actually being read and creates the output-\/data object accordingly.

This reader can only read files with version 1.\+1 or greater. Older versions can be converted to the newer versions using \doxylink{classvtk_x_m_l_hierarchical_box_data_file_converter}{vtk\+XMLHierarchical\+Box\+Data\+File\+Converter}.
