\subsubsection*{template$<$typename \+\_\+\+Matrix\+Type, typename \+\_\+\+Preconditioner$>$\newline
class Eigen::\+\+Least\+Squares\+Conjugate\+Gradient$<$ \+\_\+\+Matrix\+Type, \+\_\+\+Preconditioner $>$}
A conjugate gradient solver for sparse (or dense) least-\/square problems. 

This class allows to solve for A x = b linear problems using an iterative conjugate gradient algorithm. \doxylink{requirements_The}{The} matrix A can be non symmetric and rectangular, but the matrix A\textquotesingle{} A should be positive-\/definite to guaranty stability. Otherwise, the \doxylink{class_eigen_1_1_sparse_l_u}{Sparse\+LU} or \doxylink{class_eigen_1_1_sparse_q_r}{Sparse\+QR} classes might be preferable. \doxylink{requirements_The}{The} matrix A and the vectors x and b can be either dense or sparse.


\begin{DoxyTemplParams}{Template Parameters}
{\em \+\_\+\+Matrix\+Type} & the type of the matrix A, can be a dense or a sparse matrix. \\
\hline
{\em \+\_\+\+Preconditioner} & the type of the preconditioner. Default is \doxylink{class_eigen_1_1_least_square_diagonal_preconditioner}{Least\+Square\+Diagonal\+Preconditioner}\\
\hline
\end{DoxyTemplParams}
\textbackslash{}implsparsesolverconcept

\doxylink{requirements_The}{The} maximal number of iterations and tolerance value can be controlled via the \doxylink{class_eigen_1_1_iterative_solver_base_a1bbaf86b7df6d54e78ced4da6ed2dac1}{set\+Max\+Iterations()} and \doxylink{class_eigen_1_1_iterative_solver_base_ac43c50c69a5b621cb5a9991a1005750d}{set\+Tolerance()} methods. \doxylink{requirements_The}{The} defaults are the size of the problem for the maximal number of iterations and Num\+Traits$<$\+Scalar$>$::\+epsilon() for the tolerance.
