\doxysubsection{Detailed Description}
A table, which contains similar-\/typed columns of data. 

\doxylink{classvtk_table}{vtk\+Table} is a basic data structure for storing columns of data. Internally, columns are stored in a \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} structure called Row\+Data. However, using the \doxylink{classvtk_table}{vtk\+Table} API additionally ensures that every column has the same number of entries, and provides row access (using \doxylink{classvtk_variant_array}{vtk\+Variant\+Array}) and single entry access (using \doxylink{classvtk_variant}{vtk\+Variant}).

Inserting or removing rows via the class API preserves existing table data where possible.

\doxylink{requirements_The}{The} "{}\+Remove\+Row\texorpdfstring{$\ast$}{*}"{} and \doxylink{classvtk_table_ac6d2c4696e0dc6ee4fd8ef53cacce845}{Set\+Number\+Of\+Rows()} operations will not release memory. Call on \doxylink{classvtk_table_a7fa414130be43f36fbcccc55cb6829b8}{Squeeze\+Rows()} to achieve this after performing the operations.

\doxylink{requirements_The}{The} field data inherited from \doxylink{classvtk_data_object}{vtk\+Data\+Object} may be used to store metadata related to the table.

\begin{DoxyWarning}{Warning}
You should use the \doxylink{classvtk_table}{vtk\+Table} API to change the table data. Performing operations on the object returned by Get\+Row\+Data() may yield unexpected results. \doxylink{classvtk_table}{vtk\+Table} does allow the user to set the field data using Set\+Row\+Data(); the number of rows in the table is determined by the number of tuples in the first array (it is assumed that all arrays are the same length).

Each column added with Add\+Column {\bfseries{must}} have its name set to a unique, non-\/empty string in order for \doxylink{classvtk_table_a9ec1aa7e278a7f6dd9fc8d374b1b124e}{Get\+Value()} to function properly.
\end{DoxyWarning}
