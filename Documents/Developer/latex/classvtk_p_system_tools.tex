\doxysubsection{Detailed Description}
System tools for file system introspection. 

A class with only static methods for doing parallel file system introspection. It limits doing file stats on process 0 and broadcasting the results to other processes. It is built on VTK\textquotesingle{}s System\+Tools class and uses the global controller for communication. It uses blocking collective communication operations.
