\doxysubsection{Detailed Description}
Non-\/templated superclass for \doxylink{classvtk_smart_pointer}{vtk\+Smart\+Pointer}. 

\doxylink{classvtk_smart_pointer_base}{vtk\+Smart\+Pointer\+Base} holds a pointer to a \doxylink{classvtk_object_base}{vtk\+Object\+Base} or subclass instance and performs one Register/\+\+Un\+Register pair. This is useful for storing VTK objects in STL containers. This class is not intended to be used directly. Instead, use the \doxylink{classvtk_smart_pointer}{vtk\+Smart\+Pointer} class template to automatically perform proper cast operations.
