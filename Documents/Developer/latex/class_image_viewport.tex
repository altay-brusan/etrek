\doxysubsection{Detailed Description}
A single viewport widget containing a VTK render widget. 

This widget wraps \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} and adds:\+
\begin{DoxyItemize}
\item Mouse event forwarding to delegates
\item Active/\+inactive border styling
\item Focus handling for multi-\/viewport layouts 
\end{DoxyItemize}
