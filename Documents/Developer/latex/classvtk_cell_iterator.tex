\doxysubsection{Detailed Description}
Efficient cell iterator for \doxylink{classvtk_data_set}{vtk\+Data\+Set} topologies. 

\doxylink{classvtk_cell_iterator}{vtk\+Cell\+Iterator} provides a method for traversing cells in a data set. Call the \doxylink{classvtk_data_set_a70ced2396f9cc085cc95c2b3aeeb0b14}{vtk\+Data\+Set::\+\+New\+Cell\+Iterator()} method to use this class.

\doxylink{requirements_The}{The} cell is represented as a set of three pieces of information:\+ \doxylink{requirements_The}{The} cell type, the ids of the points constituting the cell, and the points themselves. This iterator fetches these as needed. If only the cell type is used, the type is not looked up until Get\+Cell\+Type is called, and the point information is left uninitialized. This allows efficient screening of cells, since expensive point lookups may be skipped depending on the cell type/\+etc.
