\doxysubsection{Detailed Description}
helper class to aid working with structured extents. 

\doxylink{classvtk_structured_extent}{vtk\+Structured\+Extent} is an helper class that helps in arithmetic with structured extents. It defines a bunch of static methods (most of which are inlined) to aid in dealing with extents.
