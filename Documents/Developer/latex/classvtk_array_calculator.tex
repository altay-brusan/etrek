\doxysubsection{Detailed Description}
perform mathematical operations on data in field data arrays 

\doxylink{classvtk_array_calculator}{vtk\+Array\+Calculator} performs operations on vectors or scalars in field data arrays. It uses vtk\+Function\+Parser/\+vtk\+Expr\+Tk\+Function\+Parser to do the parsing and to evaluate the function for each entry in the input arrays. \doxylink{requirements_The}{The} arrays used in a given function must be all in point data or all in cell data. \doxylink{requirements_The}{The} resulting array will be stored as a field data array. \doxylink{requirements_The}{The} result array can either be stored in a new array or it can overwrite an existing array. \doxylink{classvtk_array_calculator}{vtk\+Array\+Calculator} can run in parallel using \doxylink{classvtk_s_m_p_tools}{vtk\+SMPTools}.

\doxylink{requirements_The}{The} functions that this array calculator understands is:\+

standard operations:\+
\begin{DoxyItemize}
\item 
\item 
\item /\+ \texorpdfstring{$^\wedge$}{\string^} . (only by \doxylink{classvtk_function_parser}{vtk\+Function\+Parser}) build unit vectors:\+ i\+Hat, j\+Hat, k\+Hat (ie (1,0,0), (0,1,0), (0,0,1)) abs acos asin atan ceil cos cosh exp floor ln mag min max norm dot (only by \doxylink{classvtk_expr_tk_function_parser}{vtk\+Expr\+Tk\+Function\+Parser}) cross sign sin sinh sqrt tan tanh
\end{DoxyItemize}

Note that some of these operations work on scalars, some on vectors, and some on both (e.\+g., you can multiply a scalar times a vector). \doxylink{requirements_The}{The} operations are performed tuple-\/wise (i.\+e., tuple-\/by-\/tuple). \doxylink{requirements_The}{The} user must specify which arrays to use as vectors and/\+or scalars, and the name of the output data array.
