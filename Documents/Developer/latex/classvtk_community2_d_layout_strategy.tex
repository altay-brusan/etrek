\doxysubsection{Detailed Description}
a simple fast 2D graph layout that looks for a community array on it\textquotesingle{}s input and strengthens edges within a community and weakens edges not within the community. 

This class is a density grid based force directed layout strategy. Also please note that \textquotesingle{}fast\textquotesingle{} is relative to quite slow. :\+) \doxylink{requirements_The}{The} layout running time is O(V+E) with an extremely high constant. \begin{DoxyParagraph}{Thanks:\+}
