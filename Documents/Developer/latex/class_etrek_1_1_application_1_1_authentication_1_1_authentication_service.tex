\doxysubsection{Detailed Description}
\doxylink{namespace_etrek_1_1_application_1_1_service}{Service} for user authentication and management. 

Handles user authentication via login dialog and provides user management operations (CRUD) with cryptographic password handling.

Key responsibilities:\+
\begin{DoxyItemize}
\item Display login dialog for user authentication
\item Verify credentials using \doxylink{class_etrek_1_1_application_1_1_authentication_1_1_authentication_repository}{Authentication\+Repository}
\item Hash passwords using \doxylink{class_etrek_1_1_application_1_1_authentication_1_1_crypto_manager}{Crypto\+Manager}
\item Emit signals for user management events
\item Display user manager dialog for admin operations
\end{DoxyItemize}
