\doxysubsection{Detailed Description}
Factory for creating examination mode strategy instances. 

This factory creates the appropriate strategy implementation based on the requested examination mode. It encapsulates the strategy creation logic and allows for easy extension with new modes.

Supported modes:\+
\begin{DoxyItemize}
\item CLINICAL:\+ \doxylink{class_etrek_1_1_application_1_1_strategy_1_1_clinical_examination_strategy}{Clinical\+Examination\+Strategy} (full DICOM workflow)
\item DEMO:\+ \doxylink{class_etrek_1_1_application_1_1_strategy_1_1_demo_examination_strategy}{Demo\+Examination\+Strategy} (sample images, no persistence)
\item CALIBRATION:\+ \doxylink{class_etrek_1_1_application_1_1_strategy_1_1_calibration_examination_strategy}{Calibration\+Examination\+Strategy} (equipment calibration)
\item TEST:\+ \doxylink{class_etrek_1_1_application_1_1_strategy_1_1_test_examination_strategy}{Test\+Examination\+Strategy} (QA testing)
\end{DoxyItemize}
