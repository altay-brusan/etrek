\doxysubsection{Detailed Description}
2D Noise Generator. Generate arrays for use as noise texture in the LIC algorithm. Can generate noise with uniform or Gaussian distributions, with a desired number of noise levels, and a desired frequency (f \texorpdfstring{$<$}{<} 1 is impulse noise).
