\doxysubsection{Detailed Description}
Interface for examination workflow context. 

This context is created when a user selects a Modality Worklist item and navigates to the Examination page. It provides all the information needed to initialize the examination workflow.

\doxylink{requirements_The}{The} context includes:\+
\begin{DoxyItemize}
\item Selected Worklist\+Entry and its attributes
\item Patient demographics extracted from DICOM tags
\item Study/\+procedure information 
\end{DoxyItemize}
