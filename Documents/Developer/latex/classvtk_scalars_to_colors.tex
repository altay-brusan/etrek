\doxysubsection{Detailed Description}
Superclass for mapping scalar values to colors. 

\doxylink{classvtk_scalars_to_colors}{vtk\+Scalars\+To\+Colors} is a general-\/purpose base class for objects that convert scalars to colors. This include \doxylink{classvtk_lookup_table}{vtk\+Lookup\+Table} classes and color transfer functions. By itself, this class will simply rescale the scalars.

\doxylink{requirements_The}{The} scalar-\/to-\/color mapping can be augmented with an additional uniform alpha blend. This is used, for example, to blend a \doxylink{classvtk_actor}{vtk\+Actor}\textquotesingle{}s opacity with the lookup table values.

Specific scalar values may be annotated with text strings that will be included in color legends using {\itshape Set\+Annotations}, {\itshape Set\+Annotation}, {\itshape Get\+Number\+Of\+Annotated\+Values}, {\itshape Get\+Annotated\+Value}, {\itshape Get\+Annotation}, {\itshape Remove\+Annotation}, and {\itshape Reset\+Annotations}.

This class also has a method for indicating that the set of annotated values form a categorical color map; by setting {\itshape Indexed\+Lookup} to true, you indicate that the annotated values are the only valid values for which entries in the color table should be returned. In this mode, subclasses should then assign colors to annotated values by taking the modulus of an annotated value\textquotesingle{}s index in the list of annotations with the number of colors in the table.
