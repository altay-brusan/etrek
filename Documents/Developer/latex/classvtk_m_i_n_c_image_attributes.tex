\doxysubsection{Detailed Description}
A container for a MINC image header. 

This class provides methods to access all of the information contained in the MINC header. If you read a MINC file into VTK and then write it out again, you can use writer-\/\texorpdfstring{$>$}{>}Set\+Image\+Attributes(reader-\/\texorpdfstring{$>$}{>}Get\+Image\+Attributes) to ensure that all of the medical information contained in the file is transferred from the reader to the writer. If you want to change any of the header information, you must use Shallow\+Copy to make a copy of the reader\textquotesingle{}s attributes and then modify only the copy. \begin{DoxySeeAlso}{See also}
\doxylink{classvtk_m_i_n_c_image_reader}{vtk\+MINCImage\+Reader} \doxylink{classvtk_m_i_n_c_image_writer}{vtk\+MINCImage\+Writer}
