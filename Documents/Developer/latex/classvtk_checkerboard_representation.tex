\doxysubsection{Detailed Description}
represent the \doxylink{classvtk_checkerboard_widget}{vtk\+Checkerboard\+Widget} 

\doxylink{requirements_The}{The} \doxylink{classvtk_checkerboard_representation}{vtk\+Checkerboard\+Representation} is used to implement the representation of the \doxylink{classvtk_checkerboard_widget}{vtk\+Checkerboard\+Widget}. \doxylink{requirements_The}{The} user can adjust the number of divisions in each of the i-\/j directions in a 2D image. A frame appears around the \doxylink{classvtk_image_actor}{vtk\+Image\+Actor} with sliders along each side of the frame. \doxylink{requirements_The}{The} user can interactively adjust the sliders to the desired number of checkerboard subdivisions. \doxylink{requirements_The}{The} representation uses four instances of \doxylink{classvtk_slider_representation3_d}{vtk\+Slider\+Representation3D} to implement itself.
