◆ SharedPointIds

vtkNew<vtkIdTypeArray> vtkDIYGhostUtilities::UnstructuredDataBlockStructure::SharedPointIds

It can happen that a point can be sent by multiple blocks. If those points are not carefully tracked down, we can end up instantiating multiple times a point that should be created only once. This array lists the potential duplicate point ids that are being send / received for the current neighboring block.
