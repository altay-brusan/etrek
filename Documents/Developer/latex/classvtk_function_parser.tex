\doxysubsection{Detailed Description}
Parse and evaluate a mathematical expression. 

\doxylink{classvtk_function_parser}{vtk\+Function\+Parser} is a class that takes in a mathematical expression as a char string, parses it, and evaluates it at the specified values of the variables in the input string.

You can use the "{}if"{} operator to create conditional expressions such as if ( test, trueresult, falseresult). These evaluate the boolean valued test expression and then evaluate either the trueresult or the falseresult expression to produce a final (scalar or vector valued) value. "{}test"{} may contain \texorpdfstring{$<$}{<},\texorpdfstring{$>$}{>},=,\texorpdfstring{$\vert$}{|},\&, and () and all three subexpressions can evaluate arbitrary function operators (ln, cos, +, if, etc)
