\doxysubsection{Detailed Description}
a process that can be launched by a \doxylink{classvtk_multi_process_controller}{vtk\+Multi\+Process\+Controller} 

\doxylink{classvtk_process}{vtk\+Process} is an abstract class representing a process that can be launched by a \doxylink{classvtk_multi_process_controller}{vtk\+Multi\+Process\+Controller}. Concrete classes just have to implement \doxylink{classvtk_process_a409f8c2b315ffb06174088153709020b}{Execute()} method and make sure it set the proper value in Return\+Value.
