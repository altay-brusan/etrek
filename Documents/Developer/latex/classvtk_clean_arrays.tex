\doxysubsection{Detailed Description}
filter used to remove partial arrays across processes. 

\doxylink{classvtk_clean_arrays}{vtk\+Clean\+Arrays} is a filter used to remove (or fill up) partial arrays in a \doxylink{classvtk_data_set}{vtk\+Data\+Set} (or a \doxylink{classvtk_composite_data_set}{vtk\+Composite\+Data\+Set}) across processes (and blocks). Empty dataset on any processes is skipped and doesn\textquotesingle{}t affect the array pruned (or filled) in the output. This filter also handles certain non-\/composite data objects such a tables.
