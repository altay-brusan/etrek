\doxysubsection{Detailed Description}
describes a 4x4 matrix transformation 

A \doxylink{classvtk_perspective_transform}{vtk\+Perspective\+Transform} can be used to describe the full range of homogeneous transformations. It was designed in particular to describe a camera-\/view of a scene. 

\doxylink{requirements_The}{The} order in which you set up the display coordinates (via \doxylink{classvtk_perspective_transform_ae9d12accf4e0d0f22835748e7ba6598d}{Adjust\+ZBuffer()} and \doxylink{classvtk_perspective_transform_aa194dbd61adb47346d6ea4be5a437c52}{Adjust\+Viewport()}), the projection (via \doxylink{classvtk_perspective_transform_a008d9581e44a1eba7cb4c1372c4f56ce}{Perspective()}, \doxylink{classvtk_perspective_transform_a470bc814f0babb4b8a4e8518f756b1e9}{Frustum()}, or \doxylink{classvtk_perspective_transform_a6737cca34ecda7c69e1d4f6cf1d31b34}{Ortho()}) and the camera view (via \doxylink{classvtk_perspective_transform_ac4635f9615090e4f7b77efcf237e8636}{Setup\+Camera()}) are important. If the transform is in Pre\+Multiply mode, which is the default, set the Viewport and ZBuffer first, then the projection, and finally the camera view. Once the view is set up, the Translate and Rotate methods can be used to move the camera around in world coordinates. If the Oblique() or \doxylink{classvtk_perspective_transform_a66a490460ac48b589c6921a93ecefc99}{Stereo()} methods are used, they should be called just before \doxylink{classvtk_perspective_transform_ac4635f9615090e4f7b77efcf237e8636}{Setup\+Camera()}. 

In Post\+Multiply mode, you must perform all transformations in the opposite order. This is necessary, for example, if you already have a perspective transformation set up but must adjust the viewport. Another example is if you have a view transformation, and wish to perform translations and rotations in the camera\textquotesingle{}s coordinate system rather than in world coordinates. 

\doxylink{requirements_The}{The} Set\+Input and Concatenate methods can be used to create a transformation pipeline with \doxylink{classvtk_perspective_transform}{vtk\+Perspective\+Transform}.
