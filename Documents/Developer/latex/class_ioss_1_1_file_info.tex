\doxysubsection{Detailed Description}
Return information about the specified file. 

\begin{DoxyAuthor}{Author}
Greg Sjaardema 
\end{DoxyAuthor}
A very minimal class (at least it used to be) for providing information about a file. \doxylink{class_ioss_1_1_file_info}{File\+Info} provides information about a file\textquotesingle{}s name, path, and type (directory, symbolic link, file). Other information could be added as needed. It currently does not cache any information, so if it is heavily used, a caching capability should be added. See the Qt Toolkit QFile\+Info class for a richer file class.
