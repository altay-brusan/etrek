\doxysubsection{Detailed Description}
concrete dataset representing a path defined by Bezier curves. 

\doxylink{classvtk_path}{vtk\+Path} provides a container for paths composed of line segments, 2nd-\/order (quadratic) and 3rd-\/order (cubic) Bezier curves.

\item MOVE\+\_\+\+TO:\+ Point defining the origin of a new segment, not connected to the previous point.
\item LINE\+\_\+\+TO:\+ Draw a line from the previous point to the current one
\item CONIC\+\_\+\+CURVE:\+ 2nd order (conic/\+quadratic) point. Must appear in sets of 2, e.\+g. (0,0) MOVE\+\_\+\+TO (0,1) CONIC\+\_\+\+CURVE (1,2) CONIC\+\_\+\+CURVE defines a quadratic Bezier curve that passes through (0,0) and (1,2) using (0,1) as a control (off) point.
\item CUBIC\+\_\+\+CURVE:\+ 3rd order (cubic) control point. Must appear in sets of 3, e.\+g.
