\doxysubsection{Detailed Description}
2D Transfer function container for label map mask gradient opacity. 

Manages the texture fetched by the fragment shader when Transfer\+Function2D mode is active. \doxylink{classvtk_open_g_l_volume_lookup_table_ae9c4b1e1c172ce587adeeaf4e1f627de}{Update()} assumes the \doxylink{classvtk_image_data}{vtk\+Image\+Data} instance used as source is of type VTK\+\_\+\+FLOAT and has 1 component (\doxylink{classvtk_volume_property}{vtk\+Volume\+Property} ensures this is the case when the function is set).
