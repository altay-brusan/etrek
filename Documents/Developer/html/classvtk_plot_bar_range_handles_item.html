Detailed Description

show and control the range of a vtkAxis used with a vtkPlotBar

This class is a vtkPlotRangeHandlesItem specialization working in coordination with a vtkPlotBar. It ensures that handles are sticking to the plot bars when being dragged. Vertical and horizontal bars are both supported but the handles orientation must match the vtkPlotBar orientation.
