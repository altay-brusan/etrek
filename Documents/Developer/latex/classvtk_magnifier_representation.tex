\doxysubsection{Detailed Description}
represent a \doxylink{classvtk_border_widget}{vtk\+Border\+Widget} 

This class is used to represent and render a \doxylink{classvtk_magnifier_widget}{vtk\+Magnifier\+Widget}. To use this class, you need to specify a renderer in which to place the magnifier, and a magnification factor. Optionally, you can specify the size of the magnifier window, whether it has a border, and the particular actors to render.
