\doxysubsection{Detailed Description}
{\ttfamily \doxylink{classvtk_resource_stream}{vtk\+Resource\+Stream}} implementation for memory input. 

{\ttfamily \doxylink{classvtk_memory_resource_stream}{vtk\+Memory\+Resource\+Stream}} can be a view on existing data. Or it can copy specified data into an internal buffer. Or it can take ownership of a {\ttfamily \doxylink{classvtk_buffer}{vtk\+Buffer}}, a {\ttfamily std::\+vector} or a {\ttfamily std::\+string}.

bool vtk\+Memory\+Resource\+Stream::\+\+End\+Of\+Stream (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [override]}, {\ttfamily [virtual]}}



Check if the stream reached an end. 

\doxylink{requirements_The}{The} stream may be out of range (EOF) if a Seek call move before stream begin (0), or after stream end (max) Seek on an End\+Of\+Stream stream may restore it back to a valid state. Read on an invalid stream must do nothing and return 0.

\begin{DoxyReturn}{Returns}
Return true if the stream reached the end of input, false otherwise. 
\end{DoxyReturn}

Set buffer to stream. 

If {\ttfamily copy} is {\ttfamily false}, the source buffer must stay valid as it may be used.

Otherwise, if {\ttfamily copy} is {\ttfamily true}, given buffer will be copied into an internally managed buffer. If {\ttfamily size} is 0, this call won\textquotesingle{}t allocate anything. If {\ttfamily size \texorpdfstring{$>$}{>} 0}, {\ttfamily buffer} must not be {\ttfamily nullptr} and must point to a contiguous buffer of at least {\ttfamily size} bytes.

Regardless of {\ttfamily copy} value, this function also has the following effects:\+
\begin{DoxyItemize}
\item Reset stream position to {\ttfamily 0}.
\item End\+Of\+Stream will return {\ttfamily true} if {\ttfamily size} is {\ttfamily 0}, {\ttfamily false} otherwise.
\item Release currently owned buffer, if any.
\item Increase modified time.
\end{DoxyItemize}
