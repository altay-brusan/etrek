\doxysubsection{Detailed Description}
generate scalars or field data from point and cell ids 

\doxylink{classvtk_id_filter}{vtk\+Id\+Filter} is a filter to that generates scalars or field data using cell and point ids. That is, the point attribute data scalars or field data are generated from the point ids, and the cell attribute data scalars or field data are generated from the cell ids.

Typically this filter is used with \doxylink{classvtk_labeled_data_mapper}{vtk\+Labeled\+Data\+Mapper} (and possibly \doxylink{classvtk_select_visible_points}{vtk\+Select\+Visible\+Points}) to create labels for points and cells, or labels for the point or cell data scalar values.
