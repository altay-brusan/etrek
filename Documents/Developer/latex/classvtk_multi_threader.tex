\doxysubsection{Detailed Description}
A class for performing multithreaded execution. 

vtk\+Multithreader is a class that provides support for multithreaded execution using pthreads on POSIX systems, or Win32 threads on Windows. This class can be used to execute a single method on multiple threads, or to specify a method per thread.
