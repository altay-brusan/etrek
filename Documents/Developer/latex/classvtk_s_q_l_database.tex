\doxysubsection{Detailed Description}
maintain a connection to an sql database 

Abstract base class for all SQL database connection classes. Manages a connection to the database, and is responsible for creating instances of the associated \doxylink{classvtk_s_q_l_query}{vtk\+SQLQuery} objects associated with this class in order to perform execute queries on the database. To allow connections to a new type of database, create both a subclass of this class and \doxylink{classvtk_s_q_l_query}{vtk\+SQLQuery}, and implement the required functions:\+

\doxylink{classvtk_s_q_l_database_a1ad93ce2f8e955dee1b7fbefa29bc601}{Open()} -\/ open the database connection, if possible. \doxylink{classvtk_s_q_l_database_aca2514f61379a34c483b8495fc587d38}{Close()} -\/ close the connection. \doxylink{classvtk_s_q_l_database_a4f8604db5db64207d5d1d6b9b05a2950}{Get\+Query\+Instance()} -\/ create and return an instance of the \doxylink{classvtk_s_q_l_query}{vtk\+SQLQuery} subclass associated with the database type.

\doxylink{requirements_The}{The} subclass should also provide API to set connection parameters.

This class also provides the function Effect\+Schema to transform a database schema into a SQL database.
