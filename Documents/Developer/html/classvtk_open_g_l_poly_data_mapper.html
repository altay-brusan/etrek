vtkOpenGLPolyDataMapper::vtkGetMacro ( UseProgramPointSize ,

Allow the shader code to set the point size (with gl_PointSize variable) instead of using the one defined by the property. Note that this flag is not available on OpenGLES as the feature is enabled by default. With OpenGL, the feature is turned off by default. Warning: on MacOS, enabling the feature result in non point drawing if the shaders do not set the point size.
