\doxylink{classvtk_data_set_attributes_field_list}{vtk\+Data\+Set\+Attributes\+Field\+List}, also called vtk\+Data\+Set\+Attributes::\+\+Field\+List, is used to help with filters when dealing with arrays from multiple \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} instances, potentially from multiple inputs.

Consider a filter that appends multiple inputs, e.\+g. \doxylink{classvtk_append_poly_data}{vtk\+Append\+Poly\+Data}. Besides appending mesh elements, such a filter also needs to combine field arrays (point, and cell data) from inputs to pass on to the output. Now if all the inputs had exactly the same set of arrays, we\textquotesingle{}re all set. However, more often than not, the inputs will have different sets of arrays. \doxylink{requirements_The}{The} filter will need to match up from various inputs to combine together, potentially dropping arrays not in all inputs. Furthermore, it needs to ensure arrays in the output are flagged as attributes consistently. \item call {\ttfamily Intersect\+Field\+List} or {\ttfamily Union\+Field\+List} for all input \doxylink{classvtk_data_set_attributes}{vtk\+Data\+Set\+Attributes} instances,
