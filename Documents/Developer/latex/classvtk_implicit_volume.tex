\doxysubsection{Detailed Description}
treat a volume as if it were an implicit function 

\doxylink{classvtk_implicit_volume}{vtk\+Implicit\+Volume} treats a volume (e.\+g., structured point dataset) as if it were an implicit function. This means it computes a function value and gradient. \doxylink{classvtk_implicit_volume}{vtk\+Implicit\+Volume} is a concrete implementation of \doxylink{classvtk_implicit_function}{vtk\+Implicit\+Function}.

\doxylink{classvtk_implicit_data_set}{vtk\+Implicit\+Data\+Set} computes the function (at the point x) by performing cell interpolation. That is, it finds the cell containing x, and then uses the cell\textquotesingle{}s interpolation functions to compute an interpolated scalar value at x. (A similar approach is used to find the gradient, if requested.) Points outside of the dataset are assigned the value of the ivar Out\+Value, and the gradient value Out\+Gradient.

\begin{DoxyWarning}{Warning}
\doxylink{requirements_The}{The} input volume data is only updated when \doxylink{classvtk_implicit_volume_a65d7267af7eb69c0037f294f06e42bc3}{Get\+MTime()} is called. Works for 3D structured points datasets, 0D-\/2D datasets won\textquotesingle{}t work properly.
\end{DoxyWarning}
