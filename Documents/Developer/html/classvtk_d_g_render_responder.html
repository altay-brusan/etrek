Detailed Description

Rendering simple DG cells (i.e., those with a fixed reference shape).

This currently handles hexahedra, tetrahedra, quadrilaterals, and triangles.

Member Enumeration Documentation

◆ ScalarVisualizationOverrideType

enum class vtkDGRenderResponder::ScalarVisualizationOverrideType : int
strong

These properties are useful to debug/show-off/understand the parameter space and basis functions. The cell faces are shaded by colors that map to either of these quantities. All function values are normalized to [0, 1] before being mapped through the scalar's color map.
