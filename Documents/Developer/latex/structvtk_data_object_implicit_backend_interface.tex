\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type$>$\newline
struct vtk\+Data\+Object\+Implicit\+Backend\+Interface$<$ Value\+Type $>$}
A utility structure that can be used as a base for implicit array backend that relies on a \doxylink{classvtk_data_object}{vtk\+Data\+Object}. 

Some backend need to use the \doxylink{classvtk_data_object}{vtk\+Data\+Object} itself to compute the array value. This leads to a circular dependency, as the array is itself contained inside the \doxylink{classvtk_data_object}{vtk\+Data\+Object}. To break this dependency and to avoid issues with memory management, those backends may inherits from this \doxylink{structvtk_data_object_implicit_backend_interface}{vtk\+Data\+Object\+Implicit\+Backend\+Interface}.

\doxylink{structvtk_data_object_implicit_backend_interface}{vtk\+Data\+Object\+Implicit\+Backend\+Interface} observes the Delete\+Event of the \doxylink{classvtk_data_object}{vtk\+Data\+Object}. When raised, the backend instantiates the whole array in memory before the actual dataobject deletion.

\doxylink{requirements_The}{The} constructor requires an Array\+Name and its Association in order to retrieve the whole array to initialize the cache.\hypertarget{structvtk_data_object_implicit_backend_interface_autotoc_md795}{}\doxysubsection{\texorpdfstring{Inheritance}{Inheritance}}\label{structvtk_data_object_implicit_backend_interface_autotoc_md795}
When inheriting from \doxylink{structvtk_data_object_implicit_backend_interface}{vtk\+Data\+Object\+Implicit\+Backend\+Interface}, {\ttfamily operator()} should not be defined by the child class. Only {\ttfamily \doxylink{structvtk_data_object_implicit_backend_interface_af316668c69f4de6afd64e69bb5794178}{Get\+Value\+From\+Data\+Object()}} should be overridden to return the expected value.

Once the \doxylink{classvtk_data_object}{vtk\+Data\+Object} is deleted, the parent class handle the memory allocation and initialization. Then {\ttfamily operator()} uses the allocated memory instead of calling the custom \doxylink{structvtk_data_object_implicit_backend_interface_af316668c69f4de6afd64e69bb5794178}{Get\+Value\+From\+Data\+Object()}.
