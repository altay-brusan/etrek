abstract class specifies interface to map data 

\doxylink{classvtk_abstract_mapper}{vtk\+Abstract\+Mapper} is an abstract class to specify interface between data and graphics primitives or software rendering techniques. Subclasses of \doxylink{classvtk_abstract_mapper}{vtk\+Abstract\+Mapper} can be used for rendering 2D data, geometry, or volumetric data.
