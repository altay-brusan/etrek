Writes base64-\/encoded output to a stream. 

\doxylink{classvtk_base64_output_stream}{vtk\+Base64\+Output\+Stream} implements base64 encoding with the \doxylink{classvtk_output_stream}{vtk\+Output\+Stream} interface.
