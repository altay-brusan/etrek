Based on the search mask which was passed, this function determines all the records in the database which match the values of matching key attributes in the search mask. For each matching record, a \doxylink{class_dcm_dataset}{Dcm\+Dataset} structure is generated which will later be returned to the SCU as a result of query. \doxylink{requirements_The}{The} \doxylink{class_dcm_dataset}{Dcm\+Dataset} structures for all matching records will be stored in the protected member variable matching\+Datasets.
