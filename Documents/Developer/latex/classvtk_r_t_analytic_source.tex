\doxysubsection{Detailed Description}
Create an image for regression testing. 

\doxylink{classvtk_r_t_analytic_source}{vtk\+RTAnalytic\+Source} just produces images with pixel values determined by a Maximum\texorpdfstring{$\ast$}{*}\+Gaussian\texorpdfstring{$\ast$}{*}\+XMag\texorpdfstring{$\ast$}{*}sin(XFreq\texorpdfstring{$\ast$}{*}x)\texorpdfstring{$\ast$}{*}sin(YFreq\texorpdfstring{$\ast$}{*}y)\texorpdfstring{$\ast$}{*}cos(ZFreq\texorpdfstring{$\ast$}{*}z) Values are float scalars on point data with name "{}\+RTData"{}.
