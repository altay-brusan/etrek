\doxysubsection{Detailed Description}
Launch a process on the current machine and get its output. 

Launch a process on the current machine and get its standard output and standard error output. When {\ttfamily Execute\+In\+System\+Shell} is false, arguments needs to be added separately using the {\ttfamily \doxylink{classvtk_executable_runner_a160064472b8296e1859877dd644ae46f}{Add\+Argument}} /\+ {\ttfamily Clear\+Arguments} API, otherwise command may not work correctly. If one does not know how to parse the arguments of the command it want to execute then {\ttfamily Execute\+In\+System\+Shell} should be set to true.
