\doxysubsection{Detailed Description}
Portable directory/\+filename traversal. 

\doxylink{classvtksys_1_1_directory}{Directory} provides a portable way of finding the names of the files in a system directory.

\doxylink{classvtksys_1_1_directory}{Directory} currently works with Windows and Unix operating systems.
