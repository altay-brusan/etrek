Create an iterator for the given image, with several options. If a stencil is provided, then the iterator\textquotesingle{}s \doxylink{classvtk_image_point_data_iterator_ac1982d06e4e980f2dcbff55afec72d16}{Is\+In\+Stencil()} method reports whether each span is inside the stencil. If an extent is provided, it iterates over the extent and ignores the rest of the image (the provided extent must be within the image extent). If a pointer to the algorithm is provided and thread\+Id is set to zero, then progress events will provided for the algorithm.
