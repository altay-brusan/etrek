\doxysubsection{Detailed Description}
modify the time range/\+steps of temporal data 

\doxylink{classvtk_temporal_shift_scale}{vtk\+Temporal\+Shift\+Scale} modify the time range or time steps of the data without changing the data itself. \doxylink{requirements_The}{The} data is not resampled by this filter, only the information accompanying the data is modified.

If Periodic is true, requests for time will be wrapped around so that the source appears to be a periodic time source. If data exists for times \{0,N-\/1\}, setting periodic to true will cause time 0 to be produced when time N, 2N, 2N etc is requested. This effectively gives the source the ability to generate time data indefinitely in a loop.
