\doxysubsection{Detailed Description}
Helper to manage Qt context and other Open\+GL components. 

\doxylink{class_q_v_t_k_render_window_adapter}{QVTKRender\+Window\+Adapter} is an internal class that is used by \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget} and \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} to manage the rendering using \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window} within a Open\+GL context created via Qt.

\doxylink{class_q_v_t_k_render_window_adapter}{QVTKRender\+Window\+Adapter} is expected to be recreated anytime the context changes. In the constructor, \doxylink{class_q_v_t_k_render_window_adapter}{QVTKRender\+Window\+Adapter} will mark the \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window} ready for rendering and call Open\+GL context initialization API (vtk\+Open\+GLRender\+Window::\+\+Open\+GLInit\+Context).

By observing events on \doxylink{classvtk_generic_open_g_l_render_window}{vtk\+Generic\+Open\+GLRender\+Window}, \doxylink{class_q_v_t_k_render_window_adapter}{QVTKRender\+Window\+Adapter} can then support rendering to an internally created FBO via VTK\textquotesingle{}s rendering calls. Making sure that the rendering results are shown on the screen is handled by \doxylink{class_q_v_t_k_open_g_l_window}{QVTKOpen\+GLWindow} or \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget}.

Returns a QSurface\+Format suitable for surfaces that intend to be used for VTK rendering.

If your applications plans on using {\ttfamily \doxylink{class_q_v_t_k_open_g_l_native_widget}{QVTKOpen\+GLNative\+Widget}}, then this format (or similar) must be set as the default format on QSurface\+Format before any widgets are created.

Note this returns a QSurface\+Format required to support the Open\+GL rendering capabilities in a \doxylink{classvtk_render_window}{vtk\+Render\+Window}. Whether those features, e.\+g. multi sampling, is actually used for rendering is determined by values specified on the \doxylink{classvtk_render_window}{vtk\+Render\+Window} instance itself through appropriate API.

Passing {\ttfamily stereo\+\_\+capable=true} is same as calling {\ttfamily QSurface\+Format::\+set\+Stereo(true)}. This is necessary if you want to use quad-\/buffer based stereo in your application.
