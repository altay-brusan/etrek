\doxysubsection{Detailed Description}
Contains chemical data from the Blue Obelisk Data Repository. 

\doxylink{requirements_The}{The} Blue Obelisk Data Repository is a free, open repository of chemical information. This class is a container for this information.

\begin{DoxyNote}{Note}
This class contains only the raw arrays parsed from the BODR. For more convenient access to this data, use the \doxylink{classvtk_periodic_table}{vtk\+Periodic\+Table} class.

If you must use this class directly, consider using the static \doxylink{classvtk_blue_obelisk_data}{vtk\+Blue\+Obelisk\+Data} object accessible through vtk\+Periodic\+Table::\+\+Get\+Blue\+Obelisk\+Data(). This object is automatically populated on the first instantiation of \doxylink{classvtk_periodic_table}{vtk\+Periodic\+Table}. 
\end{DoxyNote}
