\doxysubsection{Detailed Description}
copy oriented and scaled glyph geometry to every input point (2D specialization) 

This subclass of \doxylink{classvtk_glyph3_d}{vtk\+Glyph3D} is a specialization to 2D. Transformations (i.\+e., translation, scaling, and rotation) are constrained to the plane. For example, rotations due to a vector are computed from the x-\/y coordinates of the vector only, and are assumed to occur around the z-\/axis. (See \doxylink{classvtk_glyph3_d}{vtk\+Glyph3D} for documentation on the interface to this class.)

Frequently this class is used in combination with vtk\+Glyph\+Source. \doxylink{classvtk_glyph_source2_d}{vtk\+Glyph\+Source2D} can produce a family of 2D glyphs.
